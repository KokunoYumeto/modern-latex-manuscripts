# The Island Atlas — how the interlingual lanes map together
2026-07-04, Fable 5 global synthesis. Sources: codex backup logs (through 2026-07-03 checkpoints), coordination index (updated 2026-06-30), noether-pc branch through package 160, session memory of the non-codex lanes.

## 1. The one-picture summary

This is not a set of separate translation projects. It is **one production system**: a hub of source-witnessed mathematical corpora (Noether primary; SGA, Weber, Cayley adjacent), a shared concept skeleton (the 60-term spine: ring, field, module, ideal, Noetherian, …), and one explicit selection objective (the access-gain ledger), instantiated per language family at different maturity rungs. Every island runs the same ladder:

**source shelf → term spine → proof grammar → script sidecar → review packet → pilot gate**

What differs between islands is only (a) which rung they stand on and (b) which *build type* the family got: zonal bridge, controlled register, script bridge, or local standards. Nobody inside a lane sees this; it is only visible across the logs.

## 3. The shared spine (the method invariants every island obeys)

1. **Source witness first** — no term exists without a native attestation or an explicit gap row.
2. **Concept segmentation** — the 60-term spine (T01 ring … T60), same concept IDs across lanes; per-lane instantiations: Pan-Romance spine + hit table, controlled-Arabic spine, Arabic/Farsi/Persianate ledger, Malay-Indonesian spine+proof-grammar, Interslavic term families (implicit, pre-spine).
3. **Selection by the access-gain ledger** (formalized 2026-06-29, retrofitted to active lanes):
   `access_gain_score = main_register_retention + marginal_inter_intelligibility_gain + cross_standard_recognition + source_strength + script_access − dominance_penalty − main_group_exclusion_penalty − opacity_penalty − ambiguity_penalty` — used as a ledger, not pseudo-precision.
4. **Controlled proof grammar** — definitions/theorem/proof-transition templates per register (CNL lineage: Kuhn survey, Attempto/ForTheL comparators; Lean is the formal endpoint of the same axis).
5. **Script sidecars are deterministic build artifacts** — transliteration tables + validators + visual inspection; never silent divergent translations (Interslavic Latin↔Cyrillic is the template; Hindustani and Turkic are the hard cases).
6. **Term promotion only under corpus pressure + review rights** — every choice logged with reason class (native/pan-family, international, borrowed, coined, script-stability) and status (solid-for-pilot / needs-reviewer-check); revision trail is declared part of the research value.
7. **Non-erasure + authority separation** — every artifact forkable, correctable, rejectable; local mechanical validation ≠ language authority; comparators (Esperanto, Interlingua…) are evidence floors, never authority.
8. **Method bibliography** (2026-07-03 shelf): intercomprehension/receptive multilingualism (Council of Europe, lingua receptiva), controlled natural languages, terminology governance (UNESCO/Infoterm, COTSOES), language-of-instruction access research (World Bank), language ecology caution (Bird). **Disjoint from the theory stack's NLP bibliography — see §5.**

## 4. Cross-island findings (things no single lane can see)

**F1. The binding constraint is source availability, not method and not family relatedness.** Malay-Indonesian (young lane) overtook Pan-Turkic (early priority) because native math sources are dense in one and scarce in the other. Pan-Turkic is blocked at exact hard rows; R5/R8/R9 are parked at source-locator rung. Consequence for the siting model: `source_strength` is not one axis among nine — in practice it is the gating axis; predicted intelligibility gain is unusable without a source shelf. Any siting table must be lexicographic: source floor first, then the access-gain terms.

**F2. The typology's real discriminating variable is standard+script unity, not genetic closeness.** CJK and Arabic — both huge, both internally "related" — were deliberately NOT bridged: existing written standards do the work, so they got controlled registers/local standards. Slavic and Romance got bridges because the family is split across many standards with high mutual recognizability. Hindustani got a script bridge because the split IS the script. This is an empirical regularity of the archipelago, stateable as a decision rule: *bridge where standards are many and recognizability is high; control where one standard rules; script-bridge where writing systems split one register; local standards where neither holds.*

**F3. One objective function, discovered mid-program.** The access-gain ledger was formalized 2026-06-29 and explicitly integrated into Pan-Romance and later lanes. The Slavic lane predates it and implements it *implicitly* (its Standing Principles map term-for-term: "prefer broad Slavic intelligibility" = marginal_inter_intelligibility_gain; "avoid rough Russian/Polish/Serbian" = dominance_penalty; "keep internationalisms when they reduce ambiguity" = ambiguity_penalty; "motivate every term" = source_strength). **Cheapest high-value harmonization: retrofit the Interslavic term ledger into access-gain fields** — it turns the proven lane into the calibration dataset for the objective.

**F4. The union term spine is the archipelago's missing keystone artifact.** Each lane holds its own spine file; no artifact holds the concept × family matrix (T01–T60 × {Slavic, Romance, Turkic, Arabic, Persianate, Hindustani, Malay-Indonesian, …} with chosen form, reason class, attestation counts, status). Building `UNION_TERM_SPINE` is mechanical (the JSONs exist) and yields: cross-family reason-class statistics (where do families force coinage vs internationalism?), systematic false-friend enumeration per family (FormSim×SemDist over spine rows), and the empirical input for every research question in the theory stack.

**F5. The entire archipelago is upstream of external validation.** Accepted review returns = 0 in every lane. The system is honest about this (review-ready ≠ reviewed, gates everywhere), but it means every intelligibility claim is currently editorial. The theory stack's human-testing hypotheses (H1/H2/H7) are exactly the missing validation layer — the two stacks *need* each other: practice has artifacts without measurements; theory has measurements without artifacts.

**F6. The dominance failure mode recurs at every level — and the theory stack has its formal twin.** Bridge collapsing into softened Spanish (Pan-Romance guardrail), rough Russian (Interslavic principle), Indonesian-only (Malay-Indonesian penalty), Greco-Latin "internationalisms" mistaken for global (candidate matrix), and — on the machine side — multilingual models pivoting through English-shaped latent space (latent-pivot audit in the theory docs). Same phenomenon, five instances, two substrates. This is the strongest single "harmonization" observation and a genuine paper-grade point: *centroid estimators degrade toward the dominant member unless explicitly regularized, whether the estimator is a committee, a corpus procedure, or a neural network.*

**F7. French is the interlock node.** SGA5/6 source-fidelity work (my lane), the Noether French translation lane (R1), and Romance Tier-0 witnessing (bridge evidence) all draw on the same French mathematical register. Register evidence flows between them for free — worth making explicit in the corpus map so the lanes cite each other's witnesses instead of re-collecting.

**F8. The proof-grammar axis ends in Lean.** Controlled register → controlled proof grammar → machine-checkable formal language is one continuum. The Lean audit lane is not a separate hobby: it is the calibration endpoint for what "controlled proof grammar" means, and a future register can cite it as the fully-explicit limit case.

## 5. The three-way correspondence (theory ↔ ledger ↔ lane practice)

| Theory formalization (ChatGPT doc §4, H1–H8) | Access-gain ledger field | Lane practice instance |
| --- | --- | --- |
| Recognizability + mean ILO(B, Lᵢ) | marginal_inter_intelligibility_gain + cross_standard_recognition | passive-recognizability selection; spine attestation counts (ES 60/60 … RM 30/60) |
| Regularized barycenter argmin Σ wᵢD(B,Lᵢ)² + λR(B) | dominance_penalty + main_group_exclusion_penalty | "not Spanish in softened spelling"; Interslavic voting machine; "avoid rough Russian" |
| FFRisk = FormSim × SemDist | ambiguity_penalty | Interslavic false-friend lists; term-split overlap sidecars (Indic/Dravidian) |
| HumanCost / learnability | opacity_penalty | "needs reviewer check" statuses; ZPD/comprehensible-input heuristic (theory side) |
| evidence weighting (absent in theory!) | **source_strength** | source witnesses, gap rows, hard-row blocks (Pan-Turkic) |
| siting precondition (absent in theory!) | **lingua_franca_gap** | "don't build where a standard works" (Arabic, CJK) |
| orthographic layer outside semantics | script_access | deterministic script sidecars + validators |
| latent-pivot (English-bias) audit | dominance_penalty, machine substrate | F6 above — same failure mode, neural instance |

Two-way traffic: theory gains `source_strength` and `lingua_franca_gap` (measurement realism the NLP formalization lacks); practice gains measurable versions of its editorial terms (ILO for recognizability, FormSim×SemDist for ambiguity, barycenter distance for dominance) — computable later on the project's own parallel corpora.
