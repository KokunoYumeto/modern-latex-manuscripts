# Lessons from the Noether P2 / P4 S6-S7 release

## What worked

- Treating target renders and source-derived rasters as different rights classes preserved useful QA while avoiding invented redistribution permission.
- A machine-readable visual index made non-public images durable evidence: parent scan hash, page, crop geometry, dimensions, DPI, rotation, linked structural unit, review output, and disposition survived even when pixels did not.
- Rebuilding both German and English targets independently separated textual parity from visual parity. Byte-identical extracted text and pixel-identical focal renders closed two different failure modes.
- Current-surface pruning was limited to explicit superseded German/status/checksum objects; substantive historical evidence remained in Zenodo version history.

## What failed or required care

- Raw producer archives were unsuitable public payloads because source pixels and reconstructable host paths were mixed with useful evidence.
- A literal internal workflow label survived in one otherwise public-ready English control file. The public projection changed only that wording and recorded the delta instead of mutating the frozen producer package.
- The inherited German build emits font/input warnings. Reporting a generic clean build would have overstated the evidence; the release distinguishes zero fatal/undefined/box failures from retained inherited warnings.
- Paper 2's pp.58-92 closure does not close pp.23-57. Scope must be stated as a bounded closure, not paper completion.

## Method change

Every visual-heavy release should now produce one canonical visual index before publication. Every row must carry a rights disposition. `open_payload` requires project-generated or cleared pixels; unresolved source images use `manifest_only_rights_blocked`. A source image set is never silently omitted merely because its binaries cannot be public.

Release state is also split explicitly: local freeze, archive custody, archive review, Zenodo publication, public readback, GitHub mirror, rights clearance, and human certification are distinct events. The append-only archive log records each consequential transition.
