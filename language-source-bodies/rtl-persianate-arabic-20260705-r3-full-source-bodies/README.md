# Session 06 RTL Persianate Arabic Source Bodies

This package collects literal local source bodies and source-adjacent archives/PDFs/text bodies for Arabic, Persian/Farsi, Dari, Tajik, Uyghur/Turkic RTL-adjacent, and modern Turkish adjacent material found in existing Noether caches.

Boundaries:

- 
ative-source-bodies/ contains copied source files, PDFs, HTML pages, TeX files, source archives, MediaWiki wikitext, and raw text source bodies.
- ocr-witnesses/ contains OCR, pdftotext, fulltext, string, or first-page extraction witnesses. These are not treated as native source bodies.
- generated-drafts/ intentionally contains no generated translation output.
- Urdu and Ottoman Arabic-script material are represented as explicit gap rows because no local literal source body was found in the candidate roots during this pass.

Negative claims preserved:

- Arabic evidence does not cover Persian/Farsi, Dari, Tajik, Urdu, Ottoman, or Turkic evidence.
- Persian/Farsi evidence does not cover Arabic, Dari, Tajik, Urdu, Ottoman, or Turkic evidence.
- Dari, Tajik, Urdu/Hindustani, Uyghur, Ottoman, and Pan-Turkic gates remain separate.
- This package does not claim native review, accepted terminology, license clearance, gate promotion, translation completion, lane completion, or Git publication.
