Arabic

This topic contains packages with documentation in and support for typesetting Arabic.

amiri
A classical Arabic typeface, Naskh style.
arabi
(La)TeX support for Arabic and Farsi, compliant with Babel.
arabi-add
Using hyperref and bookmark packages with arabic and farsi languages.
arabic-book
An Arabic book class.
arabluatex
ArabTeX for LuaLaTeX.
arabtex
Macros and fonts for typesetting Arabic.
arabxetex
An ArabTeX-like interface for XeLaTeX.
dad
Simple typesetting system for mixed Arabic/Latin documents.
fariscovernew
Create elegant Arabic and English title (cover) pages.
hvarabic
Macros for RTL typesetting.
na-border
Decorative borders for texts in Arabic and French.
na-cover
Custom artistic covers and borders for educational documents and magazines.
na-fancyborders
Artistic TikZ page borders for educational documents and exams.
na-pageborder
A package for adding professional decorative frames with Arabic language support.
na-position
Tables of relative positions of curves and asymptotes or tangents in Arabic documents.
na-urmborder
A package for professional geometric page borders for mathematical documents using umranda and umrandb fonts.
quran
An easy way to typeset any part of The Holy Quran.
sexam
Package for typesetting arabic exam scripts.
texnegar
Kashida justification in XeLaTeX and LuaLaTeX.
