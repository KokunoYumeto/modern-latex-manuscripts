## Ethics And Authority Requirements

Signed-language source work requires separate gates for source route, sign authority, media permission, reviewer competence, variant/context handling, captions/transcripts, screenshots/stills, and package reuse. A live URL, local HTML/JSON hash, API response summary, video pointer, English gloss, category count, or SWU-present flag does not satisfy those gates.

Required next gates before any movement:

1. Named ASL/DGS qualified reviewer or source-owner route.
2. Dated decision on link/embed/copy/screenshot/still/caption/transcript permissions.
3. Variant/context split before any entry-level sign row can be proposed.
4. File-level source/media capture policy if any future body, video, thumbnail, caption, transcript, or derived still is considered.
5. B3 package-boundary review before any raw source, media, or repository/source-archive payload appears outside `work`.
