This package collects literal local source bodies and provenance sidecars for the R6 Indigenous, creole/contact, and sign/access lanes already touched by the project.

Contents:

- `source-bodies/`: copied local PDF/HTML/text source bodies, source-route captures, sign/access route metadata, addendum body captures, and probe metadata.
