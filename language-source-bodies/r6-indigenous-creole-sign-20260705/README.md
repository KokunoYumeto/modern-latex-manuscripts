Directory separation:

- `source-bodies/`: copied local PDF/HTML/text source bodies, source-route captures, sign/access route metadata, addendum body captures, and probe metadata.
- `native-community-evidence/`: index of packaged native/community source evidence. This is not community consent or source authority.
- `ocr-witnesses/`: OCR/extracted text witnesses separated from source bodies; not source truth.
- `generated-draft/`: draft/non-canonical covered-row support for Kreyol and Bislama only.
- `pointer-only-material/`: source-acquisition, gap, source-archive, guardrail, and pointer rows; not a corpus by itself.
- `lexicon-bodies/`: lexicon/source-route/sign-access tables where locally available; no accepted terms or accepted signs.
- `reviewer-authority-evidence/`: reviewer/source-owner route and ethics evidence; no filled approval return.
- `blocker-ethics/`: blocker/ethics rows and TeX/source-archive absence status.
- `github-directives/`: local copies of GitHub directives read for pursued-goal reset provenance.
- `logbook-manifests/`: copied R6 logbook, source-canon ledgers, addendum summaries/tables, gate and checksum sidecars used to trace provenance.
