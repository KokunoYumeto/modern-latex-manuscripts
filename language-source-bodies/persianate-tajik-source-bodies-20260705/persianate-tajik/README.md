## Scope

This package collects literal source bodies and source-like files for the Session 06 Persianate/Tajik sublane:

- `fa_IR/` Persian/Farsi (Iran)
- `prs_AF/` Dari/Persian (Afghanistan)
- `tg_Cyrl_TJ/` Tajik Cyrillic
- `ur/` Urdu
- `_provenance/` copied lane evidence sidecars used to explain provenance, row status, and language boundaries

Each language bucket is separate. Persian/Farsi evidence does not authorize Dari, Tajik, or Urdu. Dari evidence does not authorize Persian/Farsi, Tajik, or Urdu. Tajik evidence remains source-discovery/non-row unless a separate review/promotion record exists. Urdu evidence is collected as Urdu evidence only.
