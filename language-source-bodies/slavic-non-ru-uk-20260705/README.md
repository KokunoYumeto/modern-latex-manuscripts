# Slavic Non-RU/UK Source Bodies

This package collects literal source bodies and source-body provenance for non-Russian, non-Ukrainian Slavic language rows touched by the Noether interlanguage work.

Boundary: source-body package and generated draft support only. No native review, accepted terminology, license clearance, gate promotion, or translation completion is claimed.

## Contents

- `source-bodies/`: copied local source PDFs, TeX-family files, HTML/text/cache bodies, and source-package build/dependency files by language.
- `source-archives/`: copied or downloaded source archives, including open-license GitHub repository archives for TeX payload rows where available.
- `source-manifests/`: copied arXiv/GitHub harvester manifests and gap reports.
- `generated-draft/`: separate draft/non-canonical support for source-canon-sufficient rows.
- `GAP_ROWS.csv`: uncovered rows that remain source-acquisition gaps.
- `MANIFEST.csv`: package manifest with hashes, provenance, license/access signals, and boundaries.
- `SHA256SUMS.txt`: checksums for package files.
- `LOGBOOK_EXCERPT.md`: excerpt from the lane run log.
