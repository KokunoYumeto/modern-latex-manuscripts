Определение. Нека K е непразно множество, в което са дефинирани
следните две операции:
• На всеки два елемента a, b ∈ K се съпоставя елемент a + b ∈ K,
който се нарича сума на a и b.
• На всеки два елемента a, b ∈ K се съпоставя елемент a.b ∈ K,
който се нарича произведение на a и b.
Kaзваме, че относно тези операции K е пръстен, ако са изпълнени
следните условия:
1. (a + b) + c = a + (b + c) — асоциативност на събирането;
2. a + b = b + a — комутативност на събирането;
3. съществува нулев елемент 0 ∈ K такъв, че a + 0 = a, за всяко
a ∈ K;
4. За всяко a ∈ K съществува противоположен елемент −a ∈ K
такъв, че a + (−a) = 0;
5. (a.b).c = a.(b.c) — асоциативност на умножението;
6. (a + b).c = a.c + b.c — дясна дистрибутивност на умножението;
7. a.(b + c) = a.b + a.c — лява дистрибутивност на умножението.
Пример 1. Нулев пръстен. Това е пръстен, който се състои от един
единствен нулев елемент.

Определение. Нека K е пръстен и K 0 е подмножество на K, K 0 6= ∅.
Казваме, че K 0 е подпръстен на K, ако са изпълнени следните условия:
(1) Ако a, b ∈ K 0 , то a + b ∈ K 0 ;
(2) Ако a ∈ K 0 , то −a ∈ K 0 .
(3) Ако a, b ∈ K 0 , то a.b ∈ K 0 .
Пример 1. 0 и K са подпръстени, които се наричат несобствени подпръстени.
Пример 2. C ⊃ R ⊃ Q ⊃ Z ⊃ 2Z. В тази верига всеки пръстен е
подпръстен на предходните
Пример 3. В пръстена на квадратните матрици от n-ти ред, диагоналните и скаларните матрици образуват подпръстени.
Пример 4. В пръстена на функциите с обща дефиниционна област,
непрекъснатите функции образуват подпръстен. Функциите, които имат
първа производна също образуват подпръстен.
Условиeто (1) в определението на подпръстен всъщност означава, че
подпръстенът наследява операциите на пръстена.
Твърдение. Относно наследените операции, подпръстена също е пръстен.
Доказателство:
Трябва да се проверят седемте аксиоми за пръстен. Верността на
всички аксиоми е очевидна с изключение на третата и четвъртата аксиома. Поради това ще проверим верността на тези две аксиоми. От K 0 6= ∅
следва, че съществува a ∈ K 0 . Съгласно (2) имаме −a ∈ K 0 . От (1) получаваме a + (−a) ∈ K 0 и 0 ∈ K 0 . Следователно K 0 има нулев елемент,
т. е. третата аксиома е изпълнена. Четвъртата е изпълнена съгласно условието (2) за подпръстен.
