Upper Sorbian spelling dictionary
=================================

Upper Sorbian dictionary for use with the spell checker of LibreOffice and OpenOffice since version 3.2.
Słownik hornjoserbšćiny - prawopisna kontrola za LibreOffice a OpenOffice wot wersije 3.2.
Obersorbisches Wörterbuch für die Rechtschreibprüfung von LibreOffice und OpenOffice ab Version 3.2

Description
===========

This extension is a spelling dictionary for LibreOffice and OpenOffice >= 3.2 . It can be downloaded from:
 http://extensions.services.openoffice.org
