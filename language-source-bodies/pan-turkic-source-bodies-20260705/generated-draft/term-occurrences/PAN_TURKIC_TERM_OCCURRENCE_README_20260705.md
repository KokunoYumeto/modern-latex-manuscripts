It excludes generated ledgers from the search so the occurrence ledger cites source bodies rather than package metadata.

Outputs:

- PAN_TURKIC_TERM_OCCURRENCE_LEDGER_20260705.csv: exact source-body path, line, searched form, and snippet for each occurrence.
- PAN_TURKIC_TERM_OCCURRENCE_GAPS_20260705.csv: language/lexeme rows with no exact packaged occurrence.
- PAN_TURKIC_TERM_OCCURRENCE_SUMMARY_20260705.csv: searched source-row and occurrence counts by language/lexeme.
- PAN_TURKIC_SOURCE_TIED_INTERLINEAR_SCAFFOLD_20260705.csv: generated-draft scaffold rows tied to exact source anchors.

These files do not claim accepted terminology, native review, source certification, bridge/pilot status, gate promotion, or translation completion. Base ring/polynomial occurrences do not close Noetherian-ring or polynomial-ring hard blockers.
