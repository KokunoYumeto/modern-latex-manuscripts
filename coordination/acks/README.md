# Coordination Acknowledgements

Every other-PC / sibling Codex or AI session that reads the coordination directives must create an acknowledgement file in this folder.

Required filename:

`ACK_SESSION_MANAGER_DIRECTIVE_<session-name>_YYYYMMDD.md`

Required contents:

- I read `coordination/OTHER_PC_SESSION_MANAGER_AND_LOGBOOK_DIRECTIVE_20260705.md`.
- My lane is: ...
- My durable logbook path is: ...
- My current output path is: ...
- I understand that actual source bodies must be pushed when they exist.
- I understand that indexes, manifests, URL lists, and checksum ledgers are not substitutes for the source corpus.
- I understand that Fable/ChatGPT-Pro branch-weighting, marginal-intelligibility, dominance-collapse, and adverse-evidence findings are governing constraints for interlanguage/Interslavic work.
- My next concrete task is: ...

No acknowledgement means the archive-maintenance session should not assume the sibling session is following the current workflow.
