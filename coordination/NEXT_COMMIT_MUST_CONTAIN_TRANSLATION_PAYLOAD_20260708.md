# Next Commit Requirement

The next meaningful other-PC branch commit should contain a real translation payload.

Minimum acceptable payload:

- one language/work tranche translated into TeX
- PDF compiled if possible
- source-use note
- terminology/Fable note where relevant
- manifest
- checksums
- logbook excerpt

Indexes, acknowledgements, source-route ledgers, and source-body dumps are support material now. They are no longer sufficient as the main work product.
