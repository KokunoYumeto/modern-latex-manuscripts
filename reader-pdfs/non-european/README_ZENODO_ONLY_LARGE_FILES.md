# Zenodo-Only Large Readers

The current non-European Zenodo record includes one front-facing reader that is intentionally not mirrored into GitHub because it is too large for a normal forkable repository:

- `50-04 Indian Original - Brahmagupta - Brahmasphutasiddhanta.pdf` — 181,662,221 bytes in Zenodo version `10.5281/zenodo.20526138`.

Use the all-version non-European record for the complete reader surface:

<https://doi.org/10.5281/zenodo.20410957>

GitHub keeps the reasonably sized reader PDFs, metadata, manifests, and source-facing notes. Large raw/provenance artifacts remain on Zenodo.
