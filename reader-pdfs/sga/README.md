# SGA Reader PDFs

This folder contains SGA working drafts, translations, source scan slices, and reference PDFs. These files are useful, but they are not a complete or globally source-faithful SGA edition.

The old `complete`, `strict`, and `source-checked` filename language has been removed from the main SGA 5, SGA 6, and SGA 7-I GitHub-facing PDFs where it overstated the current audit state. Current interpretation:

- SGA 5 has real page-local repair/source-audit work, but it is not complete and not globally source-faithful.
- SGA 6 has substantial working translation/reconstruction material, but current audits found compression/omission problems in late regions.
- SGA 7-I is partial working material, not complete source closure.

For serious use, compare formulas, diagrams, theorem statements, page order, and unusual notation against the source scans and the latest audit packets.
