# Classical Reader PDFs

This folder contains mixed-quality reader PDFs. Do not infer source accuracy from age, file count, or old package lineage.

The Cayley PDFs in this folder have been deliberately renamed as suspect draft readers. They are retained because they are useful repair/provenance material, but current audits and spot-checks found source-faithfulness failures. No Cayley volume or page range is currently promoted as a source-faithful transcription until a later page-by-page glyph/source audit explicitly re-promotes that exact range.

Other classical PDFs may have stronger scoped source checks; use the record notes and source witnesses rather than filename confidence words alone.
