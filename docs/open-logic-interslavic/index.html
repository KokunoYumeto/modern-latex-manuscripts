Method and traceability

Each unit preserves source TeX, mathematical formulae and structure. Terminology decisions are append-only. `CANON_INDEX.json` supplies replay order and byte/hash pins; the batch link binds every new unit to stable OLISV IDs. Failed R1 and R2 visual attempts remain visible as adverse history.
