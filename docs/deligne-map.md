# Deligne GitHub Coverage Map

Observed 2026-08-05. This page records what is already preserved under
[`sources/deligne`](../sources/deligne/) so that an existing paper, letter, or
language layer is checked before anybody starts it again.

This is a custody and continuation map, not a critical-edition or peer-review
claim. Inherited words such as `current`, `complete`, `verified`, and
`source-aligned` describe the named package's own scope; they do not certify
the entire Deligne corpus.

Presentation rule: open the independent English or French edition. Combined,
side-by-side, and interleaved bilingual outputs remain preserved as history but
are not reader entry points and must not displace the independent editions.

For the earliest continuous sequence, use the separate [English](../sources/deligne/forward-001-016p040-source-witness/D016_LC_p031_040/SEQ_CUM/ALL_001_016p040/PDF/ALL_001_016p040_EN.pdf) or [French](../sources/deligne/forward-001-016p040-source-witness/D016_LC_p031_040/SEQ_CUM/ALL_001_016p040/PDF/ALL_001_016p040_FR.pdf) reader. 2. For D001 or D002, use the source-aligned independent readers in the next table.
3. For later numbered papers, use the per-paper table. Paper 032, Paper 084, and Paper 085 have correction packages that override weaker layers in the aggregate redo.
4. For letters, use the independent English/French trees in the letter table.
5. The descending D078–D090 tree contains separate EN/FR TeX, PDF, and scan witnesses, but its inherited cumulative name is not itself a completion certificate.

## Continue Without Duplicating Work

1. Check this map before assigning a Deligne paper or letter.
2. Continue only from an explicit package cursor; a missing combined reader is not evidence that no independent language layer exists.
3. Use Paper 032, 084, and 085 correction packages instead of the weaker aggregate layers identified above.
4. Preserve every prior generation and rejected reading. Do not overwrite history or silently promote a directory label to certification.
5. Keep English and French editions independent and reader-facing. Preserve combined/interleaved files only as history.
