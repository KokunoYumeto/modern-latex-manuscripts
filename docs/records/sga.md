## How To Read This Record

Open the reader PDFs first. The 309-page SGA5 English working translation remains the default preview. The 381-page SGA6 English reader is full-range but deliberately layered rather than uniformly certified:

- source-PDF 001-525: inherited English control, partially synchronized but not globally source-checked;
- idx532-662 / source-PDF 526-656: synchronized against the directly checked French workpass;
- idx663-702 / source-PDF 657-692 and terminal source-PDF 693-702: scan-checked English draft pending later French reconciliation.

The SGA6 English ZIP contains editable TeX, exact authority/formula/terminology/page ledgers, two-pass build evidence, all 381 page renders, twenty contact sheets, localized prefix-repair evidence, hashes, and validation. The record also retains the French workpasses and the bounded four-page Spanish SGA6 Exposé X idx532-537 tranche.

These are substantive machine-assisted source-aware working translations and repairs. They are not independently human-certified critical editions, uniform whole-volume source certification, diagram-by-diagram certification, whole-SGA completion, or guarantees that every source ambiguity has been resolved.

Corrections, source comparisons, LaTeX fixes, and translation improvements can be suggested through GitHub issues or pull requests: <https://github.com/KokunoYumeto/modern-latex-manuscripts>.
