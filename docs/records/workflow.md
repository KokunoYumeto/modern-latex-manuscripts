## How To Read This Record

Open the reader/reference PDFs first. Use artifact ZIPs when you need scripts, workflow notes, OCR/source-witness lessons, page maps, addenda, or provenance material.

Latest workflow update 2026-06-24 adds three addenda: an archive-scope guardrail, a source-witness/public-surface status guide, and a page-unit audit harness pattern distilled from Noether, Weber, SGA6, and Steinitz. The update formalizes what should and should not be uploaded, how to label OCR/source-witness aids versus working drafts and source-repaired loci, and how to build reusable audit harnesses from canonical TeX, source inventories, page/object manifests, and chunk-on-demand renderers.
