## How To Read This Record

This record has no top-level reader PDFs in the current file surface. Open the artifact ZIPs for TeX, component PDFs, source witnesses, OCR, page images, render checks, and provenance material.

Current coverage is A Treatise on Electricity and Magnetism, Volume I: IA 1873 first-edition pp.001-044, plus earlier ledger-backed source-checked working tranches for book pages 95-101, 103, 105, 109, and the main continuous run 111-267.
