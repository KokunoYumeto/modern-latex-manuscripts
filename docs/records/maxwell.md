## How To Read This Record

Start with the status file before downloading the ZIP. The ZIP is a curated working-tranche package, not a complete Maxwell edition.

Current coverage is ledger-backed source-checked material for `A Treatise on Electricity and Magnetism`, Volume I: book pages 95-101, 103, 105, 109, and the main continuous run 111-267. The package includes the source-check ledger, compact source-checked delta packets with source witnesses and render checks, the current batch TeX/PDF substrate, Internet Archive master-image indexes and OCR/XML witnesses, audit notes, and SHA256 checksums.

Important reliability caveat: the batch TeX/PDF files are status-mixed working substrate. Source-checked claims are governed by the ledger and delta packets. OCR is a locator/witness layer, not textual authority. This record should be cited as source-checked working tranches, not as a complete Maxwell Treatise or final critical edition.

Corrections, source comparisons, LaTeX fixes, and reader-facing issue reports can be suggested through GitHub issues or pull requests: <https://github.com/KokunoYumeto/modern-latex-manuscripts>.
