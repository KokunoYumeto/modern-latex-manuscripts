# Author Page Candidates

This page is a human-readability note for deciding when a mixed shelf has become too crowded and should be split into a dedicated Zenodo author or topic record.

Dedicated records are most useful when there is a coherent reader surface, enough TeX/provenance to continue the work, and a short public status statement that does not need to borrow context from the larger shelf.

## Split Checklist

Before creating a dedicated record:

1. Put reader PDFs before artifact ZIPs.
2. Separate OCR or formula witness packages from promoted working drafts.
3. Include a one-paragraph status with exact coverage and caveats.
4. Keep source scans/provenance in ZIPs, not as confusing top-level clutter.
5. Link the GitHub issue/pull-request path for corrections.
