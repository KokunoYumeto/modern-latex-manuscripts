# al-Battani Opus Astronomicum: Work-Level Coverage and Table Status

This is the public work-level record for al-Battani's *Opus Astronomicum* / *Kitab al-Zij*, not a separate fixed-star-catalogue-only record. Earlier versions of this same Zenodo concept foregrounded the fixed-star catalogue; the current version promotes the whole work and treats the star catalogue as one completed component inside it.

Current public status:

- Text stream: all 100 body-text segments are represented in the v083 Arabic/English/Chinese reader.
- Fixed-star catalogue: complete current catalogue. The current catalogue has 485 numbered star rows across 47 Ptolemaic figures, with longitude, latitude, north/south sign, magnitude, modern identification fields, and Arabic/English star descriptions for all 485 rows. The documented Escorial-codex lacuna is shown in place rather than silently hidden.
- Geography gazetteer: complete current table layer with 269 locality entries: 93 regional midpoint rows plus 176 city rows.
- Chronology / Canon of Kings: useful partial working edition. Ruler names, sequence, and the caliph reign-length layer are usable; ancient regnal-year figures still require collation.
- Zodiac, terms, houses, and auxiliary numerical tables: not cleanly tabulated in Nallino's Latin volume. A values-table should not be fabricated from this witness alone; completing that layer requires the Arabic witness or another reliable table source.

This is an honest reader-facing surface: complete text, complete fixed-star catalogue, complete geography gazetteer, and remaining auxiliary numerical-table work identified rather than silently filled.
