# al-Battani Opus Astronomicum: Coverage and Table Status

Current public status for the al-Battani material in this record:

- Text stream: all 100 body-text segments are represented in the v083 Arabic/English/Chinese reader.
- Fixed-star catalogue: coordinate table complete. The current catalogue has 485 numbered star rows across 47 Ptolemaic figures, with longitude, latitude, north/south sign, magnitude, modern identification fields, and the documented Escorial-codex lacuna shown in place. The description layer is substantial but still deliberately marked as a collation layer: 451/485 rows have Arabic descriptions and 398/485 rows have English descriptions in the current CSV/PDF.
- Geography gazetteer: complete current table layer with 269 locality entries: 93 regional midpoint rows plus 176 city rows.
- Chronology / Canon of Kings: useful partial working edition. Ruler names, sequence, and the caliph reign-length layer are usable; ancient regnal-year figures still require collation.
- Zodiac, terms, houses, and auxiliary numerical tables: still active reconstruction work. No values-table is fabricated where Nallino's Latin volume does not supply a clean table.

This is an honest reader-facing surface: complete text, complete star-coordinate catalogue, complete geography gazetteer, and remaining numerical-table work identified rather than silently filled.
