# Colleague Author Suggestions - Source Intake Triage

Date: 2026-06-29

Purpose: quick triage of suggested authors/works for possible transcription, translation, source-audit, or reference packets. This is not a final bibliography. It records rough corpus size, translation saturation, source/reference availability, and project priority.

## Project Selection Frame

The working question is not "which authors are legally safest?" but "which corpora are mathematically important, insufficiently accessible in modern TeX/translation form, and source-available enough that the project can make real progress?" Copyright or rights status is recorded only as an operational friction flag, not as the main selection principle. If a source becomes problematic, it can be withdrawn or replaced; the source-intake priority itself is based on public mathematical value, corpus tractability, translation gaps, and source quality.

Use this table as a practical intake queue:

- **High priority:** important corpus, real gap in modern transcription/translation, sources are findable, and the work is tractable as packets.
- **Reference/sidecar:** important but already well translated, too large for a first pass, or better used as a source/terminology/formalization reference.
- **Special handling:** modern, messy, archive-heavy, or better approached through selected works rather than corpus-scale transcription.

## Immediate Priority Candidates

1. **Steiner** - manageable, important, likely under-translated; now has a source-intake packet with cleaned volume grouping and duplicate witnesses excluded from first upload. Good geometry/diagram pipeline test.
2. **Weierstrass** - important and medium-sized, with strong value for analysis/history and less duplication than Euler.
3. **Desargues** - small and historically important; difficult old French/geometry but a good source-audit showcase.
4. **Fourier lesser works** - applied/math-physics value; avoid redoing the already translated main heat treatise unless producing TeX/source apparatus.
5. **Sophus Lie thematic packets** - high value but large; split into coherent source/translation packages.
6. **Möbius** - manageable four-volume source corpus and likely good geometry/mechanics value.
7. **Eisenstein** - compact high-value number-theory corpus, especially natural alongside Gauss/Dirichlet; the source packet is now built and ready for a web/colleague source-audited TeX pass.
8. **Hilbert** - public-domain, central, and broad; best handled by selected works or themed packets rather than a whole-corpus first pass.
9. **Galois** - not the highest translation-gap target, but now has a compact 71 MB source packet and is ideal for testing the scan -> TeX -> audit workflow quickly.

## Already Active / Do Not Duplicate Blindly

- **Gauss** is already an active lane; add source-completeness work and themed translation queues rather than starting a separate Gauss DOI.
- **Euler** has the Euler Archive; use it as the canonical reference and choose gaps, not duplicate the whole archive.
- **Archimedes** already has public-domain English Heath; value is clean TeX/diagram/source apparatus, not first translation.
- **Cantor** needs paper-by-paper translation-gap triage because some key works already have good English translations.

## Operational Friction Flags

These are not priority blockers; they are just notes for how to stage the work without creating avoidable cleanup later.

- **Tarski / Gödel / Mandelbrot / Takagi** are better first approached as reference, formalization, bibliography, selected-paper, or terminology packets rather than bulk transcription lanes. Their value is real, but corpus-scale transcription is not the most efficient first deliverable.
- **Euler / Cauchy / Laplace / Lagrange** are too large for a naive "do the author" start. Split them by topic, work, and existing translation coverage.
- **Apollonius / Archimedes / Desargues / Steiner** are diagram-sensitive; they should be used to refine source-image, diagram, and apparatus workflows.
- **Gauss / Dirichlet / Eisenstein / Möbius / Hilbert / Weierstrass / Lie** are the strongest next algebra/arithmetic/geometry/analysis historical lanes from this list.
