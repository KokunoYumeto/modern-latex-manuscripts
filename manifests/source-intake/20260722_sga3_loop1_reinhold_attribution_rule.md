# SGA3 Loop-1 Reinhold attribution rule

Date: 2026-07-22

## Classification

This is a provenance and licensing rule for a future SGA3 Loop-1 English
handoff. It publishes no SGA3 body, TeX, PDF, image, OCR, or Zenodo object.

The working reconstruction uses Jacob Reinhold's public
[`jcreinhold/sga`](https://github.com/jcreinhold/sga) SGA3 Markdown at snapshot
`e7a259f3f8608ad3edf9bf6eead3fd504dd2d23e` as an English prose comparison
and draft lineage. The upstream README describes the repository as an
LLM-generated English translation and states that Reinhold's translation
contribution is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Mandatory future-publication rule

Any GitHub or Zenodo SGA3 checkpoint that reuses wording from that lineage
must:

1. credit Jacob Reinhold by name;
2. link `https://github.com/jcreinhold/sga`;
3. identify snapshot `e7a259f3f8608ad3edf9bf6eead3fd504dd2d23e`;
4. preserve CC BY 4.0 attribution for reused translation wording;
5. describe the Markdown as prose comparison/draft lineage, not French source
   authority or independent corroboration;
6. distinguish that prose lineage from this project's PDF-controlled
   equation, TeX, numbering, footnote, and diagram reconstruction; and
7. avoid presenting Reinhold's contribution as this project's original work.

The current local working README already records this separation and has
SHA-256
`8F16DBDA7C8171FEA64434A0A6AD4832C0A010B01DFA0B9142BA747BE96D8787`.
The controlling Polo-Gille PDF, OCR locator material, and older generated TeX
remain separately classified witnesses. This receipt does not adjudicate the
underlying French rights or authorize publication.
