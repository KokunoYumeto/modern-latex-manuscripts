## Use Notes

This feed is deliberately broad. Some language hints are conservative because the paths do not always expose a clean BCP-47 language code. `cjk_uncertain`, `romance_uncertain`, and `rtl_uncertain` should be treated as source-anchor shelves requiring downstream inspection rather than proof of a specific language branch.

The package includes actual file bodies and internal `manifest.csv`, `language_counts.csv`, and `SHA256SUMS.txt`. It is a practical feed for Web/Pro source-style anchoring and terminology/register comparison, not a final curated language corpus.
