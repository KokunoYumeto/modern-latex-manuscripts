# URGENT COORDINATION INSTRUCTION FOR OTHER AI LANES

## UPLOAD THE LATEX SOURCE BODIES

UPLOAD EVERY ACTUAL LATEX SOURCE FILE BODY YOU FIND.

THIS MEANS THE FILES THEMSELVES:

- `.tex`
- `.sty`
- `.cls`
- `.bib`
- `.bbx`
- `.cbx`
- `.ltx`
- `.dtx`
- `.ins`

DO NOT ONLY UPLOAD MANIFESTS.

DO NOT ONLY UPLOAD CHECKSUMS.

DO NOT ONLY UPLOAD URL LISTS.

DO NOT ONLY UPLOAD “SOURCE-CANON” LEDGERS.

DO NOT ONLY SAY THAT A FILE EXISTS SOMEWHERE ELSE.

IF A SOURCE-CANON, LANGUAGE-BASELINE, REFERENCE-CORPUS, OR REVIEWER-AUTHORITY PACKET REFERENCES A LATEX SOURCE FILE, THE PACKET MUST INCLUDE THE ACTUAL LATEX FILE BODY UNLESS THERE IS A CLEAR TECHNICAL BLOCKER.

## WHY THIS MATTERS

THE ARCHIVE-MAINTENANCE THREAD NEEDS REAL LATEX INPUTS SO WEB/PRO/CODEX SESSIONS CAN USE THEM AS BASELINE MATHEMATICAL AND TYPOGRAPHIC WITNESSES.

THE USEFUL PAYLOAD IS NOT THE CLAIM “A LATEX SOURCE EXISTS”. THE USEFUL PAYLOAD IS THE SOURCE FILE ITSELF.

THESE FILES ARE NEEDED FOR:

- LANGUAGE-REGISTER BASELINES;
- MATHEMATICAL STYLE AND TERMINOLOGY EXAMPLES;
- RTL / CJK / CYRILLIC / SLAVIC / PERSIANATE / ROMANCE / TURKIC / OTHER TYPESETTING PATTERNS;
- TRANSLATION-FRAMEWORK CONSTRUCTION;
- SOURCE-AWARE WEB/PRO HANDOFFS;
- CHECKING WHETHER GENERATED TRANSLATIONS MATCH EXISTING TECHNICAL LATEX CULTURE.

## REQUIRED PACKAGE SHAPE

FOR EVERY LANGUAGE OR LANGUAGE-FAMILY LANE, CREATE ONE OR MORE ZIP PACKAGES CONTAINING:

1. THE ACTUAL LATEX SOURCE FILES.
2. ANY COMPILED PDFS THAT BELONG TO THOSE SOURCES, IF AVAILABLE.
3. A SMALL MANIFEST WITH:
   - LANGUAGE / SCRIPT;
   - SOURCE URL OR REPOSITORY URL;
   - LICENSE IF KNOWN;
   - TOP-LEVEL TOPIC;
   - WHETHER THE FILE IS NATIVE-WRITTEN, TRANSLATED, GENERATED, OR UNKNOWN;
   - WHETHER IT IS MATHEMATICS, PHYSICS, ENGINEERING, LINGUISTICS, OR SUPPORT MATERIAL.
4. A SHORT `README.md` SAYING WHAT IS IN THE ZIP.

KEEP ZIP FILES UPLOADABLE. IF A CORPUS IS LARGE, SPLIT IT INTO MULTIPLE ZIP FILES BY LANGUAGE OR SOURCE REPOSITORY.

## PRIORITY

HIGHEST PRIORITY:

- SLAVIC LANGUAGES BEYOND RUSSIAN AND UKRAINIAN;
- INTERSLAVIC / CONSTRUCTED-SLAVIC SUPPORT MATERIAL;
- UKRAINIAN AND RUSSIAN ONLY AS COMPARISON BASELINES;
- ARABIC / PERSIAN / TAJIK / RTL MATHEMATICAL LATEX;
- CHINESE / JAPANESE / CJK MATHEMATICAL LATEX;
- SPANISH / FRENCH / ROMANCE MATHEMATICAL LATEX;
- TURKIC / BALKAN / CAUCASUS / CENTRAL-ASIAN MATHEMATICAL LATEX;
- ANY NICHE LANGUAGE WITH REAL MATHEMATICAL LATEX.

FOR EACH LANGUAGE, DO NOT STOP AT ONE OR TWO TOY FILES IF MORE EXISTS. COLLECT MANY REAL FILES.

## WHAT NOT TO DO

DO NOT SUBSTITUTE SCREENSHOTS FOR LATEX.

DO NOT SUBSTITUTE OCR TEXT FOR LATEX WHEN LATEX EXISTS.

DO NOT SUBMIT EMPTY “AUTHORITY” TABLES AS IF THEY WERE SOURCE PACKETS.

DO NOT MARK GENERATED TRANSLATIONS AS NATIVE SOURCE WITNESSES.

DO NOT CALL A PACKAGE “SOURCE-CANON COMPLETE” IF IT DOES NOT CONTAIN THE ACTUAL SOURCE FILE BODIES.

DO NOT MAKE THE ARCHIVE-MAINTENANCE THREAD RE-DOWNLOAD OR RECONSTRUCT FILES THAT YOUR LANE ALREADY FOUND.

## SIMPLE RULE

IF YOU FIND LATEX ON THE INTERNET, DOWNLOAD IT, KEEP THE ACTUAL FILE BODY, ZIP IT WITH A MANIFEST, AND PUSH OR HAND IT OFF.

EVERY TIME.
