# Interslavic/Panslavic Logbook

This log records the Interslavic/Panslavic lane as a scholarly language-engineering workflow, not merely as another translation. It tracks script policy, terminology, morphology, reviewer-facing uncertainty, and retroactive changes.

## Standing Principles

- Treat Interslavic as one language with script variants, not as separate Latin/Cyrillic translations.
- Keep Latin-script Interslavic as the lexical working form for now because the available dictionary/project materials and the first pilot were gathered in Latin orthography.
- Add Cyrillic-script renderings as deterministic reader variants, especially where user expectations or Slavic-facing readership make Cyrillic useful.
- Do not silently normalize away uncertainty. If a term is a coinage, an internationalism, or a compromise, record that fact.
- Prefer broad Slavic intelligibility over imitating any one national standard.
- Keep mathematical internationalisms when they reduce ambiguity: `invariant`, `kovariant`, `kontravariant`, `modul`, `transvekcija`.
- Avoid making Interslavic look like rough Russian, rough Polish, or rough Serbian. The point is pan-Slavic readability.
- Motivate every recurring technical term more rigorously than in Ukrainian/Russian. The motivation must say whether the choice is native/pan-Slavic, international, borrowed, coined, or chosen for script stability.
- If later papers make an Interslavic term look wrong, revise the earlier term openly and rebuild cumulative outputs. This revision trail is part of the research value of the project.

## Paper 01 v001 Decisions

### General Register

- Chose a direct, modern, pan-Slavic mathematical register.
- Used many international mathematical terms because they are both recognizably Slavic-adapted and mathematically stable.
- Avoided heavy archaism even though historical Interslavic material sometimes permits more archaic choices.

### Key Terms

- `Formensystem` -> `sistem form`
  - Reason: transparent to all Slavic readers; avoids over-coinage.
  - Status: solid for pilot.
- `ternäre biquadratische Form` -> `ternarna bikvadratična forma`; title expanded to `ternarna forma četvrtogo stepena`.
  - Reason: source fidelity plus modern clarity.
  - Status: solid for pilot.
- `relativ vollständiges System` -> `odnosno polny sistem`
  - Reason: literal technical phrase, intelligible in context.
  - Status: review but acceptable.
- `Überschiebung` -> `transvekcija`
  - Reason: classical invariant theory term; matches international/transvectant family.
  - Status: solid for pilot.
- `Faltung` -> `svijanje`
  - Reason: pan-Slavic native equivalent for folding; chosen over a heavier internationalism.
  - Status: needs reviewer check because in invariant theory it may behave closer to contraction.
- `Formenreihe` -> `ręd form`
  - Reason: mirrors Ukrainian/Russian `ряд форм`; definition in text disambiguates.
  - Status: needs reviewer check.
- `Reduzent` -> `reducent`
  - Reason: technical coinage directly corresponding to Noether's historical term.
  - Status: needs reviewer check; definition kept explicit.

### Morphology/Style Choices

- Used `jest/sut` rather than omitting copula.
  - Reason: explicit mathematical predication reads cleaner in formal prose.
- Used `obći` for general/common.
  - Reason: broadly intelligible and already expected in Interslavic contexts.
- Used `konečny`, `poznany`, `reducibilny`.
  - Reason: international/adjectival forms reduce ambiguity in technical statements.
- Used `izslědovanja` for investigations.
  - Reason: transparent across Slavic space, but should be checked against dictionary preference.

## 2026-06-09: Paper 01 Cyrillic Variant Implemented

### Tooling

- Added `tools/interslavic_latin_to_cyrillic.ps1`.
- The tool treats Latin Interslavic as the source-of-truth and generates a Cyrillic reader variant.
- The tool is TeX-aware:
  - Preamble is preserved.
  - TeX commands and structural arguments such as `\begin{...}`, `\end{...}`, and `\vspace{...}` are preserved.
  - Math mode is preserved, except human text inside `\text{...}` is transliterated.
  - `\emph{...}` is preserved as Latin, because Paper 01 uses it for German/Italian bibliographic titles.
- Dictionary route:
  - Exact single-token mappings from `RU kirillica.txt` are preferred when available.
  - Fallback table is used for technical or inflected words not present in the dictionary.

### Current Fallback Rules

- `ě -> е`
- `ę -> я`, except after `č/ć/š/ž`, where observed dictionary patterns give `ча/ша/жа`
- `ų -> у`
- `å -> о`
- `y -> ы`
- `č/ć -> ч`
- `š -> ш`
- `ž -> ж`
- `c -> ц`
- `j -> ј`
- `lj/nj -> ль/нь` in fallback
- Roman labels such as `I`, `II`, `III`, `IV`, and `XVII` are preserved as Latin Roman numerals.
- A small protected-Latin list is used for bibliographic words outside `\emph{...}`: `Sitzungsberichte`, `Math`, `Annalen`, `Giorn`, `Battaglini`, `Rend`, `Circ`, `Mat`, `Palermo`, `Memoria`, `Accademia`, etc.
