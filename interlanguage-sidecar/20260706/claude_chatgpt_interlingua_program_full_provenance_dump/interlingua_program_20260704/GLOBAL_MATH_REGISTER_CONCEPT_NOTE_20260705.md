# Concept note: the standardized global mathematics register
2026-07-05. Idea lineage (corrected 2026-07-05): **Codex GPT-5 uk/ru/isv session** first listed "purpose-built mathematical interlanguages, where formula grammar and proof discourse could define a narrow, transparent controlled language" as a generalization pilot (CONSTRUCTED_LANGUAGE_AI_REFLECTIONS.md, June 2026) → **Floris** extended it with the global-weights framing (voice note 2026-07-05; "Yugoslavic" was a speech-to-text artifact for Interslavic) — "a standardized global mathematics language… mathematicians have very little trouble reading math in other languages, so it's probably the easiest genuine global interlanguage… maybe as emergent form of the general interlanguage creation work here, because we could then use the weights for any concept globally." Assessment + first measurement: Fable.

## 1. The idea decomposes exactly on our three strata — and the programme already measures all three

| Stratum | Global status | Our evidence |
| --- | --- | --- |
| **Formula/notation layer** | ALREADY the only successful global interlanguage ever deployed (∀, ∫, commutative diagrams; ISO 80000-2 standardizes it) | This is WHY the heuristic is true: a mathematician "reads" Russian papers because the formulas carry the skeleton |
| **Proof-prose layer** | a tiny closed register — the realistic design target | Our own coverage grind IS the census: 96.6% of all Noether-corpus prose tokens are covered by ~530 lemma groups. A ~500-lemma controlled register is learnable in days — nothing like a general language |
| **Concept-term layer** | partially internationalized, measurably | F12 (~15/37 concepts pan-branch internationalisms), the marker table, and now the global-attractor probe |

## 2. Historical anchor (this exact idea has been run before)
- **Peano, Latino sine flexione + Formulario Mathematico (1895–1908)**: a mathematician's global auxiliary language, used to publish real mathematics. Outcome: the NOTATION layer survived (into notation we all use — ∈, ⊃, ℕ); the prose layer died. This is the strongest single data point: the global math language already exists and it is the formula layer; prose globalization lost to local languages + one hegemon.
- Modern descendants of the prose idea: controlled natural languages (AMS-English conventions, ForTheL/Naproche) and, as the formal limit, Lean — our F8 already places the programme on this axis.

## 3. What is genuinely NEW in Floris's version
Not "one more auxiliary language" — the **weights**. The access-gain machinery generalizes from per-family to global: for every concept the marker table holds (increasingly) the form vector across families with branch weights; a global register is just the **argmax column** of the same weighted max-coverage objective, computed worldwide instead of per zone. We don't build a new lane; we add a COLUMN.

Two predicted outcomes (partially confirmed by probe v0):
- Concept terms: the optimizer largely rediscovers Greco-Latin internationalisms (+ the Sino basin for CJK — borrowing, not cognacy, is the only bridge across script families).
- Proof-grammar connectives: NO global attractor exists (F12b at world scale — connectives are pure inheritance in every family). The connective layer of a global register is necessarily DESIGNED or symbolic. This is where the register stops being emergent and starts being constructed.

## 4. First measurement (probe v0, tonight — crude, mechanical_probe tier)
[GLOBAL_ATTRACTOR_PROBE_v0](GLOBAL_ATTRACTOR_PROBE_v0_20260705.json): 57 concepts had ≥3 language families of data in marker v3.3. Only 5 (9%) show a Latin-sphere global attractor — **but this number is deflated by a known data artifact**: the uk/ru cells of the marker table carry corpus-extracted PHRASES, not lemmas ("двусторонне неразложимые кольца" for ring), so first-word clustering explodes basins. v0's real yields:
- **Hyper-attractors survive even dirty data**: matrix, center, identity, and the eponym pair noetherian/artinian. Insight: **eponyms are the strongest global-attractor class** (and, per F14, also trap-proof) — a global register leans on eponyms harder than any national language does.
- The v0.1 fix is already on the roadmap for other reasons: lemma-normalize the E-columns from the concept ledger. Then the real attractor share is measurable. Prediction registered now: nouns ≥60%, connectives ≈0%.

## 5. Cautions (from our own findings)
- **F6 dominance trap**: "standardized global" without the dominance penalty collapses to English-lite. The ledger's dominance term is not optional here; it is the difference between a register and a hegemon relabeled.
- **Survivor bias in the heuristic**: mathematicians who read across languages are the survivors of English-mediated training. STUDENTS — the access-gain target population — cannot. A global register mostly serves the already-served; the zonal bridges serve the excluded. So:
- **Best near-term use = evaluation frame, not product**: the global-attractor column gives every zonal lane its baseline. *A zonal bridge is justified exactly where it beats the global attractor* — e.g., Interslavic connectives beat any Latinate connective set for Slavic readers without English. That turns "why Interslavic and not just English/international vocabulary?" — the first question any reviewer (or grant panel) will ask — into a measured, per-concept answer.
