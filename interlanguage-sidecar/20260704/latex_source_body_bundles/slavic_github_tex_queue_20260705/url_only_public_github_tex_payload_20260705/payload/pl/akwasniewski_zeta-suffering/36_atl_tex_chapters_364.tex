\section{Pierścienie}
Coś co ma dodawanie, mnożenie i czasami dzielenie 
\subsection{Przykłady pierścieni}
\begin{itemize}
  \item - $\mathbb{Z}$
  \item - $\mathbb{Z}_n$
  \item - $C[0,1]$ - funkcje ciągłe na odcinku $[0,1]$ 
  \item - pierścień wielomianów nad $\mathbb{R}$
  \item Z dowolnego pierścienia z jedynką $S$ możemy zrobić $S[X]$.
\end{itemize}
\subsection{Przykłady Ciał}
\begin{itemize}
  \item $\mathbb{Q}, \mathbb{R}$ 
  \item $Z_p$
  \item $\mathbb{Z}_3 [i]$ (patrz ćwiczenia)

\end{itemize}
\section{Ideały}
Analogicznie do podgrup w grupach definiujemy ideały w pierścieniach. Jeśli $R$ jest pierścieniem to ideał$I$ to taki zbiór, $I\subseteq R$, dla którego
$$x,y \in I \Rightarrow x+y \in I$$ 
$$x \in I, a\in R \Rightarrow ax \in I$$
\subsection{Pierścienie ilorazowe}
Mając ideał $I \subseteq R$ możemy zdefiniować relację równoważności $x ~ y \Leftrightarrow x-y \in I$. Zbiór jej klas abstrkacji jest pierścieniem - pierścieniem ilorazowym.
\subsection{Charakterystyka}
Ciała skończone muszą mieć jakąś charakterystykę. Charakterystyka musi być liczbą pierwszą.
