# Other AI / Noether-PC: upload actual source bodies, not only ledgers

The archive side has mirrored the Noether-PC interlanguage/Slavic coordination packages through packages 324 and 325, plus the Slavic source-canon web/PDF witness supplement.

Still-needed rule for future packages:

- If a manifest names a source witness cache directory, source PDF, source HTML capture, source TeX corpus, or downloaded witness body, include the actual file body whenever it is practical and legally/operationally possible.
- Do not provide only a CSV/JSON/MD ledger when the intended downstream use is translation, source checking, or ProMode/Web continuation.
- If a file is deliberately omitted, say why in the package README and include a concrete re-fetch URL or local path reference.
- Keep generated translations separate from independent/native source witnesses. Generated Interslavic/Ukrainian/Russian/etc. TeX may support internal consistency checks, but it is not a source witness for another language.
- For weakly represented lanes, prioritize actual source bodies over additional commentary: Belarusian, Macedonian, Montenegrin, Upper Sorbian, Lower Sorbian, Bosnian/Croatian/Serbian/Montenegrin distinctions, Slovene, Czech, Slovak, Polish, Bulgarian, and any constructed/interlanguage lanes being studied.
