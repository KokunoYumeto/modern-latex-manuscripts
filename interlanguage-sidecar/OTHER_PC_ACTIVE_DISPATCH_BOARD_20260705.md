## Immediate Assignments For Idle Sessions

1. Gather literal LaTeX/source-body corpora for one target language.
2. Package source bodies with a manifest, byte size, and SHA256.
3. Audit whether previous ZIPs contain actual TeX/PDF/source bodies or only indexes/logs.
4. Apply Fable/ChatGPT-Pro branch-weight and marginal-intelligibility constraints to a terminology block.
5. Build a source-use status table: native source, generated draft, OCR witness, pointer-only, rejected.
6. Repair interlanguage choices that fail dominance-collapse, false-friend, or adverse-evidence checks.
7. Create a compact web/pro handoff ZIP containing only useful bodies, logs, and manifests.

## Blocking Constraint

Do not call an interlanguage output functional unless it is tied to source bodies and to the Fable/ChatGPT-Pro constraint layer. Generated translation alone is not enough.
