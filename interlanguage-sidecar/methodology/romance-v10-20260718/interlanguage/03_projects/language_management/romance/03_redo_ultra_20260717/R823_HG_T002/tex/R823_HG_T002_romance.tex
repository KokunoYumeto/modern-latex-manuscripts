\subsection*{§ 2. Classes de representation}

% T-025
Se pote transformar un representation direct $\mathfrak D$ de $\mathfrak{o}$ in $\mathsf T$ in un representation isomorf $\mathfrak D'$ per transformar cata matrice con un matrice regular $P$.
% T-025A
Assi, al elemento $c$ de $\mathfrak{o}$ se associa, in loco de $C\subseteq\mathfrak D$, $P^{-1}CP\subseteq P^{-1}\mathfrak D P$.

% T-026
Representationes que se pote transformar un in le altere de iste maniera se nomina \emph{equivalente}.

% T-027
Tote le representationes equivalente a un representation forma un \emph{classe de representation} (in le fonte: d. D. K.).

% T-028
Le equivalencia de representationes reciproc se defini del mesme maniera.
% T-029
Representationes reciproc se nomina equivalente si un se pote obtener ex le altere per transformation con un matrice regular.
% T-030
Tote le representationes equivalente a un representation reciproc fix forma un \emph{classe de representationes reciproc}.

\section*{Nota editorial de senso}

In le terminologia historic del fonte, \emph{matrice regular} significa hic un matrice invertibile. Le forma historic es conservate, ma non es generalisate a altere sensos moderne de ``regular matrix''. \emph{Equivalente} non es fusionate con \emph{isomorf}: in iste section, equivalencia exige le transformation explicite per un mesme matrice invertibile. Le notation $C\subseteq\mathfrak D$ e $P^{-1}CP\subseteq P^{-1}\mathfrak D P$ es conservate exactmente del autoritate, sin correction silentiose.
