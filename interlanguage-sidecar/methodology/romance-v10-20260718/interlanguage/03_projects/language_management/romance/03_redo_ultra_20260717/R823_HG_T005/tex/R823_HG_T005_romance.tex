\subsection*{§ 4 (continuation): Isomorfia e cambio de base}

% T-051
Le isomorfia inter $\overline{\mathfrak D}$ e le representation es explicate per le formulas sequente. Si al transformation linear generate per $c\in\mathfrak{o}$ corresponde le matrice $C$, dunque
% T-E9
\[
c(x_1,\ldots,x_n)=(x_1,\ldots,x_n)C,
\]
% T-052
e si, in maniera analoge, al elemento $d\in\mathfrak{o}$ corresponde le matrice $D\in\mathsf T_n$,
% T-E10
\[
d(x_1,\ldots,x_n)=(x_1,\ldots,x_n)D,
\]
% T-053
in tal caso evidentemente
% T-E11
\[
\begin{aligned}
(c+d)(x_1,\ldots,x_n)
&=(cx_1+dx_1,\ldots,cx_n+dx_n)\\
&=(x_1,\ldots,x_n)(C+D).
\end{aligned}
\]
% T-054
Et etiam
% T-E12
\[
\begin{aligned}
cd(x_1,\ldots,x_n)
&=c(dx_1,\ldots,dx_n)=c((x_1,\ldots,x_n)D)\\
&=(cx_1,\ldots,cx_n)D=(x_1,\ldots,x_n)CD.
\end{aligned}
\]
% T-055
Assi, le transformationes linear de $\mathfrak M$ a se mesme generate per $\mathfrak{o}$, realisate mediante un base determinate $x_\nu$ de $\mathfrak M$, dona un representation de grado $n$ de $\mathfrak{o}$ in $\mathsf T$.

Si $(y_1,\ldots,y_n)$ es un altere base de $\mathfrak M$, illo deriva de $(x_1,\ldots,x_n)$ per multiplication con un matrice regular $P$:
% T-E13
\[
(y_1,\ldots,y_n)=(x_1,\ldots,x_n)P.
\]
% T-057
Si un transformation linear de $\mathfrak M$ es realisate per le matrice $C$ relative al base $x_\nu$, relative al base $y_\nu$ illo es realisate per $P^{-1}CP$. Nam, si
% T-E14
\[
c(x_1,\ldots,x_n)=(x_1,\ldots,x_n)C,
\]
in tal caso
\[
\begin{aligned}
c(y_1,\ldots,y_n)
&=c(x_1,\ldots,x_n)P=((x_1,\ldots,x_n)C)P\\
&=(x_1,\ldots,x_n)CP=((y_1,\ldots,y_n)P^{-1})CP\\
&=(y_1,\ldots,y_n)P^{-1}CP.
\end{aligned}
\]
% T-058
De isto se conclude directmente:
% T-059
\emph{Le modul $\mathfrak M$ dona tote le representationes de un classe de representation, si tote le bases de $\mathfrak M$ es usate pro realisar le transformationes linear de $\mathfrak M$ inducite per $\mathfrak{o}$.}

\section*{Nota editorial de senso}

Le tupla ordinate $(x_1,\ldots,x_n)$ es tractate como un vector-riga, e le matrices acta al dextra. Le pares $c\mapsto C$ e $d\mapsto D$ resta fixe. Dunque $(c+d)\mapsto C+D$ e $cd\mapsto CD$; le ordine $CD$ non es invertite per un convention moderne de composition.

Le cambio de base ha le direction $(y_1,\ldots,y_n)=(x_1,\ldots,x_n)P$. Per iste direction, le matrice del mesme transformation in le base $y_\nu$ es $P^{-1}CP$, non $PCP^{-1}$. Le forma historic \emph{matrice regular} es limitate hic al senso de matrice invertibile.

Le conclusion dice que variar tote le bases de $\mathfrak M$ dona tote le representationes \emph{de un classe de representation}. Isto non affirma que tote le matrices de $\mathsf T_n$ es obtenite, ni que $\mathfrak M$ produce tote le classes de representation. Solmente le matrices del transformationes inducite per $\mathfrak{o}$ e exprimite in le bases de $\mathfrak M$ es in scope.
