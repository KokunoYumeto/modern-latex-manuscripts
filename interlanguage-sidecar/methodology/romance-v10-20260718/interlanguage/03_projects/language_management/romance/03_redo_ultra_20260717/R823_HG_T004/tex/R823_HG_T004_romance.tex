\subsection*{§ 4. Le relation inter moduls de representation e representationes}

% T-039
\textbf{1.} \emph{Cata modul de representation determina in maniera unic un classe de representation: un modul direct de representation determina un classe direct, e un modul reciproc determina un classe reciproc (in le abbreviationes del fonte: d. D. M. a d. D. K.; r. D. M. a r. D. K.).}

% T-040
Le construction es le sequente.

% T-041
Le multiplication del modul direct de representation $\mathfrak M$ per un elemento $c$ de $\mathfrak{o}$ defini un homomorfism de $\mathfrak M$ a se mesme.
% T-042
Per causa del lege associativ $(cm)\tau=c(m\tau)$, iste homomorfism admitte le elementos de $\mathsf T$ como operadores; dunque illo es un \emph{transformation linear} de $\mathfrak M$ a se mesme.
% T-043
Isto significa que le association $m\mapsto cm=m'$ ha le proprietate sequente:
% T-E6
\[
\text{Si } y_i\mapsto y_i'(=cy_i),\text{ in tal caso etiam }
\sum y_i\tau_i\mapsto \sum y_i'\tau_i\left(=c\sum y_i\tau_i\right).
\]

% T-044
Se defini le suma $\mathfrak T_1+\mathfrak T_2$ de duo transformationes linear
% T-E7
\[
\mathfrak T_1:\ m\mapsto m'(=c_1m)
\quad\text{e}\quad
\mathfrak T_2:\ m\mapsto m''(=c_2m)
\]
% T-045
como le transformation $m\mapsto m'+m''(=(c_1+c_2)m)$, e lor producto $\mathfrak T_1\cdot\mathfrak T_2$ como le transformation componite $m\mapsto (m'')'=c_1c_2m$.
% T-046
In tal caso, le collection del distinct transformationes linear de $\mathfrak M$ generate per le elementos de $\mathfrak{o}$ forma un imagine $\overline{\mathfrak D}$ de $\mathfrak{o}$ obtenite per un homomorfism de anels.

% T-047
Ora se elige un base arbitrari $x_1,\ldots,x_n$ de $\mathfrak M$.
% T-048
Le transformation linear generate per $c$ es determinate si se cognosce como le elementos del base $x_i$ es transformate, dunque si se cognosce le matrice $(\gamma_{ij})=C$ del system de equationes
% T-E8
\[
x'_j=cx_j=\sum x_i\gamma_{ij}.
\]
% T-049
Per un altere elemento $x=\sum x_j\tau_j$, se ha directmente $x'=\sum x'_j\tau_j$.
% T-050
Iste matrices $C$ corresponde in maniera unic al distinct transformationes linear, nam le matrices e le transformationes determina un le altere. Le matrices forma, como se vide directmente, un anel isomorf a $\overline{\mathfrak D}$; dunque un imagine de $\mathfrak{o}$ obtenite per un homomorfism de anels, e assi un representation de grado $n$ de $\mathfrak{o}$.

\section*{Nota editorial de senso}

Le unicitate se refere al \emph{classe de representation}, non a un sol representation. In le continuation del fonte, bases differente del mesme modul produce le representationes differente del classe. Le phrase \emph{de $\mathfrak M$ a se mesme} declara un application con dominio e codominio $\mathfrak M$; illo non adde un affirmation de surjectivitate.

Le producto $\mathfrak T_1\mathfrak T_2$ conserva le convention del fonte e su resultado explicite $c_1c_2m$. Nulle convention moderne de composition pote inverter iste ordine silentiose. Le forma test \emph{base} es limitate al base del modul libere in le formulas coordinate; le senso ordinari de fundament non es admittite. \emph{Imagine} nomina le anel resultante, durante que \emph{homomorfism} nomina le application.
