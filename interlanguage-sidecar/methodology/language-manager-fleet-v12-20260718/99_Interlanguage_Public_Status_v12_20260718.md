# Public status: interlanguage methodology v0.12

This version publishes a frozen language-manager fleet map, stable manager
control ledgers, and selected small working outputs from eight lanes.

## Included status classes

- source-reconciled working readers and bounded working translations;
- reproducible build and render evidence;
- terminology, adverse-evidence, source, and continuation ledgers;
- unreviewed microtranches explicitly labelled as such;
- pointers to full payloads already held by the Noether, SGA, and Interlanguage
  records.

## Excluded claims

This release does not certify native-language quality, community acceptance,
semantic perfection, universal mathematical correctness, proof checking, peer
review, or critical-edition status. The SGA 5 Spanish and SGA 6 French
workpasses were actively changing at capture time and are described but not
sealed as new translation releases here.

The large source-body corpora already present in earlier numbered ZIPs are not
duplicated. The v0.12 snapshot adds the current management and classification
layer needed to understand those files accurately.
