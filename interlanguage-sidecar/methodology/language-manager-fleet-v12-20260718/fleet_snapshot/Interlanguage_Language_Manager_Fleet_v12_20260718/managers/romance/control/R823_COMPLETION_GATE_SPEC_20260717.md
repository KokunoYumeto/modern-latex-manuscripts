# R823 French/Spanish completion gate

This gate exists to prevent nominal Papers 1--43 coverage or a compiling draft from being reported as a finished R823 translation.

Run `scripts/noether_r823_completion_gate.py` separately for Spanish and French. A passing result requires all of the following:

1. The authority TeX hash is the verified R823 hash `EE8955BCF7A263917BE57DBC8F682601550CDCB5260D02CA6D486C6A6DFD4F21`. The 81-row source manifest `R823_SOURCE_UNIT_MANIFEST_20260717.csv` must also match hashes recomputed directly from that authority; pass it with `--source-unit-manifest`.
2. The expanded target TeX has Papers 1--43 and target-language structural headings for the 31-section long-form book, the Kapferer--Noether unit, bibliography, and terminal lists. Commented headings and prose mentions do not count. Generate its exact 81-row manifest with `scripts/noether_r823_target_unit_manifest.py` and pass that file with `--target-unit-manifest`; every unit hash and the repeated `target_document_sha256` for the whole expanded target must match the live TeX. Braced, unbraced, line-leading, and inline `\input`/`\include` forms are expanded; any unparsed or missing inclusion fails.
3. No explicit untranslated/TODO placeholder remains.
4. Supply `--log`, `--fls`, and `--pdf` from the same root build. The log must contain a successful output signature whose basename and page count match the PDF; the recorder file must name the root and every expanded TeX dependency, and its declared PDF/XDV output must bind to the same build. The cumulative PDF, log, and recorder file must be newer than every recorded local source dependency. The PDF floor cannot be lowered below 430 pages.
5. The source-parity ledger contains `source-reconciled` rows, with hashes, for:
   - `P01` through `P43`;
   - `BOOK_TITLE_INTRO` and `BOOK_S01` through `BOOK_S31`;
   - `POST45_MAIN` and `POST45_NOETHER_SUPPLEMENT`;
   - `BIBLIOGRAPHY`, `SHORT_NOTICES`, `BOOK_REVIEWS`, and `BOOKS_WITH_NOETHER`.
   The gate recomputes both sides: every `source_sha256` must match the verified R823 slice, every `target_sha256` must match the corresponding live target slice, every row must carry the live whole-target `target_document_sha256`, and every `source-reconciled` row must cite nonblank `review_evidence`. Merely well-formed hexadecimal values do not pass. Supply the pending seed with `--parity-seed-ledger`, the exact 81-row direct router with `--evidence-map`, and the canonical promotion program with `--parity-promoter`. The gate verifies the promoter program's pinned SHA-256, reruns it in a temporary directory, and requires the supplied parity ledger to be byte-for-byte identical to that output. It also dereferences all 81 direct evidence records, rehashes every declared supporting artifact, and binds every such file into the final snapshot fingerprint. A hand-edited or stale parity CSV therefore cannot pass.
   `scripts/noether_r823_parity_ledger_seed.py` can join the two manifests without manufacturing review: it marks new or hash-changed rows pending and preserves prior review state only when the exact source unit, target unit, and whole expanded target hashes all remain unchanged.
6. The terminology ledger has at least 60 distinct, nonblank source-supported/reviewed decisions with the columns `source_term,target_term,sense,status,source_evidence`. Duplicate term/target/sense triples fail. At least 60 rows must carry a genuinely concrete source locator: exact R823/German-authority lines, an identified independent native-language source with a numeric page, or an independent native-language TeX file with an exact line and pinned SHA-256. Target-branch TeX line numbers (including hash-pinned ones), unpinned TeX lines, bare section numbers, or vague phrases such as “R823 chapters” do not count toward the minimum, which cannot be lowered below 60.
7. The visual-QA ledger has exactly one passing row for each scope `changed-pages`, `full-cumulative-spread`, and `terminal-material`, with columns `scope,status,language,pdf_sha256,target_document_sha256,pages,renderer,render_path,review_notes`. Hashes must match the live artifacts. The `pages` field uses only comma/semicolon-separated numbers or ranges; `full-cumulative-spread` must equal the complete set `1` through the live final PDF page, and terminal material must include the final page. Each `render_path` must point to a CSV render manifest—not merely a directory—with columns `page,render_path,sha256,pdf_sha256,renderer`. Every declared page must have exactly one live, readable image under the pinned 120-dpi Poppler profile. The gate freshly rerenders every candidate PDF page, hashes normalized RGB pixels and geometry, and requires every stored render to match the fresh candidate pixels as well as its file and PDF hashes. A rehashed arbitrary image therefore fails. All render manifests and images enter the final snapshot fingerprint. Review notes must contain at least 80 characters and ten words.
8. The gate itself runs the book structural audit over the live expanded target and requires `present-structural-review` for all 31 sections. `scripts/noether_r823_book_structure_audit.py` remains available for a standalone CSV and rejects any authority hash other than canonical R823. This detects gross compression or formula loss but does not replace bilingual semantic review.
9. No one of the 81 target units falls below 65% of its corresponding German source character count. This is only a gross-omission tripwire, not evidence of good translation; a unit can exceed the floor and still fail bilingual review.
10. The gate itself runs the paper structural audit and requires no gross structural risk across Papers 1--43. `scripts/noether_r823_paper_structure_audit.py` remains available for a standalone hash-bound CSV. It checks the same compression floor, math-token volume independent of inline/display presentation, and a tolerant display-structure omission tripwire. The normal TeX build remains responsible for detecting broken math delimiters; this audit likewise cannot certify linguistic fidelity.
11. Pass `--visual-review-record` with a structured JSON review decision bound to the exact candidate PDF, expanded target, pinned renderer executable, complete full-render manifest, all-page pixel binding, reviewed page range, reviewer provenance, timezone-aware review time, method, and findings. The record must cover every candidate page and must identify the same full-cumulative manifest used by the visual-QA ledger. This makes a prior review decision replayable without pretending that a machine image hash is itself human or scholarly review.
12. Pass `--final-audit` with a readable audit containing exactly one labeled German-authority SHA-256, expanded target SHA-256, and final PDF SHA-256. Every one of the 81 direct source-reconciliation records must declare this audit as a hash-pinned supporting artifact. The gate rejects an audit that merely exists beside the corpus but is not integrated into every unit's evidence graph.
13. Immediately before emitting its result, the gate re-hashes every authority, target, dependency, PDF/build, parity seed/map/promoter, direct unit-evidence corpus, supporting artifact, visual-review record, visual manifest, and rendered page image, and re-expands the target. Any mid-run mutation, new dependency, changed whole-target hash, modified support file, or replaced render fails the snapshot.

The automated gate does **not** prove semantic accuracy or native quality. Those remain manual review requirements. Conversely, a beautiful sample or clean compilation cannot compensate for a failing scope/parity row.

## Adversarial implementation replay

Before certification, run `scripts/noether_r823_gate_adversarial_selftest.py` against the live cumulative and pass the same pinned promoter with `--parity-promoter` plus the exact Poppler executable with `--pdftoppm`. The replay must report all of these probes: `preamble_hash`, `comment_mask`, `heading_context`, `input_parser`, `strict_source_locator`, `page_coverage`, `render_hash`, `poppler_pdf_derivation`, `visual_review_binding`, `direct_evidence_support_hash`, `final_audit_semantic_hash`, and `canonical_promoter_byte_exact`. The render probes prove that arbitrary rehashed pixels and stale review records are rejected. The final promoter probe builds a substantive synthetic 81-row evidence corpus, reproduces its parity ledger with the canonical promoter, and proves that a one-byte hand edit is rejected.

On 2026-07-18 the French live graph replay passed with 130 expanded dependencies. That result validates the hardening implementation only; its moving expanded-target hash is not a completion or freeze hash.
