# Africa, Horn, and West language-management lane

This is one administrative translation manager, not one language family and
not a proposed African interlanguage.

## Mandate

- Translate every admitted work into every named target routed here, including
  Noether, SGA, and works whose authoritative source is not yet English.
- Keep Horn and West African research as separate subprograms, then keep every
  language, standard, audience, register, and script lane distinct wherever
  evidence or review authority differs.
- Maintain source corpora, native examples, the typed evidence graph, the
  declared family/cohort tree, concept crosswalks, terminology and adverse
  ledgers, scripts/register policies, worker returns, hashes, and continuation
  cursors.
- Never treat geography, script, a lingua franca, a source-language authority,
  a generated draft, or a raw occurrence count as target-language acceptance.

## Binding research model

- `EVIDENCE_GRAPH.json` is the typed, channel-separated provenance and routing
  graph. It is not a weighted automaton and does not auto-decide terms.
- `FAMILY_COHORT_TREE.json` declares genealogical dependence and administrative
  routing. The manager root is explicitly non-genealogical.
- `TARGET_INVENTORY_20260717.csv`, `SOURCE_FLOOR_LEDGER_20260717.csv`, and
  `SCRIPT_REGISTER_POLICY_20260717.csv` prevent geographic or script-based
  evidence transfer.
- `WORK_REGISTRY_20260717.csv` retains the manager's responsibility for the
  full project corpus rather than silently narrowing the lane to Noether.
- `CONCEPT_CROSSWALK_SEED_20260717.csv` contains source-extracted candidates,
  not accepted terms.
- `ADVERSE_LEDGER.csv` holds standing traps and vetoes separately from gaps.

W0 remains a projection. Unified v6.2 readiness is rejected. No scalar score
may promote or reject a form, and no community-certification wording is
permitted without an accepted return from a named reviewer/community route.

## Completion gate

A finished translation tranche requires all of the following in the named
target lane:

1. authoritative source coordinates and a source-use note;
2. translated TeX;
3. a successfully compiled PDF;
4. visual inspection of that PDF;
5. terminology and adverse-choice notes;
6. manifest and hashes;
7. a precise continuation cursor;
8. an explicit label distinguishing draft, reviewed, and accepted status.

The compiled PDF is mandatory. A TeX-only draft is not a completed tranche.
