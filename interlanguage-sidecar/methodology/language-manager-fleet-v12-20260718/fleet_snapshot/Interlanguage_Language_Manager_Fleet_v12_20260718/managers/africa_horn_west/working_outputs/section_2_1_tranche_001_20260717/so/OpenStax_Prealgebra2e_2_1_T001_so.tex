\section*{2.1 Adeegso afka aljebrada}

Dhammaadka qaybtan, waxaad awoodi doontaa inaad:

\begin{itemize}
  \item adeegsato doorsoomeyaal iyo astaamaha aljebrada;
  \item kala garato tibaaxaha iyo isle'egyada.
\end{itemize}

Aljebrada dhexdeeda, xarfaha alifbeetada ayaa loo adeegsadaa inay matalaan
doorsoomeyaal. Xarfaha inta badan doorsoomeyaal ahaan loo adeegsado waa
$x$, $y$, $a$, $b$, iyo $c$.

\subsection*{Doorsoomeyaal iyo madoorsoomeyaal}

\textbf{Doorsoome} waa xaraf matala tiro ama xaddi qiimihiisu is beddeli karo.

\textbf{Madoorsoome} waa tiro qiimaheedu mar walba isku mid yahay.

\subsection*{Tibaaxo iyo isle'egyo}

\textbf{Tibaax} waa tiro, doorsoome, ama isku-dar ka kooban tirooyin,
doorsoomeyaal iyo astaamaha xisaab-fallada.

\textbf{Isle'egtu} waxay ka kooban tahay laba tibaaxood oo ay isku xirto
calaamadda isle'egta.
