\section*{Векторлор, кошуу жана скалярга көбөйтүү}

\emph{Вектор} — сандардан турган бир мамычалуу же бир саптуу тизме. Вектордун ар бир саны анын \emph{компонентасы} деп аталат. Бардык компоненталары нөл болгон векторду \emph{нөл вектор} деп атайбыз жана адатта \(\vec{0}\) деп белгилейбиз.

Мисалы,
\[
  \vec{v}=\begin{pmatrix}1\\3\\7\end{pmatrix}
\]
болсо, \(\vec{v}\) векторунун үчүнчү компонентасы \(7\).

\emph{Векторлорду кошуу} бирдей өлчөмдөгү векторлор үчүн компоненталар боюнча жүргүзүлөт:
\[
  \begin{pmatrix}1\\3\\7\end{pmatrix}+
  \begin{pmatrix}2\\0\\4\end{pmatrix}
  =
  \begin{pmatrix}3\\3\\11\end{pmatrix}.
\]

\emph{Скалярга көбөйтүүдө} сан \(r\) вектордун ар бир компонентасына көбөйтүлөт:
\[
  r\begin{pmatrix}1\\3\\7\end{pmatrix}
  =
  \begin{pmatrix}r\\3r\\7r\end{pmatrix}.
\]

\paragraph{Дарбаза.} Бул кыргызча булак \emph{вектордук мейкиндик}, \emph{бирдик вектор}, жана үч тилдүү техникалык глоссарий күбөлөрүнө таянат. Бул азырынча кароо үчүн гана берилген котормо; терминдер стандарт катары көтөрүлгөн жок.
