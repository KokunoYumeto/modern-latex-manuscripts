# Turkic language manager

This is the single cross-work manager lane for translation into Turkic languages. It is not a Turkish-only lane, a Noether-only lane, or a Pan-Turkic constructed-language claim. Its scope includes Noether, SGA, Hefferon, works not yet in English, and any later work placed in the interlanguage programme.

No original archive is moved, rewritten, or deleted. Exact duplicates found in the canonical package are recorded and not copied into the manager lane.

## Manager structure

- `00_lane_control/`: scope, package registry, work registry, provisional cohort tree, script/register policy, and consolidation ledgers.
- `01_recovered_witnesses/`: navigation and provenance for preserved packages and archives.
- `02_native_examples/`: nonduplicated source witnesses recovered from the raw working archive.
- `03_working_translations/`: review-only TeX and translation packets, organized by work or cross-work function.
- `04_comparison_web/`: typed evidence and cross-language review bundles.
- `05_worker_returns/`: consolidated returns from earlier production/research lanes.
- `06_publication_candidates/`: only tranches that pass the complete TeX/PDF/QA gate.
- `90_logs/`: consolidation and validation logs.

## Non-negotiable boundaries

1. Every production unit names a living target language, script, register, audience, work, and stable source unit.
2. Turkish evidence cannot stand in for Azerbaijani, Turkmen, Tatar, Bashkir, Kazakh, Kyrgyz, Uzbek, Uyghur, Chuvash, or an uncovered Turkic language.
3. Transliteration or script conversion is not a second language witness.
4. Support, candidate, competitor, adverse, absence, and veto evidence remain separate channels.
5. The family/cohort tree measures declared dependence and breadth only. It has no weights or edge lengths in the present lane and cannot promote a term.
6. Old automaton, branch-weight, marginal-intelligibility, and readiness artifacts are preserved as archaeology or diagnostics. Unified v6.2 readiness is rejected as a decision measure.
7. No current packet demonstrates external/community review. Generated drafts never become native-language witnesses.
8. A completed translation tranche requires translated TeX, a successfully compiled PDF, compile log, render check, source-use note, terminology/adverse note, manifest, hashes, diff or change ledger, and continuation cursor. Plain text or failed compilation is unfinished work.
