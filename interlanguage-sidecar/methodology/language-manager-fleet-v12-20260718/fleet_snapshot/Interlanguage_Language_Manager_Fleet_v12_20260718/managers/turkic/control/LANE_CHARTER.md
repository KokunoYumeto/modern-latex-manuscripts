Later user instructions override older operational interpretations. The instruction that another task should hold does not apply to this manager.

## Scope

This one manager owns translation of every work into selected Turkic target standards and maintains the shared Turkic source corpus, examples, concept web, terminology/adverse ledger, script/register controls, and worker returns. Work and language are dimensions inside this lane, not reasons to create separate manager tasks.

The manager preserves Oghuz, Kipchak, Karluk/Southeastern, Oghur, Siberian/Northeastern, and classification-pending boundaries. The provisional tree is a symmetric routing surface with equal leaf depth, no weights, and no edge lengths. It is not a claim that all internal classifications are settled.

## Research object

Operational decisions use:

- a typed evidence graph for source-to-concept-to-form-to-decision provenance;
- a declared family/cohort tree for dependence and breadth;
- a vector of hard readiness gates rather than a scalar score.

Every consequential decision should conform to `OPERATIONAL_DECISION_INTERFACE.schema.json`. The six evidence channels are `support`, `candidate`, `competitor`, `adverse`, `absence`, and `veto`. A use weight is not a truth probability, and no scalar can auto-promote or auto-reject a form.

## Default production unit

An ordinary translation into one named standard, with:

- stable source snapshot and unit ID;
- target language, BCP 47 tag, script, register, and audience;
- typed evidence records and a cross-Turkic concept crosswalk;
- script and formula invariants;
- source-fidelity and terminology change ledger;
- compiling TeX and PDF plus render QA;
- manifest, hashes, and continuation cursor.

No bridge or controlled Pan-Turkic register may replace the named-standard translation.
