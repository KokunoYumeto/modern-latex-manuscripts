# Interlanguage Research Method, Evidence Graphs, and Manager Handoffs

## Current release

This release consolidates the current interlanguage research layer used by the
mathematical-manuscript translation programme. It reconciles the Fable and
ChatGPT Pro research record, reproduces the arithmetic of the current
Interslavic State C and unified marker packages, and delivers one common method
to eight persistent language-group management lanes.

The full editable research department, executable audit, exact automaton data
archives, extracted CSV/JSON/Markdown bodies, and lane-specific handoffs are in
`12_Interlanguage_Research_Department_and_Automata_v05_20260717.zip`.

## What the current model actually contains

Three mathematical objects have different jobs:

1. A typed, channel-separated evidence graph records provenance and routing
   from source to concept, form, evidence, and decision.
2. A rooted language-family or reader-cohort tree measures dependence,
   concentration, branch breadth, and diminishing returns from closely related
   witnesses.
3. A formal weighted automaton or transducer is appropriate only when an
   extraction process specifies an alphabet, states, transitions, a semiring,
   initial/final behavior, and path aggregation.

The preserved data packages historically use the word `automaton`, but their
current operational role is evidence-graph serialization and source routing.

## Reproduced findings

The audit reproduces the Interslavic State C snapshot with 1,229 ledger rows,
1,215 unique term IDs, 100 concept buckets, and 9,124 graph edges. Its branch
mass is East/West/South = 2341/223/239, giving effective branch count
`D1 = 1.7537043785`. The W0 filtered projection changes the mass to
2341/333/348 and `D1 = 1.993192`, but W0 remains unapplied candidate work.

The unified v6.2 package contains 15 lane rows, 1,522 marker rows, 6,088 edges,
and 362 concept rows. Its reported readiness value is exactly the formula
`100*m/(m+a+1)`, where `m` combines support and candidate mass and `a` is
adverse mass. Because candidate-only lanes can therefore score above 95, this
number is rejected as readiness, correctness, quality, or translation priority.

Both packages' output manifests verify. Neither package pins the complete
generation-input chain, and neither arithmetic result certifies linguistic
decisions.

## Operational method

Every manager now uses the same evidence rules across every mathematical work:

- start from controlled concepts and intended senses, not English strings;
- keep support, candidate, competitor, adverse, absence, and veto channels
  separate;
- distinguish concept-shelf evidence from row-verified witnesses;
- treat generated translations as consistency material, never native evidence;
- state the evidence unit, language/cohort partition, dependence model,
  provenance distribution, and missing data before reporting branch metrics;
- require source, sense, script/register, adverse-evidence, and review gates
  instead of scalar auto-promotion;
- preserve the pre-change state, applied diff, and unresolved reviewer question;
- reserve external/community status for actual external/community returns.

The eight management lanes are Slavic/Interslavic; Chinese/Japanese/Korean;
Spanish/French/Romance; English/Germanic; Turkic; Arabic/Persianate/RTL;
Malay/Southeast Asian/Pacific; and Horn of Africa/West Africa. These lanes own
translations for every work, while the research layer supplies shared method
and evidence controls.

## Status and limitations

This is a complete release of the current research-method package, not a claim
that any language or manuscript corpus is complete. No lane currently has an
accepted external/community review return. Human comprehension experiments,
symmetrically justified family/cohort trees, row-level context verification,
latent-pivot audits, and target-specific source expansion remain open.

The release is provided so that the reasoning, data, rejected metrics, scripts,
and management handoffs can be inspected and reused rather than remaining
inside transient AI sessions.
