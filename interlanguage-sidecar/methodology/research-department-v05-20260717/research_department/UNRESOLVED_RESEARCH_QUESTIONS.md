# Unresolved research questions

These are research gaps, not reasons to stop ordinary translation work that already has adequate source and QA infrastructure.

## Validation gaps

1. No lane has an accepted external/community review return.
2. No controlled human comprehension experiment has validated the bridge or register choices.
3. Existing intelligibility claims need speaker-language, prior-exposure, education, script, and register controls.
4. Internal AI triangulation needs continued error accounting, but it cannot substitute for points 1–3.

## Evidence-model gaps

1. Define a symmetric or explicitly justified family/cohort topology and branch lengths for each lane that uses dependence correction.
2. Define the evidence unit per calculation and prohibit mixed-unit arithmetic in code and schema validation.
3. Calibrate within-language/source saturation rather than assigning arbitrary “quality” products.
4. Separate provenance rank from numerical permitted-use weight.
5. Complete row-level context verification for concept-shelf writebacks.
6. Establish source-floor thresholds per target without making machine readability a gate against PDF-heavy or under-resourced traditions.
7. Define community-approved target distributions before any governance weighting.

## Formal-model gaps

1. If weighted automata are retained as more than a package name, define the input alphabet, transition behavior, semiring, initial/final weights, accepted behavior, and a task whose path semantics add value.
2. Decide whether extraction is best modeled as a finite-state transducer, a workflow DAG, a probabilistic graphical model, or a database provenance algebra; do not force one formalism across unrelated jobs.
3. Test whether edge-coverage PD improves source-acquisition decisions over simpler branch-first heuristics.
4. Specify uncertainty intervals or sensitivity bands for D1/KL when witnesses and tree structure are incomplete.
5. Clean the unified graph’s pseudo-concepts before it becomes an API source.

## Linguistic-model gaps

1. Run ILO or related neighborhood-overlap measurements on controlled concept/context sets.
2. Audit latent-English/pivot bias before using multilingual-model geometry.
3. Validate `FFRisk = FormSim × SemDist` against human error and reaction-time data.
4. Compare regularized-barycenter candidates with actual community and comprehension outcomes.
5. Determine when a global mathematical attractor beats a zonal form and when it merely reflects English/Latin dominance.
6. Complete non-Slavic proof-connective probes; the current 15-row connective result is not globally exhaustive.

## Lane-specific gaps

- **Slavic:** row-verify the long tail; resolve ring, ręd, jednako, and važiti through appropriate authority; complete symmetric dependence modeling; finish dual-script production gates.
- **CJK:** clean source manifests; expand language-specific native source bodies; formalize Simplified/Traditional, Hanja, and typography policies; retain local-standard status.
- **Romance:** fill specialist Noether gaps from specialist sources; test Spanish/French dominance; expand beyond current ES/FR-heavy evidence.
- **English/Germanic:** build independent non-English Germanic witness shelves; prevent English from acting as a hidden pivot for other managers.
- **Turkic:** execute format-relaxed source intake; define subbranches and script policies; test whether any bridge intervention is warranted.
- **Arabic/Persianate/RTL:** expand separate living-language evidence; finish RTL build invariants; retain false-sense traps.
- **Malay/SEA/Pacific:** separate unrelated sublanes; upgrade candidates to target-specific witnesses; avoid administrative pan-language inference.
- **Horn/West Africa:** build the target inventory and source floors from scratch; partition by actual families, standards, and scripts; develop community review paths.

## Interface gaps

1. Add automated JSON Schema validation to manager return pipelines.
2. Add source-hash and context-anchor verification.
3. Add a hard check that generated/draft sources cannot set `target_witness` or `external_certification` uses.
4. Add a hard check that a numeric branch statistic cannot be emitted without unit, partition, target distribution, and interpretation limit.
5. Add pre-change snapshot and diff verification to every applied terminology patch.
6. Define a shared concept-ID registry without making English glosses the identity key.

## Stop conditions for research claims

Stop and report a gap rather than promote when:

- the source sense is unresolved;
- a trap or homograph has no context window;
- support and competitors are collapsed;
- the evidence unit or deduplication key is unknown;
- the lane’s source floor is not met;
- the script/register invariants are undefined;
- an external/community claim is requested without external/community evidence;
- a scalar is being used to bypass hard gates.
