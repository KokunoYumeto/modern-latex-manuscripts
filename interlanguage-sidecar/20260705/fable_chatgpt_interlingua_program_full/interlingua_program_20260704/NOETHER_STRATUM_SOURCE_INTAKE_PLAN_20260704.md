# Noether-Stratum Source Intake Plan (plan only — no fetching without go)
2026-07-04. Target: the 21 C2 rows a curriculum shelf cannot witness — classical invariant-theory and older-algebra vocabulary (binary/ternary/biquadratic form, complete-system family, covariant/contravariant, transvection, resultant, elementary divisor, modulus, ground form, reduction…). These need era-appropriate specialist sources per branch.

## What to look for (per branch, in priority order)
Historical university algebra / invariant theory texts, 1880–1960, digitized:

- **Czech**: K. Petr, *Počet integrální*-era algebra texts; B. Bydžovský, *Úvod do algebry* / determinant-theory textbooks (uses klasická terminologie: invarianty, kovarianty, výslednice=resultant, elementární dělitelé); E. Weyr's matrix/determinant work. Library: **Kramerius** (kramerius5.nkp.cz, digitalniknihovna.cz) — public-domain scans with OCR.
- **Polish**: Mostowski & Stark, *Algebra wyższa* (PWN, has full classical terminology: wyznacznik, wielomian, niezmiennik=invariant, formy dwuliniowe); S. Zaremba's algebra lectures; older Lwów/Warszawa lecture scripts. Libraries: **Polona** (polona.pl), ICM/BWN, Delta/Wiadomości Matematyczne archives.
- **Croatian/Serbian**: Đ. Kurepa, *Viša algebra* (Zagreb/Beograd — the standard higher-algebra reference with prsten/polje/invarijanta vocabulary); Rad JAZU older algebra papers. Libraries: **digitalna.nsk.hr**, Matica srpska digital, NB Srbije.
- **Slovenian**: Plemelj-era lecture notes; Vidav, *Algebra* (older editions). Library: **dLib.si**.
- **Bulgarian**: Obreškov (Обрешков), *Висша алгебра* — classical resultants/invariants terminology. Library: национална библиотека / **COBISS.bg**, sci.bg archives.
- **Slovak**: Schwarz-era algebra texts; else cs sources double for terminology (explicit crosswalk note, not silent merging).

## Method (unchanged discipline)
Source-first intake per lane rules: download → hash → extract text → register in a shelf manifest (mirror of the 20260624 shelf format) → term-probe the 21 pending concepts → context windows → concept-shelf witnesses. Licenses: public-domain era preferred; else quote-length snippets only. Every file enters SOURCE_USE_POLICY category 2 (language_family_witness) at concept_shelf level.

## Expected yield

Residual gaps after this pass are likely genuine "concept never naturalized in branch X" findings — themselves publishable data points for the historical-stratum siting question.
