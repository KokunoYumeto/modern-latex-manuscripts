# URGENT DIRECTIVE FOR OTHER AI SESSIONS: LATEX SOURCE ANCHORS

UPLOAD EVERY PROJECT-RELEVANT CANONICAL LATEX SOURCE FILE YOU FIND.

DO NOT ONLY SUMMARIZE. DO NOT ONLY LIST LINKS. DO NOT ONLY SAY “FOUND SOURCES.” THE DELIVERABLE IS THE ACTUAL SOURCE-ANCHOR PACKAGE.

FOR EVERY LANGUAGE OR LANGUAGE FAMILY YOU ARE WORKING ON, COLLECT PUBLICLY DISTRIBUTED CANONICAL / SCHOLARLY / TECHNICAL LATEX SOURCES AT SCALE. THE TARGET IS HUNDREDS OF LATEX FILES PER LANGUAGE WHERE POSSIBLE, NOT FIVE TOKEN EXAMPLES.

PRIORITY LANGUAGES AND FAMILIES:

- INTERSLAVIC AND AUXILIARY / CONSTRUCTED INTERLANGUAGE WORK
- ALL NON-RUSSIAN, NON-UKRAINIAN SLAVIC LANGUAGES
- UKRAINIAN
- RUSSIAN
- POLISH, CZECH, SLOVAK, SLOVENE, CROATIAN, SERBIAN, BOSNIAN, BULGARIAN, MACEDONIAN, BELARUSIAN, LOWER/UPPER SORBIAN, MONTENEGRIN WHERE AVAILABLE
- PERSIAN / FARSI
- ARABIC
- CHINESE
- JAPANESE
- SPANISH
- FRENCH
- ROMANCE, GERMANIC, RTL, CJK, AND OTHER LANGUAGE-FAMILY BASELINES RELEVANT TO THE PROJECT

WHAT COUNTS:

- `.tex`, `.sty`, `.cls`, `.bib`, `.bbl`, `.ltx`, `.dtx`, `.ins`, AND CLOSELY RELATED LATEX SOURCE FILES
- ARXIV / PUBLIC GITHUB / PUBLIC UNIVERSITY / PUBLIC JOURNAL-SOURCE / PUBLIC CORPUS LATEX SOURCES
- MATH, LINGUISTICS, TECHNICAL, FORMAL, SCIENTIFIC, AND SCHOLARLY SOURCES
- SOURCES THAT SHOW REAL TARGET-LANGUAGE MATHEMATICAL OR TECHNICAL STYLE

WHAT TO PACKAGE:

- ONE ZIP PER LANGUAGE OR LANGUAGE FAMILY WHEN POSSIBLE
- A MANIFEST CSV/JSON FOR EACH ZIP WITH SOURCE URL, LANGUAGE, FILE COUNT, LICENSE/PROVENANCE WHEN KNOWN, AND NOTES
- KEEP RAW LATEX SOURCE FILENAMES WHERE USEFUL, BUT AVOID BROKEN WINDOWS PATH LENGTHS
- INCLUDE A README THAT SAYS WHETHER THE PACKAGE IS DIRECT SOURCE TEXT, URL-ONLY, OR MIXED
- IF YOU ONLY HAVE URLS, PACKAGE THE URL MANIFEST AND SAY DOWNLOAD FAILED OR NOT YET DONE

WHAT NOT TO DO:

- DO NOT CLAIM WITNESS STATUS FOR GENERATED TRANSLATIONS
- DO NOT TREAT INTERNAL GENERATED INTERSLAVIC/RUSSIAN/UKRAINIAN TRANSLATIONS AS INDEPENDENT CANONICAL LANGUAGE ATTESTATION
- DO NOT MIX SOURCE-ANCHOR CORPORA WITH GENERATED PROJECT OUTPUT WITHOUT CLEAR FOLDERS AND MANIFESTS
- DO NOT GIVE FIVE FILES AND CALL IT DONE

PUT THE RESULT ON GITHUB IN THE INTERLANGUAGE SIDECAR / SOURCE-ANCHOR AREA OR A CLEARLY NAMED BRANCH. IF YOU CANNOT PUSH, WRITE A ZIP AND A MANIFEST SOMEWHERE CODEX CAN SWEEP.

SHORT VERSION:

GET THE LATEX. GET A LOT OF IT. PACKAGE IT BY LANGUAGE. INCLUDE MANIFESTS. PUSH IT.
