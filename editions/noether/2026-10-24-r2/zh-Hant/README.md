# 埃米·諾特數學著作集：繁體字版

收錄第1—43篇論文、M. Deuring記錄的1929/30年冬季學期《超複量代數》講義、H. Kapferer論文及與E. Noether合作的補充、書目、短訊與書評目錄以及參與編著的書籍目錄。內容涵蓋不變量、理想、域、代數與表示論。

這是由簡體中文文本轉換繁簡字形的繁體字版，保留原有詞彙；未作臺灣、香港或澳門的區域語言本地化。

## 作者、翻譯與出處

原作者為Emmy Noether及各篇署名的共同作者；講義由M. Deuring記錄。中文底本由AI翻譯，繁體字本繼承R9 / ED0011中文文本及其詞彙。早期製作方為Manuscript Typesetting Project / OpenAI Codex；現存出處資料不足以確定其準確模型。R9中文彙編及繁體字轉換程式由OpenAI Codex——GPT-5.6 Sol，Ultra推理強度於2026-08-12製作；轉換採用opencc-python-reimplemented 0.1.7的s2t設定。2026-10-23—2026-10-24由AI製作的訂正與排版：OpenAI Codex——GPT-6 Astra，Ultra推理強度；2026-10-26：Claude Opus 5.5（Anthropic）。這不表示出版者親自翻譯，亦不表示經過獨立人工學術審閱。

其德文底本為ED0011/v047（2026-08-08）。早期中文文本見[2026-06-12彙編](https://doi.org/10.5281/zenodo.20836874)；[歷史多語種彙編](https://doi.org/10.5281/zenodo.20412587)保存相關版本。這些DOI不是當前GitHub版的新DOI。原刊資訊、署名與文獻引用見正文。
