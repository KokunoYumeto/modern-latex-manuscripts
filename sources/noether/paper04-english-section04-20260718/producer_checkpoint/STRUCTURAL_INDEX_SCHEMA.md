# Structural index schema

`STRUCTURAL_INDEX.jsonl` is the hierarchical authority for this bounded unit. Each JSON object has a stable `unit_id`, positive integer `record_revision`, nullable `supersedes`, evidence class, authority role, status, confidence, a `unit_type`, an exact R823 line span, a printed-page span, a parent ID, ordered child IDs, outbound cross-references, a target locator, a mandatory source-mapping uncertainty statement, and a review state. The section root also carries the exact continuation cursor.

The index is append-only after package freeze. Every initial object has explicit `record_revision: 1` and `supersedes: null`. A correction appends an object with the same stable `unit_id`, gives the next integer revision, names the prior record as `unit_id@revision` in `supersedes`, and explains the correction. Consumers resolve each stable ID to its highest revision before validating parent/child references. Duplicate stable IDs without this exact revision chain are invalid. A parent outside this bounded index and cross-references absent from the local ID set are external Paper 4 references; all locally named child IDs and local cross-references must resolve.
