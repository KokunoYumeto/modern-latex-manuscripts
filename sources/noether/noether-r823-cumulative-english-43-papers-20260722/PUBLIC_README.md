# Emmy Noether: R823-Synchronized English Numbered Papers

This package contains the inherited English translation of Emmy Noether's 43 numbered papers, updated to the current R823 German LaTeX authority.

- Coverage ends at R823 line 20967, the end of Paper 43.
- The separately appended German lecture beginning at R823 line 20968 is outside this package and has not been translated here.
- `Noether_R823_Cumulative_English_Workpass.tex` is the master source.
- `fragments/` contains the 48 source fragments required recursively by the master.
- `Noether_R823_Cumulative_English_Workpass.pdf` is the verified 407-page A4 reader.
- `SHA256SUMS.csv` is self-excluding and records every other public file in this package.

Build from the package root with two runs of `pdflatex Noether_R823_Cumulative_English_Workpass.tex`.

Publication must update the existing Noether GitHub corpus and Zenodo concept DOI `10.5281/zenodo.20412587`; it must not create a duplicate concept. Rights, attribution, accessibility, and release metadata remain under archive-maintainer control.
