# Emmy Noether, Paper 4 — English Introduction checkpoint

This bounded working checkpoint contains the English title apparatus, complete
Introduction, and complete Postscript of Emmy Noether's 1911 paper *Zur
Invariantentheorie der Formen von n Variabeln*.

Coverage is R823 German TeX lines 3559–3589. The next translation cursor is
R823 line 3591, §1. The reader PDF has two A4 pages and the package contains one
editable TeX unit.

The dedicated 1911 journal scan governs the printed title, byline, page-local
note identities, emphasis, ambiguous glyphs, and article boundary. R823 is the
routed editable German authority. A later searchable collected-work
reproduction and an inherited English candidate were used only as dependent
comparison witnesses. None of those source or candidate bodies is redistributed
here; their hashes and roles are recorded in `SOURCE_CONTROL_HASHES.csv`.

The leading “4.” is the project collection number and is explicitly disclosed
in the document; it is absent from the title printed in the 1911 journal. The
journal prints “Von Frl. Emmy Noether in Erlangen,” rendered here as “By Miss
Emmy Noether in Erlangen.” All sixteen page-local symbolic notes in the bounded
source are retained using page-qualified target labels.

This successor replaces an unpublished local checkpoint that incorrectly
treated the collected-work reproduction as the original witness. That earlier
package remains held and must not be published.

This is one machine-assisted, source-audited working unit. It is not the
complete paper, a critical edition, external peer review, mathematical
certification, community certification, or a rights determination.
