# Lessons learned: Paper 4 sections 6-7

1. Source-defect alerts are locators, not authority; each locus must be reopened against the original print.
2. A German source repair should propagate only where a target body is actually wrong. Section 6 required a German word-boundary fix but no target-body rewrite.
3. Diacritic changes on mathematical symbols require rendered inspection in every affected script, not only text extraction.
4. Internal mathematical recurrence can corroborate a source reading, but must remain distinct from independent source authority.
5. Source repair, target survival, build success, render QA, and linguistic certification are separate states.
6. Machine-readable structural, decision, and difficulty records make later cross-language repair survival testable.
