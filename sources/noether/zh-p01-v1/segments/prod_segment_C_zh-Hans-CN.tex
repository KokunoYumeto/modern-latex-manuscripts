我们把一个初始型连同所有由它通过对自身作缩并而产生的型定义为一个\glqq{}型列\grqq{}。根据上述定理，型列 $s_x^m t_x^n u_\sigma^\mu u_\tau^\nu$ 可以排列成一个矩形图式。依次推进时可得到：
\begin{enumerate}
\item 向右推进一列，得到所有由相邻的型经缩并 I 产生的型；
\item 向下推进一行，得到所有由上方的型经缩并 II 产生的型，因而也就得到所有由缩并产生的型。
\end{enumerate}

在这些前提下，关于化简子的定理可以按最一般的形式，并在如下定义下
\begin{center}
\glqq{}化简子是一个可化简的型列\grqq{}
\end{center}
表述如下：

\begin{center}
\srcspaced{若一个型列的初始型之所以可化简，是因为它的某一项由同一个化简子作缩并而产生，而该型列的终型又由这个同一项经缩并而产生，那么整个型列都是可化简的。}
\end{center}

还应列举以下进一步的化简方法：
\begin{enumerate}
\item 所谓\glqq{}双重化简\grqq{}，即以两种方式化简同一个型，以求得\srcspaced{高阶型之间的一个关系}；
\item \glqq{}同分解型作缩并\grqq{}，它一方面表现出\srcspaced{借助化简子进行}化简的特征，另一方面表现出\srcspaced{\glqq{}双重化简\grqq{}}的特征。
\end{enumerate}
