\section*{20. 绝对不可约性的一个代数判据}
\begin{center}
作者\\[0.25em]
哥廷根的埃米·诺特。\\[0.6em]
Math. Ann. 85（1922），第26--33页
\end{center}

设一个多项式的系数属于任意一个抽象定义的域。如果将系数域扩张到
一个代数闭域后，该多项式仍然不可约，就称它为\emph{绝对不可约的}
\srcfnmark{1)}。\srcfntext{1)}{E. Steinitz 在他的《域的代数理论》
（J. f. M. 137 (1910)，第167页）中证明了，每个域都能以本质上唯一的
方式扩张为代数闭域，即扩张为一个使每个一元多项式都能分解为一次因子的
域；由此他也给出了代数基本定理的有理对应形式。}\addtocounter{footnote}{1}
下文我将说明，与相对于一个给定域的不可约性不同，绝对不可约性可以
\emph{用代数方式}刻画；更确切地说，有如下定理：

\emph{对于每个具有 \(n\ge2\) 个变量和未定系数的多项式，都可以给它
对应一个关于这些系数和另外一些不定元的整有理、整系数函数，即可约性
形式；对于每个同次数的特殊多项式，绝对不可约的充要条件就是这个可约性
形式不恒等于零。} 换言之：\emph{对于每一组特殊的系数值，如果可约性
形式关于各不定元恒等于零，并且这组值不导致降次，那么相应的特殊多项式
就是可约的；反之亦然。}

如果不用多项式，而考察多一个变量的齐次形式，那么次数条件就由一个
更简单的条件取代，即系数系不恒等于零。

作为这个定理的直接推论，还可得到 A. Ostrowski 最先提出的结论
\footnote{《论代数量的算术理论》。Gött. Nachr. 1919，第279页
（引理见第296页）。-- 据我所知，对于由通常数构成的域，Ostrowski
也得到了上面的主定理；他将于近期发表有关研究。在我的证明安排中，
主定理对任意抽象定义的域都成立，这是因为对不定元构成的可约性形式
具有\emph{与具体选作基础的域无关的数系数}。}：

\emph{每个以代数数为系数的绝对不可约多项式，模包含其系数域的任意
有限代数域 \(\Omega\) 的每个素理想仍然不可约，至多只有 \(\Omega\)
中的有限多个素理想例外。特别地，\(\Omega\) 也可以是有理数域。}

关于相对整函数理论的进一步应用\footnote{D. Hilbert，《数学问题》。
Gött. Nachr. 1900，第253页，问题14。}，我拟在别处讨论。

1. 首先证明：\emph{每个具有 \(n\ge2\) 个变量和未定系数的多项式都
是绝对不可约的。} 令
\srcnumdisplay{(1)}{%
\begin{aligned}
F(x)&=\sum A_{i_1\ldots i_n}x_1^{i_1}\cdots x_n^{i_n} &&(i_1+\cdots+i_n\le l),\\
G(x)&=\sum B_{j_1\ldots j_n}x_1^{j_1}\cdots x_n^{j_n} &&(j_1+\cdots+j_n\le m),\\
H(x)&=F(x)G(x)=\sum C_{k_1\ldots k_n}(A,B)x_1^{k_1}\cdots x_n^{k_n} &&(k_1+\cdots+k_n\le l+m),
\end{aligned}
}
其中 (A) 和 (B) 表示不定元，而 (C(A,B)) 是 (A) 和 (B) 的
整系数双线性组合。因此，商
\(D=C(A,B)/C_{0\ldots0}(A,B)\) 是各商
\(A/A_{0\ldots0}\) 和 \(B/B_{0\ldots0}\) 的有理函数；但是这些函数的
个数大于其宗量的个数，因为前者为
\(\binom{l+m+n}{n}-1\)，而两组宗量的个数分别为
\(\binom{l+n}{n}-1\) 和 \(\binom{m+n}{n}-1\)，并且有
\[
\binom{l+m+n}{n}+1>
\binom{l+n}{n}+\binom{m+n}{n}
\quad\text{当 } n\ge2,\ l>0,\ m>0\text{ 时}.
\]
因此，诸 (D(A,B)) 之间至少存在\emph{一个}代数关系，从而诸
\(C(A,B)\) 之间也存在一个代数关系：
\srcnumdisplay{(2)}{%
\Phi(Z)\ne0\quad[\text{关于 }Z_{k_1\ldots k_n}\text{ 恒等}],\ 
\Phi(C(A,B))=0\quad[\text{关于 }A,B\text{ 恒等}],
}
其中 \(\Phi\) 表示一个整系数多项式。

因此，以\emph{不定元 (Z)} 为系数的多项式
\srcnumdisplay{(3)}{%
E(x)=\sum Z_{k_1\ldots k_n}x_1^{k_1}\cdots x_n^{k_n}
\qquad(k_1+\cdots+k_n\le l+m)
}
在 \(n\ge2\) 时必定\emph{绝对不可约}\srcfnmark{4)}。
\srcfntext{4)}{因为按照第2节的说法，不定元 (Z) 不是
\(\mathfrak P\) 的零点。}\addtocounter{footnote}{1}

2. 在代换 \(Z=C(A,B)\) 后关于 (A,B) 恒等于零的所有这些多项式
\(\Phi(Z)\) 构成一个\emph{多项式理想}\srcfnmark{5)}，
\srcfntext{5)}{这些总体通常称为模；但真正刻画它们的性质是：它们在
包含 \(\Phi_1\) 和 \(\Phi_2\) 时也包含 \(\Phi_1-\Phi_2\)，在包含
\(\Phi\) 时也包含 \(\Psi\Phi\)，其中 \(\Psi\) 是 (Z) 的任意整系数
多项式；这实际上是理想性质。}\addtocounter{footnote}{1}
更确切地说，构成一个\emph{素理想 \(\mathfrak P\)}；因为如果借助这个
代换，一个乘积 \(\Phi_1\Phi_2\) 恒等于零，那么至少有一个因子恒等于
零。由于(2)关于 (A,B) 恒等成立，所以对于每一组特殊值 (A,B)，
(2)仍然成立；这里 (A,B)，因而 \(\Gamma=C(A,B)\)，可以是任意一个
域中的量。\emph{所以，在某个扩域中可约的每个多项式的系数
\(\Gamma\) 都满足条件 \(\Phi(\Gamma)=0\)，即为 \(\mathfrak P\) 的
零点，}也就是 \(\mathfrak P\) 的有限多个基多项式的公共零点；现在还须
\emph{证明逆命题}。

为此要注意，如果通过引入一个新变量 (y)，把(1)中的多项式变为
次数分别为 (l,m,l+m) 的齐次形式 (F(x,y),G(x,y),H(x,y))，那么
 (A,B,C) 之间的一切关系仍然保持不变。因此，如果某些系数
\(\Gamma\) 使例如 \(F(x,y)\)\footnote{把
\(F,G,\ldots,f,g,\ldots\) 中的不定元换成特殊值系而得到的多项式
和形式，下文一律以加上横线来表示：
\(\bar F,\bar G,\ldots,\bar f,\bar g,\ldots\)。} 成为 (y) 的一个
幂，那么这些系数也成为 \(\mathfrak P\) 的零点；而从齐次形式转回非齐次
多项式时，与此相应的是 \(\bar H(x)\) 的降次，并不对应于分解。下文将
证明，除这种降次外，逆命题总是成立；特别是，\emph{对于齐次形式，只要
各 \(\Gamma\) 不全为零，逆命题就毫无例外地成立；换言之，
\(\mathfrak P\) 的每个零点都能由参数表示 \(\Gamma=C(A,B)\) 给出，
其中 (A,B) 是某个扩域中的量}\srcfnmark{7)}。
\srcfntext{7)}{由素理想 \(\mathfrak P\) 定义一个不可约代数构形这一
性质，可以推出 \(\mathfrak P\) 的零点“在一般情形下”由参数表示给出。
但众所周知，这并不能推出参数表示对于每一组特殊值都不失效；我最初忽略
了这一点，A. Ostrowski 早已向我指出。这里给出的证明建立在更初等的
概念上。}\addtocounter{footnote}{1}

我将通过直接构造有限多个函数 \(\Phi(Z)\) 来完成这个证明。具体说，
借助 Kronecker 代换
\[
 x_\lambda=\xi^{d^{\,n-\lambda}}\text{\srcfnmark{8)}}
\]
我把(1)中的多项式对应到\emph{一个}变量的多项式；指出其指数中会出现
空缺，再通过构造相应系数的范数，得到函数 \(\Phi(Z)\) 以及所求判据。

\srcfntext{8)}{Festschrift，第11页。}
\addtocounter{footnote}{1}
3. 令：
\srcnumdisplay{(4)}{%
\begin{aligned}
d&=l+m+1; &\qquad i&=i_1d^{n-1}+i_2d^{n-2}+\cdots+i_n;\\
j&=j_1d^{n-1}+\cdots+j_n; &\qquad k&=k_1d^{n-1}+\cdots+k_n.
\end{aligned}
}
借助 Kronecker 代换，(1) 中的多项式 $F,G,H$ 分别对应于多项式
\srcnumdisplay{(5)}{%
\begin{aligned}
 f(\xi)&=\sum A_{i_1\ldots i_n}\xi^i &&(i_1+\cdots+i_n\le l),\\
 g(\xi)&=\sum B_{j_1\ldots j_n}\xi^j &&(j_1+\cdots+j_n\le m),\\
 h(\xi)&=\sum C_{k_1\ldots k_n}(A,B)\xi^k &&(k_1+\cdots+k_n\le l+m).
\end{aligned}
}
众所周知，这个对应是\emph{一一对应}，因为对于 (5) 中出现的所有
\emph{（诱导）}指数，由 $k=0$ 也可推出
$k_1=0,\ldots,k_n=0$；因而由 $i+j=i'+j'$ 还可推出
$i_1+j_1=i'_1+j'_1;\ldots;i_n+j_n=i'_n+j'_n$。所以，只有当相应的
$x_1^{i_1}\cdots x_n^{i_n}x_1^{j_1}\cdots x_n^{j_n}$ 也产生相同的
指数时，不同的乘积 $\xi^i\xi^j$ 才可能产生同一个指数 $\xi^k$。
于是得到：
\srcnumdisplay{(6)}{%
h(\xi)=f(\xi)g(\xi),
}
而且，如果关系 (6) 成立，并且 $f(\xi)$ 与 $g(\xi)$ 中不出现不同于
诱导指数的指数，那么反过来可得
\srcnumdisplay{(7)}{%
H(x)=F(x)G(x).
}
这里，\emph{$f(\xi)$ 与 $g(\xi)$ 的诱导指数中确实存在空缺}。
事实上，$f(\xi)$ 的最高指数为 $ld^{n-1}$，次高指数为
$(l-1)d^{n-1}+d^{n-2}$；二者之差
$d^{n-2}(d-1)>1$，因为 $d=l+m+1\ge3$ 且 $n\ge2$；对于
$g(\xi)$ 也是如此。

对不定元 $A,B$ 成立的关系 (6) 与 (7)，对于 $A,B$ 的每个特定
值组仍然成立。为了使次数保持不变，我借助变元 $\eta$ 与 $y$
将 (6) 和 (7) 齐次化。\emph{因此，齐次形式 $H(x,y)$ 在某个
代数扩张域中分解，当且仅当相应的二元形式 $h(\xi,\eta)$ 在该域中
能够分解为两个因子，并且这些因子中不出现不同于诱导指数的指数。}

4. 为了实施第 2 节末尾所述的范数构造，令
\[
 a_1,b_1;\ldots; a_p,b_p;\quad a_{p+1},b_{p+1};\ldots; a_{p+q},b_{p+q}
\]
表示新的不定元。令
\srcnumdisplay{(8)}{%
\begin{aligned}
 \varphi(\xi,\eta)&=(a_1\xi+b_1\eta)\cdots(a_p\xi+b_p\eta)
     =r_p\xi^p+r_{p-1}\xi^{p-1}\eta+\cdots+r_0\eta^p,\\
 \psi(\xi,\eta)&=(a_{p+1}\xi+b_{p+1}\eta)\cdots(a_{p+q}\xi+b_{p+q}\eta)
     =s_q\xi^q+s_{q-1}\xi^{q-1}\eta+\cdots+s_0\eta^q,\\
 \chi(\xi,\eta)&=\varphi(\xi,\eta)\psi(\xi,\eta)
     =t_{p+q}\xi^{p+q}+t_{p+q-1}\xi^{p+q-1}\eta+\cdots+t_0\eta^{p+q};
\end{aligned}
}
这里 $r,s,t$ 分别表示齐次化的基本对称函数；也就是说，它们是关于
$a,b$ 各列分别为线性的对称函数，并且每个在各列中齐次且同维数的
整系数对称函数，都能由它们整式地且以整数系数构成，而且这种构成
方式是唯一的。

现在引入另外的不定元 $u_{\mu\nu}$，并构造线性形式
\srcnumdisplay{(9)}{%
\zeta(u,a,b)=\sum u_{\mu\nu}r_\mu s_\nu,
}
其中求和遍及预先给定的指标 $\mu$ 与 $\nu$。将 $\zeta(u)$ 与所有
通过置换序列 $a,b$ 而产生、且与 $\zeta(u)$ 及彼此均不相同的共轭
量相乘——也就是说，把 $\zeta(u)$ 看作由 $r_\mu(a,b)$ 与
$s_\nu(a,b)$ 所生成的域中的函数时，取它关于由 $t(a,b)$ 所生成
的域的范数 $N(\zeta(u))$——所得结果是所有序列 $a,b$ 的一个
整系数对称函数，它在每个序列中齐次且同维数。因此，根据上面的
结论，它是 $t(a,b)$ 与 $u_{\mu\nu}$ 的一个唯一确定的整系数
整函数：
\srcnumdisplay{(10)}{%
N(\zeta(u,a,b))=T(t(a,b),u)\qquad[\text{关于 }a,b,u\text{ 恒等}].
}
同样的论证表明，还可得到
\[
N(z-\zeta(u))=z^\delta+T_{\delta-1}(t,u)z^{\delta-1}+\cdots+T(t,u)
\qquad[\text{关于 }a,b,u,z\text{ 恒等}],
\]
其中所有 $T$ 都表示 $t$ 与 $u$ 的整系数整函数。这个恒等式的
两边在 $z=\zeta(u)$ 时都消失；而且，由于基本对称函数
$r(a,b),s(a,b)$ 在代数上独立，当依照 (8) 将 $t(a,b)$ 置为
$r$ 与 $s$ 的一个整系数双线性组合 $w(r,s)$，并将 $\zeta(u)$
视为 $r$ 与 $s$ 的函数时，这种消失关于 $r,s$ 恒等成立。因此
得到
\srcnumdisplay{(11)}{%
\zeta(u)^\delta+T_{\delta-1}(w(r,s),u)\zeta(u)^{\delta-1}+\cdots+T(w(r,s),u)=0
\quad[\text{关于 }r,s,u\text{ 恒等}].\,\text{\textsuperscript{9)}}
}
\srcfntext{9)}{当 (9) 中的求和遍及所有指标时，(11) 表示 Kronecker
对 Gauss 定理的推广，而且本质上采用了 Kronecker 的证明编排
（Zur Theorie der Formen höherer Stufen, Berliner Ber. 1883,
Werke, 2, S.~417）。}
\addtocounter{footnote}{1}

恒等式 (10) 与 (11) 对于 $a,b$ 的所有特定值组 $\alpha,\beta$，
或者相应地对于 $r,s$ 的所有特定值组 $\varrho,\sigma$，仍然成立。
特别是，如果选取 $\varrho,\sigma$，使所有乘积
$\varrho_\mu\sigma_\nu$ 都消失——这里 $\mu,\nu$ 表示 (9) 中出现的
指标——从而 $\zeta(u)$ 在代入这些值后消失，那么令
$w(\varrho,\sigma)=\tau$，由 (11) 得：
\srcnumdisplay{(12)}{%
T(\tau,u)=0\qquad[\text{关于 }u\text{ 恒等}].
}

反过来，设 $\tau_0,\ldots,\tau_{p+q}$ 是不全为零的
\emph{值组，并且满足 (12)。} 由于在某个代数扩张域中存在分解
\srcnumdisplay{(12)}{%
\bar\chi(\xi,\eta)=\tau_{p+q}\xi^{p+q}+\cdots+\tau_0\eta^{p+q}
=(\alpha_1\xi+\beta_1\eta)\cdots(\alpha_{p+q}\xi+\beta_{p+q}\eta),
}
其中任何一个因子中的 $\alpha$ 与 $\beta$ 都不同时为零
\srcfnmark{10)},\srcfntext{10)}{这个（有理的）“代数学基本定理”
是一个存在性定理，第 2 节末尾所说的逆命题无例外成立，正是以它
为依据。}\addtocounter{footnote}{1} 但某些 $\alpha$ 或 $\beta$
可以为零，于是 $\tau=t(\alpha,\beta)$。把这些值代入 (10)，
并利用 (12)，可知 $\zeta(u,\alpha,\beta)$ 或它的某一个共轭
因子关于 $u$ 恒等消失。因此，在适当重新编号 $\alpha,\beta$ 后，
若令 $r(\alpha,\beta)=\varrho$、$s(\alpha,\beta)=\sigma$，
这就意味着 $\bar\chi(\xi,\eta)$ \emph{至少容许一种分解：}
\srcnumdisplay{(13)}{%
\bar\chi(\xi,\eta)=\bar\varphi(\xi,\eta)\bar\psi(\xi,\eta)
=\sum \varrho_\kappa\xi^\kappa\eta^{p-\kappa}\cdot\sum \sigma_\lambda\xi^\lambda\eta^{q-\lambda},
}
\emph{使得 $\zeta(u)$ 中出现的所有乘积
$\varrho_\mu\sigma_\nu$ 都消失，但 $\varrho$ 或 $\sigma$ 并非
全部为零。}

5. 现在令 (8) 中的次数 $p,q$ 分别等于 $ld^{n-1}$ 和 $md^{n-1}$，即等于 (5) 中 $f(\xi)$ 和 $g(\xi)$ 的次数。把指标 $\mu,\nu$ 分拆为 $\mu^{(1)},\nu^{(1)},\mu^{(2)},\nu^{(2)}$；其中 $\mu^{(1)}$ 遍历 $f(\xi)$ 中缺失的所有指数，$\nu^{(1)}$ 遍历 $\psi(\xi,\eta)$ 中 $\xi$ 的所有指数；相应地，$\nu^{(2)}$ 遍历 $g(\xi)$ 中缺失的所有指数，$\mu^{(2)}$ 遍历 $\varphi(\xi,\eta)$ 中 $\xi$ 的所有指数。再令
\[
 e(\xi)=\sum Z_{k_1\ldots k_n}\xi^k\qquad(k_1+\cdots+k_n\le l+m)
\]
表示与多项式 (3) 相应的一元多项式；
\[
 S(Z,u)
\]
表示关于 $Z$ 和 $u$ 的整系数多项式；它由 $T(t,u)$ --- 即 (10) 中唯一确定的右端，其中 (9) 的求和遍及上述指标 $\mu^{(1)},\nu^{(1)},\mu^{(2)},\nu^{(2)}$ --- 通过把 $t$ 替换为系数 $Z$ 以及 $e(\xi)$ 的相应零点而得到。

现在把 $r,s$ 替换为 $f(\xi)$ 和 $g(\xi)$ 的系数 $A,B$ 以及相应零点，则在指定的求和下，经此代入后 $\zeta(u)$ \emph{消失}。此外，$t=w(r,s)$ 变为 $h(\xi)$ 的系数 $C(A,B)$ 及其相应零点；因此 $T(t,u)$ 变为 $S(C(A,B),u)$。由恒等式 (11) 便得到
\srcnumdisplay{(14)}{%
S(C(A,B),u)=0.\qquad[\text{关于 }A,B,u\text{ 恒等}].
}
由于 (14) 对每一个特化值系都保持成立，所以在一个\emph{扩张域中分解为两个因子}的这种特化 $\bar H(x)$ 或一般的 $\bar H(x,y)$，其系数 $\Gamma=C(A,B)$ 满足条件
\srcnumdisplay{(15)}{%
S(\Gamma,u)=0\qquad[\text{关于 }u\text{ 恒等}].
}

反过来，如果多项式 $\bar H(x)$，或形式 $\bar H(x,y)$ 的不全为零的系数 $\Gamma$ 满足条件 (15)，那么根据上面的论述，这等价于 $T(\tau,u)=0$，其中 $\tau$ 表示 $\bar h(\xi,\eta)$ 的全部系数。因而根据 (13)，在 $\Gamma$ 的一个扩张域中存在分解：
\[
 \bar h(\xi,\eta)=\bar f(\xi,\eta)\cdot\bar g(\xi,\eta),
\]
其中，由于指定的求和，$\bar f$ 和 $\bar g$ 中不出现任何不同于诱导指数的指数；于是存在关系
\[
 \bar H(x,y)=\bar F(x,y)\cdot\bar G(x,y).
\]
由此，只要在 $y=1$ 时没有因子变为零次，也就是说，特别是在 $\Gamma$ 不会导致 $\bar H(x)$ 次数降低时，还可得到关系
\[
 \bar H(x)=\bar F(x)\cdot\bar G(x).
\]

\emph{因此，条件 (15) 是 $\bar H(x,y)$ 在一个扩张域中分解为两个因子的充要条件；在排除次数降低时，它也是 $\bar H(x)$ 作这种分解的充要条件。}

由此还可推出，$S(Z,u)$ 不可能关于 $Z$ 和 $u$ 恒等消失，因为第 1 节已经证明，当 $n\ge2$ 时，以不定元为系数的多项式，因而也包括相应的多一个变量的齐次形式，都是绝对不可约的。因此，若用 $U$ 表示 $u$ 的幂积，则有：
\[
S(Z,u)=\sum \Phi_\lambda(Z)U_\lambda,
\]
其中 $\Phi_\lambda(Z)$ 根据 (14) 成为属于 $\mathfrak P$ 的多项式。\emph{由此证明了，$\mathfrak P$ 除了由参数表示 $\Gamma=C(A,B)$ 给出的零点以外，没有其他零点；这里 $A$ 和 $B$ 属于 $\Gamma$ 的一个代数扩张域。}这样便证明了第 2 节末尾所陈述的逆命题。

6. \emph{现在可以直接表述绝对不可约性的条件。}为此，只需把 (3) 中 $E(x)$ 的次数以所有可能的方式分解为两个正数之和 $l+m$，并为每个分解构造形式 $S(Z,u)$。这些形式的乘积
\srcnumdisplay{(16)}{%
R(Z,u)=\prod S(Z,u)
}
便构成 $E(x)$ 的\emph{可约性形式}；因为根据上面的论述，$\bar E(x)$ 或 $\bar E(x,y)$ 的每一次\emph{分解}，都对应于 (16) 的一个因子消失，反过来也成立。这样便证明了\emph{引言中提出的主定理}，同时也说明了如何用有限多个步骤实际构造可约性形式。

7. 由\emph{可约性形式的存在性} (16)，立即可以推出引言中提到的\emph{奥斯特罗夫斯基定理}。设
\[
 \bar E(x)=\sum \Gamma_{k_1\ldots k_n}x_1^{k_1}\cdots x_n^{k_n}
 \qquad(k_1+\cdots+k_n\le v)
\]
是一个以代数整数 $\Gamma$ 为系数的绝对不可约多项式；$\frK$ 表示包含所有 $\Gamma$ 的一个有限代数数域，$\mathfrak p$ 表示 $\frK$ 中的一个素理想。

那么，为 $\bar E(x)$ 的准确次数构造的可约性形式 $R(Z,u)$，在代入 $Z=\Gamma$ 后仍然\emph{不为零}；即
\[
 R(\Gamma,u)=\sum P_\lambda U_\lambda\ne0\qquad[\text{关于 }u\text{ 恒等}].
\]
因而，理想 $\mathfrak r=(P_1,P_2,\ldots)$ 只能被 $\frK$ 中\emph{有限多个}素理想整除。因此，如果 $\mathfrak p$ 不同于这有限多个素理想，那么 $R(\Gamma,u)$ 模 $\mathfrak p$ 不会恒等消失；又因为模 $\mathfrak p$ 的剩余类仍然构成一个域，所以可以推出，$\bar E(x)$ \emph{模 $\mathfrak p$ 不可约}，更准确地说，是绝对不可约的。$\bar E(x,y)$ 也是如此，因此模 $\mathfrak p$ 时同样不会发生次数降低。

如果 $\bar E(x)$ 的系数是代数分数，还必须要求 $\mathfrak p$ 不同于整除公分母 $\Delta$ 的有限多个素理想；模其余所有素理想时，可以用 $\Delta\cdot\bar E(x)$ 代替 $\bar E(x)$，从而满足上述假设。定理得证。
