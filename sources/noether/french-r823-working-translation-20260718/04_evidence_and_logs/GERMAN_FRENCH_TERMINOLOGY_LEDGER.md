# Registre terminologique allemand → français (R823)

Statut : canon de production français, version du 17 juillet 2026. Le sens est déterminé par R823; les sources françaises natives contrôlent la forme et le registre. Les anciennes traductions françaises ne sont que mémoire secondaire.

## Règles de registre

1. Le français reste une langue cible autonome : aucune forme pan-romane n'est introduite pour augmenter une intercompréhension supposée.
2. Les mots historiques de Noether sont conservés lorsqu'ils désignent une construction propre au texte, mais une définition moderne exacte est donnée lorsqu'un calque serait trompeur.
3. Les oppositions de sens sont maintenues : irréductible/indécomposable, isomorphe/semblable, idéal premier/idéal primaire, théorème principal/théorème fondamental.
4. Les exemples natifs SGA/SMF/Bourbaki servent au registre, non à modifier le contenu de R823.
