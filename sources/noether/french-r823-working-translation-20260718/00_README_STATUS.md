
# Noether French R823 working translation

## Public status

This package contains the 494-page French cumulative working translation of the
R823 Emmy Noether corpus, its exact editable TeX build closure, the hash-pinned
German R823 authority, build records, terminology and unit-parity ledgers, and
the evidence used by the completion gate.

Declared scope: Papers 1-43, the complete 31-section lecture book, the
Kapferer-Noether item, bibliography, notices, reviews, and books prepared with
Noether's participation. The hardened archive replay passed all 35 declared
checks after its adversarial parser/evidence test suite passed.

This is a source-reconciled working translation. It is not a critical edition,
native-French peer review, semantic proof of every translation choice,
mathematical proof checking, or a guarantee that every symbol is error-free.
The record deliberately exposes its evidence so later reviewers can correct it.
