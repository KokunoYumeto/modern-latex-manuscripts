\section*{26. 代數數域中理想論的抽象構造}

\begin{center}
J. Ber. d. DMV 33 (1924), S. 102
\end{center}

4. E. Noether，哥廷根：代數數域中理想論的抽象構造。

這裡給出了若干抽象性質；它們同代數數域中的理想論完全等價，因而刻畫出所有擁有這種理想論的環。這些環是具有單位元且無零因子的環，在其中雙鏈條件（Doppelkettensatz）成立——每一條由理想組成的除子鏈（Teilerkette）都在有限步後中止；對於每個非零理想，模該理想的每一條倍數鏈（Vielfachenkette）也同樣在有限步後中止——並且這些環相對於它們的商域是整閉的。若去掉後一假設，則得到關於有限 order（此處為數論中的環論概念）中理想論的若干定理，其中一部分已見於 Dedekind（第 3 版），但未給出證明。

詳述將發表於 \emph{Mathematische Annalen}。
