Unter der \emph{Darstellung einer Gruppe} -- in einem vorgegebenen Körper $P$ -- versteht man bekanntlich das Folgende: Den Elementen $a,b,\ldots$ der Gruppe $\mathfrak{G}$ werden Matrizen $A,B,\ldots$ mit Koeffizienten aus $P$ zugeordnet, derart dass dem Produkt $ab$ das Produkt $AB$ entspricht; das System der Matrizen wird ein homomorphes Bild der Gruppe. Mit dieser Darstellung ist zugleich eine Darstellung des \guillemotleft Gruppenrings\guillemotright{} gegeben, der aus allen \guillemotleft Gruppenzahlen\guillemotright, d. h. allen linearen Verbindungen $a\alpha+b\beta+\cdots+c\gamma$ besteht, wo $a,b,\ldots,c$ alle Kombinationen von je endlich vielen Gruppenelementen, $\alpha,\beta,\ldots,\gamma$ entsprechend von je endlich vielen Elementen aus $P$ durchlaufen (wobei die $a,b,\ldots,c$ als linear unabhängig betrachtet werden und die Multiplikation durch Gruppenmultiplikation und Rechengesetze definiert ist). Die Darstellung des Gruppenrings wird zugleich homomorph inbezug auf Addition; die Darstellung der Gruppen ordnet sich so dem allgemeinen Problem der \emph{Darstellung der Ringe} unter, wobei Homomorphie inbezug auf Addition und Multiplikation verlangt wird.
