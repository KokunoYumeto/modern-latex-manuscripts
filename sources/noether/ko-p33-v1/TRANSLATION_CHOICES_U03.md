# P33-KO-U03 translation choices

This file records translator choices, not checking or certification.

- `Darstellung einer Gruppe` and `Darstellung der Ringe` are rendered `군의 표현` and `환의 표현`.
- `Gruppenring` is rendered `군환` (`群環`); historical `Gruppenzahl` is rendered `군수` (`群數`) and retained in quotation marks.
- `homomorphes Bild` is rendered `준동형상`; `Homomorphie` is rendered `준동형성`.
- The source's range clause is rendered as arbitrary finite selections of group elements and corresponding coefficients from $P$.
- `Rechengesetze` is rendered `연산법칙` without expanding a list absent from the source.
- This is an unchecked ko-KR translation. No ko-KP, source, Korean-review, specialist, or external validation is claimed.
