# P33-KO-U06 translation choices

This file records translator choices, not checking or certification.

- Ideals and modules viewed additively are rendered `아이디얼과 가군 ... 덧셈에 관한 아벨군`.
- `Darstellungsmodul` is rendered `표현가군`; `Modulklasse` retains `가군류`.
- `Satz über das direkte Produkt` is rendered `직접곱 정리`; `Kompositionsreihensatz` is `합성열 정리`.
- `Reduktion` retains `환원`; the block matrix is preserved without normalization.
- `Faktorgruppen` retains U05's `인자군`; `irreduzible Darstellung` is rendered `기약 표현`.
- This is an unchecked ko-KR translation. No ko-KP, source, Korean-review, specialist, or external validation is claimed.
