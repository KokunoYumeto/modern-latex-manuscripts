# P33-KO-U07 translation choices

This file records translator choices, not checking or certification.

- `Diagonaldarstellungen` is rendered `대각표현`; equivalence of representations is `표현의 동치`.
- `Zerfallen` is rendered quoted `분해`; `unzerfällbare Bestandteile` is rendered `직접분해 불가능한 성분`, kept distinct from U06's `기약 표현`.
- `Satz vom direkten Produkt` retains `직접곱 정리`.
- The block-diagonal matrix is preserved without normalization; `reduzieren` retains `환원되다`.
- This is an unchecked ko-KR translation. No ko-KP, source, Korean-review, specialist, or external validation is claimed.
