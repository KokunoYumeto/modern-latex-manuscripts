# Emmy Noether R823 source-synchronized components

This bundle collects bounded translation components reconciled to the current
R823 German authority and admitted only after their stated build, manifest,
and visual-QA gates passed. It supplements, rather than replaces, the full
multilingual cumulative working readers.

## English components

Standalone English components are included for Papers 5, 7, 10, 18, 20, 25,
26, 27, 28, 29, 36, and 37. Each paper directory contains editable TeX, a
compiled PDF, the German authority and prior-English controls used by that
task, correction or disposition records, build/visual evidence, and a
verified local manifest. These twelve papers are component-ready. The full
English cumulative reader remains the older RA10 working branch and has not
yet been rebased paper by paper to R823.

The six additions in this 2026-07-18 package are Papers 5, 7, 18, 25, 27,
and 36. Their package manifests contain 88 checked rows with zero hash
failures; their final TeX builds report no warning, box, missing-character,
undefined-control, or fatal-error diagnostics; and all eleven rendered pages
were inspected. These checks establish bounded component integrity, not
independent human certification of the entire English corpus.

## CJK components

Papers 26 and 36 are included in Simplified Chinese, Traditional Chinese,
Japanese, and Korean, with German R823 controls. Simplified Chinese and
Japanese were recovered from existing cumulative readers and reconciled for
these units. Traditional Chinese is a controlled generic script/register
adaptation, not a Taiwan- or Hong-Kong-localized edition. Korean is working
translation coverage. No external native-language signoff is claimed.

## Slavic book-front component

The title/introduction unit of Noether's lecture-book material is included in
Ukrainian, Russian, Interslavic Latin, and deterministic Interslavic Cyrillic.
All four three-page outputs built and passed the package's internal structural
and visual checks. This is 1 of 32 core book units; the next cursor is
`BOOK_S01`. It is not a complete book translation or community certification.

## Boundaries

Paper-level words such as `complete`, `closed`, or `ready` inside component
logs apply only to the explicitly bounded paper or unit. Paper 3 was still in
production when this package was sealed. French, Spanish, and other language
rebases remain separate active lanes. Nothing here is a critical edition,
whole-corpus source-faithfulness certificate, synchronized multilingual
corpus, native-language approval, or publication-grade proofreading.
