\section*{26. 代数体におけるイデアル論の抽象的構成}

\begin{center}
J. Ber. d. DMV 33 (1924), S. 102
\end{center}

4. E. Noether, ゲッティンゲン：代数体におけるイデアル論の抽象的構成。

代数体におけるイデアル論と完全に同値であり、したがってそのようなイデアル論をもつすべての環を特徴づける抽象的性質が示された。それは、単位元をもち零因子をもたない環であって、二重鎖条件（Doppelkettensatz）が成り立つもの、すなわちイデアルからなる任意の約イデアル鎖（Teilerkette）が有限で止まり、また零イデアルと異なる任意のイデアルを法として任意の倍イデアル鎖（Vielfachenkette）も有限で止まるもの、かつその商体に関して代数的に整閉であるものである。最後の仮定を外すと、有限オーダー（order）におけるイデアル論についての定理が得られ、その一部は Dedekind（第3版）にすでに証明なしで見られる。

詳しい叙述は \emph{Mathematische Annalen} に現れる予定である。
