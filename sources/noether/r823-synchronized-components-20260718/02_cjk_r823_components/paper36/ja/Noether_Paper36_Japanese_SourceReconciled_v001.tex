\section*{36. イデアル微分と共役差積}

\begin{center}
\emph{J. Ber. d. DMV 39 (1930), S. 17}
\end{center}

2. E. Noether，ゲッティンゲン：イデアル微分と共役差積。

代数的数体の共役差積を，定義イデアルの\emph{微分商}として捉える方法を示す。この定義が通常の定義と一致することは，それ自体興味ある構造定理から従う。これらの構造定理は，類似の意味でラグランジュの補間公式の一般化をなす。

詳しい叙述は \emph{Mathematische Annalen} に掲載される予定である。
