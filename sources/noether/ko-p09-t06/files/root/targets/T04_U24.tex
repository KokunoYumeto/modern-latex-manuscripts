$\mathfrak G$는 다음과 같은 \emph{모든 양}으로 이루어진다고 하자.
\[
\begin{array}{@{}l@{\quad}c@{}}
(1)& z=\alpha+g_1(\eta)\cdot\eta_1+g_2(\eta)\cdot\eta_2+\cdots+g_t(\eta)\cdot\eta_t.
\end{array}
\]
\emph{여기서 $\alpha$는 모든 대수적 정수를, $\eta_1\cdots\eta_t$는 모든 기저의 수를 두루 취하며, $g_1(\eta)\cdots g_t(\eta)$는 $\eta_1\cdots\eta_t$의 각 고정된 조합마다 서로 독립적으로 $\eta$의 모든 정수적 대수함수를 두루 취한다.}\srcfn{***)}{모듈 성질은 양 $z-\alpha$에 성립한다.}
