# Machine-readable evidence contract

- CSV files are UTF-8 without BOM, rectangular, and begin with a stable public record ID, positive append-only revision, and explicit status. Spreadsheet formula-injection prefixes are forbidden.
- JSONL files contain one JSON object per nonblank line, have no duplicate keys, and use stable public IDs with append-only positive revisions.
- Source alignment, formula/symbol/note comparison, terminology, adverse-witness evidence, structural coverage, difficulty/failure history, source controls, build evidence, render evidence, and artifact receipts remain distinct evidence types.
- R823 is the editable German routing authority. The original 1911 print governs the four disputed dotted complementary-symbol occurrences and the inclusive `rho <= n` endpoint where R823 is internally inconsistent. The inherited English TeX is comparison-only.
- Excluded source bodies, scans, scan renders, inherited-English bodies, raw logs, private paths, and coordination records are represented only by public-safe descriptions, byte counts, and hashes.
- A mechanical `PASS` closes only the named bounded gate. It is not mathematical certification, critical editing, independent human review, peer review, rights clearance, accessibility certification, or publication action.
