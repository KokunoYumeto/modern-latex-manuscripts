
# Visual evidence rights and disposition

The package publishes eight project-generated target-reader page renders: four `zh-Hans-CN` pages and four controlled-generic `zh-Hant` pages. Each record binds the parent PDF, page, full-page pixel box, dimensions, density, rotation, image hash, structural work ID, QA state, and publication disposition.

Five German source-control renders are represented by metadata, hashes, dimensions, page numbers, and QA dispositions only. Their pixels are deliberately absent because this release does not assert redistribution rights over that source-control text. No source scans or source-scan crops are included.
