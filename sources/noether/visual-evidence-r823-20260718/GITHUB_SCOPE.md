GitHub mirrors the complete machine-readable image index, reconciliation
summary, and upload manifest. The 3,024 binary images remain in the Zenodo ZIP
to avoid adding hundreds of megabytes of reproducibility imagery to ordinary
Git history. The index supplies each image's public ZIP path, byte count,
SHA-256, dimensions, role, linked output page/unit, parent-asset binding,
rights classification, and publication disposition.

The images are render and review witnesses. They do not independently certify
mathematical correctness, translation quality, source fidelity, or
native-language acceptance.
