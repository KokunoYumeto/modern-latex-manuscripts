# Rights and attribution: Noether Paper 3 English working translation

Source work: Emmy Noether, *Zur Invariantentheorie der Formen von n Variabeln*, Jahresbericht der Deutschen Mathematiker-Vereinigung 19 (1910), pp. 101-104.

This package preserves author, source title, venue, year, pagination, byline, and printed notes. The leading `3.` in the standalone title is editorial navigation for the project collection and is explicitly disclosed as absent from the 1910 printed title.

The English text is a user-directed, machine-assisted project working translation edited against the current R823 German transcription and all four original GDZ page images. The inherited RA10 English was used as one dependent project candidate. No claim of sole human translation, external scholarly certification, or public-domain determination is made here.

The proposed public checkpoint contains only the project-created English TeX/PDF and sanitized provenance/QA controls. It excludes the German transcription, inherited English candidate, original article PDF, page images, raw build logs, private absolute paths, and scan-derived material. Rights uncertainty in upstream witnesses does not block local source comparison, but it is not silently converted into a license for those witnesses.
