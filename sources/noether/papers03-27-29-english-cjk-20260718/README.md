# Noether Papers 03, 27, 28, and 29: bounded English/CJK checkpoints

This grouped package preserves one source-audited English Paper 3 working
translation and bounded Korean/Chinese/Japanese working translations for Papers
27-29, together with their editable TeX, source controls, terminology/decision
records, structural/difficulty indexes where supplied, and complete render-QA
images. Producer text files containing host-local paths or internal task labels
were curated to private-local references; `PUBLIC_FILE_MANIFEST.csv` records
both producer and public hashes.

These are machine-assisted source-aware working translations, not a complete
Noether corpus, critical edition, proof check, native/community certification,
or independent scholarly review. Generic Traditional Chinese is not a
Taiwan/Hong Kong/Macao localization. Korean and Japanese terminology holds
remain visible in the component notes.
