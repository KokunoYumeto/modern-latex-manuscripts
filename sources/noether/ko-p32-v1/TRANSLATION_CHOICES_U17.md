# P32-KO-U17 translation choices

This file records translator choices, not checking or certification.

- `rationale Primzahl` is rendered `유리소수`; `ganze rationale positive Zahl` is simplified to `양의 정수`.
- `Primteiler` is `소인수`; `Exponent` of $2\pmod p$ is rendered multiplicative `위수`.
- `höchste ... Potenz von 2` is expanded as `2의 가장 큰 거듭제곱 ... 나누는`.
- Inclusion-minimal splitting fields retain `극소 분해체`; the congruence is preserved.
- This is an unchecked ko-KR translation. No ko-KP, source, Korean-review, specialist, or external validation is claimed.
