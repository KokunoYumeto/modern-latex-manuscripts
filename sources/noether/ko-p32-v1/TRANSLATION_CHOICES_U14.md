This file records translator choices, not checking or certification.

- `Elementare Behandlung` is rendered `초등적 고찰`; `Quaternionenkörper`/`Quaternionengruppe` are `사원수체`/`사원수군`.
- `Gruppenring` retains `군환`; `hyperkomplexes System` retains `초복소수계`.
