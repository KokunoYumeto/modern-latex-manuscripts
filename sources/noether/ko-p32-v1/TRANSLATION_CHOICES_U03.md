# P32-KO-U03 translation choices

This file records translator choices, not checking or certification.

- `Zerfällungskörper kleinsten Grades` is rendered `최소 차수의 분해체`, while inclusion-minimal `minimaler Zerfällungskörper` is distinguished as `극소 분해체`.
- Historical `nichtkommutativer Körper` and `Quaternionenkörper` are rendered `비가환체` and `사원수체`; the division-ring sense is left for checker adjudication.
- `zweiseitig einfacher Ring` is rendered `양쪽 단순환`; `Nichtbeschränktheit` is `비유계성`/`상계가 없음`.
- `vollkommener Grundkörper`, `Faktorensystem`, and `nichtkommutative Einbettung` are rendered `완전체인 기초체`, `인자계`, and `비가환 매장`.
- The source emphasis command is retained structurally through `\srcspaced`.
- This is an unchecked ko-KR translation. No ko-KP, source, Korean-review, specialist, or external validation is claimed.
