# P32-KO-U04 translation choices

This file records translator choices, not checking or certification.

- `Charakterisierung` is rendered `특성화`; `Zerfällungskörper` retains `분해체`.
- `hyperkomplexes System` retains the P33 choice `초복소수계`.
- `homomorphes Bild`, `Darstellungsklasse`, and transformed representations are rendered `준동형상`, `표현류`, and `변환표현`.
- Historical `Gruppenring`/`Gruppenzahl` retain `군환` (`群環`)/`군수` (`群數`).
- `reduzible`, `irreduzible`, `vollständig reduzible`, and `absolut irreduzible` are rendered `가약`, `기약`, `완전가약`, and `절대기약`.
- This is an unchecked ko-KR translation. No ko-KP, source, Korean-review, specialist, or external validation is claimed.
