# P32-KO-U06 translation choices

This file records translator choices, not checking or certification.

- `größter kommutativer Unterkörper` is rendered `극대 가환 부분체`.
- `Grad ... inbezug auf $P$` is rendered `$P$ 위에서의 차수`; `Schurscher Index` is `슈어 지수`.
- `Zerfällungskörper kleinsten Grades` retains `최소 차수의 분해체`.
- `absolut irreduzible Darstellungsklasse` and `irreduzible Darstellungsklasse inbezug auf $P$` are `절대기약 표현류` and `$P$에 대한 기약 표현류`.
- `unter ihnen enthalten` is rendered `이들 가운데 하나이다`, as class membership rather than field inclusion inside every member.
- This is an unchecked ko-KR translation. No ko-KP, source, Korean-review, specialist, or external validation is claimed.
