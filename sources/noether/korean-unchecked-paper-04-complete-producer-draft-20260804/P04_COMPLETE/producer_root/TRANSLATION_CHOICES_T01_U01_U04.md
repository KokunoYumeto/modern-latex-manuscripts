## Coupled sense windows

- `n-är / Formen von n Variabeln`: `n항 영역` for the historical arity domain; `n개 변수의 형식` in the title. This must not be read as a claim about an (n)-ary operation.
- `Formensystem / Formenzusammenhang / invariante Bildung`: `형식계 / 형식들의 연관관계 / 불변 구성식`. `Bildung` here is a constructed covariant/invariant object, not ordinary formation.
- `ganze invariante Bildungen`: `정수 불변 구성식`. `ganze` is held as the historical polynomial/integral contrast and must not be imported automatically from algebraic-integer terminology.
- `symbolische Darstellbarkeit / symbolische Identitäten`: `기호적 표현 가능성 / 기호 항등식`. The window is classical symbolic invariant theory, not computer-symbolic representation.
- `Variabelnreihe / Symbolreihe höherer Stufe`: `더 높은 단계의 변수열 / 기호열`. `Reihe` means an indexed row/series of variables or symbols, not a numerical series.
- `kogredient / kontragredient`: provisionally `동변 / 반변`, with source phrases retained in the checker questions. These describe transformation behavior and may require a more historical Korean rendering.
- `Determinantenaggregat / Matrizenprodukt`: `행렬식 결합식 / 행렬곱`. `Matrizenprodukt` is source-defined as the sum of products of corresponding minors, equivalently the determinant of the product matrix; it is not licensed to mean arbitrary modern matrix multiplication without that window.
- `Faltungsprozeß / Grundfaltung`: `수축 과정 / 기본 수축`. This follows the P01 distinction between general transvection/Überschiebung and the source's Faltung family, but remains corpus-wide checker debt.
- `Zerlegungsidentität / unzerlegbare Identität`: `분해 항등식 / 분해 불가능 항등식`. The first is a named identity that apparently decomposes a row; the second concerns irreducibility of the identity itself.
- `Normalform / äquivalentes System`: `정규형 / 동치인 계`. `Normalform` is characterized through invariant differential operations, not modern matrix normal form by default.
- Grassmann's `progressives / regressives / gemischtes Produkt`: provisionally `전진곱 / 후퇴곱 / 혼합곱`, always with the historical source family visible to a checker.
- `Gewicht / oberer Gewichtsindex / unterer Gewichtsindex`: `무게 / 위 무게지수 / 아래 무게지수`. Modern `가중치` is an unresolved alternative; the source defines the exact numerical role (\rho(n-\rho)), (\rho), and (n-\rho).
- `Reihenzahl / Reihen der Matrix`: provisionally `열의 수 / 행렬의 열`. This keeps the paper's established `Reihe` family visible, but modern Korean matrix terminology may require `행` in some clauses.
