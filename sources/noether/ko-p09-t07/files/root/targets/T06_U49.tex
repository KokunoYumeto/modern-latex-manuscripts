\emph{각 고정된 $\nu$에 대하여 영역 $\mathfrak G_\nu$ $(\nu=1,2,\ldots)$가 다음과 같은 모든 양으로 이루어진다고 하자.}
\[
\begin{array}{@{}l@{\quad}c@{}}
(1)& z=f(\eta)+g_1(\eta)\eta_1^\nu+g_2(\eta)\eta_2^\nu+\cdots+g_t(\eta)\eta_t^\nu.
\end{array}
\]
\emph{여기서 $f(\eta)$는 $\eta$의 모든 정수적 다항식을, $\eta_1,\ldots,\eta_t$는 모든 기저의 수를 두루 취한다. 또한 $g_1(\eta),\ldots,g_t(\eta)$는 $\eta_1^\nu,\ldots,\eta_t^\nu$의 각 고정된 조합마다 서로 독립적으로 $\eta$의 모든 정수적 대수함수를 두루 취한다.}
