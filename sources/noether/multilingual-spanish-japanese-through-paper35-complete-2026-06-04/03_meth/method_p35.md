# Paper 35 methodology notes

Scope: Paper 35, `Über Maximalbereiche aus ganzzahligen Funktionen`, complete in Spanish and Japanese.

Terminology policy: `Integritätsbereich` continues as Spanish `dominio íntegro` and Japanese `整域`; `Integritätsbasis` continues as `base íntegra` / `整基底`.  This preserves the cumulative global refinement made for the ideal-theory and algebraic-number-theory papers, and is intended to keep later Takagi-style integrations coherent.

`ganzzahlige Funktionen` is rendered as `funciones de coeficientes enteros` / `整係数関数`, not as an analytic “entire function.”  `relativ-ganze Funktionen` is rendered as `funciones relativamente enteras` / `相対的に整な関数`, preserving the Hilbert-14 integrality context.

Paper 35 uses `Maximalbereich` as a saturation domain with respect to integral denominators.  It is translated as `dominio maximal` / `極大領域` and explicitly kept distinct from maximal ideals.

Source normalization recorded: the source witness has inconsistent total-generator notation (`t`/`s`) in §2 after first using `f_1,...,f_t`.  The translations use `s` for the total number of generators and `t` for the transcendence degree/Jacobian rank, matching the mathematical development of §§2-3.  The German source witness is preserved unchanged.

Source correction recorded: the illustrative formula in the introduction is rendered as `x^2=(2x)^2/2^2`; the current text witness has the compact/defective reading `x^2=(2x)/2^2`.  This is treated as a scan/OCR defect because the displayed example is otherwise false.
