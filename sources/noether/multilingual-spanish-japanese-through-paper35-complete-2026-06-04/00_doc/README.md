# Noether Paper 35 Spanish/Japanese package

This package continues the Spanish/Japanese Noether cumulative branch through Paper 35.

Structure is intentionally path-safe: one ZIP, one root folder, then subfolders only.  The package root and file names are short for local Codex/Windows path-length safety.

Main outputs:
- `01_work/es/N35_ES.pdf`, `01_work/es/N35_ES.tex`
- `01_work/ja/N35_JA.pdf`, `01_work/ja/N35_JA.tex`
- `02_cum/es/N35_cum_ES.pdf`, `02_cum/es/N35_cum_ES.tex`
- `02_cum/ja/N35_cum_JA.pdf`, `02_cum/ja/N35_cum_JA.tex`

Source/control witnesses are in `04_src/`; render checks are in `07_rend/`.
