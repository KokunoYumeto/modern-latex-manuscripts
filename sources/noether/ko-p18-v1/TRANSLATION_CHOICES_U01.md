# P18-KO-U01 translation choices

This file records translator choices, not checking or certification.

- `Sitzung` is rendered `회의`; `Vorsitz` is rendered `의장`.
- The author form follows the established Korean Noether style `E. 뇌터(Noether)`.
- `Loewy` and `Hentzelt` are provisionally rendered `뢰비(Loewy)` and `헨첼트(Hentzelt)`, preserving the source spellings for checker review.
- `eine Arbeit ... zur Eliminationstheorie` is rendered `소거론 논문`; `im Kriege gefallen` is rendered `전쟁 중 전사한`.
- This is a ko-KR working translation. No ko-KP wording, source check, specialist approval, or external validation is claimed.
