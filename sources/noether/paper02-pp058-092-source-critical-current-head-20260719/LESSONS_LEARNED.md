# Lessons learned: Paper 2 pp. 58-92

1. Repair symbol families by semantic role and protected negative controls, never by character-wide replacement.
2. Enlarged pages and strips improve inspection ergonomics but do not create optical detail; retain the original source as authority.
3. Dense mathematical tables need row, cell, title, corner, exponent, and geometry checks in addition to TeX extraction.
4. A current cumulative merge is governed by exact hunks and source-backed survival, not package sequence numbers.
5. Page/leaf closure must be stated separately from whole-paper or whole-corpus completion.
6. False positives and no-patch decisions are reproducibility evidence and belong beside confirmed fixes.
