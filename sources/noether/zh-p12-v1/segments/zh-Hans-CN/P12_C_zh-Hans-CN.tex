\begin{center}
\textbf{II. 正规坐标、等价性与约化定理。}
\end{center}

我通过积分求解与
\(f\!\left(\frac{dx}{dt}\right)\) 相应的变分问题来得到正规坐标：
\srcnumdisplay{(9)}{%
\begin{gathered}
\Omega_1=\delta f\!\left(\frac{dx}{dt}\right)
-\frac{d}{dt}f_\delta\!\left(\frac{dx}{dt}\right)=0
\quad(\text{关于 }\delta x\text{ 恒等成立}),\\
\frac{d}{dt}f\!\left(\frac{dx}{dt}\right)=0
\quad(\text{作为推论或附加条件}).
\end{gathered}
}
由于假定 \(f(dx)\) 是齐次的，这个方程组在参数代换
\(t=\varkappa\cdot\tau\) 下变为自身；因此，如果借助 (9) 把
\(\frac{d^\rho x_i}{dt^\rho}\) 表示为第一阶导数的函数
\(\varphi_\rho^{(i)}\!\left(\frac{dx}{dt}\right)\)，那么
\(\varphi_\rho^{(i)}\) 是 \(\rho\) 次齐次的：
\srcnumdisplay{(10)}{%
\varphi_\rho^{(i)}\!\left(\varkappa\cdot\frac{dx}{dt}\right)
=\varkappa\varphi_\rho^{(i)}\!\left(\frac{dx}{dt}\right).
}
现在，在积分 (9) 时，对 \(t=t_0\) 给定初值
\[
x=(x)_0,\qquad \frac{dx}{dt}=\left(\frac{dx}{dt}\right)_0
\]
并令
\srcnumdisplay{(11)}{%
u_i=(t-t_0)\left(\frac{dx_i}{dt}\right)_0,
}
——由于 \(f\!\left(\frac{dx}{dt}\right)=\mathrm{const.}\)，参数
\((t-t_0)\) 与“极值曲线的长度”成比例——那么借助 (10)，按
\((t-t_0)\) 的幂展开便得到
\srcnumdisplay{(12)}{%
x_i-(x_i)_0=u_i+\frac12\varphi_2^{(i)}(u)+\cdots+
\frac{1}{\rho!}\varphi_\rho^{(i)}(u)+\cdots
}
这个展开可以看作变量变换 \(x_i=x_i(u)\)，其中各个 \(u\) 正是黎曼
正规坐标。因此，根据 (11) 和 (12)，这些坐标把经过 \((x)_0\) 的极值
曲线变成直线。此外，任意变量变换 \(x=x(y)\) 根据 (11) 都对应于相关
正规坐标的一个线性变换 \(u=u(v)\)；其系数只依赖于任意选定的值系
\((x)_0\)，所以微分 \(du,\delta u\) 与 \(u\) 本身服从同一个变换。

借助 (12)，设 \(f(x,dx)\) 变为 \(F(u,du)\)；或者将其按 \(u\) 的幂展开：
\srcnumdisplay{(13)}{%
F(u,du)=F_0(u,du)+F_1(u,du)+\cdots+F_\rho(u,du)+\cdots
}
这里 \(F_\rho(u,du)\) 表示关于 \(u\) 的 \(\rho\) 次齐次形式。由于变换
\(u=u(v)\) 是线性的，根据 \(F(u,du)=G(v,dv)\)，各个齐次分量也分别
变为对应的分量：
\srcnumdisplay{(14)}{%
F_\rho(u,du)=G_\rho(v,dv).
}
因此，如果对 \((x)_0\) 任取一个固定的常值系，那么 (13) 和 (14) 表明，
\(f(dx)\) 与 \(g(dy)\) 的等价性等同于相应函数系 \(F_\rho(u,du)\) 在线性
变换下的等价性。此外，\(F_\rho(u,du)\)，或者相应的
\(F_\rho(\delta u,du)\)，是在点 \(x=(x)_0\) 处取的 \(f(dx)\) 的不变量；
确切地说，它们构成该点 \(x=(x)_0\) 的一个完备基本函数系。事实上，
\[
F_\rho(\delta u,du)=\frac1{\rho!}\sum
\frac{\partial F_\rho}{\partial \delta u^\rho}\,\delta u^\rho;
\qquad
\frac{\partial F_\rho}{\partial \delta u^\rho}
=\left(\frac{\partial F(du)}{\partial u^\rho}\right)_0,
\]
而借助 (12)，后一导数恰好可以用在 \(x=(x)_0\) 处取的 \(f(dx)\) 的导数
表示出来；同样构成的 \(G(dv)\) 的导数也可以用 \(g(dy)\) 的导数表示。
又由于
\[
\left(\frac{\partial^{\rho+\sigma}F(du)}
{\partial u^\rho\partial du^\sigma}\right)_0
=
\frac{\partial^{\rho+\sigma}F_\rho(\delta u,du)}
{\partial\delta u^\rho\partial du^\sigma}
\]
只要把高阶微分换成与 \(dx,\delta x\) 同变的 \(p,q,r,\ldots\)，
\(f(dx)=F(du)\) 的每一个在点 \(x=(x)_0\) 处取的不变量也就成为
\(F_\rho(\delta u,du)\) 的一个射影不变量。现在可以把 \((x)_0\) 看作
参数；点 \(x=(x)_0\) 处的每一个不变量，只要重新用 \(x\) 替换
\((x)_0\)，就对应于 \(f(dx)\) 的一个不变量。因此，如果
\(F_\rho(\delta u,du)\) 变为在 \(x=(x)_0\) 处取的不变量
\(\Psi_\rho(\delta x,dx)\)——当 \(x=(x)_0\) 时，\(du,\delta u\) 变为
\(dx,\delta x\)——那么 \(\Psi_\rho\) 本身构成一个完备系统的基本函数。
现在还需用 \(f(dx)\) 的显式不变量，即用函数 (8)，来表示这个基本函数系。
这些函数通过微分过程生成这一事实表明，这是可以做到的。对于最高阶项，
这些过程变为简单的极化过程；与克莱布施--戈丹级数展开类似的一个变换，
再结合对被略去项所作的归纳论证，便证明了这一断言。如果所考察的是一个
联立系统的不变量，那么还须在基本函数 (8) 中加入其余微分表达式的协变
导数；把与 \(f(dx)\) 相应的正规坐标引入这些表达式，就可以看出这一点。

这样一来，已被化归为 (14) 的 \(f(dx)\) 与 \(g(dy)\) 的等价性，也等同于
\(\Psi_\rho\) 的等价性，或者同样等同于函数 (8) 在微分的线性变换下的
等价性，而且不需要任何特殊的可积性条件；这一点来自化归为 (14) 的
可能性。至此，约化定理的各个部分全都得证。特别地，函数序列
\([\Omega_2],[\Omega_3],\ldots,[\Omega_\rho],\ldots\) 恒等于零，是
\(f(dx)\) 能够变换为常系数表达式的充要条件。

最后，如果不是以所有解析变换组成的群为基础，而是以它的一个子群为基础，
那么相应的 \(u\) 的线性变换群也变为射影群的一个子群；\(f(dx)\) 的不变量
仍然是函数 (8) 在线性变换下的不变量，但现在所针对的是这个子群。因此，
通过齐次化，可以把非齐次函数 \(f(dx)\) 的情形化归到仿射群；这里的完备
系统可以从对多一个变量构造的函数 (8) 导出。

约化定理给出二次形式这一特殊情形，更一般地也给出 \(p\) 次形式的情形：
这里的函数系在 \([\Omega_2]\) 处终止，更一般地在 \([\Omega_p]\) 及其
协变导数处终止，因为所有后续基本函数都是这些函数的射影不变量。这也
说明了黎曼曲率形式 \([\Omega_2]\) 在二次形式中所具有的特殊地位。二次
形式，或者说 \(p\) 次形式的等价性问题，正好归结为 \([\Omega_2]\)，
或者说 \([\Omega_2]\ldots[\Omega_p]\) 及其协变导数在线性变换下的
等价性；而 \([\Omega_2]\)，或者说 \([\Omega_2]\ldots[\Omega_p]\)
恒等于零，是变换为常系数形式的充要条件。这就为二次形式陈述了最著名的
结果之一。

更为详尽的论述将于近期刊载在《数学年刊》上。
