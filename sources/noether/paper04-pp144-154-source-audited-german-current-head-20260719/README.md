## What changed

The archive intake restored source numbering, display and run-in structure,
author emphasis, page-local footnote symbols, headings, list labels, and
punctuation. Its newly promoted mathematical transcription repair is the
printed p. 150 double-prime subscript `n-rho-1`, replacing `n-lambda-1`.
Four already-filed Section 8 source-defect repairs were independently checked
and retained.

The producer's full cumulative TeX was not copied over the live repository
head. Only the bounded audited content was reconciled into the current base;
all content outside that band remains from the existing repository source.
See `SCOPE_AND_MERGE_RECEIPT.md`.
