# CJK visual evidence open payload

This directory is the GitHub-readable projection of the bounded CJK visual-evidence checkpoint dispatched on 2026-07-22.

- Public images: 290 project-generated or project-recovered PNG files, 154,772,219 bytes.
- Public package members: 296 files, 160,900,941 bytes.
- Exact ZIP: `CJK_VISUAL_EVIDENCE_OPEN_PAYLOAD_20260718.zip`, 142,908,011 bytes, SHA-256 `96919DFA424A467C44AF277708024154B04384C3C35CDB3E3C8DBCC4D839F2F8`.
- Private inventory represented by the public-safe index: 2,020 images, 174,401,236 bytes.
- Dispositions: 290 open-payload images, 14 rights-blocked images represented by metadata only, and 1,716 non-project images excluded.

The GitHub tree contains the ZIP's 290 image members and six public-safe metadata members without the oversized ZIP container. The exact ZIP is preserved on the existing Interlanguage Zenodo concept, `10.5281/zenodo.21124403`, in version [`10.5281/zenodo.21485338`](https://doi.org/10.5281/zenodo.21485338). The `ZENODO_RELEASE_*` controls record that publication and its exact checksums.

The 14 rights-blocked images are not redistributed. Their hashes, dimensions, candidate provenance, and disposition are retained in `metadata/VISUAL_EVIDENCE_RIGHTS_BLOCKED_METADATA.jsonl`. Parent and structural links are deterministic candidates unless explicitly confirmed. The 49 metadata-incomplete records, including one inherited undecodable PNG, remain visibly held rather than silently normalized.

These files are provenance and visual-QA evidence. They do not certify translation accuracy, source fidelity, mathematical correctness, native-language quality, or rights clearance. Temporary and before-state renders are intentionally retained, with supersession recorded per item.
