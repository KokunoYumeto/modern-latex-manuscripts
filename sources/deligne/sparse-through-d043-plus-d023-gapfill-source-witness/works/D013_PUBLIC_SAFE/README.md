# D013 publication-safe source carrier

This directory preserves the independently audited D013 work used by the cumulative readers.

- `D013_EN.tex` and `D013_EN.pdf` are the standalone English edition.
- `D013_FR.tex` and `D013_FR.pdf` are the diplomatic French edition.
- `D013_APPARATUS.tex` and `D013_APPARATUS.pdf` record source alignment, uncertainty, corrections, and excluded publication furniture.
- `audited_extraction/` is the complete exact extraction of the audited archive except `_EXTRACTION_MEMBERS.tsv`, which was an extraction-machine ledger containing a local-account path and was therefore excluded from the candidate public surface.
- `source_archive/D013_AUDITED_COMPLETE_CUMULATIVE_FULL_STATE.zip` is the original audited archive preserved byte-for-byte.
- `zero_accepted/` contains exact public-safe evidence that the inherited baseline began at ZERO_ACCEPTED. The private-path-bearing historical return envelope is deliberately excluded.
- `gate/` contains the independent corpus-gate receipts and manifests. Private-path-bearing gate scripts and worklogs are deliberately excluded.

The authority PDF controls. Publication furniture is excluded from both reader bodies and recorded in the apparatus. The source-language reader, English translation, and apparatus were verified through independent cold builds, page/unit/formula/citation gates, all-page topology checks, and visual review before insertion.
