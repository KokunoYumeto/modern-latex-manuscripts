LA CONJECTURE DE WEIL. I

(3.7) Pour chaque partition P de [1,2k] en parties à deux éléments {i_α,j_α} (i_α<j_α), on définit

           ψ_P : ⊗^(2k)ℱ_0 → Q_ℓ(−kβ) : x_1⊗…⊗x_(2k) ↦ ∏_α ψ(x_(i_α),x_(j_α)).

Soit x un point fermé de X. L’hypothèse (ii) assure que les coinvariants de π₁(U,u) dans ⊗^(2k)ℱ_u sont les coinvariants dans ⊗^(2k)ℱ_u du groupe symplectique tout entier (π₁ est Zariski-dense dans Sp). Soit 𝒫 l’ensemble des partitions P. D’après H. Weyl (The classical groups, Princeton University Press, chap. VI, § 1), pour 𝒫′⊂𝒫 convenable, dépendant de dim(ℱ_u), les ψ_P pour P∈𝒫′ définissent un isomorphisme

           (⊗^(2k)ℱ_u)_(π₁) = (⊗^(2k)ℱ_u)_Sp →^{~} Q_ℓ(−kβ)^𝒫′.

Soit N le nombre d’éléments de 𝒫′. D’après (2.10), la formule ci-dessus donne

           H_c^2(U,⊗^(2k)ℱ) ≃ Q_ℓ(−kβ−1)^N.

Puisque H_c^0(U,⊗^(2k)ℱ)=0, la formule (1.14.3) se réduit à

           Z(U_0,⊗^(2k)ℱ_0,t)
             = det(1−F^*t,H^1(U,⊗^(2k)ℱ)) / (1−q^(kβ+1)t)^N.

Cette fonction Z est donc le développement en série de Taylor d’une fonction rationnelle n’ayant de pôle qu’en t=1/q^(kβ+1). Nous utiliserons seulement le fait que les pôles sont de valeur absolue 1/q^(kβ+1) dans C. Cela pourrait se déduire d’arguments généraux sur les groupes réductifs. Si α est une valeur propre de F_x sur ℱ_0, alors α^(2k) est une valeur propre de F_x sur ⊗^(2k)ℱ_0. Notons encore α un quelconque conjugué complexe de α. La puissance inverse 1/α^(2k/deg(x)) est un pôle de det(1−F_x t^deg(x),⊗^(2k)ℱ)^(−1). D’après (3.4) et (3.6), on a donc

           |1/q^(kβ+1)| ≤ |1/α^(2k/deg(x))|,

soit

           |α| ≤ q_x^(β/2+1/(2k)).

Faisant tendre k vers l’infini, on trouve que

           |α| ≤ q_x^(β/2).

Par ailleurs, l’existence de ψ assure que q_x^β α^(−1) est également valeur propre, d’où l’inégalité

           |q_x^β α^(−1)| ≤ q_x^(β/2),

soit

           q_x^(β/2) ≤ |α|.

Ceci achève la démonstration.
