PIERRE DELIGNE

Le morphisme de Gysin

           H^(n−1)(Y,Q_ℓ)(−1) → H^(n+1)(X_u,Q_ℓ)

est surjectif (cet argument est dual de A)), et on applique l’hypothèse de récurrence à Y_0.

Si les cycles évanescents sont nuls, la suite exacte de (5.8) b) fournit une suite exacte

           ⊕_(s∈S)Q_ℓ(m−n) → E_2^(0,n+1) → H^(n+1)(X_u,Q_ℓ).

La valeur propre de F agissant sur Q_ℓ(m−n) est q^(d/2), et H^(n+1) se traite comme plus haut.

C) E_2^(1,n). Si on disposait du théorème de Lefschetz « difficile », on saurait que 𝓔∩𝓔^⊥ est nul, et que R^n f_*Q_ℓ est somme directe de j_*𝓔 et d’un faisceau constant. Le H^1 d’un faisceau constant sur P^1 est nul, et il suffirait d’appliquer (6.3).

Faute d’avoir déjà démontré Lefschetz « difficile », il nous va falloir dévisser. Si les cycles évanescents sont nuls, R^n f_*Q_ℓ est constant ((5.8) b)) et E_2^(1,n)=0. On peut donc supposer, et on supposera, les cycles évanescents non nuls. Filtrons R^n f_*Q_ℓ=j_*j^*R^n f_*Q_ℓ (5.8) par les sous-faisceaux j_*𝓔 et j_*(𝓔∩𝓔^⊥). Si les cycles évanescents δ ne sont pas dans 𝓔∩𝓔^⊥, on dispose de suites exactes :

(7.1.2)    0 → j_*𝓔 → R^n f_*Q_ℓ → faisceau constant → 0.

(7.1.3)    0 → faisceau constant j_*(𝓔∩𝓔^⊥) → j_*𝓔 → j_*(𝓔/(𝓔∩𝓔^⊥)) → 0.

Si, à Dieu ne plaise, les δ sont dans 𝓔∩𝓔^⊥, on a 𝓔⊂𝓔^⊥, et des suites exactes :

(7.1.4)    0 → le faisceau constant j_*𝓔^⊥ → R^n f_*Q_ℓ → un faisceau 𝓕 → 0

(7.1.5)    0 → 𝓕 → le faisceau constant j_*j^*𝓕 → ⊕_(s∈S)Q_ℓ(n−m)_s → 0.

Dans le premier cas, les suites exactes longues de cohomologie fournissent

(7.1.2′)   H^1(D,j_*𝓔) → H^1(R^n f_*Q_ℓ) → 0,

(7.1.3′)   0 → H^1(D,j_*𝓔) → H^1(D,j_*(𝓔/(𝓔∩𝓔^⊥)))

et on applique (6.3).

Dans le second cas, elles fournissent

(7.1.4′)   0 → H^1(D,R^n f_*Q_ℓ) → H^1(D,𝓕),

(7.1.5′)   ⊕_(s∈S)Q_ℓ(n−m) → H^1(D,𝓕) → 0

et on remarque que F agit sur Q_ℓ(n−m) par multiplication par q^(d/2).

Lemme (7.2). — Soit X_0 une variété projective non singulière absolument irréductible de dimension d sur F_q. Soient X sur F̄_q déduit de X_0 par extension des scalaires et α une valeur propre de F^* agissant sur H^d(X,Q_ℓ). Alors, α est un nombre algébrique dont tous les conjugués complexes, encore notés α, vérifient

           |α|=q^(d/2).
