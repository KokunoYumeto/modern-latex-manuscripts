PIERRE DELIGNE

La transformation de monodromie T respecte la forme d’intersection Tr(x∪y) sur H^n(X_t,Z). Pour n impair, c’est une transvection symplectique. Pour n pair, c’est une symétrie orthogonale.

(4.2) Voici l’analogue de (4.1) en géométrie algébrique abstraite. Le disque D est remplacé par le spectre d’un anneau de valuation discrète hensélien A à corps résiduel algébriquement clos. Soient S ce spectre, η son point générique (spectre du corps des fractions de A), s son point fermé (spectre du corps résiduel). Le rôle de t est joué par un point générique géométrique η̄ (spectre d’une clôture algébrique du corps des fractions de A).

Soit f : X→S un morphisme propre, avec X régulier purement de dimension n+1. On suppose f lisse, sauf pour un point quadratique ordinaire x dans la fibre spéciale X_s. Soit ℓ un nombre premier différent de la caractéristique résiduelle p de S. Notant X_(η̄) la fibre générique géométrique, on dispose encore d’un morphisme de spécialisation

(4.2.1)    sp : H^i(X_s,Q_ℓ) ←^{~} H^i(X,Q_ℓ) → H^i(X_(η̄),Q_ℓ).

Le rôle de T est joué par l’action du groupe d’inertie I=Gal(η̄/η), agissant sur H^i(X_(η̄),Q_ℓ) par transport de structure (cf. (1.15)) :

(4.2.2)    I=Gal(η̄/η) → GL(H^i(X_(η̄),Q_ℓ)).

Les données (4.2.1), (4.2.2) décrivent entièrement les faisceaux R^i f_*Q_ℓ sur S.

(4.3) Posons n=2m pour n pair, et n=2m+1 pour n impair. (4.2.1) et (4.2.2) se décrivent encore en terme d’un cycle évanescent

(4.3.1)    δ∈H^n(X_(η̄),Q_ℓ)(m).

Ce cycle est bien défini au signe près.

Pour i≠n,n+1, on a

(4.3.2)    H^i(X_s,Q_ℓ) →^{~} H^i(X_(η̄),Q_ℓ)    (i≠n,n+1).

Pour i=n,n+1, on a une suite exacte

(4.3.3)    0 → H^n(X_s,Q_ℓ) → H^n(X_(η̄),Q_ℓ)
             →^{x↦Tr(x∪δ)} Q_ℓ(m−n) → H^(n+1)(X_s,Q_ℓ)
             → H^(n+1)(X_(η̄),Q_ℓ) → 0.

L’action (4.2.2) de I (la monodromie locale) est triviale si i≠n. Pour i=n, elle se décrit comme suit.

A) n impair. — On dispose d’un homomorphisme canonique

           t_ℓ : I → Z_ℓ(1),

et l’action de σ∈I est

           x ↦ x ± t_ℓ(σ)(x,δ)δ.
