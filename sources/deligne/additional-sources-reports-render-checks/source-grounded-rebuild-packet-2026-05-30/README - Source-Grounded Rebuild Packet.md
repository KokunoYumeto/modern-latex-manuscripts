# Deligne strict restart package

All previously delivered Deligne translations in this thread are treated as draft/draft-aid area unless rebuilt from the source-grounded files in this package.

Strict rebuild rule:

- no compressed numbered ranges;
- no authorial paragraph omitted;
- no theorem/proposition/lemma/corollary/remark/example collapsed into a summary;
- all displayed math, diagrams, figures, references, footnotes, and bibliography material must be preserved;
- English and French TeX/PDF layers are delivered separately;
- final outputs must be cumulative only when explicitly requested.

This package contains source-grounded slices and extracted French text for every Deligne paper previously worked on in this thread:
32, 42, 45, 56, 57, 58, 69, 70, 71, 83, 84, 85, 87, 88.

The older outputs are copied into draft-aid area so they can be used only as draft aids.
