The section 9 given a map of the formalism of the Tannakian categories a the theorie of Picard-Vessiot. Si $E$ is of type finite: $E = A^n/R$, $E$ is of presentation finite if and only if $R$ is of type finite, and $\omega(E) = A M_B / \omega(R)$ is of presentation finite if and only if $\omega(R)$ is of type finite. the assertion respee en resulte.
\end{proof}
