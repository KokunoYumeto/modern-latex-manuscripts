# Source aid package use

This batch used the local Deligne source aid package dated 2026-06-03 for split-paper source PDFs, page counts, and first-page orientation witnesses. The authoritative source scan included in the paper folders is the split PDF `source_pdfs/01_papers/10_Theorie_de_Hodge_II.pdf`; the package manifest records 53 pages for that source PDF.

For each installment, the scan PDF in `SCAN/` is a direct page selection from that split source PDF and is not a substitute for the EN/FR TeX/PDF transcriptions.
