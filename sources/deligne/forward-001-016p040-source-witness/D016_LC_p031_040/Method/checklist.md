# Per-installment checklist

Use this before shipping a clean paper installment.

1. Source pages rendered at 200--250 dpi.
2. EN TeX compiles twice.
3. FR TeX compiles twice.
4. EN PDF opens and has no obvious first/middle/last-page layout failures.
5. FR PDF opens and has no obvious first/middle/last-page layout failures.
6. Scan PDF page count equals the source range length.
7. Cumulative output includes all prior pages and the new installment.
8. Cumulative output has no artificial blank gaps between installments.
9. ZIP has one top folder.
10. Paper folders contain only TEX, PDF, and SCAN subfolders.
11. No `.aux`, `.log`, `.out`, `.png`, `.jpg`, `.md`, `.txt`, or `.csv` files in the paper ZIP.
12. No visible labels such as source checked, verified, working, audit, or report.
