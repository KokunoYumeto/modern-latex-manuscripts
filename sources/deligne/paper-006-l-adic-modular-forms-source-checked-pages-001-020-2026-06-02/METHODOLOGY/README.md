# Deligne transcription methodology cumulative packet v01

This packet is a reusable work-aid for the Deligne paper transcription/retranslation lane.

It is intentionally separate from clean paper deliverables. Paper ZIPs should remain reader-facing: TeX, PDF, and scan sidecars only. This packet keeps the working method, special-character conventions, and scripts needed by another local machine or another session to reproduce the same workflow more efficiently.

Current workflow baseline:

1. Treat the scan/rendered page as the source of authority.
2. Build in small installments, normally 5--10 source pages.
3. Maintain both installment and cumulative paper outputs.
4. Compile EN and FR TeX independently.
5. Include the source scan sidecar separately; never use the scan as a substitute for the TeX paper.
6. Keep process notes, logs, screenshots, and audit reports out of the clean paper ZIP.
7. Keep this methodology ZIP cumulative and update it whenever a new failure mode or fix is discovered.
