# Package method notes

This package follows the standardized `lmodern`/standard-math format and short-path cumulative layout.

Clean deliverables:
- `New/TEX`, `New/PDF`, `New/SCAN`: current installment.
- `Cum/D078` through `Cum/D090`: cumulative carried-forward corpus.
- `QA` and `Method`: audit/contact/render/build notes only, never inserted into clean PDFs.

Visual fidelity rule used here: diagrams, commutative squares, triangles, table-like displays, and formula blocks are rebuilt in TeX/TikZ rather than inserted as raster screenshots.
