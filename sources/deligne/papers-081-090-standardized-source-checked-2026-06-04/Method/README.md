# Package method

Short-path cumulative layout, standardized `lmodern`/standard-LaTeX math format.

Clean deliverables:
- `New/` has the current paper/installment.
- `Cum/` has the cumulative descending lane.
- `QA/` and `Method/` are outside the clean mathematical PDFs.

Diagram policy: rebuild diagrams in TeX and inspect rendered quality, not just inclusion. Avoid cramped grids and ambiguous crossing arrows; use spacing and arrow styles that make the source geometry clear.
