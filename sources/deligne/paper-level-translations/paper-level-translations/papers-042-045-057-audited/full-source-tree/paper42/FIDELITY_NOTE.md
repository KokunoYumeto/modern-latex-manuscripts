# Paper 42 - integration over a vanishing cycle

This package contains a working English translation and a cleaned French TeX alignment layer for Deligne's paper "Integration sur un cycle evanescent".

Scope included in this pass:

- introduction and main theorem/corollary;
- analytic integral formula and vanishing-cycle interpretation;
- algebraic local-trace construction;
- relation with the Picard functor;
- proof of the theorem and corollary;
- degree estimates and Furstenberg comparison;
- signs appendix;
- bibliography.

The English and French files are typeset mathematical TeX, not raw verbatim OCR. Formula labels and the sign appendix formulas are retained in TeX form. This is a working audited translation layer; a later microscopic audit can still compare every phrase against the source scan.
