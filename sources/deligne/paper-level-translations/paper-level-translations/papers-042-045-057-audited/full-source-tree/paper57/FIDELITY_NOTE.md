# Fidelity note: Deligne Paper 57, The Tame Symbol

This package contains a full working English TeX/PDF translation and a cleaned French working TeX/PDF alignment layer for Deligne's paper **Le symbole modéré** / **The Tame Symbol**.

Coverage checklist:

- title and author;
- introduction and numbered sections;
- displayed formulas including the tame symbol formula, product formula, derived-category morphisms, and the reciprocity formulation;
- numbered formulas and local/global constructions;
- final bibliography/reference material in the working text layer.

The English layer is intended as a faithful mathematical translation. The French layer is a cleaned working TeX alignment layer, not a raw OCR/verbatim block.
