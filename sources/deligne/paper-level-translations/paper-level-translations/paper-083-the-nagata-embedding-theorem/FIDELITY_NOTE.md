# Fidelity note — Deligne paper 83

This package contains a cleaned French TeX layer and a full English TeX translation of Deligne paper 83, *Le théorème de plongement de Nagata* / *The Nagata Embedding Theorem*.

Scope of this batch:

- title, author, French abstract, English abstract;
- section 0, reminders on blow-ups;
- Lemmas 0.2, 0.3, 0.4, 0.5;
- Definition 1.1;
- Theorem 1.2, Lemma 1.3, Corollary 1.4, Lemma 1.5, Lemma 1.7, Theorem 1.6;
- comments, acknowledgements, and references;
- all displayed formulas and commutative diagrams are represented in TeX/TikZ-CD, not screenshots.

The French PDF is a cleaned working TeX layer, not a raw verbatim OCR dump. The English PDF is a full translation layer, not a summary.
