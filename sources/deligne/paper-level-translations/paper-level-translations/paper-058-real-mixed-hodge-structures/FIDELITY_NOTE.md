# Fidelity note — Deligne Paper 58

This package contains a cleaned French TeX working layer and an English working translation of *Structures de Hodge mixtes réelles*.

Coverage preserves the mathematical spine of the paper: the three-opposite-filtration formalism, the automorphism \(d=a_Fa_{\overline F}^{-1}\), formula (1.1.1), Proposition 1.2, Remark 1.3, tensor-compatibility, Construction 1.6 of the Tannakian group as a semidirect product, and Proposition 2.1 for real mixed Hodge structures.

No raw verbatim/OCR layer is used. The French layer is a modern working TeX reconstruction; the English layer is a working translation. The small schematic set pictures in the proof of the lemma are represented by the defining set formulas \(I(p,q)\), \(J(p,q)\), and \(K(p,q)\), which are the mathematical content used in the proof.

Both PDFs were recompiled after correcting an initial font/header problem; rendered first-page checks confirmed normal text layout.
