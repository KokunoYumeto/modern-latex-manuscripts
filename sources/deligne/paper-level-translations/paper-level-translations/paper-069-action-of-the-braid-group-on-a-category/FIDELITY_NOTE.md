# Deligne paper 69 fidelity note

This package contains a full working English translation and a full French working TeX layer for paper 69, **Action du groupe des tresses sur une catégorie**.

This pass replaces the earlier partial English-only file and includes the geometric figures as TikZ vector drawings rather than raster screenshots.

Included elements:

- complete introduction and both applications;
- Sections 1 and 2;
- all theorem / lemma / proposition / remark numbering appearing in the paper;
- all displayed formulas and numbered formulas in the paper;
- categorical square diagrams and triangular limit diagrams in TikZ-CD;
- the stereographic projection / root-arrangement figure and gallery-move figures drawn in TikZ;
- bibliography.

Known status: the large root-arrangement figure is a faithful schematic redraw, not a pixel copy of the source illustration. It is included as modern TeX/TikZ vector graphics.
