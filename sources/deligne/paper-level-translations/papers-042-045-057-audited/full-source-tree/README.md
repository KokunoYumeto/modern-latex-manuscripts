# Deligne audited packet 27: papers 42, 45, 57

This package contains English and French TeX/PDF layers for three completed Deligne papers.

- Paper 42: Integration over a vanishing cycle / Integration sur un cycle evanescent.
- Paper 45: Gabber's lemma / Le lemme de Gabber.
- Paper 57: The tame symbol / Le symbole modéré.

No source-slice PDFs are included. The French files are cleaned TeX/PDF alignment layers rather than raw verbatim OCR blocks. Paper 57's French layer was cleaned in this pass to remove the visible working-note paragraph and recompiled.

PDF page totals are listed in `reports/manifest.csv`.
