# Open Logic Project — Hindi working reader through HI-OLP-0009

This package contains the first nine accepted `hi-Deva-IN` translation units
from the Interlanguage Hindi Open Logic programme. It is a substantive working
draft: the translated TeX sources, the Hindi build support and pinned font, a
14-page cumulative reader PDF, terminology data, licence evidence, and QA
evidence are included.

The included sections cover introductory sets and relations:

1. element-determined equality (`sfr/set/bas`)
2. subsets and power sets (`sfr/set/sub`)
3. important sets (`sfr/set/imp`)
4. unions and intersections (`sfr/set/uni`)
5. pairs and products (`sfr/set/pai`)
6. Russell's paradox (`sfr/set/rus`)
7. relations as sets (`sfr/rel/set`)
8. special properties of relations (`sfr/rel/prp`)
9. equivalence relations (`sfr/rel/eqv`)

All reader-facing text in these nine bounded source files is translated into
Hindi. Mathematical notation, LaTeX commands, labels, OLP stable IDs, and
formal identifiers were preserved and checked unit by unit.

This is **not** a completed Open Logic translation, a human-reviewed edition,
a critical edition, or a PDF/UA accessibility certification. The PDF is a
machine-assisted working draft. The exact continuation cursor is
`content/sets-functions-relations/relations/orders.tex`.

See `BUILD.md`, `SOURCE_AND_LICENSE.md`, `COVERAGE_AND_CURSOR.md`, and
`qa/QA_REPORT.md`. `CHECKSUMS.csv` binds every released file except itself.
