\Article{28}
The three formulas (6), (7), (8) already contain what is essential for solving our problem. To complete them, all that remains is a mechanical calculation, namely to derive the values of the various derivatives and substitute them. In this expansion we write at once, in place of the undetermined values \(x,x'\) and so on, \(y\) and so on, the particular values corresponding to \(X=T,\ Y=B\), namely \(f,f'\) and so on, \(g\) and so on. Setting, for brevity,
\[
\begin{aligned}
\cos B&=c\\
\sin B&=s\\
\BareRoot{(1-ee\sin B^2)}&=k
\end{aligned}
\]
we obtain the following eighteen values
\[
\begin{aligned}
f&=-\frac{k\sin T}{ac}\mathord{.}s\\
f'&=-\frac{k\cos T}{ac}\mathord{.}s\\
f''&=-\frac{\sin T}{akcc}\mathord{.}(1-2eess+ees^4)\\
f'''&=+\frac{k\sin T}{ac}\mathord{.}s\\
f''''&=-\frac{\cos T}{akcc}\mathord{.}(1-2eess+ees^4)\\
f^{\mathrm{v}}&=-\frac{\sin T}{ak^3c^3}\mathord{.}((2-3ee)s+(ee+2e^4)s^3-(2ee+e^4)s^5+e^4s^7)
\end{aligned}
\]
