\noindent\hspace*{1.2em}Elimination from the equation $f(x,y,z)=0$ allows the coordinate $z$ to be expressed as a function of $x$ and $y$. For simplicity, let us suppose this has been done and that we have found
\[
z=F(x,y)
\]
Then we can use
\[
z-F(x,y)=0
\]
as the equation of the surface, or set
\[
f(x,y,z)=z-F(x,y).
\]

Thus, if we set
\[
dF(x,y)=tdx+udy
\]
we obtain
\[
P=-t,\qquad Q=-u,\qquad R=1,
\]
where $t,u$ are functions only of $x$ and $y$. We further set
\[
dt=Tdx+Udy,\qquad du=Udx+Vdy.
\]

On the entire surface we therefore have
\[
dz=tdx+udy
\]
and hence on the curve
\[
\zeta=t\xi+u\eta.
\]
Differentiating and substituting the above values for $d\xi,d\eta,d\zeta$ gives
\[
\begin{aligned}
(\zeta'-t\xi'-u\eta')\frac{ds}{r}&=\xi dt+\eta du\\
&=(\xi\xi T+2\xi\eta U+\eta\eta V)ds
\end{aligned}
\]
or
\[
\begin{aligned}
\frac1r&=\frac{\xi\xi T+2\xi\eta U+\eta\eta V}{-\xi't-\eta'u+\zeta'}\\
&=\frac{Z(\xi\xi T+2\xi\eta U+\eta\eta V)}{X\xi'+Y\eta'+Z\zeta'}\\
&=\frac{Z(\xi\xi T+2\xi\eta U+\eta\eta V)}{\cos L\lambda'}.
\end{aligned}
\]
