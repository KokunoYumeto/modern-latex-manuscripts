# Jean-Pierre Serre: FAC partial working transcription

This package preserves a readable French working transcription of Jean-Pierre
Serre's *Faisceaux algebriques coherents* (Annals of Mathematics (2) 61
(1955), 197-278).

## Current scope

- 70 of the 82 printed source pages are transcribed.
- The current reader is 54 A4 pages.
- Missing source indices are 21, 22, 25, 26, 71, 72, 73, 74, 77, 78, 79,
  and 80. With printed page equal to source index plus 196, these are printed
  pages 217, 218, 221, 222, 267, 268, 269, 270, 273, 274, 275, and 276.
- Source indices 1-82 have all been classified; the twelve gaps are omitted
  rather than filled with placeholder prose.

The reader is useful mathematical work, but it is not a complete
transcription, critical edition, mathematical certification, or accessibility
certification. Citation-critical formulas and unusual readings should still be
checked against the source.

## Public files

- `reader/Serre_FAC_French_Partial_Working_Transcription_20260731.pdf` is the
  direct 54-page reader.
- `source/fac.tex` and `source/fac_body.tex` are the editable source closure.
- `evidence/SOURCE_NOTES.md` records source defects and uncertain readings.
- `visual-evidence/` contains four actual scan-derived crops opened during
  source work, plus exact page, rasterization, bounding-box, dimension, and
  hash provenance. They are source pixels, not screenshots of the reader.
- `release/02_Serre_FAC_French_Partial_Source_and_Visual_Evidence_20260731.zip`
  is the compact FAC source/evidence download.
- `release/03_Serre_GAGA_French_FirstPass_TeX_Custody_20260731.zip` preserves
  the separately completed first-pass GAGA TeX source. Its earlier reader is
  withheld because visible page-join sentinels remain.

The raw build log, auxiliary file, authority PDF, private caches, and process
status notes are not part of this public package.
