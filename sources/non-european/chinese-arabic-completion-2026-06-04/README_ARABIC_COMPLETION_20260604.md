Chinese Mathematical Classics - Arabic Translation Completion Package

Date: 2026-06-04

This package contains the current Arabic translation TeX/PDF outputs for the
Chinese mathematical classics slice of the project. It was recovered from the
Claude output folder and checked locally by Codex before publication.

Scope:

- Jiuzhang Suanshu / Nine Chapters, vols. 1-9
- Li Ye, Ceyuan Haijing, vols. 1-12
- Qin Jiushao, Shuxue Jiuzhang, fascicles 1-9
- Sunzi Suanjing
- Yang Hui, Xiangjie Jiuzhang, parts 1-3

The source folder keeps every lower-level TeX/PDF file, including overlapping
or redundant pieces such as Qin fascicle 4 as a standalone file. The public
combined readers avoid double-counting that overlap.

Local Codex checks:

- 17 individual PDF files opened and were page-counted.
- 17 TeX source files are present.
- Five combined reader PDFs were assembled for the public surface.
- Combined reader page counts: Nine Chapters 67, Li Ye 104, Qin 116, Sunzi 7,
  Yang Hui 74.
- Short-path text extraction found no obvious process labels such as ChatGPT,
  Claude, sandbox, prompt, agent, screenshot, or TODO.
- Visual spot checks showed readable Chinese/Arabic parallel layout on sampled
  pages. Translation accuracy has not been independently proofread by a human.

Status:

Working translation draft, suitable for public inspection and continuation; not
