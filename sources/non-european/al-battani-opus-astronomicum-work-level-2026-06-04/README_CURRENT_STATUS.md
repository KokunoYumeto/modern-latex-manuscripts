# al-Battani Opus Astronomicum: current work status

This record is the single work-level Zenodo record for al-Battani's *Opus Astronomicum* / *Kitab al-Zij*. Earlier versions of this same concept DOI foregrounded the fixed-star catalogue; the record now gathers the full al-Battani work package without creating a second DOI for the same work.

Important correction: the generated trilingual text reader is a working layout draft, not a finished canonical edition. It represents the 100 body-text segments, but its text stream has not yet been fully audited against Nallino and its tables are not inserted at their proper locations in the work. It is therefore included as a preserved working artifact, not as the front-facing final reader.

The most reliable current components are:

- the Nallino source witness for the original work;
- the canonical v083 TeX/data/report package for the text stream;
- the complete fixed-star catalogue table edition and dataset;
- the complete geographical gazetteer table edition and dataset;
- the useful but partial chronology / Canon of Kings layer;
- the Claude source/data/workflow package, which preserves the actual scripts, notes, source slices, and working files used to reconstruct the table layers.

Known open work:

- build a professional reader with proper front matter, contents, chapter order, and tables placed where they belong;
- audit the round83 trilingual text stream against Nallino;
- collate the ancient regnal figures in the chronology layer;
- source the zodiac / terms / houses auxiliary numerical tables from an appropriate Arabic witness or another reliable table source.

No table values are fabricated here. Where a table layer is not supported by the current source witness, it is marked as open rather than silently filled.
