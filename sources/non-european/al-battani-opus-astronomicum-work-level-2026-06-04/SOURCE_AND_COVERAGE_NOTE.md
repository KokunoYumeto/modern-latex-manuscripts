# Source and Coverage Note

This is the work-level record for al-Battani's *Opus Astronomicum* / *Kitab al-Zij*. Earlier versions of this same Zenodo concept foregrounded the fixed-star catalogue; the current version supersedes that presentation and gathers the whole al-Battani work package in one place.

Reader scope:
- Working trilingual text reader: 100 body-text segments, Arabic source with English and Chinese translations. This is a layout/audit draft, not a professional canonical reader.
- Nallino source witness for audit.
- Canonical v083 TeX/data/report package.
- Table reference supplement.
- Fixed-star catalogue: 485 numbered star rows across 47 Ptolemaic figures, with ecliptic longitude and latitude values, north/south signs, magnitudes, and modern identification fields. The Escorial-codex lacuna for Argo Navis, Hydra, and the start of Crater is shown explicitly rather than filled silently.
- Geographical gazetteer: 269 locality entries.
- Chronology / Canon of Kings: partial working edition, with ancient regnal-year figures still flagged for collation.

Main source witness:
- C. A. Nallino, *Al-Battani sive Albatenii Opus Astronomicum*, especially Pars II (Milan, 1907), printed table "Situs et magnitudines stellarum fixarum anno 1191 a Dhu 'l-qarnayn".

This record exists so the al-Battani work itself is easy to cite, download, and reuse. The broader non-European mathematics record remains the umbrella corpus and provenance shelf. The front-facing publication status should be read from the current-status note: the source and table/data layers are stronger than the assembled reader.
