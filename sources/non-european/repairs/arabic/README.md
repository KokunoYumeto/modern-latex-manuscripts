# al-Khwarizmi 30-05 reader repair

The public 30-05 reader is a romanized transliteration/commentary draft, not Arabic-script prose.
This repaired TeX build uses left-to-right English document direction and fonts with both Latin and Arabic coverage, removing the boxed-glyph failure visible in the prior public PDF.
The Arabic-script original-language draft remains the separate 60-02 reader.
