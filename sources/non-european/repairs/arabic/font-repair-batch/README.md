# Arabic reader font repair batch

These files preserve the local-font TeX/PDF builds promoted to the public reader surface.
The repair pass replaces Linux-only Noto font paths with Windows-available fonts and keeps CJK/Arabic shaping readable.
30-03 Yang Hui is not promoted in this batch because the current source still needs a clean complete rebuild.
