# Non-European Mathematics Sources

This folder mirrors the editable TeX/source bundle for the current Non-European Mathematics Zenodo record:

https://zenodo.org/records/20423975

The combined TeX files are inspection and review bundles, organized by language/corpus and by work where possible. Many constituent sources are standalone LaTeX documents with their own preambles, so the combined bundles are not asserted to compile as single documents without further editing.

Some source-rendered PDF components are intentionally held out of the top-level reader surface on Zenodo because they contain visible upstream error-page artifacts. They are preserved in the source/provenance archives for rerendering and repair rather than being presented as clean public readers.
