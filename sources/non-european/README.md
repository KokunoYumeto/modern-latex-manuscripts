# Non-European multilingual TeX sources

This ZIP contains combined TeX source bundles by language/corpus and the
individual TeX/support files used to produce the current public PDFs.

The combined files are inspection and review bundles. Many constituent
sources are standalone LaTeX documents with their own preambles, so the
combined source bundle is not asserted to compile as one document.

## Partly hallucinated drafts

The TeX sources of the *Nine Chapters* (`sources/chinese/jiuzhang-suanshu-*`), Li Ye's *Ceyuan haijing* (`sources/chinese/li-ye-ceyuan-haijing-vols*`), Qin Jiushao's *Shuxue jiuzhang* (`sources/chinese/qin-jiushao-*`), the *Āryabhaṭīya* (`sources/indian/aryabhata-aryabhatiya.tex`) and the *Līlāvatī* (`sources/indian/bhaskara-ii-lilavati.tex`), and the translations made from them under `sources/translations/`, are partly hallucinated drafts: they contain text the historical authors did not write. See `reader-pdfs/non-european/partly-hallucinated-drafts/README.md`.
