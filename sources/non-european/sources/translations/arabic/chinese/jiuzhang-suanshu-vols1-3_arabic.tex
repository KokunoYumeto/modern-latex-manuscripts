\section*{劉徽九章算術注原序 | \ar{الْمُقَدِّمَةُ لِلْجُزْآنِ فِي عِلْمِ الْحِسَابِ}}
\addcontentsline{toc}{section}{Preface: 劉徽九章算術注原序}

\begin{bilingual}
\cnline{%
\begin{center}
\rule{0.4\columnwidth}{0.4pt}
\end{center}
}
\arline{%
\begin{center}
\rule{0.4\columnwidth}{0.4pt}
\end{center}
}

\cnline{%
昔在包犧氏始畫八卦，以通神明之德，以類萬物之情，作九九之術以合六爻之變。
}
\arline{%
قَدِيمًا، فِي زَمَنِ بَاوْ شِي، رَسَمَ الثَّمَانِيَةَ الأَخْطُوطَ، لِيُطْلِعَ عَلَى خَصَائِصِ الْآلِهَةِ، وَلِيَصِفَ طَبَائِعَ الْخَلَائِقِ، وَابْتَدَعَ طَرِيقَةَ التَّرْقِيمِ التِّسْعِيَّةَ لِتُطَابِقَ تَغَيُّرَاتِ الْخُطُوطِ السِّتَّةِ.
}

\cnline{%
暨於黃帝神而化之，引而伸之，於是建曆紀，協律呂，用稽道原，然後兩儀四象精微之氣可得而效焉。
}
\arline{%
ثُمَّ فِي زَمَنِ الْإِمْبَرَاطُورِ الأَصْفَرِ، تَمَّ تَطْوِيرُهَا وَتَوْسِيعُهَا، فَأُنْشِئَ التَّقْوِيمُ وَالْمَوَازِينُ الصَّوْتِيَّةُ، وَبِهَا تَمَّ اسْتِقْصَاءُ أَصْلِ الطَّرِيقِ، وَحِينَئِذٍ أَصْبَحَ مِنَ الْمُمْكِنِ فَهْمُ دِقَّةِ قُوَى الْأَرْضَيْنِ وَالصُّوَرِ الأَرْبَعِ.
}

\cnline{%
記稱隸首作數，其詳未之聞也。
}
\arline{%
وَفِي السِّجِلَّاتِ أَنَّ لِي شُو أَوَّلَ مَنْ وَضَعَ الْعَدَدَ، لَكِنَّ التَّفَاصِيلَ لَمْ تَصِلْنَا.
}

\cnline{%
按周公制禮而有九數，九數之流，則九章是矣。
}
\arline{%
وَحَسَبَ مَا وَرَدَ، فَإِنَّ دُكْ أُونْ وَضَعَ الطَّقْسَ فَكَانَتِ التِّسْعُ عُلُومِ الرِّيَاضِيَّاتِ، وَمِنْ سَيْلِ هَذِهِ التِّسْعَةِ كَانَ هَذَا الْكِتَابُ الْجُزْآنِ.
}

\cnline{%
往者暴秦焚書，經術散壞。自時厥後，漢北平侯張蒼、大司農中丞耿壽昌皆以善算命世。
}
\arline{%
فِي الْعَهْدِ السَّابِقِ، حِينَ أَحْرَقَتْ دَوْلَةُ تْشِنَ الْعُنِيفَةَ الْكُتُبَ، تَشَتَّتَتِ الْعُلُومُ. وَمُنْذُ ذَلِكَ الْوَقْتِ، فَإِنَّ جَانَغ تْسَانْغ وَغِنْغ شُو شْانْغ مِنْ حَاكِمِيَّةِ هَانْ قَدْ أَتْقَنُوا فَنَّ الْحِسَابِ.
}

\cnline{%
蒼等因舊文之遺殘，各稱刪補。故校其目則與古或異，而所論者多近語也。
}
\arline{%
وَقَامَ تْشَانْغ وَغَيْرُهُ بِتَنْظِيمِ مَا تَبَقَّى مِنَ النُّصُوصِ الْقَدِيمَةِ، فَكَانَتْ عُنَوَانُهَا قَدْ تَخْتَلِفُ عَنِ الْقَدِيمِ، وَكَانَتْ مُسْتَخْدَمَةً بِلُغَةٍ قَرِيبَةٍ.
}

\cnline{%
徽幼習九章，長再詳覽。觀陰陽之割裂，總算術之根源，探賾之暇，遂悟其意。
}
\arline{%
أَنَا هُوِي، فِي صِغَرِي تَعَلَّمْتُ الْجُزْآنَ، وَفِي كِبَرِي دَرَسْتُهَا مُفَصَّلًا. أَرَى تَقْسِيمَ الْيِنِ وَالْيَانْغِ، وَأَجْمَعُ جُذُورَ عِلْمِ الْحِسَابِ، وَفِي أَوْقَاتِ الِاسْتِكْشَافِ، أَدْرَكْتُ مَعْنَاهَا.
}

\cnline{%
是以敢竭頑魯，采其所見，為之作注。
}
\arline{%
لِهَذَا أَجْرُؤُ عَلَى بَذْلِ جُهْدِي، مُسْتَخْدِمًا مَا أَرَاهُ، لِأَشْرَحَ هَذَا الْكِتَابَ.
}

\cnline{%
事類相推，各有攸歸，故枝條雖分而同本榦者，知發其一端而已。
}
\arline{%
الْأُمُورُ تَتَشَابَهُ وَتَتَشَابَكُ، لِكُلٍّ مِنْهَا مَصِيرُهَا، فَالْأَفْرُعُ مُنْتَشِرَةٌ لَكِنَّ لَهَا أَصْلًا وَاحِدًا، وَمَنْ يَعْرِفُ بِدَايَتَهَا يَعْرِفُ كُلَّ شَيْءٍ.
}

\cnline{%
又所析理以辭，解體用圖，庶亦約而能周，通而不黷，覽之者思過半矣。
}
\arline{%
وَأُوَضِّحُ الْمَبَادِئَ بِاللُّغَةِ، وَأَشْرَحُ الْهَيْكَلَ بِالرُّسُومِ، لَعَلَّهَا تَكُونُ مُوجَزَةً وَشَامِلَةً، وَاضِحَةً غَيْرَ مُبْهَمَةٍ، فَيَفْهَمَ الْقَارِئُ نِصْفَ الْمَعْنَى بِنِصْفِ الْعَمَلِ.
}

\cnline{%
且算在六藝，古者以賓興賢能，教習國子。雖曰九數，其能窮纖入微，探測無方。
}
\arline{%
الْحِسَابُ مِنَ الْفُنُونِ السِّتَّةِ، وَفِي الْقُدُمَاءِ كَانَ يُسْتَخْدَمُ لِتَرْبِيَةِ أَبْنَاءِ الدَّوْلَةِ. وَمَعَ أَنَّهَا تُسَمَّى التِّسْعَ عُلُومٍ، فَإِنَّهَا تَسْتَطِيعُ أَنْ تَصِلَ إِلَى أَدْقِّ التَّفَاصِيلِ وَأَدْنَى الْمَرَاتِبِ.
}

\cnline{%
至於以法相傳，亦猶規矩度量可得而共，非特難為也。
}
\arline{%
وَأَمَّا تَنَاقُلُ الطُّرُقِ، فَإِنَّهُ كَالْمِقْيَاسِ وَالْمِيزَانِ الَّذِي يُمْكِنُ الِاشْتِرَاكُ فِيهِ، وَلَيْسَ بِالْأَمْرِ الصَّعْبِ.
}

\cnline{%
當今好之者寡，故世雖多通才達學，而未必能綜於此耳。
}
\arline{%
فِي هَذَا الزَّمَانِ قَلَّ الْمُحِبُّونَ لَهَا، فَالْعَالَمُ مَلِيءٌ بِالْمَوَاهِبِ وَالْعُلُومِ، لَكِنَّهُمْ لَا يَسْتَطِيعُونَ الْجَمْعَ بَيْنَهَا فِي هَذَا الْفَنِّ.
}

\cnline{%
周官大司徒職，夏至日中立八尺之表，其景尺有五寸，謂之地中。
}
\arline{%
فِي مَنْصِبِ الْمُعَلِّمِ الْكَبِيرِ لِدُوْلَةِ تْشُو، فِي يَوْمِ الْصَّيْفِ، تُوضَعُ عَصَا بِطُولِ ثَمَانِيَةِ أَذْرُعٍ، وَظِلُّهَا خَمْسَةَ عَشَرَ بُوصَةً، وَيُسَمَّى مَرْكَزَ الْأَرْضِ.
}

\cnline{%
徽尋九數有重差之名，原其指趣乃所以施於此也。
}
\arline{%
وَأَجِدُ أَنَّ مِنَ التِّسْعِ عُلُومٍ مَا يُسَمَّى الِاسْتِقْصَاءَ، وَأَصْلُ مَعْنَاهُ يُطَبَّقُ هُنَا.
}

\cnline{%
凡望極高、測絕深而兼知其遠者必用重差，句股則必以重差為率，故曰重差也。
}
\arline{%
فِي كُلِّ مَنْظَرٍ إِلَى عُلْوٍ شَاهِقٍ، أَوْ قِيَاسِ عُمْقٍ لَا يُنْتَهَى، أَوْ مَعْرِفَةِ بُعْدٍ مَعَهُمَا، يَجِبُ اسْتِخْدَامُ الِاسْتِقْصَاءِ، وَالْوَتْرُ وَالْعَمُودُ يَسْتَخْدِمَانِهِ كَنِسْبَةٍ، فَلِهَذَا يُسَمَّى اسْتِقْصَاءً.
}

\cnline{%
雖天圓穹之象猶曰可度，又況泰山之高與江海之廣哉。
}
\arline{%
وَمَعَ أَنَّ صُورَةَ السَّمَاءِ الْمُدَوَّرَةِ الْمُقَبَّبَةِ قَابِلَةٌ لِلْقِيَاسِ، فَكَيْفَ بِعُلُوِّ جَبَلِ تَايْ شَانْ وَاتِّسَاعِ الْأَنْهَارِ وَالْبِحَارِ؟
}

\cnline{%
徽以為今之史籍且略舉天地之物，考論厥數，載之於志，以闡世術之美。
}
\arline{%
أَظُنُّ أَنَّ كُتُبَ التَّارِيخِ الْحَالِيَّةَ تُعْطِي نَظْرَةً مُجْمَلَةً عَلَى أَشْيَاءِ السَّمَاءِ وَالْأَرْضِ، فَأُحَقِّقُ أَعْدَادَهَا وَأَسْجُلُهَا فِي مُذَكَّرَاتِي، لِأُبَيِّنَ جَمَالَ فُنُونِ الْعَالَمِ.
}

\cnline{%
輒造重差，并為注解，以究古人之意，綴於句股之下。
}
\arline{%
أَصْنَعُ الِاسْتِقْصَاءَ وَأُشَرِّحُهُ، لِأَسْتَقْصِيََ مَقَاصِدَ الْقُدَمَاءِ، وَأُلْحِقُهُ بِفَصْلِ الْوَتْرِ وَالْعَمُودِ.
}

\cnline{%
度高者重表，測深者累矩，孤離者三望，離而又旁求者四望。
}
\arline{%
قِيَاسُ الْعُلُوِّ بِالْجَدَاوِلِ الْمُضَاعَفَةِ، وَقِيَاسُ الْعُمْقِ بِالْمَنَاسِيرِ الْمُتَرَاكِمَةِ، وَالْمَوْقِفُ الْمُنْفَرِدُ يَحْتَاجُ ثَلَاثَ مَنَاظِرَ، وَالْمَوْقِفُ الْمُنْفَرِدُ ذُو الِاسْتِكْشَافِ الْجَانِبِيِّ يَحْتَاجُ أَرْبَعَ مَنَاظِرَ.
}

\cnline{%
觸類而長之，則雖幽遐詭伏，靡所不入。
}
\arline{%
مَنْ طَبَّقَ هَذَا عَلَى أَصْنَافِ الْأُمُورِ وَتَمَادَى فِيهِ، فَإِنَّهُ يَصِلُ إِلَى كُلِّ خَافِيَةٍ وَبَعِيدَةٍ وَغَامِضَةٍ، وَلَا شَيْءَ يَعْجِزُ عَنْهُ.
}

}

\section{卷第一：方田 | \ar{الْجُزْءُ الأَوَّلُ: الْحُقُولُ الْمُسْتَطِيلَةُ}}
\label{sec:fangtian}
\addcontentsline{toc}{subsection}{Fangtián -- Rectangular Fields | \ar{الْحُقُولُ الْمُسْتَطِيلَةُ}}

\begin{center}
\textit{方田以御田疇界域} \quad|\quad \textit{\ar{الْحُقُولُ الْمُسْتَطِيلَةُ لِلْمُعَالَجَةِ حُدُودِ الْأَرَاضِي}}
\end{center}

\bigskip

\begin{bilingual}
\cnline{%
\noindent\textbf{方田}者，田之正也。諸田不等，以方為正，故曰方田。此章以御田疇界域，論各種田地面積之計算法，并及分數四則運算之法。
}
\arline{%
\textbf{الْحُقُولُ الْمُسْتَطِيلَةُ}: هِيَ أَصْلُ الْحُقُولِ. الْحُقُولُ مُخْتَلِفَةٌ، وَالْمُسْتَطِيلُ هُوَ الْأَصْلُ، فَلِهَذَا سُمِّيَتْ "الْحُقُولَ الْمُسْتَطِيلَةَ". يُعَالِجُ هَذَا الْفَصْلُ حُدُودَ الْأَرَاضِي، وَيَنَاقِشُ طُرُقَ حِسَابِ مَسَاحَاتِ الْحُقُولِ مِنْ أَنْوَاعٍ مُخْتَلِفَةٍ، وَأَيْضًا عَمَلِيَّاتِ الْكُسُورِ الأَرْبَعِ.
}
\end{bilingual}

\bigskip

%% ----- Problems 1-2 -----
\begin{bilingual}
\cnline{\problemnum{一}\, 今有田廣十五步，從十六步。問為田幾何？}
\arline{\problemnum{١}\, يُوجَدُ حَقْلٌ عَرْضُهُ خَمْسَةَ عَشَرَ خُطْوَةً، وَطُولُهُ سِتَّةَ عَشَرَ خُطْوَةً. كَمْ مِنَ الأَرْضِ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}一畝。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} مُوّ (وَحِدَةُ مِسَاحَةٍ).}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{二}\, 又有田廣十二步，從十四步。問為田幾何？}
\arline{\problemnum{٢}\, وَفِي حَقْلٍ آخَرَ عَرْضُهُ اثْنَا عَشَرَ خُطْوَةً، وَطُولُهُ أَرْبَعَ عَشْرَةَ خُطْوَةً. كَمْ مِنَ الأَرْضِ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}一百六十八步。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} مِئَةٌ وَثَمَانٍ وَسِتُّونَ خُطْوَةً.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{方田術曰：}}廣從步數相乘得積步。以畝法二百四十步除之，即畝數。百畝為一頃。
}
\arline{%
\textcolor{methodcolor}{\textbf{طَرِيقَةُ الْحُقُولِ الْمُسْتَطِيلَةِ:}} اضْرِبْ عَدَدَ خُطُوَاتِ الْعَرْضِ فِي عَدَدِ خُطُوَاتِ الطُّولِ فَتَحْصُلُ عَلَى الْمِسَاحَةِ. اقْسِمْ عَلَى مِئَتَيْنِ وَأَرْبَعِينَ خُطْوَةً لِكُلِّ مُوّ، فَتَحْصُلُ عَلَى عَدَدِ الْمُوّاتِ. وَمِائَةُ مُوّ تُسَاوِي قِرْيَةً وَاحِدَةً.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}此積謂田之冪。凡廣從相乘謂之冪。畝法二百四十步者，古制也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} هَذِهِ الْمِسَاحَةُ هِيَ مُرَبَّعُ الْحَقْلِ. وَكُلُّ مَا يُحْصَلُ عَلَيْهِ مِنْ ضَرْبِ الْعَرْضِ فِي الطُّولِ يُسَمَّى مُرَبَّعًا. وَمِئَتَانِ وَأَرْبَعُونَ خُطْوَةً لِكُلِّ مُوّ هِيَ النِّظَامُ الْقَدِيمُ.
}
\end{bilingual}

%% ----- Problems 3-4 -----
\begin{bilingual}
\cnline{\problemnum{三}\, 今有田廣一里，從一里。問為田幾何？}
\arline{\problemnum{٣}\, يُوجَدُ حَقْلٌ عَرْضُهُ لِيٌّ وَاحِدٌ، وَطُولُهُ لِيٌّ وَاحِدٌ. كَمْ مِنَ الأَرْضِ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}三頃七十五畝。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} ثَلَاثُ قُرًى وَخَمْسَةٌ وَسَبْعُونَ مُوًّا.}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{四}\, 又有田廣二里，從三里。問為田幾何？}
\arline{\problemnum{٤}\, وَفِي حَقْلٍ آخَرَ عَرْضُهُ لِيَّانِ، وَطُولُهُ ثَلَاثَةُ أَلْيَاتٍ. كَمْ مِنَ الأَرْضِ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}二十二頃五十畝。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} اثْنَتَانِ وَعِشْرُونَ قَرْيَةً وَخَمْسُونَ مُوًّا.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{里田術曰：}}廣從里數相乘得積里。以三百七十五乘之，即畝數。
}
\arline{%
\textcolor{methodcolor}{\textbf{طَرِيقَةُ حُقُولِ اللِّي:}} اضْرِبْ عَدَدَ أَلْيَاتِ الْعَرْضِ فِي عَدَدِ أَلْيَاتِ الطُّولِ فَتَحْصُلُ عَلَى مِسَاحَةِ الْأَلْيَاتِ. اضْرِبْ ذَلِكَ فِي ثَلَاثِمِائَةٍ وَخَمْسَةٍ وَسَبْعِينَ، فَتَحْصُلُ عَلَى عَدَدِ الْمُوّاتِ.
}
\end{bilingual}

%% ----- Problems 5-6 (Fraction reduction) -----
\begin{bilingual}
\cnline{\problemnum{五}\, 今有十八分之十二。問約之得幾何？}
\arline{\problemnum{٥}\, يُوجَدُ اثْنَا عَشَرَ عَلَى ثَمَانِيَةَ عَشَرَ. كَمْ يَكُونُ بَعْدَ الِاخْتِصَارِ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}三分之二。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} ثُلْثَانِ.
}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{六}\, 又有九十一分之四十九。問約之得幾何？}
\arline{\problemnum{٦}\, وَفِي كَسْرٍ آخَرَ تِسْعَةٌ وَأَرْبَعُونَ عَلَى وَاحِدٍ وَتِسْعِينَ. كَمْ يَكُونُ بَعْدَ الِاخْتِصَارِ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}十三分之七。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} سَبْعَةٌ عَلَى ثَلَاثَةَ عَشَرَ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{約分術曰：}}可半者半之，不可半者，副置分母子之數，以少減多，更相減損，求其等也。以等數約之。
}
\arline{%
\textcolor{methodcolor}{\textbf{طَرِيقَةُ اخْتِصَارِ الْكُسُورِ:}} مَا يَنْقَسِمُ إِلَى النِّصْفِ فَانْصِفْهُ، وَمَا لَا يَنْقَسِمُ، فَضَعْ أَعْدَادَ الْبَسْطِ وَالْمَقَامِ عَلَى الْجَانِبِ، وَاطْرَحِ الْأَصْغَرَ مِنَ الْأَكْبَرِ، وَكَرِّرِ الطَّرْحَ بَيْنَهُمَا، فَتَطْلُبُ الْعَدَدَ الْمُشْتَرَكَ. وَبِالْعَدَدِ الْمُشْتَرَكِ تُبَسِّطُ الْكَسْرَ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}約分者，物之數量不可悉全，必以分言之。等數者，約之篤也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} الِاخْتِصَارُ: كَمِّيَاتُ الْأَشْيَاءِ لَا تَكُونُ كَامِلَةً عَادَةً، فَلَابُدَّ مِنَ التَّعْبِيرِ عَنْهَا بِالْكُسُورِ. وَالْعَدَدُ الْمُشْتَرَكُ هُوَ أَصْلُ الِاخْتِصَارِ.
}
\end{bilingual}

%% ----- Problems 7-9 (Adding fractions) -----
\begin{bilingual}
\cnline{\problemnum{七}\, 今有三分之一，五分之二。問合之得幾何？}
\arline{\problemnum{٧}\, يُوجَدُ ثُلْثٌ، وَثُلْثَانِ مِنْ خَمْسَةٍ. كَمْ يَكُونُ مَجْمُوعُهَا؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}十五分之十一。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} أَحَدَ عَشَرَ عَلَى خَمْسَةَ عَشَرَ.}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{八}\, 又有三分之二，七分之四，九分之五。問合之得幾何？}
\arline{\problemnum{٨}\, وَكَسْرٌ آخَرُ: اثْنَانِ عَلَى ثَلَاثَةٍ، وَأَرْبَعَةٌ عَلَى سَبْعَةٍ، وَخَمْسَةٌ عَلَى تِسْعَةٍ. كَمْ يَكُونُ مَجْمُوعُهَا؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}得一、六十三分之五十。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} وَاحِدٌ، وَخَمْسُونَ عَلَى ثَلَاثَةٍ وَسِتِّينَ.}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{九}\, 又有二分之一，三分之二，四分之三，五分之四。問合之得幾何？}
\arline{\problemnum{٩}\, وَكَسْرٌ آخَرُ: نِصْفٌ، وَثُلْثَانِ، وَثَلَاثَةٌ عَلَى أَرْبَعَةٍ، وَأَرْبَعَةٌ عَلَى خَمْسَةٍ. كَمْ يَكُونُ مَجْمُوعُهَا؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}得二、六十分之四十三。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} اثْنَانِ، وَثَلَاثَةٌ وَأَرْبَعُونَ عَلَى سِتِّينَ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{合分術曰：}}母互乘子，并為實，母相乘為法，實如法而一。不滿法者，以法命之。其母同者，直相從之。
}
\arline{%
\textcolor{methodcolor}{\textbf{طَرِيقَةُ جَمْعِ الْكُسُورِ:}} اضْرِبْ كُلَّ مَقَامٍ فِي بَسْطِ الْمَقَامِ الْآخَرِ، وَاجْمَعْ فَتَحْصُلُ عَلَى الْبَسْطِ. وَاضْرِبِ الْمَقَامَاتِ بَعْضُهَا فِي بَعْضٍ فَتَكُونُ الْمَقَامَ. وَاقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ. فَإِنْ بَقِيَ شَيْءٌ، فَأَطْلِقْ عَلَيْهِ اسْمَ الْمَقَامِ. فَإِنْ تَسَاوَتِ الْمَقَامَاتُ، فَاجْمَعْ مُبَاشَرَةً.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}合分者，并數之義也。母互乘子，約而言之。母相乘為法者，齊而同之也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} جَمْعُ الْكُسُورِ: هُوَ مَعْنَى جَمْعِ الْأَعْدَادِ. ضَرْبُ كُلِّ مَقَامٍ فِي بَسْطِ الْآخَرِ هُوَ تَبْسِيطٌ. وَضَرْبُ الْمَقَامَاتِ بَعْضُهَا فِي بَعْضٍ لِيَكُونَ الْمَقَامَ هُوَ تَوْحِيدُهَا.
}
\end{bilingual}

\begin{bilingual}

\end{bilingual}

\begin{bilingual}

}
\arline{%
\textcolor{methodcolor}{\textbf{طَرِيقَةُ طَرْحِ الْكُسُورِ:}} اضْرِبْ كُلَّ مَقَامٍ فِي بَسْطِ الْآخَرِ، وَاطْرَحِ الْأَصْغَرَ مِنَ الْأَكْبَرِ، فَالْبَاقِي يَكُونُ بَسْطًا. وَاضْرِبِ الْمَقَامَاتِ بَعْضُهَا فِي بَعْضٍ فَتَكُونُ الْمَقَامَ. وَاقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ.

%% ----- Problems 12-14 (Comparing fractions) -----
\begin{bilingual}
\cnline{\problemnum{一二}\, 今有八分之五，二十五分之十六。問孰多？多幾何？}
\arline{\problemnum{١٢}\, يُوجَدُ خَمْسَةٌ عَلَى ثَمَانِيَةٍ، وَسِتَّةَ عَشَرَ عَلَى خَمْسَةٍ وَعِشْرِينَ. أَيُّهُمَا أَكْبَرُ؟ وَبِكَمْ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}二十五分之十六多，多二百分之三。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} سِتَّةَ عَشَرَ عَلَى خَمْسَةٍ وَعِشْرِينَ هُوَ الْأَكْبَرُ، بِزِيَادَةِ ثَلَاثَةٍ عَلَى مِئَتَيْنِ.}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{一三}\, 又有九分之八，七分之六。問孰多？多幾何？}
\arline{\problemnum{١٣}\, وَكَسْرَانِ آخَرَانِ: ثَمَانِيَةٌ عَلَى تِسْعَةٍ، وَسِتَّةٌ عَلَى سَبْعَةٍ. أَيُّهُمَا أَكْبَرُ؟ وَبِكَمْ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}九分之八多，多六十三分之二。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} ثَمَانِيَةٌ عَلَى تِسْعَةٍ هِيَ الْأَكْبَرُ، بِزِيَادَةِ اثْنَيْنِ عَلَى ثَلَاثَةٍ وَسِتِّينَ.}

\textcolor{methodcolor}{\textbf{術曰：}}半周半徑相乘得積步。

又術曰：周徑相乘，四而一。

又術曰：徑自相乘，三之，四而一。

又術曰：周自相乘，十二而一。

\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} نِصْفُ الْمُحِيطِ مَضْرُوبٌ فِي نِصْفِ الْقُطْرِ فَيَحْصُلُ عَلَى الْمِسَاحَةِ.

طَرِيقَةٌ أُخْرَى: اضْرِبِ الْمُحِيطَ فِي الْقُطْرِ، وَاقْسِمْ عَلَى أَرْبَعَةٍ.

طَرِيقَةٌ أُخْرَى: اضْرِبِ الْقُطْرَ فِي نَفْسِهِ، وَاضْرِبْ فِي ثَلَاثَةٍ، وَاقْسِمْ عَلَى أَرْبَعَةٍ.

طَرِيقَةٌ أُخْرَى: اضْرِبِ الْمُحِيطَ فِي نَفْسِهِ، وَاقْسِمْ عَلَى اثْنَيْ عَشَرَ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}此于徽術，當為田十畝二百八步三百一十四分步之一百一。臣淳風等謹依密率，為田十畝二百步八十八分步之八十七。

按：半周為從，半徑為廣，故廣從相乘為積步也。假令圓徑二尺，圓中容六觚之一面，與圓徑之半，其數均等。合徑率一而外周率三也。

又按：為圖，以六觚之一面乘一弧半徑，三之，得十二觚之冪。若又割之，次以十二觚之一面乘一弧之半徑，六之，則得二十四觚之冪。割之彌細，所失彌少。割之又割，以至于不可割，則與圓周合體而無所失矣。觚面之外，又有餘徑。以面乘餘徑，則冪出觚表。若夫觚之細者，與圓合體，則表無餘徑。表無餘徑，則冪不外出矣。以一面乘半徑，觚而裁之，每輒自倍。故以半周乘半徑而為圓冪。

此一周、徑，謂至然之數，非周三徑一之率也。周三者，從其六觚之環耳。以推圓規多少之覺，乃弓之與弦也。然世傳此法，莫肯精核；學者踵古，習其謬失。不有明據，辯之斯難。凡物類形象，不圓則方。方圓之率，誠著于近，則雖遠可知也。由此言之，其用博矣。謹按圖驗，更造密率。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} وَحَسَبَ طَرِيقَتِي، يَجِبُ أَنْ يَكُونَ الْحَقْلُ عَشَرَةَ مُوّاتٍ وَمِائَتَيْنِ وَثَمَانِيَ خُطُوَاتٍ وَمِائَةً وَوَاحِدًا عَلَى ثَلَاثِمِائَةٍ وَأَرْبَعَةَ عَشَرَ. وَحَسَبَ النِّسْبَةِ الدَّقِيقَةِ لِي شُونْفِنْج: عَشَرَةُ مُوّاتٍ وَمِائَتَانِ مِنَ الْخُطْوَةِ وَسَبْعٌ وَثَمَانُونَ عَلَى ثَمَانٍ وَثَمَانِينَ مِنَ الْخُطْوَةِ.

التَّفْسِيرُ: نِصْفُ الْمُحِيطِ هُوَ الطُّولُ، وَنِصْفُ الْقُطْرِ هُوَ الْعَرْضُ، فَضَرْبُ الْعَرْضِ فِي الطُّولِ يُعْطِي الْمِسَاحَةَ. لِنَفْتَرِضْ أَنَّ قُطْرَ الدَّائِرَةِ ذِرَاعَانِ، فَوَجْهُ السِّدَاسِيِّ الْمَكْتُوبِ فِيهَا مَعَ نِصْفِ الْقُطْرِ يَتَسَاوَيَانِ. فَنِسْبَةُ الْقُطْرِ وَاحِدٌ، وَنِسْبَةُ الْمُحِيطِ ثَلَاثَةٌ.

وَأَيْضًا: فِي الرَّسْمِ، اضْرِبْ وَجْهَ السِّدَاسِيِّ فِي نِصْفِ قُطْرِ الْقَوْسِ، وَاضْرِبْ فِي ثَلَاثَةٍ، فَتَحْصُلُ عَلَى مِسَاحَةِ الِاثْنَيْ عَشَرَ ضِلْعًا. فَإِنْ قُسِّمَتْ مَرَّةً أُخْرَى، ثُمَّ اضْرِبْ وَجْهَ الِاثْنَيْ عَشَرَ ضِلْعًا فِي نِصْفِ قُطْرِ الْقَوْسِ، وَاضْرِبْ فِي سِتَّةٍ، فَتَحْصُلُ عَلَى مِسَاحَةِ الْأَرْبَعَةِ وَالْعِشْرِينَ ضِلْعًا. وَكُلَّمَا كَانَ التَّقْسِيمُ أَدَقَّ، كَانَ النَّقْصُ أَقَلَّ. وَإِنْ تَمَّ التَّقْسِيمُ حَتَّى لَا يُمْكِنُ التَّقْسِيمُ، فَإِنَّهَا تَنْدَمِجُ مَعَ الْمُحِيطِ الدَّائِرِيِّ دُونَ أَيِّ نَقْصٍ.

هَذَا الْمُحِيطُ وَالْقُطْرُ هُمَا أَعْدَادٌ حَقِيقِيَّةٌ، لَيْسَا نِسْبَةَ ثَلَاثَةٍ لِلْقُطْرِ إِلَى الْوَاحِدِ. الثَّلَاثَةُ لِلْمُحِيطِ هِيَ مِنْ حَلْقَةِ السِّدَاسِيِّ فَقَطْ. وَالتَّفْرِيقُ بَيْنَ الدَّائِرَةِ وَالْمُسْطَّرِ كَالْفَرْقِ بَيْنَ الْقَوْسِ وَالْوَتَرِ. وَلَكِنَّ النَّاسَ يُنَاقَلُونَ هَذِهِ الطَّرِيقَةَ دُونَ تَحْقِيقٍ، وَالْعُلَمَاءُ يَتْبَعُونَ الْقُدَمَاءَ فِي أَخْطَائِهِمْ. فَبِدُونِ دَلِيلٍ وَاضِحٍ، يَصْعُبُ الْجَدَلُ. كُلُّ شَيْءٍ فِي الطَّبِيعَةِ، إِنْ لَمْ يَكُنْ دَائِرِيًّا فَهُوَ مُرَبَّعٌ. وَنِسَبُ الدَّائِرَةِ وَالْمُرَبَّعِ ظَاهِرَةٌ فِي مَا هُوَ قَرِيبٌ، وَبِهَا يُمْكِنُ مَعْرِفَةِ مَا هُوَ بَعِيدٌ. وَمِنْ هَذَا الْمَنْطِقِ، فَإِنَّ اسْتِخْدَامَهَا وَاسِعٌ. وَبِنَاءً عَلَى التَّجْرِبَةِ، أُحْدِثُ نِسْبَةً دَّقِيقَةً.
}
\end{bilingual}

\textcolor{methodcolor}{\textbf{術曰：}}以徑乘周，四而一。

\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} اضْرِبِ الْقُطْرَ فِي الْمُحِيطِ، وَاقْسِمْ عَلَى أَرْبَعَةٍ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}宛田者，中央隆高，形如覆碗。此術以徑乘周四而一，亦猶圓冪之義也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} الْحَقْلُ الْمُحَدَّبُ: مُرْتَفِعٌ مِنَ الْوَسَطِ، وَشَكْلُهُ كَالْقَدَحِ الْمَقْلُوبِ. هَذِهِ الطَّرِيقَةُ بِضَرْبِ الْقُطْرِ فِي الْمُحِيطِ وَالْقِسْمَةِ عَلَى أَرْبَعَةٍ، هِيَ أَيْضًا كَمَعْنَى مِسَاحَةِ الدَّائِرَةِ.

\arline{\problemnum{٣٦}\, وَفِي حَقْلُ قَوْسٍ آخَرَ، وَتَرُهُ ثَمَانٍ وَسَبْعُونَ خُطْوَةً وَنِصْفُ خُطْوَةٍ، وَسَهْمُهُ ثَلَاثَ عَشْرَةَ خُطْوَةً وَسَبْعَةٌ عَلَى تِسْعَةٍ مِنَ الْخُطْوَةِ. كَمْ مِنَ الْأَرْضِ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{三八}\, 又有環田，中周六十二步、四分步之三，外周一百一十三步、二分步之一，徑十二步、三分步之二。問為田幾何？}
\arline{\problemnum{٣٨}\, وَفِي حَقْلٍ حَلَقِيٍّ آخَرَ، مُحِيطُهُ الدَّاخِلِيُّ اثْنَانِ وَسِتُّونَ خُطْوَةً وَثَلَاثَةٌ عَلَى أَرْبَعَةٍ، وَمُحِيطُهُ الْخَارِجِيُّ مِائَةٌ وَثَلَاثَ عَشْرَةَ خُطْوَةً وَنِصْفُ خُطْوَةٍ، وَقُطْرُهُ اثْنَا عَشَرَ خُطْوَةً وَثُلْثَا خُطْوَةٍ. كَمْ مِنَ الْأَرْضِ؟}
\end{bilingual}

\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} أَرْبَعَةُ مُوّاتٍ وَمِائَةٌ وَسِتٌّ وَخَمْسُونَ خُطْوَةً وَرُبْعُ خُطْوَةٍ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}并中外周而半之，以徑乘之為積步。

密率術曰：置中外周步數，分母、子各居其下。母互乘子，通全步，內分子。以中周減外周，餘半之，以益中周。徑亦通分內子，以乘周為實。分母相乘為法，除之為積步，餘積步之分。以畝法除之，即畝數也。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} اجْمَعِ الْمُحِيطَيْنِ الدَّاخِلِيَّ وَالْخَارِجِيَّ وَانْصِفْهُمَا، وَاضْرِبِ النَّاتِجَ فِي الْقُطْرِ فَتَحْصُلُ عَلَى الْمِسَاحَةِ.

طَرِيقَةُ النِّسْبَةِ الدَّقِيقَةِ: ضَعْ عَدَدَ خُطُوَاتِ الْمُحِيطَيْنِ الدَّاخِلِيِّ وَالْخَارِجِيِّ، وَلِكُلٍّ مِنْهُمَا مَقَامٌ وَبَسْطٌ تَحْتَهُ. اضْرِبْ كُلَّ مَقَامٍ فِي بَسْطِ الْآخَرِ، وَحَوِّلِ الْخُطُوَاتِ الْكَامِلَةَ مَعَ الْبَسْطِ. وَاطْرَحِ الْمُحِيطَ الدَّاخِلِيَّ مِنَ الْخَارِجِيِّ، وَانْصِفِ الْبَاقِيَ، وَأَضِفْهُ إِلَى الْمُحِيطِ الدَّاخِلِيِّ. وَحَوِّلِ الْقُطْرَ أَيْضًا مَعَ بَسْطِهِ، وَاضْرِبْ فِي الْمُحِيطِ فَيَكُونُ الْبَسْطَ. وَاضْرِبِ الْمَقَامَاتِ بَعْضُهَا فِي بَعْضٍ فَتَكُونُ الْمَقَامَ، وَاقْسِمْ فَتَحْصُلُ عَلَى الْمِسَاحَةِ. ثُمَّ اقْسِمْ عَلَى مِئَتَيْنِ وَأَرْبَعِينَ فَتَحْصُلُ عَلَى عَدَدِ الْمُوّاتِ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}環田者，如圓環之形。并中外周而半之者，猶并兩邪而半之也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} الْحَقْلُ الْحَلَقِيُّ: شَكْلُهُ كَالْحَلْقَةِ الدَّائِرِيَّةِ. جَمْعُ الْمُحِيطَيْنِ الدَّاخِلِيِّ وَالْخَارِجِيِّ وَنَصْفُهُمَا كَجَمْعِ الْمُنْحَرِفَيْنِ وَنَصْفِهِمَا.
}
\end{bilingual}

\begin{bilingual}

\textcolor{methodcolor}{\textbf{طَرِيقَةُ الْإِشَارَةِ:}} اضْرِبِ الْمَوْجُودَ فِي نِسْبَةِ الْمَطْلُوبِ فَيَكُونُ الْبَسْطَ، وَاجْعَلْ نِسْبَةَ الْمَوْجُودِ مَقَامًا، وَاقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ.

\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} مَعْنَى هَذِهِ الطَّرِيقَةِ هُوَ مَعْنَى الْإِشَارَةِ. كُلُّ عَدَدٍ مُتَعَلِّقٍ بِآخَرَ يُسَمَّى نِسْبَةً. النِّسْبَةُ: هِيَ تَعَلُّقُ كُلٍّ بِكُلٍّ. فَإِنْ وُجِدَتْ كُسُورٌ فَتَشَتَّتَتْ، وَإِنْ لَمْ تَكُنْ كُسُورٌ فَلَمْ تَتَشَتَّتْ. وَجَمِيعُ هَذِهِ النِّسَبِ لِكُلٍّ مِنْهَا مَطْلُوبٌ، فَلِهَذَا تُسَمَّى طَرِيقَةَ الْإِشَارَةِ.
}
\end{bilingual}

\begin{bilingual}

}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} عَكْسُ النِّسْبَةِ: هُوَ عَكْسُ نِسْبَتِهِ. فِي نِسْبَتِهِ، مَا شِرَاءَهُ هُوَ الْمَقَامُ، وَهُنَا عَدَدُ الْقُرُوشِ هُوَ الْمَقَامُ، فَلِهَذَا يُسَمَّى عَكْسَ نِسْبَتِهِ. فَإِنْ لَمْ يَتِمَّ الْقَسْمُ فَاطْرَحِ الْبَسْطَ مِنَ الْمَقَامِ عَكْسِيًّا، فَالْمَقَامُ قَلِيلٌ وَالْبَسْطُ كَثِيرٌ. وَكُلُّ الشَّيْئَيْنِ يُضْرَبُ فِي عَدَدِ مَا حُصِلَ عَلَيْهِ مِنَ الْكَثْرَةِ وَالْقِلَّةِ مِنَ الْبَسْطِ وَالْمَقَامِ، فَتَحْصُلُ عَلَى عَدَدِ كُلِّ شَيْءٍ.
}
\end{bilingual}

\section{卷第三：衰分 | \ar{الْجُزْءُ الثَّالِثُ: التَّوْزِيعُ الْمُرَجَّحُ}}
\label{sec:cuifen}
\addcontentsline{toc}{subsection}{Cuīfēn -- Distributing by Proportion | \ar{التَّوْزِيعُ الْمُرَجَّحُ}}

\begin{center}
\textit{衰分以御貴賤粟稅之率} \quad|\quad \textit{\ar{التَّوْزِيعُ الْمُرَجَّحُ لِلْمُعَالَجَةِ نِسَبِ الضَّرَائِبِ وَالْأَرْزَاقِ}}
\end{center}

\bigskip

\begin{bilingual}
\cnline{%
本章論比例分配之法，包括按等級、按數量、按比率之分配問題。\textit{衰分術}為本章之核心算法。
}
\arline{%
يَنَاقِشُ هَذَا الْفَصْلُ طُرُقَ التَّوْزِيعِ التَّنَاسُبِيِّ، وَمِنْهَا التَّوْزِيعُ حَسَبَ الرُّتْبِ، وَحَسَبَ الْكَمِّيَّةِ، وَحَسَبَ النِّسْبَةِ. \textit{طَرِيقَةُ التَّوْزِيعِ الْمُرَجَّحِ} هِيَ الْخَوَارِزْمِيَّةُ الْجَوْهَرِيَّةُ فِي هَذَا الْفَصْلِ.
}
\end{bilingual}

\bigskip

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{衰分術曰：}}各置列衰，副并為法，以所分乘未并者各自為實，實如法而一。不滿法者，以法命之。
}
\arline{%
\textcolor{methodcolor}{\textbf{طَرِيقَةُ التَّوْزِيعِ الْمُرَجَّحِ:}} ضَعْ كُلَّ تَفَاوُتٍ مُصَفَّفٍ، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. وَاضْرِبِ الْمَقْسُومَ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ. فَإِنْ لَمْ يَتِمَّ الْقَسْمُ، فَأَطْلِقْ عَلَيْهِ اسْمَ الْمَقَامِ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}衰分者，差分也。列衰者，列其差數以為率也。各置列衰，副并為法，以所分乘未并者各自為實，實如法而一，即各得其分也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} التَّوْزِيعُ الْمُرَجَّحُ: هُوَ التَّوْزِيعُ بِالْفَرْقِ. التَّفَاوُتُ الْمُصَفَّفُ: هُوَ صَفُّ أَعْدَادِ الْفَرْقِ لِتَكُونَ نِسْبَةً. ضَعْ كُلَّ تَفَاوُتٍ مُصَفَّفٍ، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. وَاضْرِبِ الْمَقْسُومَ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا، ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلٌّ عَلَى حِصَّتِهِ.
}
\end{bilingual}

\vspace{0.5em}

%% ----- Cuifen Problems 1-3 -----
\begin{bilingual}
\cnline{\problemnum{一}\, 今有大夫、不更、簪裹、上造、公士，凡五人，共獵得五鹿。欲以爵次分之，問各得幾何？}
\arline{\problemnum{١}\, يُوجَدُ خَمْسَةُ أَشْخَاصٍ: دَافُو، وَبُو غِنْغ، وَزَان غُو، وَشَانغ دَاو، وَغُونْغ شِي. اصْطَادُوا خَمْسَ غِزْلَانٍ. يُرِيدُونَ تَوْزِيعَهَا حَسَبَ رُتَبِ الْأَلْقَابِ. كَمْ لِكُلٍّ مِنْهُمْ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}大夫得一鹿、三分鹿之二。不更得一鹿、三分鹿之一。簪裹得一鹿。上造得三分鹿之二。公士得三分鹿之一。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} دَافُو يَحْصُلُ عَلَى غَزَالَةٍ وَثُلْثَيْ غَزَالَةٍ. بُو غِنْغ يَحْصُلُ عَلَى غَزَالَةٍ وَثُلْثِ غَزَالَةٍ. زَان غُو يَحْصُلُ عَلَى غَزَالَةٍ. شَانغ دَاو يَحْصُلُ عَلَى ثُلْثَيْ غَزَالَةٍ. غُونْغ شِي يَحْصُلُ عَلَى ثُلْثِ غَزَالَةٍ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}列置爵數，各自為衰，副并為法。以五鹿乘未并者，各自為實。實如法得一鹿。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} صَفِّ أَعْدَادَ الْأَلْقَابِ، وَكُلٌّ مِنْهَا يَكُونُ تَفَاوُتًا. وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَ غِزْلَانٍ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى غَزَالَةٍ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}大夫五，不更四，簪裹三，上造二，公士一，是為列衰。副并得一十五為法。以五鹿乘未并者，大夫得二十五，不更得二十，簪裹得一十五，上造得一十，公士得五，各自為實。實如法而一，即各得鹿數也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} دَافُو خَمْسَةٌ، بُو غِنْغ أَرْبَعَةٌ، زَان غُو ثَلَاثَةٌ، شَانغ دَاو اثْنَانِ، غُونْغ شِي وَاحِدٌ، وَهَذِهِ هِيَ التَّفَاوُتَاتُ الْمُصَفَّفَةُ. الْمَجْمُوعُ خَمْسَةَ عَشَرَ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَ غِزْلَانٍ فِي كُلِّ مَا لَمْ يُجْمَعْ: دَافُو يَحْصُلُ عَلَى خَمْسَةٍ وَعِشْرِينَ، بُو غِنْغ عَلَى عِشْرِينَ، زَان غُو عَلَى خَمْسَةَ عَشَرَ، شَانغ دَاو عَلَى عَشَرَةٍ، غُونْغ شِي عَلَى خَمْسَةٍ، كُلٌّ مِنْهَا بَسْطٌ. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلٌّ عَلَى عَدَدِ غِزْلَانِهِ.
}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{二}\, 今有牛、馬、羊食人苗。苗主責之粟五斗。羊主曰：「我羊食半馬。」馬主曰：「我馬食半牛。」今欲衰償之，問各出幾何？}
\arline{\problemnum{٢}\, يُوجَدُ بَقَرَةٌ وَحِصَانٌ وَشَاةٌ قَدْ أَكَلَتْ مَحَاصِيلَ رَجُلٍ. صَاحِبُ الْمَحَاصِيلِ يَطْلُبُ مِنْهُمْ خَمْسَةَ أَدْوَاءٍ مِنَ الدُّخْنِ. قَالَ صَاحِبُ الشَّاةِ: "شَاتِي أَكَلَتْ نِصْفَ مَا أَكَلَهُ الْحِصَانُ". وَقَالَ صَاحِبُ الْحِصَانِ: "حِصَانِي أَكَلَ نِصْفَ مَا أَكَلَتْهُ الْبَقَرَةُ". يُرِيدُونَ التَّوْزِيعَ بِنِسْبَةِ مَا أَكَلَتْهُ. كَمْ يَدْفَعُ كُلٌّ مِنْهُمْ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}牛主出二斗八升、七分升之四。馬主出一斗四升、七分升之二。羊主出七升、七分升之一。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} صَاحِبُ الْبَقَرَةِ يَدْفَعُ دُوَّيْنِ وَثَمَانِيَةَ أَرْبَاعِ الْقَدَحِ وَأَرْبَعَةٌ عَلَى سَبْعَةٍ مِنْ رُبْعِ الْقَدَحِ. صَاحِبُ الْحِصَانِ يَدْفَعُ دُوًّا وَاحِدًا وَأَرْبَعَةَ أَرْبَاعِ الْقَدَحِ وَاثْنَانِ عَلَى سَبْعَةٍ مِنْ رُبْعِ الْقَدَحِ. صَاحِبُ الشَّاةِ يَدْفَعُ سَبْعَةَ أَرْبَاعِ الْقَدَحِ وَوَاحِدٌ عَلَى سَبْعَةٍ مِنْ رُبْعِ الْقَدَحِ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}置牛四、馬二、羊一，各自為列衰，副并為法。以五斗乘未并者各自為實。實如法得一斗。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} ضَعْ الْبَقَرَةَ أَرْبَعَةً، وَالْحِصَانَ اثْنَيْنِ، وَالشَّاةَ وَاحِدَةً، كُلٌّ مِنْهَا يَكُونُ تَفَاوُتًا مُصَفَّفًا. وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَةَ أَدْوَاءٍ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى دُوّ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}羊食半馬，馬食半牛，則牛食四分，馬食二分，羊食一分，是為列衰。副并得七為法。以五斗乘未并者，牛得二十，馬得一十，羊得五，各自為實。實如法而一，即各出之數也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} شَاتِي أَكَلَتْ نِصْفَ مَا أَكَلَهُ الْحِصَانُ، وَحِصَانِي أَكَلَ نِصْفَ مَا أَكَلَتْهُ الْبَقَرَةُ، فَالْبَقَرَةُ أَكَلَتْ أَرْبَعَةَ أَجْزَاءٍ، وَالْحِصَانُ اثْنَيْنِ، وَالشَّاةُ وَاحِدًا، وَهَذِهِ هِيَ التَّفَاوُتَاتُ الْمُصَفَّفَةُ. الْمَجْمُوعُ سَبْعَةٌ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَةَ أَدْوَاءٍ فِي كُلِّ مَا لَمْ يُجْمَعْ: الْبَقَرَةُ تَحْصُلُ عَلَى عِشْرِينَ، الْحِصَانُ عَلَى عَشَرَةٍ، الشَّاةُ عَلَى خَمْسَةٍ، كُلٌّ مِنْهَا بَسْطٌ. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلٌّ عَلَى مَا يَدْفَعُهُ.
}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{三}\, 今有甲持錢五百六十，乙持錢三百五十，丙持錢一百八十，凡三人俱出關，關稅百錢。欲以錢數多少衰出之，問各幾何？}
\arline{\problemnum{٣}\, يُوجَدُ جَا يَحْمِلُ خَمْسَ مِئَةٍ وَسِتِّينَ قُرْشًا، وَيِي يَحْمِلُ ثَلَاثَ مِئَةٍ وَخَمْسِينَ قُرْشًا، وَبِنْغ يَحْمِلُ مِائَةً وَثَمَانِينَ قُرْشًا. جَمِيعُهُمْ يَعْبُرُونَ الْحَدَّ، وَالْجِبَايَةُ مِائَةُ قُرْشٍ. يُرِيدُونَ دَفْعَهَا حَسَبَ كَمِّيَّةِ مَا يَحْمِلُونَ. كَمْ يَدْفَعُ كُلٌّ مِنْهُمْ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}甲出五十一錢、一百九分錢之四十一。乙出三十二錢、一百九分錢之一十二。丙出一十六錢、一百九分錢之五十六。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} جَا يَدْفَعُ وَاحِدًا وَخَمْسِينَ قُرْشًا وَوَاحِدًا وَأَرْبَعِينَ عَلَى مِائَةٍ وَتِسْعَةٍ مِنَ الْقُرْشِ. يِي يَدْفَعُ اثْنَيْنِ وَثَلَاثِينَ قُرْشًا وَاثْنَيْ عَشَرَ عَلَى مِائَةٍ وَتِسْعَةٍ مِنَ الْقُرْشِ. بِنْغ يَدْفَعُ سِتَّةَ عَشَرَ قُرْشًا وَسِتَّةً وَخَمْسِينَ عَلَى مِائَةٍ وَتِسْعَةٍ مِنَ الْقُرْشِ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}各置錢數為列衰，副并為法，以百錢乘未并者，各自為實，實如法得一錢。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} ضَعْ عَدَدَ قُرُوشِ كُلٍّ مِنْهُمْ تَفَاوُتًا مُصَفَّفًا، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْمِائَةَ قُرْشًا فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى قُرْشٍ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}甲五百六十，乙三百五十，丙一百八十，各以其錢數為列衰。副并得一千九十為法。以百錢乘未并者，甲得五萬六千，乙得三萬五千，丙得一萬八千，各自為實。實如法而一，即各出稅錢也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} جَا خَمْسُ مِئَةٍ وَسِتُّونَ، يِي ثَلَاثُ مِئَةٍ وَخَمْسُونَ، بِنْغ مِائَةٌ وَثَمَانُونَ، كُلٌّ مِنْهُمْ بِعَدَدِ قُرُوشِهِ تَفَاوُتٌ مُصَفَّفٌ. الْمَجْمُوعُ أَلْفٌ وَتِسْعُونَ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْمِائَةَ قُرْشًا فِي كُلِّ مَا لَمْ يُجْمَعْ: جَا يَحْصُلُ عَلَى سِتَّةٍ وَخَمْسِينَ أَلْفًا، يِي عَلَى خَمْسَةٍ وَثَلَاثِينَ أَلْفًا، بِنْغ عَلَى ثَمَانِيَةَ عَشَرَ أَلْفًا، كُلٌّ مِنْهَا بَسْطٌ. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلٌّ عَلَى مَا يَدْفَعُهُ مِنَ الضَّرِيبَةِ.

\begin{bilingual}
\cnline{\problemnum{四}\, 今有女子善織，日自倍，五日織五尺。問日織幾何？}
\arline{\problemnum{٤}\, تُوجَدُ امْرَأَةٌ حَاذِقَةٌ فِي النَّسْجِ، تَتَضَاعَفُ إِنْتَاجُهَا كُلَّ يَوْمٍ. فِي خَمْسَةِ أَيَّامٍ نَسَجَتْ خَمْسَ أَذْرُعٍ. كَمْ نَسَجَتْ كُلَّ يَوْمٍ؟}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}初日織一寸、三十一分寸之十九。次日織三寸、三十一分寸之七。次日織六寸、三十一分寸之十四。次日織一尺二寸、三十一分寸之二十八。次日織二尺五寸、三十一分寸之二十五。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} الْيَوْمُ الْأَوَّلُ نَسَجَتْ بُوصَةً وَاحِدَةً وَتِسْعَةَ عَشَرَ عَلَى وَاحِدٍ وَثَلَاثِينَ مِنَ الْبُوصَةِ. الْيَوْمُ الثَّانِي نَسَجَتْ ثَلَاثَ بُوصَاتٍ وَسَبْعَةٌ عَلَى وَاحِدٍ وَثَلَاثِينَ. الْيَوْمُ الثَّالِثُ نَسَجَتْ سِتَّ بُوصَاتٍ وَأَرْبَعَةَ عَشَرَ عَلَى وَاحِدٍ وَثَلَاثِينَ. الْيَوْمُ الرَّابِعُ نَسَجَتْ ذِرَاعًا وَبُوصَتَيْنِ وَثَمَانِيَةً وَعِشْرِينَ عَلَى وَاحِدٍ وَثَلَاثِينَ. الْيَوْمُ الْخَامِسُ نَسَجَتْ ذِرَاعَيْنِ وَخَمْسَ بُوصَاتٍ وَخَمْسَةً وَعِشْرِينَ عَلَى وَاحِدٍ وَثَلَاثِينَ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}置一、二、四、八、十六為列衰，副并為法，以五尺乘未并者，各自為實，實如法得一尺。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} ضَعْ وَاحِدًا وَاثْنَيْنِ وَأَرْبَعَةً وَثَمَانِيَةً وَسِتَّةَ عَشَرَ تَفَاوُتًا مُصَفَّفًا، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَةَ أَذْرُعٍ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى ذِرَاعٍ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}日自倍者，初日一，次日二，第三日四，第四日八，第五日十六，是為列衰。副并得三十一為法。以五尺乘未并者，初日得五，次日得一十，第三日得二十，第四日得四十，第五日得八十，各自為實。實如法而一，即各日織之數也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} التَّضَاعُفُ كُلَّ يَوْمٍ: الْيَوْمُ الْأَوَّلُ وَاحِدٌ، الثَّانِي اثْنَانِ، الثَّالِثُ أَرْبَعَةٌ، الرَّابِعُ ثَمَانِيَةٌ، الْخَامِسُ سِتَّةَ عَشَرَ، وَهَذِهِ هِيَ التَّفَاوُتَاتُ الْمُصَفَّفَةُ. الْمَجْمُوعُ وَاحِدٌ وَثَلَاثُونَ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَةَ أَذْرُعٍ فِي كُلِّ مَا لَمْ يُجْمَعْ: الْيَوْمُ الْأَوَّلُ يَحْصُلُ عَلَى خَمْسَةٍ، الثَّانِي عَلَى عَشَرَةٍ، الثَّالِثُ عَلَى عِشْرِينَ، الرَّابِعُ عَلَى أَرْبَعِينَ، الْخَامِسُ عَلَى ثَمَانِينَ، كُلٌّ مِنْهَا بَسْطٌ. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلُّ يَوْمٍ عَلَى مَا نَسَجَهُ.
}
\end{bilingual}

\cnline{\problemnum{五}\, 今有北鄉算八千七百五十八，西鄉算七千二百三十六，南鄉算八千三百五十六，凡三鄉，發傜三百七十八人。欲以算數多少衰出之，問各幾何？}
\arline{\problemnum{٥}\, يُوجَدُ لِقَرْيَةِ الشَّمَالِ ثَمَانِيَةُ آلَافٍ وَسَبْعُ مِئَةٍ وَثَمَانِيَةٌ وَخَمْسُونَ حَسَابًا، وَلِقَرْيَةِ الْغَرْبِ سَبْعَةُ آلَافٍ وَمِائَتَانِ وَسِتَّةٌ وَثَلَاثُونَ حَسَابًا، وَلِقَرْيَةِ الْجَنُوبِ ثَمَانِيَةُ آلَافٍ وَثَلَاثُ مِئَةٍ وَسِتَّةٌ وَخَمْسُونَ حَسَابًا. جَمِيعُ الْقُرَى الثَّلَاثِ يُرِيدُونَ إِحْضَارَ ثَلَاثِ مِئَةٍ وَثَمَانِيَةٍ وَسَبْعِينَ عَامِلًا. يُرِيدُونَ تَوْزِيعَهُمْ حَسَبَ عَدَدِ الْحِسَابَاتِ. كَمْ لِكُلِّ قَرْيَةٍ؟}

\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}各置算數為列衰，副并為法，以所發傜人數乘未并者，各自為實，實如法得一人。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} ضَعْ عَدَدَ حِسَابَاتِ كُلِّ قَرْيَةٍ تَفَاوُتًا مُصَفَّفًا، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ عَدَدَ الْعُمَّالِ الْمُرْسَلِينَ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى رَجُلٍ وَاحِدٍ.

\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{六}\, 今有稟粟，大夫、不更、簪裹、上造、公士，凡五人，一十五斗。今有大夫一人後來，亦當稟五斗。倉無粟，欲以衰出之，問各幾何？}
\arline{\problemnum{٦}\, يُوجَدُ تَقْسِيمُ أَرْزَاقٍ مِنَ الدُّخْنِ: دَافُو، وَبُو غِنْغ، وَزَان غُو، وَشَانغ دَاو، وَغُونْغ شِي، خَمْسَةُ أَشْخَاصٍ، مِقْدَارُهَا خَمْسَةَ عَشَرَ دُوًّا. يُوجَدُ دَافُو قَدْ أَتَى مُتَأَخِّرًا، وَيَسْتَحِقُّ أَيْضًا خَمْسَةَ أَدْوَاءٍ. الْمَخْزَنُ لَا يَحْتَوِي عَلَى دُخْنٍ، فَيُرِيدُونَ أَنْ يُخْرِجُوهَا بِنِسْبَةٍ. كَمْ يَدْفَعُ كُلٌّ مِنْهُمْ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}大夫出一斗、四分斗之一。不更出一斗。簪裹出四分斗之三。上造出四分斗之二。公士出四分斗之一。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} دَافُو يَدْفَعُ دُوًّا وَاحِدًا وَرُبْعَ دُوّ. بُو غِنْغ يَدْفَعُ دُوًّا وَاحِدًا. زَان غُو يَدْفَعُ ثَلَاثَةَ أَرْبَاعِ دُوّ. شَانغ دَاو يَدْفَعُ ثُلْثَيْ دُوّ. غُونْغ شِي يَدْفَعُ رُبْعَ دُوّ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}各置所稟粟斛斗數，爵次均之，以為列衰，副并而加後來大夫亦五斗，得二十以為法。以五斗乘未并者各自為實。實如法得一斗。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} ضَعْ مَا يَسْتَحِقُّهُ كُلٌّ مِنْهُمْ مِنَ الْقُرُوشِ الْمُتَسَاوِيَةِ تَفَاوُتًا مُصَفَّفًا، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ وَأَضِفْ إِلَيْهَا دَافُو الْمُتَأَخِّرُ الَّذِي يَسْتَحِقُّ خَمْسَةَ أَدْوَاءٍ، فَالْمَجْمُوعُ عِشْرُونَ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَةَ أَدْوَاءٍ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى دُوّ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}五人各五斗，合稟二十五斗。今有十五斗，不足十斗。後來大夫亦當稟五斗，并之得二十斗為法。以所不足五斗乘未并者，大夫得二十五，不更得二十，簪裹得一十五，上造得一十，公士得五，各自為實。實如法而一，即各出之數也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} الْخَمْسَةُ أَشْخَاصٍ، كُلٌّ مِنْهُمْ خَمْسَةُ أَدْوَاءٍ، يَجْمَعُونَ خَمْسَةً وَعِشْرِينَ دُوًّا. الْآنَ يُوجَدُ خَمْسَةَ عَشَرَ دُوًّا، نَاقِصَ عَشَرَةِ أَدْوَاءٍ. دَافُو الْمُتَأَخِّرُ يَسْتَحِقُّ أَيْضًا خَمْسَةَ أَدْوَاءٍ، فَالْمَجْمُوعُ عِشْرُونَ دُوًّا فَتَكُونُ الْمَقَامَ. اضْرِبِ النُّقْصَانَ الْخَمْسَةَ أَدْوَاءٍ فِي كُلِّ مَا لَمْ يُجْمَعْ: دَافُو يَحْصُلُ عَلَى خَمْسَةٍ وَعِشْرِينَ، بُو غِنْغ عَلَى عِشْرِينَ، زَان غُو عَلَى خَمْسَةَ عَشَرَ، شَانغ دَاو عَلَى عَشَرَةٍ، غُونْغ شِي عَلَى خَمْسَةٍ، كُلٌّ مِنْهَا بَسْطٌ. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلٌّ عَلَى مَا يَدْفَعُهُ.
}
\end{bilingual}

\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} الثَّلَاثَةُ أَشْخَاصٍ، كُلٌّ مِنْهُمْ يَحْصُلُ عَلَى قُرَابَةٍ وَدُوّ وَاحِدٍ وَخَمْسَةِ أَرْبَاعِ الْقَدَحِ وَخَمْسَةٌ عَلَى ثَلَاثَةَ عَشَرَ مِنْ رُبْعِ الْقَدَحِ. الِاثْنَانِ، كُلٌّ مِنْهُمَا يَحْصُلُ عَلَى سَبْعَةِ أَدْوَاءٍ وَسِتَّةِ أَرْبَاعِ الْقَدَحِ وَاثْنَا عَشَرَ عَلَى ثَلَاثَةَ عَشَرَ مِنْ رُبْعِ الْقَدَحِ.}
\end{bilingual}

\begin{bilingual}

}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} ضَعْ ثَلَاثَةَ أَشْخَاصٍ، كُلُّ وَاحِدٍ مِنْهُمْ ثَلَاثَةٌ؛ وَاثْنَيْنِ، كُلُّ وَاحِدٍ مِنْهُمَا اثْنَانِ، تَفَاوُتًا مُصَفَّفًا. وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْخَمْسَ قَرَابِيَّ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى قُرَابَةٍ.
}
\end{bilingual}

%% ----- Return-rate method -----
\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{返衰術曰：}}列置衰而令相乘，動者為不動者衰。
}
\arline{%
\textcolor{methodcolor}{\textbf{طَرِيقَةُ التَّوْزِيعِ الْعَكْسِيِّ:}} صَفِّ التَّفَاوُتَاتِ وَاجْعَلْهَا تَتَضَارَبُ، فَالْمُتَحَرِّكُ يَكُونُ تَفَاوُتًا لِلْمَرْبُوطِ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}返衰者，反其列衰也。令相乘者，以多乘少，以少乘多，各為其率。動者為不動者衰，言各以不動者為法，動者為實也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} التَّوْزِيعُ الْعَكْسِيُّ: هُوَ عَكْسُ التَّفَاوُتِ الْمُصَفَّفِ. جَعْلُهَا تَتَضَارَبُ: الْكَثِيرُ يُضْرَبُ فِي الْقَلِيلِ، وَالْقَلِيلُ يُضْرَبُ فِي الْكَثِيرِ، وَكُلٌّ مِنْهُمَا يَكُونُ نِسْبَتَهُ. الْمُتَحَرِّكُ يَكُونُ تَفَاوُتًا لِلْمَرْبُوطِ: يَعْنِي أَنَّ كُلًّا يَكُونُ الْمَرْبُوطُ مَقَامُهُ، وَالْمُتَحَرِّكُ بَسْطُهُ.
}
\end{bilingual}

%% ----- Problems 8-9 -----
\begin{bilingual}
\cnline{\problemnum{八}\, 今有大夫、不更、簪褭、上造、公士，凡五人，共出百錢。欲令高爵出少，以次漸多，問各幾何？}
\arline{\problemnum{٨}\, يُوجَدُ خَمْسَةُ أَشْخَاصٍ: دَافُو، وَبُو غِنْغ، وَزَان غُو، وَشَانغ دَاو، وَغُونْغ شِي. جَمِيعُهُمْ يَدْفَعُونَ مِائَةَ قُرْشٍ. يُرِيدُونَ أَنْ يَدْفَعَ صَاحِبُ اللَّقَبِ الْأَعْلَى أَقَلَّ، وَيَزْدَادَ الْبَاقُونَ تَدْرِيجِيًّا. كَمْ يَدْفَعُ كُلٌّ مِنْهُمْ؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}大夫出八錢、一百三十七分錢之一百四。不更出一十錢、一百三十七分錢之一百三十。簪褭出一十四錢、一百三十七分錢之八十二。上造出二十一錢、一百三十七分錢之一百二十三。公士出四十三錢、一百三十七分錢之一百九。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} دَافُو يَدْفَعُ ثَمَانِيَةَ قُرُوشٍ وَمِائَةً وَأَرْبَعَةً عَلَى مِائَةٍ وَسَبْعَةٍ وَثَلَاثِينَ مِنَ الْقُرْشِ. بُو غِنْغ يَدْفَعُ عَشَرَةَ قُرُوشٍ وَمِائَةً وَثَلَاثِينَ عَلَى مِائَةٍ وَسَبْعَةٍ وَثَلَاثِينَ. زَان غُو يَدْفَعُ أَرْبَعَةَ عَشَرَ قُرْشًا وَثَمَانِيَةً وَثَمَانِينَ عَلَى مِائَةٍ وَسَبْعَةٍ وَثَلَاثِينَ. شَانغ دَاو يَدْفَعُ وَاحِدًا وَعِشْرِينَ قُرْشًا وَمِائَةً وَثَلَاثًا وَعِشْرِينَ عَلَى مِائَةٍ وَسَبْعَةٍ وَثَلَاثِينَ. غُونْغ شِي يَدْفَعُ ثَلَاثَةً وَأَرْبَعِينَ قُرْشًا وَمِائَةً وَتِسْعَةً عَلَى مِائَةٍ وَسَبْعَةٍ وَثَلَاثِينَ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}置爵數各自為衰，而返衰之，副并為法。以百錢乘未并者各自為實。實如法得一錢。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} ضَعْ أَعْدَادَ الْأَلْقَابِ، كُلٌّ مِنْهَا يَكُونُ تَفَاوُتًا، ثُمَّ عَكِّسْهَا، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْمِائَةَ قُرْشًا فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى قُرْشٍ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}高爵出少，以次漸多，故令大夫五、不更四、簪裹三、上造二、公士一，返衰之。大夫得一百二十，不更得六十，簪裹得四十，上造得三十，公士得二十四，是為列衰。副并得二百七十四為法。以百錢乘未并者，各自為實。實如法而一，即各出錢數也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} صَاحِبُ اللَّقَبِ الْأَعْلَى يَدْفَعُ أَقَلَّ، وَيَزْدَادُ الْبَاقُونَ تَدْرِيجِيًّا، فَدَافُو خَمْسَةٌ، بُو غِنْغ أَرْبَعَةٌ، زَان غُو ثَلَاثَةٌ، شَانغ دَاو اثْنَانِ، غُونْغ شِي وَاحِدٌ، عَكِّسْهَا. دَافُو يَحْصُلُ عَلَى مِائَةٍ وَعِشْرِينَ، بُو غِنْغ عَلَى سِتِّينَ، زَان غُو عَلَى أَرْبَعِينَ، شَانغ دَاو عَلَى ثَلَاثِينَ، غُونْغ شِي عَلَى أَرْبَعَةٍ وَعِشْرِينَ، وَهَذِهِ هِيَ التَّفَاوُتَاتُ الْمُصَفَّفَةُ. الْمَجْمُوعُ مِائَتَانِ وَأَرْبَعَةٌ وَسَبْعُونَ فَتَكُونُ الْمَقَامَ. اضْرِبِ الْمِائَةَ قُرْشًا فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلٌّ عَلَى مَا يَدْفَعُهُ.
}
\end{bilingual}

\begin{bilingual}
\cnline{\problemnum{九}\, 今有甲持粟三升，乙持糲米三升，丙持糲飯三升。欲令合而分之，問各幾何？}
\arline{\problemnum{٩}\, يُوجَدُ جَا يَحْمِلُ ثَلَاثَةَ أَرْبَاعِ الْقَدَحِ مِنَ الدُّخْنِ، وَيِي يَحْمِلُ ثَلَاثَةَ أَرْبَاعِ الْقَدَحِ مِنَ الرُّزِّ الْخَشِنِ، وَبِنْغ يَحْمِلُ ثَلَاثَةَ أَرْبَاعِ الْقَدَحِ مِنَ الرُّزِّ الْخَشِنِ الْمَطْبُوخِ. يُرِيدُونَ أَنْ يَجْمَعُوهَا ثُمَّ يُقَسِّمُوهَا. كَمْ يَحْصُلُ كُلٌّ عَلَى؟}
\end{bilingual}

\begin{bilingual}
\cnline{\textcolor{answercolor}{\textbf{荅曰：}}甲二升、一十分升之七。乙四升、一十分升之五。丙一升、一十分升之八。}
\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} جَا يَحْصُلُ عَلَى رُبْعَيْ قَدَحٍ وَسَبْعَةٌ عَلَى عَشْرَةٍ مِنْ رُبْعِ الْقَدَحِ. يِي يَحْصُلُ عَلَى أَرْبَعَةِ أَرْبَاعِ الْقَدَحِ وَخَمْسَةٌ عَلَى عَشْرَةٍ مِنْ رُبْعِ الْقَدَحِ. بِنْغ يَحْصُلُ عَلَى رُبْعِ الْقَدَحِ وَثَمَانِيَةٌ عَلَى عَشْرَةٍ مِنْ رُبْعِ الْقَدَحِ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}以粟率五十、糲米率三十、糲飯率七十五為衰、而返衰之，副并為法。以九升乘未并者各自為實。實如法得一升。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} اجْعَلْ نِسْبَةَ الدُّخْنِ خَمْسِينَ، وَنِسْبَةَ الرُّزِّ الْخَشِنِ ثَلَاثِينَ، وَنِسْبَةَ الرُّزِّ الْخَشِنِ الْمَطْبُوخِ خَمْسَةً وَسَبْعِينَ تَفَاوُتًا، ثُمَّ عَكِّسْهَا، وَاجْمَعِ النُّسُوخَ عَلَى الْجَانِبِ فَتَكُونُ الْمَقَامَ. اضْرِبِ التِّسْعَةَ أَرْبَاعِ الْقَدَحِ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى رُبْعِ قَدَحٍ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}甲持粟率五十，乙持糲米率三十，丙持糲飯率七十五，返衰之。甲得四千五百，乙得七千五百，丙得三千，是為列衰。副并得一萬五千為法。以九升乘未并者，各自為實。實如法而一，即各得之數也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} جَا يَحْمِلُ دُخْنًا نِسْبَتُهُ خَمْسُونَ، يِي يَحْمِلُ رُزًّا خَشِنًا نِسْبَتُهُ ثَلَاثُونَ، بِنْغ يَحْمِلُ رُزًّا خَشِنًا مَطْبُوخًا نِسْبَتُهُ خَمْسَةٌ وَسَبْعُونَ، عَكِّسْهَا. جَا يَحْصُلُ عَلَى أَرْبَعَةِ آلَافٍ وَخَمْسِ مِئَةٍ، يِي عَلَى سَبْعَةِ آلَافٍ وَخَمْسِ مِئَةٍ، بِنْغ عَلَى ثَلَاثَةِ آلَافٍ، وَهَذِهِ هِيَ التَّفَاوُتَاتُ الْمُصَفَّفَةُ. الْمَجْمُوعُ خَمْسَةَ عَشَرَ أَلْفًا فَتَكُونُ الْمَقَامَ. اضْرِبِ التِّسْعَةَ أَرْبَاعِ الْقَدَحِ فِي كُلِّ مَا لَمْ يُجْمَعْ فَيَكُونُ كُلٌّ مِنْهَا بَسْطًا. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ، فَيَحْصُلُ كُلٌّ عَلَى مَا يَسْتَحِقُّهُ.
}
\end{bilingual}

\arline{\textcolor{answercolor}{\textbf{الْجَوَابُ:}} سِتَّةُ قُرُوشٍ وَثَلَاثَةٌ عَلَى أَرْبَعَةٍ مِنَ الْقُرْشِ.}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{methodcolor}{\textbf{術曰：}}以月三十日，乘千錢為法。以息三十乘今所貸錢數，又以九日乘之，為實。實如法得一錢。
}
\arline{%
\textcolor{methodcolor}{\textbf{الطَّرِيقَةُ:}} اضْرِبْ ثَلَاثِينَ يَوْمًا فِي أَلْفِ قُرْشٍ فَتَكُونُ الْمَقَامَ. وَاضْرِبِ الرِّبْحَ الثَّلَاثِينَ فِي عَدَدِ الْقُرُوشِ الْمُقَرَضَةِ، ثُمَّ اضْرِبْ فِي تِسْعَةِ أَيَّامٍ فَتَكُونُ الْبَسْطَ. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى قُرْشٍ.
}
\end{bilingual}

\begin{bilingual}
\cnline{%
\textcolor{commentarycolor}{\small\textit{劉徽注：}}此術以月三十日乘千錢為法者，得一萬，是為貸錢一萬，一日息三十也。以息三十乘今所貸七百五十錢，得二萬二千五百，又以九日乘之，得二十萬二千五百，為實。實如法得一錢，即九日之息也。
}
\arline{%
\textcolor{commentarycolor}{\small\textit{شَرْحُ لِيُو هُوِي:}} هَذِهِ الطَّرِيقَةُ: ضَرْبُ الثَّلَاثِينَ يَوْمًا فِي أَلْفِ قُرْشٍ لِلْمَقَامِ، فَالنَّاتِجُ عَشْرَةُ آلَافٍ، وَمَعْنَاهُ أَنَّ قَرْضَ عَشْرَةِ آلَافِ قُرْشٍ يَرْبِحُ فِي الْيَوْمِ ثَلَاثِينَ قُرْشًا. وَاضْرِبْ الرِّبْحَ الثَّلَاثِينَ فِي الْقُرُوشِ الْمُقَرَضَةِ السَّبْعِ مِئَةٍ وَخَمْسِينَ، فَالنَّاتِجُ اثْنَانِ وَعِشْرُونَ أَلْفًا وَخَمْسُ مِئَةٍ، ثُمَّ اضْرِبْ فِي تِسْعَةِ أَيَّامٍ، فَالنَّاتِجُ مِئَتَانِ وَأَلْفَانِ وَخَمْسُ مِئَةٍ فَتَكُونُ الْبَسْطَ. ثُمَّ اقْسِمِ الْبَسْطَ عَلَى الْمَقَامِ فَتَحْصُلُ عَلَى قُرْشٍ، وَهُوَ رِبْحُ التِّسْعَةِ أَيَّامٍ.
}
\end{bilingual}
