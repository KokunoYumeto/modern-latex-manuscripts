# Sylvester Batch 09 Review Guide

Start with the cumulative PDF and the cumulative source-scan PDF. For page-level checking, use `source_page_manifest.csv` and the PNG page images.

The new-work range is book pp. 119-151. The source page mapping is:

`book page N -> source PDF page N + 18`.

The source scans are included twice:
- cumulatively under `cumulative_current/source_scans_for_checking/`;
- for the new work only under `new_work_this_round/source_scans_for_checking/`.

The front-facing edition files are in `original_language/{tex,pdf,txt}`. The TeX is the authoritative editable artifact.
