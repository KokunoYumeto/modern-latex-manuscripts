# Fondements de la géométrie algébrique (FGA)

This version contains two separate cumulative readers: one French edition and
one English translation. Each covers Exposés 149, 182, 190, 195, 212, 221, 232,
and 236, the 1962 Commentaires, and all eight linked errata. They are independent files and are not
combined, parallel, side-by-side, or interleaved.

This version completes the bounded source-text scope and the shared semantic and
reference scaffold. The scaffold contains stable source-aligned units, targets,
reference candidates and edges, explicit residuals, a concept/term index, and a
pre-Stacks migration table. No official Stacks tags are assigned or invented.
The direct scan shows only printed pages 298 and 299 in the Exposé 182 erratum
witness although the intake catalog says 298--300; this authority-metadata
discrepancy is retained explicitly in `resid.csv` rather than repaired silently.

`authority.csv` records all seventeen NUMDAM witnesses used for this version.
`changes.csv` records all 77 admitted corrections. `fga-fr.tex` and
`fga-en.tex` are the cumulative masters; the source ZIPs contain their exact
included TeX files, shared preamble, and a copy of the shared semantic scaffold.
`sem.json` is its validation receipt. Producer commit: `2c10022eed41cb0e889a7b7cbfaa17fcee6f9945`.

Rights: No source scans are redistributed. The authority links point to NUMDAM. No license or permission is inferred for Grothendieck's underlying text; the Zenodo metadata therefore makes no new license assertion.
