
\chapter{Перевірка форматування PDF і виправлення верстки}
\label{chap:session08_pdf_qa}

Цей розділ фіксує не математичний прогрес, а стабілізацію результату. Після зауваження щодо сторінки Roth було виконано ширшу перевірку поточних PDF-артефактів: інтегрованого TeX-довідника, standalone addendum PDF, standalone-модулів Zuazua, Peeter Joot antenna, sensor-fusion, Correll robotics, Roth robust filter, local TeX worker micro-Lie та приватного Blackman OCR gap.

\section{Що саме перевірялося}
Для кожного PDF виконано три рівні перевірки:
\begin{enumerate}
\item відкриття PDF і підрахунок сторінок;
\item рендеринг репрезентативних сторінок і всіх сторінок з edge-risk прапорцями;
\item автоматична перевірка на очевидні проблеми: текст або графіка біля самого краю сторінки, дуже порожні сторінки, replacement glyph у витягнутому тексті, а також візуальний contact-sheet перегляд.
\end{enumerate}

Це не є математичним proofreading. Це технічна перевірка, спрямована на те, щоб не роздавати PDF з обрізаними заголовками, чорними квадратами, зламаною кирилицею або явно неконтрольованими довгими рядками.

\section{Виправлення після sweep}
Після першого sweep було знайдено три реальні проблемні класи.
\begin{enumerate}
\item У старому standalone Zuazua були довгі running headers, які заходили в правий край сторінки. Зібрано новий \texttt{plain/openany} wrapper без running headers.
\item У Peeter-Joot antenna standalone верстка пропусків рисунків і Mathematica-code блоків давала сміттєві або надто довгі рядки. Wrapper замінено на варіант з breakable \texttt{Verbatim}, правильними сигнатурами placeholder-макросів і поглинанням зайвих аргументів image-макросів.
\item У Correll robotics standalone були зайві порожні сторінки від book/openright логіки. Модуль перескладено як \texttt{oneside/openany} з plain page style.
\end{enumerate}

\section{Практичне правило далі}
Надалі будь-який standalone PDF, який іде в public-review або batch-передачу агентам, має мати мінімально:
\begin{enumerate}
\item XeLaTeX або LuaLaTeX build log;
\item render contact sheet для першої, середньої, останньої та flagged сторінок;
\item CSV з кількістю сторінок, edge-risk прапорцями та replacement-glyph перевіркою;
\item окреме поле \texttt{public\_release\_status}: public, staged, local-gap або rejected.
\end{enumerate}
