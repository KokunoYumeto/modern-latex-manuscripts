\section{Базова задача}

Нехай $\Omega\subset\R^n$ - обмежена область, а $y=y(x,t)$ - невідома функція. Базове хвильове рівняння з умовою Діріхле:
\begin{subequations}
\begin{align}
  y_{tt}-\Delta y &= h && \text{в } \Omega\times(0,T),\\
  y &= 0 && \text{на } \partial\Omega\times(0,T),\\
  y(0)&=y^0,
  & y_t(0)&=y^1 && \text{в } \Omega.
\end{align}
\end{subequations}
Тут $h$ - джерело або керування. Природний енергетичний простір для початкових даних:
\begin{equation}
  (y^0,y^1)\in H_0^1(\Omega)\times L^2(\Omega).
\end{equation}

\section{Енергія і збереження}

Для однорідного рівняння без джерела енергія
\begin{equation}
  E(t)=\frac12\int_\Omega \left(|y_t(x,t)|^2 + |\nabla y(x,t)|^2\right)\,dx
\end{equation}
зберігається:
\begin{equation}
  \frac{dE}{dt}=0.
\end{equation}
Це перший sanity check для будь-якого чисельного або перекладного матеріалу про хвилі. Якщо виведення дисипації або стабілізації не пояснює, куди йде енергія, формула підозріла.

\section{Точна керованість}

У формі exact controllability задача ставиться так: для заданих початкового і кінцевого станів знайти керування $h$ таке, що розв'язок досягає цілі в момент $T$:
\begin{equation}
  y(T)=z^0,
  \qquad
  y_t(T)=z^1.
\end{equation}
Нетривіальність задачі залежить від трьох речей:
\begin{enumerate}[label=\arabic*.]
\item часу $T$;
\item того, де саме дозволене керування: у всій області, у підобласті $\omega\subset\Omega$, або на границі;
\item функціональних просторів для даних і керувань.
\end{enumerate}

Коли керування локалізоване, часто пишуть
\begin{equation}
  y_{tt}-\Delta y = \chi_\omega h,
\end{equation}
де $\chi_\omega$ - характеристична функція підобласті керування. Це вже не тривіальна задача інтерполяції в часі: геометрія області та час $T$ мають значення.

\section{Стабілізація через демпфування}

Стабілізація питає не ``як потрапити в точний стан'', а ``як зробити так, щоб енергія спадала''. Базова модель із демпфуванням:
\begin{equation}
  y_{tt}-\Delta y + a(x)y_t = 0,
\end{equation}
де $a(x)\ge 0$. Тоді
\begin{align}
  \frac{dE}{dt}
  &= \int_\Omega y_t(y_{tt}-\Delta y)\,dx \\
  &= -\int_\Omega a(x)|y_t|^2\,dx \le 0.
\end{align}
Отже, енергія не зростає. Для експоненційного затухання потрібні сильніші умови, часто сформульовані через геометрію променів, observability inequality або унікальне продовження.

\section{Спостережуваність як двоїста форма}

У Hilbert Uniqueness Method (HUM) керованість пов'язується з нерівністю спостережуваності для adjoint або однорідного рівняння. У спрощеному вигляді:
\begin{equation}
  E(0) \le C \int_0^T\int_\omega |\phi_t(x,t)|^2\,dx\,dt,
\end{equation}
де $\phi$ - розв'язок однорідного хвильового рівняння. Зміст: вся початкова енергія має бути ``видима'' через спостереження на $\omega$ протягом часу $T$.

Для перекладу важливо не змішувати:
\begin{itemize}
\item controllability = керованість;
\item observability = спостережуваність;
\item stabilization = стабілізація;
\item damping = демпфування;
\item dissipation = дисипація.
\end{itemize}

\section{Чисельні перевірки}

Для FDM/FEM-перекладів цього матеріалу мінімальні перевірки:
\begin{enumerate}[label=\arabic*.]
\item \textbf{Energy check.} Без демпфування дискретна енергія не має системно рости.
\item \textbf{CFL.} Для явних схем часовий крок має задовольняти умову стійкості.
\item \textbf{Boundary conditions.} Dirichlet і Neumann не можна міняти місцями у тексті або коді.
\item \textbf{Control support.} $\omega$ - підобласть, $\Gamma$ - частина границі; це різні типи керування.
\item \textbf{Units.} У хвильовому рівнянні з фізичною швидкістю $c$ записують $y_{tt}-c^2\Delta y=0$; нормалізований випадок $c=1$ треба явно зазначати.
\end{enumerate}

\section{Позиція в корпусі}

Цей блок важливий не через одну конкретну application story, а тому що він зв'язує PDE, енергетичні методи, оптимальне керування, стабільність, чисельні схеми і функціональний аналіз. Після FDM/FEM-основи і state-space control він має стати одним із головних мостів до математичного моделювання фізичних систем.
