\section*{Fetch script policy}

Для кожного arXiv target спершу пробувати source tarball:
\begin{lstlisting}
mkdir -p fetched_current/<id>
curl -L https://arxiv.org/e-print/<id> -o fetched_current/<id>/source
file fetched_current/<id>/source
tar -tf fetched_current/<id>/source | head -80
\end{lstlisting}
Якщо e-print містить TeX, перекладати source-first. Якщо є тільки PDF, робити extraction/OCR audit і вирішувати, чи потрібен public source replacement.
