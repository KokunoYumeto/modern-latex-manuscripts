# Ukrainian Applied Mathematics Source Package

This public source package accompanies the Ukrainian Applied Mathematics working record. It contains TeX sources, reports, selected source-side material, and build/check artifacts for the reader PDFs exposed at the top level of the Zenodo record.

Directory guide:

- `source_tex/current_core/`: integrated TeX source modules and supporting terminology files.
- `source_tex/pysdr_ukrainian_selected_tex_current/`: selected Ukrainian PySDR TeX conversion source.
- `reports/`: public QA/build summaries and file manifests.
- `experimental_tex_drafts_codex_5_3/`: experimental Codex draft material preserved for provenance and future checking.

The package is a working scholarly source bundle. Later versions should replace partial modules with fuller source-checked translations while keeping earlier work available through Zenodo version history.
