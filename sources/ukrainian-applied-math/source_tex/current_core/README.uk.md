# Українське ядро прикладної математики - сесія 05

Це TeX-first пакет для українського довідника з прикладної математики: сигнали, оцінювання стану, керування, чисельні методи, RF/SDR, сенсорне злиття та інженерні обчислення.

У сесії 05 додано:

- глибший ESKF/IMU матеріал за Solà;
- окремий компільований український модуль `arxiv_1711_02508_sola_eskf_ua_core`;
- чисту копію останнього auxiliary local run-виводу;
- worker pack для Codex-Spark;
- явну PySDR RST-to-TeX доріжку.

Головні PDF:

- `pdf/ukrainian_applied_math_core_session05.pdf`
- `pdf/paper_modules/arxiv_1711_02508_sola_eskf_ua_core.pdf`
