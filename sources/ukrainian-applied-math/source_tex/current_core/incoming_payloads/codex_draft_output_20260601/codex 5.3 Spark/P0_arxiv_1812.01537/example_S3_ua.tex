\begin{fexample}	{Група одиничних кватерніонів $S^3$}
\label{ex:S3_intro}
Другий приклад групи Лі, який також досить легко уявити, — група одиничних кватерніонів із кватерніонним множенням (igRef{fig:manifold_q}).
Одиничні кватерніони мають вигляд $
\bfq=\cos(\theta/2)+\bfu\sin(\theta/2)$, де $
\bfu=iu_x+ju_y+ku_z$ — унітарна вісь, а $
\theta$ — кут повороту.

\emph{-- Дія:}
Вектори $
\bfx=ix+jy+kz$ поворотом у 3D просторі на кут $
\theta$ навколо одиничної осі $
\bfu$ перетворюються подвійним кватерніонним добутком: $
\bfx'=\bfq\,\bfx\,\bfq^*$.

\emph{-- Факти групи:} 
Добуток одиничних кватерніонів є одиничним кватерніоном, тотожність дорівнює 1, а обернений елемент — спряжений $
\bfq^*$.

\emph{-- Факти маніфолду:} 
Умова одиничної норми визначає 3-сферу $S^3$, сферичну 3-вимірну поверхню або 
\emph{маніфолд} у 4-вимірному просторі.
Одиничні кватерніони еволюціонують з часом на цій поверхні.
Група (сфера) локально схожа на лінійний простір (дотичну гіперплощину $
\bbR^3\subset\bbR^4$), але не глобально.
\end{fexample}
