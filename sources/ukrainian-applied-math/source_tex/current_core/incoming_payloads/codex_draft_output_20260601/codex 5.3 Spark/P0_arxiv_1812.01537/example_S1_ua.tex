\begin{fexample}	{Група одиничних комплексних чисел $S^1$}
\label{ex:S1}

Наш перший приклад групи Лі, найпростішій для візуалізації, — це група одиничних комплексних чисел із множенням комплесних чисел (igRef{fig:manifold_z}).
Одиничні комплексні числа мають вигляд $
\bfz=\cos\theta+i\sin\theta$.

\emph{-- Дія:}
 Вектори $
\bfx=x+iy$ поворотом на кут $
\theta$ через добуток комплесних чисел перетворюються як $
\bfx'=\bfz\,\bfx$. 

\emph{-- Факти групи:}
Добуток одиничних комплексних чисел — одиничне комплексне число, тотожність дорівнює 1, а обернений елемент — спряжений $
\bfz^*$.

\emph{-- Факти маніфолду:} 
Умова одиничної норми визначає одиничну окружність в комплексній площині (яку можна розглядати як 1-сферу, звідси назва $S^1$).
Це крива з 1 ступенем свободи в 2-вимірному просторі.
Одиничні комплексні числа еволюціонують з часом саме на цій окружності.
Група (коло) локально схожа на лінійний простір (дотичну пряму), але не глобально.
\end{fexample}
