# Standalone paper translation modules

These are source-preserved starts for singular papers. They are separate from the integrated bespoke reference so that a reviewer can cite, compare, and complete each original paper independently.

Current starts:

- `arxiv_1711_02508_sola_eskf_ua_start`
- `arxiv_1812_01537_micro_lie_ua_start`

Each module is intentionally short at this stage: it establishes Ukrainian terminology, TeX conventions, source scope, and the first practical translated sections. The complete translation should keep the original paper structure.
