\section{Пріоритет, якщо треба спалити Spark/Codex weekly pool}

Spark не ставимо на semantic-heavy full translation. Йому віддаємо:
\begin{enumerate}[label=\arabic*.]
\item RST/Markdown-to-TeX conversion для PySDR і Labbe;
\item TeX compile-error repair на малих modules;
\item glossary extraction з batch output;
\item invariant checks: labels, refs, citations, math delimiter balance;
\item section splitting і release-card generation;
\item smoke builds і log summarization.
\end{enumerate}

\section{Definition of done для Spark batch}

Batch вважається завершеним, якщо він дає:
\begin{enumerate}[label=\arabic*.]
\item один \texttt{.tex} або малий набір \texttt{.tex} файлів;
\item \texttt{BUILD.md} з командою компіляції;
\item \texttt{CHECK\_REPORT.md} з unresolved issues;
\item \texttt{TERMS.csv} з новими термінами;
\item no non-source additions;
\item no unsolicited changes to equations.
\end{enumerate}
