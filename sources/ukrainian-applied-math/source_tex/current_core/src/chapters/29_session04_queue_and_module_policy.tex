\section{Що змінилося}

Після вхідного auxiliary local run-пакета черга більше не є лінійною ``переклади наступну статтю''. Вона має три паралельні доріжки:

\begin{enumerate}[label=\arabic*.]
\item \textbf{State estimation / robotics core.} Solà ESKF, micro Lie theory, continuous-time state estimation, Kalman notebooks, Autonomous Robots.
\item \textbf{Signals / RF / SDR core.} PySDR QA, SDR architecture survey, Maxwell/antenna foundations, ThinkDSP, signal-processing course.
\item \textbf{PDE / control / numerical core.} FDM/FEM, wave equation controllability, optimization and least-squares infrastructure.
\end{enumerate}

auxiliary local run вже дав повний або частковий output для SDR, antenna, sensor-fusion і Zuazua chapter 1. Тому перший пріоритет тепер не ``перекласти це ще раз'', а зробити ці модулі компільованими, глосарно узгодженими і прив'язаними до ядра.

\section{Правило ``оригінальна стаття чи інтегрований розділ''}

\begin{itemize}
\item Якщо джерело є короткою або середньою TeX-статтею з чіткою структурою, робити \textbf{source-preserved paper module}.
\item Якщо джерело є довгою монографією, робити \textbf{chapter-select modules} плюс короткий інтегрований розділ.
\item Якщо джерело є survey з великим літературним апаратом, робити \textbf{glossary + taxonomy extraction} для головного довідника, а повний переклад тримати окремо.
\item Якщо джерело містить dated hardware catalogs, не перекладати їх першим. Спершу витягнути довгоживучу математику: architecture, signal path, formulas, checks.
\end{itemize}
