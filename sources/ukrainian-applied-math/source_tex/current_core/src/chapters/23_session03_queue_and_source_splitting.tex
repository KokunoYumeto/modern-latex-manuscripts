\section{Що зроблено в цій сесії}

У цій сесії додано чотири практичні шари, яких бракувало після сесії 02:

\begin{enumerate}
\item архітектуру двох продуктів: зведений довідник і джерельні переклади окремих статей;
\item джерельний старт для Solà ESKF/кватерніонної статті;
\item вимірювальне оновлення ESKF, ін'єкцію, reset і NIS;
\item сенсорні моделі, часові зсуви, калібрування, байєсівську фільтрацію/згладжування, базове керування, цифрові фільтри і Якобіани.
\end{enumerate}

Це розширює документ від ``орієнтація + фільтр'' до робочого мінімуму для прикладного оцінювання, сигналів і керування.

\section{Що не робити зараз}

\begin{itemize}
\item Не перекладати великі передмови, історичні огляди і списки літератури до того, як готові математичні ядра.
\item Не витрачати токени на OCR сучасних PDF, якщо вже є TeX або Markdown source.
\item Не зшивати всі джерела в один моноліт без мапи походження.
\item Не публікувати приватні scan-gap матеріали в GitHub; публічна гілка має бути source-first і освітня.
\end{itemize}

\section{Формат окремої статті}

Для одиничної статті створювати:

\begin{lstlisting}
paper_modules/
  arxiv_1711_02508_sola_eskf_ua/
    SOURCE.md
    translation_status.csv
    src/
      main.tex
      sections/
        00_abstract_ua.tex
        01_quaternion_conventions_ua.tex
        02_error_state_ua.tex
        03_noise_ua.tex
    pdf/
      arxiv_1711_02508_sola_eskf_ua_draft.pdf
\end{lstlisting}

Так локальні агенти можуть працювати незалежно: один агент добудовує окрему статтю, інший підтримує зведений довідник.

\section{Критерій готовності P0-модуля}

P0-модуль готовий до зовнішнього перегляду, якщо:

\begin{enumerate}
\item компілюється через XeLaTeX або має чітку Markdown/RST збірку;
\item усі формули збережено як TeX, не як зображення;
\item є мапа джерела;
\item є список неперевірених формул;
\item терміни узгоджено з \texttt{terminology\_seed};
\item є мінімум один чисельний sanity check або формульна перевірка розмірностей.
\end{enumerate}
