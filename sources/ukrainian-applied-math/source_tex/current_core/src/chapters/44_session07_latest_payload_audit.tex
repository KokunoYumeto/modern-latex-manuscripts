\chapter{Сесія 07: фактичний повний payload і що з ним робити}
\label{chap:session07-payload}

\sourcebox{Джерела сесії: останній файл \texttt{ukrainian\_output.zip} з auxiliary local run та \texttt{codex 5.3 Spark.zip}. Попередня сесія 06 була зібрана на основі меншого архіву, де частина заявлених папок була відсутня. Новий архів уже містить фактичну повну партію: розділи 1--3 Zuazua, повні/ядрові сенсорні огляди, робастне фільтрування, шість розділів Correll, SDR survey і десять антенних фрагментів.}

Мета цієї сесії не в тому, щоб перетворити все на одну непрохідну книгу. Є два шари.

Перший шар --- \emph{інтегрований практичний довідник}. Він має відповідати на питання: які формули, поняття і перевірки потрібні інженеру, щоб читати і реалізовувати сучасні матеріали з сигналів, оцінювання стану, робототехніки, RF, чисельного моделювання і оптимізації.

Другий шар --- \emph{source-preserved модулі}. Якщо auxiliary local run або Spark уже дали майже самодостатній TeX для конкретної статті чи книги, його слід залишати окремим модулем. Це краще для цитування, контролю ліцензій, порівняння з оригіналом і подальшої автоматичної перевірки.

\section{Що змінилося відносно сесії 06}

Попередній аудит бачив лише частину заявленого auxiliary local run payload. Новий архів містить такі корисні блоки:
\begin{itemize}[leftmargin=*]
\item \sourcepath{zuazua_wave_2402.17894/}: \texttt{chapter01\_uk.tex}, \texttt{chapter02\_uk.tex}, \texttt{chapter03\_uk.tex}. Це вже не тільки постановка задачі, а й гранична та внутрішня керованість.
\item \sourcepath{antenna_peeterjoot/}: десять фрагментів про рівняння Максвелла, першу лекцію з теорії антен, поляризацію, взаємність, дуальність, масиви Чебишова, дротяні антени, RCS/EIRP.
\item \sourcepath{sensor_fusion_2506.19769/}: повний огляд multi-sensor fusion для embodied AI.
\item \sourcepath{sensor_fusion_2410.15480/}: повний огляд event-based sensor fusion for odometry.
\item \sourcepath{roth_robust_filter_1703.02428/}: практично важливі частини Student's $t$ filtering/smoothing.
\item \sourcepath{autonomous_robots_correll/}: шість розділів: сенсори, бачення, локалізація, картографування, SLAM, планування шляхів.
\item \texttt{codex 5.3 Spark.zip}: часткові переклади micro Lie theory і приватний OCR/LaTeX старт для Blackman chapter 4.
\end{itemize}

Це означає, що найважливіша прогалина сесії 06 --- відсутність фактичних модулів для event fusion, robust filtering і Correll robotics --- закрита. Тепер вузьке місце змістилось з ``нема джерела'' до ``треба зібрати, компілювати, перевірити терміни, і не змішати release-staging шар''.

\section{Практична політика інтеграції}

Матеріал з керованості хвильового рівняння, антен, SDR, сенсорного злиття, SLAM і робастного фільтрування є нормальною прикладною математикою та інженерною теорією. У публічному шарі він має залишатися на рівні теорії, симуляцій, перевірок формул, оцінювання невизначеності та загальної інженерної грамотності. Конкретні польові конфігурації, цільові workflow або інструкції бойового застосування не включаються.
