\section{Що додано}

У цій сесії додано TeX-рівень для першого практичного P0-блоку:
\begin{enumerate}[leftmargin=2em]
\item кватерніонні угоди, добуток, матриці лівого/правого множення;
\item ESKF-архітектура для IMU-систем;
\item неперервно-дискретне масштабування шумів і коваріацій;
\item мінімальний шар груп Лі для $\SO(3)$ і $\SE(3)$;
\item QA-формули для Kalman/EKF/ESKF;
\item TeX-модуль з уже українського PySDR щодо дискретизації, частотної області та I/Q.
\end{enumerate}

Це не фінальна книга, а робочий компільований каркас. Його можна різати на batch-и, подавати локальним агентам, порівнювати з upstream-джерелами і розширювати без OCR.

\section{Нотатка про корисність}

Найбільший практичний виграш зараз не в тому, щоб перекладати все підряд. Найбільший виграш - стабільні TeX-модулі, які покривають вузькі місця:
\begin{enumerate}[leftmargin=2em]
\item орієнтація і похибки орієнтації;
\item дискретизація неперервних шумів;
\item коваріації та якобіани;
\item частотне мислення і комплексні відліки;
\item чисельні перевірки, які ловлять зламані формули.
\end{enumerate}

Це саме ті місця, де машинний переклад без TeX-дисципліни найчастіше робить текст зовні гладким, але технічно небезпечним.
