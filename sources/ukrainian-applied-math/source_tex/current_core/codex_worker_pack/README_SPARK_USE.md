# Codex-Spark worker pack for the Ukrainian applied-math translation lane

Use GPT-5.3-Codex-Spark as a fast separate token pool for mechanical, verifiable work. Do not use it as the sole mathematical editor for high-risk derivations.

Best tasks:

1. Convert already-Ukrainian PySDR RST files to TeX.
2. Split large TeX files into translation batches.
3. Preserve labels, citations, equations, environments, and code blocks while translating prose.
4. Run compile/grep checks and patch minimal LaTeX breakage.
5. Produce manifests and status files.

Use Spark only for source-grounded TeX translation and checking.
