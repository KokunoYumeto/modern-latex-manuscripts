# Ukrainian Applied Mathematics and Engineering Library — Work Package

This is a human-facing consolidation of the current Ukrainian applied mathematics translation lane.

The package contains:

- an integrated Ukrainian TeX/PDF reader on signals, state estimation, ESKF, Lie groups, Kalman filtering, SDR/RF, sensor fusion, VIO/SLAM, wave-equation controllability, robust filtering, robotics, PySDR, GNSS-denied navigation, and current preprint radar;
- standalone translated or partially translated modules;
- TeX source for the integrated reader;
- source-status and quality-audit reports;
- a current 2025--2026 arXiv research radar and fetch script;
- next-task task notes for local local organizer/local TeX worker/translation system-style agents.

The public-facing framing is simply applied mathematics and engineering theory with utilitarian prioritization. There is no need for opsec-style banners or performative restriction language in the reader. The useful metadata are source status, translation status, build status, mathematical QA status, and next translation priority.

Recommended next translation work:

1. Full Solà ESKF and full micro-Lie source-preserved translations.
2. Sensor fusion and odometry deepening: event cameras, asynchronous fusion, VIO/SLAM, calibration, covariance.
3. Labbe Kalman notebooks to clean TeX.
4. GNSS-denied VIO/SLAM current preprints from the research radar.
5. FDM/FEM and optimization modules for breadth.

Use `01_integrated_reader/` for the main reader PDF, `02_standalone_modules/` for individual PDFs, and `03_tex_source/` for machine-editable source.
