*The empty set is a relation, not an axiom.* The poser's core idea, in his words: "the empty set is the definition of the homology between levels rather than an axiom," on the basis that "empty is never not a bijection, as it implies non-empty, so no non-dual datum can be empty — it is not a primitive but relational." Formal shape (fixed with the audit instance): for a layer map η_n: L_n → L_{n+1}, the interlevel datum is the origin fibre H⁰_nul(y; η_n) := η_n^{-1}(y) ≅ Hom_{Set/L_{n+1}}(ŷ, η_n); ∅ occurs *only* as the value "no origin below" of this relational functor — never as a carrier element; and a **nullity is a locus of the complement** N(η_n) = L_{n+1} ∖ im η_n — not an empty set. Consequences the program depends on: there is exactly one empty relational value however many nullities coexist (dissolving the "many empty sets" set-theoretic conundrum); supported zero, fresh nullity, and cancellation state are distinct *typed* states; and the global datum is the stack of interlevel relations. *Predatum (K0).* Pre-𝔹: before the 0/1, empty/inhabited, branch/complement distinction exists — "non-empty and non-inhabited." Early name F_not_2: "the field with no 2 elements — but NOT with 1 element, since 1 implies 0 and that is a bijection; NOT F₁ (contradictio in terminis, as the F₁ literature itself knows)."
