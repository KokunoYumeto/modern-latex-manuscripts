# SGA 3 English working reader through Exposé III

This is a bounded public-progress checkpoint, not a complete SGA 3
translation.

## Scope

- Editorial Notice and Introduction.
- Complete Exposé I.
- Complete Exposé II.
- Complete Exposé III through Section 4.38 and its bibliography.
- Continuation: Exposé IV.
- Reader: 200 A4 pages.

The controlling source witness is the current Polo--Gille reader, SHA-256
`B0984B5BF322A88AB455709578E4E41EB43D6E1C91931282CFEE64F2C1F69BE2`.
OCR was used only as a locator and drafting witness.

Jacob C. Reinhold's public `jcreinhold/sga` Markdown at snapshot
`e7a259f3f8608ad3edf9bf6eead3fd504dd2d23e` was comparison and drafting
material, not textual authority or independent corroboration. Reinhold states
that his translation contribution is CC BY 4.0. That statement does not grant
rights in the underlying French work or unrelated project contributions.
