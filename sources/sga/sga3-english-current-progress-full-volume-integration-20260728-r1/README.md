# SGA 3 English current-progress cumulative reader

This package is the preferred readable SGA 3 English integration frozen on
28 July 2026. It puts the current mathematics in one reader instead of
requiring readers to assemble dozens of bounded checkpoints.

## Included scope

- Editorial Notice and Introduction.
- Complete current working bodies for Exposes I-XXIII.
- Complete current working bodies for Exposes XXV-XXVI.
- Terminal bibliography and the Tome III index.
- Explicit in-reader gap notices for the four-page Tome III mathematical
  guide and Expose XXIV.

The reader has 1,434 A4 pages. It is a current-progress Loop-1 working
integration, not a complete SGA 3 translation, a critical edition, or final
diagram/reference/accessibility certification.

## Reader-facing files

- `00c_SGA3_English_CurrentProgress_Cumulative_Latest_20260728.pdf` is the
  preferred current reader.
- `02c_SGA3_English_CurrentProgress_Cumulative_Latest_20260728.tex` is its
  directly accessible master TeX.
- `10c9_SGA3_CurrentProgress_FullVolume_Integration_Source_20260728.zip`
  contains the exact recorder-derived build closure: 723 TeX files and 142
  PNG assets, plus a self-checking manifest and validation record.

Older cumulative readers and bounded checkpoints remain immutable history.
They are not the preferred current reading surface.

## Authority and comparison lineage

The component-specific Polo-Gille SGA 3 PDFs documented by the underlying
working packages control French wording, formulas, numbering, notes, page
order, and diagram appearance. Floris's pre-existing GPU OCR was consulted
read-only as locator and drafting material; no OCR was generated or rerun
for this integration.

Jacob C. Reinhold's English Markdown at
`https://github.com/jcreinhold/sga`, revision
`e7a259f3f8608ad3edf9bf6eead3fd504dd2d23e`, is credited comparison and
drafting lineage, not source authority or independent corroboration. His
stated CC BY 4.0 applies only to his translation contribution.

No new license or redistribution right is asserted for the underlying French
works, the Polo-Gille editions, or the integrated English reconstruction.

## Diagram state

The integrated reader uses native TeX diagrams where current component work
provides them. It also retains 142 source-derived Loop-1 PNG assets needed to
make the current text readable. Those assets are provisional transcription
witnesses, not a final diagram-fidelity claim.

Existing 600- and 1200-dpi evidence remains valid append-only history and
context. Diagram approval based only on 300 dpi is not treated as final.
Later diagram-final successors require native TeX and direct lead comparison
to authority at about 5000 dpi, escalating to 9000 dpi where ambiguity
remains. This working reader does not claim that later gate.

## Compact public shape

The cumulative PDF and master TeX remain direct files because readers use
them directly. Source dependencies and machine controls are grouped in one
ZIP. Older cumulative/source states stay in the existing history ZIPs rather
than being promoted as dozens of loose landing-page files.
