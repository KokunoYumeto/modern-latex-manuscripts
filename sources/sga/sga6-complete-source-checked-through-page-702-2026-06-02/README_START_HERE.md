# SGA 6 Complete Source-Checked Working Edition

This source packet contains the strict bilingual SGA 6 working edition through the end of the original 702-page source scan.

## Public Readers

- `reader-pdfs/sga/20 SGA 6 - Complete Strict Source-Checked Edition - English Translation.pdf`
- `reader-pdfs/sga/21 SGA 6 - Complete Strict Source-Checked Edition - French Reconstruction.pdf`

## Scope

- Source scan pages: 001-702.
- Printed pages: front matter through printed page 700.
- Final added range: source pages 693-702, containing the terminological index and index of notations.
- Source witness: `SourceScan/SGA6_source_pages_001_702_original_complete.pdf`.

## Included Material

- `English/` and `French/`: cumulative TeX/PDF readers plus the final index-only TeX/PDF segment.
- `SourceScan/`: complete source scan witness and final index source slice.
- `RenderChecks/`: sampled cumulative render checks and full render checks for the final index pages.
- `CompileLogs/`: retained build logs for the cumulative and final index builds.
- `Methodology/`: transcription/rendering notes and helper scripts.
- `Manifests/`: coverage, PDF info, validation, SHA256, and diagram/general audit files.

The local source drop also contained an `All_Rendered_PDFs` directory duplicating PDFs already present in the folders above. That duplicate folder is intentionally not mirrored here so the GitHub tree remains forkable.
