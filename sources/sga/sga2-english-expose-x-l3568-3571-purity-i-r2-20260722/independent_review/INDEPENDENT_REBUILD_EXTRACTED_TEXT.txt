    Proof of the purity theorem. We first prove (i) by induction on the dimension. Let A be a noetherian local
ring of dimension 2. Set X ′ = Spec(A), x = r(A), and X = X ′ \ {x}. We have depth A = 2. We may therefore
apply Lemma 3.5 to the pair (X ′ , {x}), and hence Et(X ′ ) −→ Et(X) is fully faithful.
    Now let r : R −→ X be an étale covering defined by the coherent, locally free, étale OX -algebra A = r∗ (OR ).
Let i : X −→ X ′ denote the canonical immersion. I claim that i∗ (A) = B is a coherent OX ′ -algebra. Indeed, it
suffices to apply the “finiteness theorem,” VIII, 2.3. I also claim that this algebra has depth at least 2 at x: it is
the direct image of an OX -module, with X = X ′ \ {x}. Since A is a regular ring of dimension 2, we have

                                                 pd B + depth B = dim A = 2,

where pd B denotes the projective dimension of B. Thus pd B = 0, so B is projective and therefore free.
Consequently, B defines a finite flat covering of X ′ = Spec(A). The set of points of X ′ at which this covering
is not étale is a closed subset of X ′ whose defining ideal is principal, namely the discriminant ideal of B/A. By
construction this closed subset is contained in x = r(A); it is therefore empty because dim A = 2.
    Let A now be a regular noetherian local ring with dim A = n ≥ 3. Suppose that (i) has been proved for rings
of dimension less than n. To prove that A is pure, we may assume by Corollary 3.8 that A is complete. Choose
t ∈ r(A) whose image in r(A)/r(A)2 is nonzero. Then B = A/tA is a regular noetherian local ring of dimension
n − 1, and is therefore pure because n − 1 ≥ 2. The conclusion follows from Lemma 3.9(i), which is applicable
because A is complete.
