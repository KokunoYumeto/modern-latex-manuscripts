# SGA 7 II live transcription custody snapshot

This directory preserves one exact, privacy-clean snapshot of the active SGA 7
II source-transcription work. It is a GitHub source-survival checkpoint, not a
complete Tome II reader, English translation, critical edition, rights
clearance, or Zenodo upload.

## Authority and mapping

- Work: SGA 7 II, Lecture Notes in Mathematics 340.
- Controlling scan: 446-page Institute for Advanced Study scan, 12,587,545
  bytes, SHA-256
  `FA679DEBFC8ADA3232D7E752A1837FC6CE474488E20A44D7641CF296876E1297`.
- Source page images are 2010 x 3000 pixels; body scan indices are 8-445.
- For the 421 pages carrying printed folios, `folio = scan index - 7`.
- The scan, its extracted text layer, and all source pixels are excluded from
  this public custody snapshot.

The source image controls every reading. Any OCR or text layer is a locator or
drafting witness only. Printed defects are preserved in the transcription and
recorded separately in `SOURCE_NOTES.md` rather than silently normalized.

## Public-surface choices

The snapshot contains mathematical TeX and source-reading apparatus only.
Private status paths, AI/process notes, scripts, scans, OCR bodies, images,
build outputs, and caches are excluded. A privacy scan found zero private
absolute paths, personal names, task identifiers, credentials, or agent
workspace strings.

The already published SGA 7 I reader/source package remains unchanged at
Zenodo record `21711433` under concept DOI `10.5281/zenodo.20410947`. This
snapshot neither duplicates nor supersedes it. A later coherent SGA 7 II
reader should use the same concept only after an exact privacy-clean handoff.
