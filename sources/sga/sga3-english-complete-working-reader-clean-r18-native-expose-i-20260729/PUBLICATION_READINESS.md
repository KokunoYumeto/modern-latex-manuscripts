# Publication readiness

Status: `PASS_CURRENT_PROGRESS_READER`

The package is suitable for GitHub custody and for a compact successor on the
existing SGA Zenodo concept. The reader-facing set is:

1. the 1,470-page cumulative PDF;
2. the editable master TeX; and
3. one source-and-history ZIP.

R18 supersedes R17 as the preferred reader by adding the sealed native-
diagram successor for Expose I to the existing X, XVI, XVIII, XXII, and XXIV
integrations. It retains all 4,591 internal GoTo actions while reducing
raster image objects from 128 to 103. Fifteen unreferenced automatic
`figure.*` destinations from the raster wrappers become fifteen unreferenced
automatic `section*.*` destinations under the native layout. The synthetic
page anchors `page.1471` and `page.1472` disappear because the reader is two
pages shorter. No GoTo action targeted any of those automatic anchors.

The PDF contains no workflow status, production status, source-status preface,
comparison-lineage prose, or release-audit notes. This status does not certify
a critical edition, blanket rights clearance, PDF accessibility remediation,
or completion of every remaining native-diagram successor.
