# Source-image visual evidence

This directory contains actual image evidence derived from the publicly
available SGA 7 II source scan, not a rights-blocked placeholder ledger.

- `source-pages/`: four complete 600-dpi page renders.
- `detail-crops/`: six 600-dpi crops focused on the recovered formulas,
  propositions, and local-cohomology diagram, plus the exact 400-dpi crop
  used for the Expose-XVIII title/contents boundary at scan index 261.
- `VISUAL_EVIDENCE_INDEX.csv`: exact parent/page/crop/hash provenance.

The parent scan is `Number12.pdf`, 12,587,545 bytes, SHA-256
`FA679DEBFC8ADA3232D7E752A1837FC6CE474488E20A44D7641CF296876E1297`.
It is not bundled. PDF page numbers in the index are one-based; scan indices
are zero-based. Rotation is zero for every object.
