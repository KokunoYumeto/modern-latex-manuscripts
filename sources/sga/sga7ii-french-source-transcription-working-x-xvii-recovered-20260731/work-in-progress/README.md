the cumulative reader and from all X-XVII completeness claims.

inclusive (book folios 255-301), with no internal gap in that bounded range.

file. Indices 309-334 remain outside this WIP and Expose XVIII is therefore
incomplete.

errors and produced 24 nonempty A4 pages. It retained one disclosed overfull
box in the display spanning body lines 438-465; this WIP has not passed the
reader-level visual and release gates applied to X-XVII.
