# Expose XVIII work in progress

`expose_XVIII_partial.tex` is preserved source work only. It is excluded from
the cumulative reader and from all X-XVII completeness claims.

The file contains 48 continuous source-page markers, scan indices 261-308
inclusive (book folios 254-301), with no internal gap in that bounded range.
The first marker is the Expose-XVIII title and contents page. Indices 309-334
remain outside this WIP and Expose XVIII is therefore incomplete.

An isolated three-pass pdfLaTeX check of this body completed with zero fatal
errors and produced 25 nonempty A4 pages. It retained one disclosed overfull
box in the display spanning body lines 438-465; this WIP has not passed the
reader-level visual and release gates applied to X-XVII.
