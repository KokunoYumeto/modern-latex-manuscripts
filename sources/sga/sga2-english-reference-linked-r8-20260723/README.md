# SGA 2 English reader - exhaustive machine-readable references, R8

This is an archive-curated, no-overwrite **metadata successor** to the rejected
R7 public projection. The English TeX, compiled PDF, macro file, all fifteen
part files, and reference ledgers are byte-identical to R7. R8 changes no
translation, mathematics, visible wording, locator, hyperlink, label, page,
or PDF byte.

R7 passed its exact-set, manifest, privacy, graph, font, and destination-validity
gates, but an independent archive audit found one publication-control defect:
three public-facing controls called all 1,384 PDF link annotations internal
GoTo annotations. Direct PDF action-dictionary readback instead finds 1,382
internal GoTo annotations and 2 URI annotations. R8:

- records 1,384 total link annotations, split into 1,382 internal GoTo and
  2 URI annotations;
- preserves the valid R7 reader and machine evidence byte-for-byte;
- retains the superseded R6 controls under `predecessor_r6_controls`; and
- regenerates the public manifest, checksum manifest, aggregate identity, and
  validation receipt from the corrected successor bytes.

The final reader has 184 A4 pages, 618 declared targets, 1,154 closed internal
edges, 1,536 named PDF destinations, 1,382 valid internal GoTo annotations,
2 URI annotations, and zero invalid named GoTo destinations. All fifteen source
parts reverse-reconstruct exactly after removing only the inserted reference
wrappers. Visible text and page geometry are unchanged from the predecessor.

This directory is the privacy-clean archive-curated R8 public projection.
Local validation, archive acceptance, publication, and remote readback remain
distinct states.
