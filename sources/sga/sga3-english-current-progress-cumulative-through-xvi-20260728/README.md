# SGA 3 English current-progress cumulative reader

This package provides one reading surface for all substantially complete SGA 3
English translation work available to the archive on 2026-07-28.

## Included

- Editorial Notice and Introduction
- Exposes I-XIII
- Expose XVI

The 950-page PDF is continuous through Expose XIII, places an explicit gap page
for Exposes XIV-XV, then includes the complete current Expose XVI Loop-1
working translation. It ends with a visible boundary notice. Exposes XVII-XXVI
are not included.

## Working-state limits

This is a preservation-oriented working reader, not a claim that SGA 3 is
complete, critically edited, rights-cleared as a whole, or exhaustively
certified under the project's reference convention.

- Exposes I-III still contain temporary source-derived diagram images.
- Expose VII uses the latest readable repaired working source. Its text and
  repaired layout are worth preserving here, while its final standalone
  diagram/reference release certification remains tracked separately.
- Expose X is complete as a Loop-1 English text-and-equation body. Four raster
  diagram placeholders remain for Loop 2.
- Exposes XII and XIII are complete readable Loop-1 bodies. Their exhaustive
  standalone reference/package closeout remains separate.
- Expose XVI is complete as a Loop-1 body. Three source-derived raster diagram
  placeholders remain for Loop 2.
- Exposes XIV-XV and XVII-XXVI are absent.

The Polo-Gille PDFs control the French text, formulas, numbering, notes, and
diagram appearance. The pre-existing user-supplied OCR was consulted read-only
as locator and drafting assistance only; it was not rerun. Jacob Reinhold's
`jcreinhold/sga` English Markdown at commit
`e7a259f3f8608ad3edf9bf6eead3fd504dd2d23e` is credited comparison and drafting
lineage, not source authority. Its stated CC BY 4.0 license applies to that
translation contribution only and does not license the underlying French work
or this package as a whole.
