# SGA 3 English complete working reader

This package is the preferred readable English SGA 3 integration frozen on
28 July 2026. It puts the current continuous mathematical text in one reader
instead of requiring readers to assemble many bounded checkpoints.

## Included scope

- Editorial Notice and Introduction.
- Exposes I-XXVI.
- The Tome III mathematical guide.
- The terminal index.

The reader has 1,469 A4 pages. It is a complete current working translation
surface for the available integrated SGA 3 scope. It is not a critical
edition, peer review, blanket rights clearance, final diagram-fidelity
certification, or accessibility-remediated PDF.

## Reader-facing files

- `00c00_SGA3_English_Complete_Working_Reader_20260728.pdf` is the preferred
  current reader and sorts before the bounded SGA 3 component PDFs.
- `02c00_SGA3_English_Complete_Working_Reader_20260728.tex` is the directly
  accessible master TeX.
- `10c9_SGA3_English_Complete_Working_Reader_Source_and_Predecessor_20260728.zip`
  contains the exact recorder-derived build closure, release controls, and
  the superseded 1,434-page cumulative reader and master TeX.

The older cumulative reader remains preserved inside the grouped ZIP and in
immutable prior archive versions. It is no longer the preferred loose file.

## Reader cleanup

Reader-facing production notes, AI/process prefaces, working-state boxes,
production-boundary pages, and process captions were removed. Source-reading
notes that document substantive textual or mathematical choices remain.
Required provenance and attribution are recorded in
`PROVENANCE_AND_RIGHTS.md`, outside the reader.

## Current technical state

The PDF contains 9,483 named destinations, 4,590 valid internal GoTo actions,
61 embedded font resources, zero Type 3 fonts, and 153 raster image XObjects.
It has no unresolved references, citations, or rerun requests. The current
diagram implementation is heterogeneous: native TeX is used where integrated,
while some source-derived raster witnesses remain. This reader therefore does
not claim final native-diagram closure.

The PDF is untagged and has no XMP metadata stream. The editable TeX is the
durable source surface.
