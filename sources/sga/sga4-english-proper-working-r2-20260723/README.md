# SGA 4 proper English working reader R2

This public-progress package covers SGA 4 proper, Exposés I--XIX including
Exposé V bis. It excludes SGA 4½.

## Reader status

The 864-page reader passed exact source closure, isolated builds, PDF
destination and link checks, fonts, rendered review, rights-notice review, and
privacy review. It repairs the visibly broken references, destination
collisions, placeholders, missing glyphs, diagrams, bookmarks, and metadata in
the rejected R1 predecessor.

R2 is deliberately described as a working reader rather than an exhaustive
reference-certified release. Its later package audit found that the complete
co-current convention-v2 target, edge, candidate, and residual ledgers were
missing or misclassified, and that a build summary needed to report the
accurate converging page sequence `860 / 864 / 864`. Those evidence-package
limitations do not alter the reader bytes published here. The active R3 work
will supersede this checkpoint when its graph and remaining diagram-link
evidence are coherently frozen.
