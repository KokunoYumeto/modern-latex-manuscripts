En efecto, veremos a partir de aquí, por inducción ascendente sobre el entero $i$, que se tiene
\[
(\alpha_i)_*(\alpha_i)^*\Bigl(\prod_{j\le i}[p^*(\check L_j)\otimes\mathcal O_P(-1)]\Bigr)=0.
\tag{3.6.5}
\]
En el caso $i=r$, la afirmación (3.6.5) se escribe
\[
\prod_i[p^*(\check L_i)\otimes\mathcal O_P(-1)]=0,
\]
o también
\[
\prod_i(\xi+c_1(p^*(\check L_i)))=0,
\]
de donde se sigue inmediatamente (3.6). Para $i=1$, la afirmación (3.6.5) se sigue de (3.6.2). Supongámosla verdadera para $i$ y demostremos que lo es para $i+1$. Pongamos, para simplificar,
\[
N=\prod_{j\le i}[p^*(\check L_j)\otimes\mathcal O_P(-1)].
\]
La igualdad (3.6.5) para $i$ se escribe también
\[
(\alpha_{i+1})_*(\alpha_{i+1,i})_*(\alpha_{i+1,i})^*(\alpha_{i+1})^*(N)=0,
\]
es decir, teniendo en cuenta la fórmula de proyección para $\alpha_{i+1,i}$,
\[
(\alpha_{i+1})_*\bigl[(\alpha_{i+1})^*(N)(\alpha_{i+1})^*(p^*(\check L_{i+1})\otimes\mathcal O_P(-1))\bigr]=0,
\]
de donde se sigue inmediatamente el resultado deseado.

\begin{statement}{Corolario 3.7}
\begin{enumerate}[label=(\roman*)]
\item Para todo $\mathcal O_S$-módulo localmente libre $E$ y todo entero $i$, se tiene
\[
c_i(\check E)=(-1)^i c_i(E).
\]
\item Si $E$ es un $\mathcal O_S$-módulo localmente libre de rango $r$, se tiene
\[
c_1(E)=c_1(\Lambda^rE).
\]
\item Más generalmente, las clases de Chern de un producto tensorial o de una potencia exterior se expresan mediante los polinomios universales explicitados en (SGA 6 V 6.1).
\end{enumerate}
\end{statement}

\emph{Demostración.} Demostremos, por ejemplo, (ii); las demás afirmaciones se ven de manera análoga. Utilizando el esquema de banderas de $E$, se reduce al caso en que $E$ admite una filtración con cocientes invertibles $L_i$. Entonces la afirmación se sigue del isomorfismo bien conocido
\[
\Lambda^r(E)\simeq\bigotimes_i L_i.
\]
