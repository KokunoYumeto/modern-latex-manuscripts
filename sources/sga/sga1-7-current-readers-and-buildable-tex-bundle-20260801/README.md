# SGA 1-7 current English reader bundle

`00_Current_SGA1-7_English_Readers_and_Buildable_TeX_20260801.zip` is the
one-click reader/source bundle. It contains the current cumulative English
reader PDF and buildable TeX closure for SGA 1 through SGA 6, plus the complete
working English reader and source closure for SGA 7 I.

The bundle deliberately excludes provenance archives, QA imagery, raw logs,
historical releases, authority scans, and internal project notes. Those remain
separately preserved in the archive.

The SGA 7 I subtree covers all written exposes I, II, VI, VII, VIII, and IX
through EOF. It is translation-complete and readable, but not exhaustively
clickable-reference certified.
