# SGA 1 English complete-volume working reader

This is the current complete-volume English working reader translated from the
corrected French TeX for arXiv `math/0206203v2`.

## Scope

- Complete SGA 1 volume in the current working translation.
- Reader: 262 A4 pages.
- Editable closure: one master TeX file and 138 recursively referenced
  translation fragments.

The PDF contains real internal navigation: an independent structured replay
found 1,212 named destinations and 1,569 GoTo link annotations on 233 of 262
pages.

## Files

- `SGA1_English_CompleteVolume_Working_NoExhaustiveCertification_20260722.pdf`:
  directly readable complete-volume working reader.
- `SGA1_English_CompleteVolume_Working_Master_20260722.tex`: primary editable
  master.
- `SGA1_English_CompleteVolume_Working_Source_20260722.zip`: exact recursive
  TeX closure with its own checksum manifest and source-package note.

## Status and caveats

This reader has not yet received independent exhaustive convention-v2
certification for every theorem, equation, and bare internal reference. The
existing links are usable, but the deeper exhaustive link audit remains in
progress and may produce a later replacement.

The previously source-audited bounded checkpoint through the complete proof of
Corollary I.9.3 remains preserved as predecessor and evidence. This
complete-volume working reader does not erase that checkpoint or its audit
trail.

Corrected French arXiv TeX is the textual authority. Comparison translations
and PDFs are controls only. This package does not assert a new license in the
underlying French work, a critical edition, mathematical certification,
independent human peer review, or accessibility certification. Preserve the
project attribution and rights caveats when redistributing it.
