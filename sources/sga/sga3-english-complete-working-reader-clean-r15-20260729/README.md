# SGA 3 English reader

This package fronts one continuous English reader for SGA 3:

- Editorial Notice and Introduction;
- Exposes I-XXVI;
- the Tome I subject index;
- the Tome III mathematical guide; and
- the terminal Tome III index.

The PDF is the reading surface. The master TeX is directly available for
editing. The source-and-history ZIP contains the exact recursive build
closure, package controls, and the superseded 28 July clean reader. It keeps
the public landing surface compact instead of presenting hundreds of source
fragments as loose files.

The reader deliberately contains no AI attribution, workflow status,
production notes, source-status chapter, or release-audit prose. Those
materials belong in the archive documentation, not in the mathematics.

This remains a scholarly working translation and TeX edition. Some diagrams
still use source-derived raster dependencies while native replacements are
prepared. The package does not claim a critical edition, blanket rights
clearance, or final diagram-fidelity certification.
