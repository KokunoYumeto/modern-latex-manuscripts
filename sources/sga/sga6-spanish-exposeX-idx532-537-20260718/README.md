# SGA6 Spanish Expose X, idx532-537

This is the GitHub mirror of the bounded four-page Spanish working translation
first published on SGA version `10.5281/zenodo.21421508` and retained on the
current SGA version `10.5281/zenodo.21421931`. It covers source indexes
532-537 / printed pages 519-524. It is not a complete expose or volume and has
not received native-language review.

Run `build.ps1` to rebuild into `output/pdf`. Run `validate.ps1` either before
or after rebuilding; it uses the included French source-control excerpt,
published reader/build log, six direct source witnesses, and four render-check
pages. Its fresh result is written to `QA_VALIDATION_CURRENT.json` so the
published `QA_VALIDATION.json` receipt remains unchanged.

The first Zenodo package preserved the original validator with machine-local
paths. This GitHub mirror repairs those paths and includes the two small inputs
the validator expects. The translation text, front PDF, witnesses, ledgers, and
published QA receipt are unchanged.

`SHA256SUMS.csv` is the immutable checksum receipt for the published Zenodo
package. `SHA256SUMS_GITHUB_MIRROR.csv` covers this corrected portable mirror,
including the repaired validator and added source-control input.
