# SGA 3 English reader R28

This package presents the current assembled SGA 3 English reader as a clean
reading object:

- `00c_SGA3_English_Reader.pdf` is the 1,470-page A4 reader.
- `02c_SGA3_English_Master.tex` is the editable master.
- `10c_SGA3_English_Source_R28_20260730.zip` groups the complete recursive
  TeX source, provenance, exact reference controls, and member checksums.

The reader contains the mathematical text and genuine historical editorial
apparatus. It does not display project workflow, source-status banners,
machine or assistant narration, review-state notices, or build commentary.
Those matters belong in archive controls, not in the book.

R28 also completes the stable internal destination layer. It contains 13,132
named destinations and 12,344 valid internal GoTo actions. All 3,744 mapped
stable targets replay to the intended page and coordinates.

This is an English scholarly working edition. It does not assert a new
license over the underlying French work, critical-edition status, peer
review, or tagged-PDF accessibility.
