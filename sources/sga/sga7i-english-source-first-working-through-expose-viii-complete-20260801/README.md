# SGA 7 I English working reader through complete Expose VIII

This current-progress reader contains complete English Exposes I, II, VI,
VII, and VIII. It covers source folios 1-312 of the 528-folio SGA 7 I scan.
The exact continuation is Expose IX, Introduction 0.1, authority
`source/expose_IX_body.tex` line 5, zero-based scan index 324 / source folio
313 / physical PDF page 325.

This is a bounded working reader, not a complete English SGA 7 I, critical
edition, peer review, mathematical certification, accessibility certification,
or rights-clearance decision.
