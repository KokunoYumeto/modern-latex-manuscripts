# SGA2 Expose VI visual evidence

This package contains four project-generated target-page renders and seven
project-generated machine-readable-ledger previews for the bounded SGA2
Expose VI English checkpoint. Every image has a stable ID, hash, dimensions,
parent binding, linked unit, review output, and QA disposition.

No French source scan, source crop, or source-page raster is redistributed.
Direct French pages 65-68 were reviewed locally at 300 dpi; their rights remain
separate, so the public package records that review boundary without pixels.
This is render and evidence QA, not source certification or human peer review.
