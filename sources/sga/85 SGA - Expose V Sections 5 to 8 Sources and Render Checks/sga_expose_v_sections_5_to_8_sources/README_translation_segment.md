# SGA Translation translation segment

source package. this translation segment translates the remaining part of SGA 4, Exposé V.

## Translated range

- SGA 4, Exposé V, Section 5: The functors `R^q u_*` and the Cartan-Leray spectral sequence relative to a morphism of topoi
- SGA 4, Exposé V, Section 6: Local Ext and cohomology with supports
- SGA 4, Exposé V, Section 7: Appendix: Čech cohomology
- SGA 4, Exposé V, Section 8: Appendix: Local inductive limits, by P. Deligne

Source range: `05/05.tex`, lines 1947-4410.

This completes the current working English LaTeX draft of SGA 4, Exposé V.
