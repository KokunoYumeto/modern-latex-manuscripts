# Publication readiness

Status: `READY_FOR_WORKING_PUBLICATION`

This package is ready to replace the earlier through-XXII snapshot as the
preferred current-progress SGA 3 reading surface.

- Frozen producer-input identities recorded before integration.
- Three converged XeLaTeX passes, all exit 0.
- 1,166 A4 pages.
- No fatal errors, undefined controls, undefined references, duplicate
  destinations, missing glyphs, invalid PDF actions, or Type 3 fonts.
- 7,340 named destinations and 4,004 valid internal link annotations.
- Visual review of the newly extended Expose XVII span, complete Expose XX,
  Expose XX diagram pages, the new Expose XXI span, every new join and partial
  boundary, both explicit gap surfaces, and the final page.
- Exact source ZIP, privacy, extraction, and fresh three-pass rebuild replay

## Honest limits

- SGA 3 is incomplete: Expose XIX and Exposes XXIII-XXVI are absent.
- Exposes XVII, XXI, and XXII are explicitly partial.
- Some source-derived raster diagrams remain pending native reconstruction.
- Earlier component certifications vary. This cumulative snapshot does not
  upgrade every included component to a common terminal quality tier.
- The visual check supports a readable working release. It is not a new
  volume-wide Claude-style high-zoom diagram certification.
- The PDF is not claimed tagged or accessibility-remediated.
- No blanket license or transfer of underlying French rights is asserted.

The package is suitable for public survival, reading, correction, and
continuation. Later no-overwrite successors should replace it as more
translation and native-diagram work becomes available.
