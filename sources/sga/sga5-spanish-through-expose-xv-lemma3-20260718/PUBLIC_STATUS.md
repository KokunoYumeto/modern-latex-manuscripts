# Public status

This release is a source-aware Spanish SGA 5 working-translation checkpoint.
It contains 356 integrated TeX units and a 304-page reader, reaching Expose XV
through Lemma 3. It supersedes the previous public Spanish checkpoint through
Expose XV Proposition 1.

It is intentionally incomplete. It is not OCR-only output, but it is also not
an independently human-certified translation, a critical edition,
diagram-by-diagram certification, or a guarantee that every unflagged symbol
is source-perfect.

Corrections should be proposed through:
https://github.com/KokunoYumeto/modern-latex-manuscripts
