\subsection*{5.10. Casos particulares}
\subsubsection*{a) El caso no ramificado: $Y' = \emptyset$, es decir, $Y = \emptyset$.}

En este caso, la fórmula (5.1.1) se convierte en:

\begin{equation}\tag{5.11}
\Tr_{\bZ_\ell[G],\varphi}(f'^\vee_{H_{U',X'}(\ell)}) = \sum_{x \in X^f} \nu_x(f) \mathrm{NW}_f^{G,\varphi}(x)
\end{equation}

\subsubsection*{b) El caso de multiplicidades iguales a 1: $\nu_{x'}(g_{X'}^{-1}f') = 1$ para todo $x'\in {Y'}^{g_{Y'}^{-1}f'_{Y'}}$ y todo $g\in G$.}

En este caso, la fórmula 5.1.1 se reduce a la fórmula 5.11. Este caso se da, en particular, si $\dim X = 1$ y $\nu_x(f)=1$ para todo $y\in Y$.% SOURCE_ANOMALY_PRESERVED: the certified source binds y but prints subscript x.
