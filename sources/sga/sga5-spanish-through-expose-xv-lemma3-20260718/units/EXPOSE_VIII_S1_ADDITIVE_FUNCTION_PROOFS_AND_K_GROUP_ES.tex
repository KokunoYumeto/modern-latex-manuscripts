Para demostrar $\delta)$ se utilizan las sucesiones exactas:
\[
0\longrightarrow Z^i\longrightarrow E^i\longrightarrow B^{i+1}\longrightarrow 0,
\]
\[
0\longrightarrow B^i\longrightarrow Z^i\longrightarrow H^i(E)\longrightarrow 0.
\]
La demostración de $\varepsilon)$ se hace por inducción sobre $n$, utilizando la sucesión exacta
\[
0\longrightarrow F_{n-1}\longrightarrow F\longrightarrow F/F_{n-1}\longrightarrow 0.
\]
Para demostrar $\varphi)$, sean $E\in\Ob\cD$ y
\[
F=\bigoplus_{n\in\mathbb Z^+}E_n,\qquad E_n=E,\quad n\in\mathbb Z^+.
\]
Entonces $E\oplus F\simeq F$ y, aplicando $\gamma)$, se tiene
\[
f(F)=f(F)+f(E),
\]
por tanto, $f(E)=0$.

Si se considera, para todo grupo abeliano $G$, el grupo abeliano $A_{\cD}(G)$ de las funciones aditivas de $\cD$ en $G$, se obtiene de manera evidente un funtor covariante
\[
A_{\cD}:\Ab\longrightarrow\Ab.
\]
El funtor $A_{\cD}$ es representable. Un par de representación $(K_{\cD}(\cC),\varphi)$ puede obtenerse de la manera siguiente. Denotando por $L$ el grupo abeliano libre generado por los objetos de $\cD$, sea $R$ el subgrupo de $L$ generado por los elementos de la forma $E-E'-E''$ para cada sucesión exacta
\[
0\longrightarrow E'\longrightarrow E\longrightarrow E''\longrightarrow 0
\]
de $\cC$. Se pone
\[
K_{\cD}(\cC)=L/R.
\]
La aplicación $\varphi$ se obtiene componiendo las dos aplicaciones canónicas
\[
\Ob\cD\longrightarrow L\longrightarrow L/R.
\]
Cuando no haya peligro de confusión, se puede abreviar la notación:
\[
K_{\cD}(\cC)=K(\cD).
\]
