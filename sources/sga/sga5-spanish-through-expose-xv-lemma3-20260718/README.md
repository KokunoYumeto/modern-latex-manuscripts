# SGA 5 Spanish through Expose XV Lemma 3

This is a frozen, bounded release of the growing Spanish SGA 5 translation.
It contains a 304-page PDF and the 356 editable TeX units actually integrated
into that PDF.

## Coverage

The package includes complete source-reconciled Spanish working translations
of Exposes I, III A, III B, V, VI, VII, VIII, X, and XII. Expose XV continues
through section 3 no. 2, the rationality theorem, and the complete proofs and
formal summary of Lemmas 1--3.

The next source cursor is French authority line 15068, where the three
reductions to the projective-line case begin.

## Contents

- `sga5_es.tex`: cumulative Spanish master.
- `units/`: exactly 356 integrated editable units; no later draft units.
- `output/pdf/sga5_es.pdf`: the frozen 304-page reader.
- `authority/sga5_fr_workpass.tex`: frozen French authority witness.
- `evidence/`: source map, parity and unit hashes, terminology decisions,
  source anomalies, build evidence, and visual-QA ledger.
- `render_checks/`: exact boundary/new pages 302--304 inspected for this
  checkpoint.
- `build.ps1` and `scripts/`: reproducible local build/evidence helpers.
- `SHA256_MANIFEST.csv`: byte-level inventory generated after packaging.

## Authority

The translation was reconciled unit by unit against the frozen French
workpass and uses the source scan as the decisive witness where needed.
English material is translation memory only and cannot promote a unit.

This is serious working material, but it remains incomplete and may contain
mathematical, typographical, translation, or diagram errors. It is not a
critical edition or independent human certification.
