# Publication readiness

Status: `READY_FOR_TARGETED_CROP_AND_METADATA_PUBLICATION`.

The public surface is intentionally two compact ZIP files. The image ZIP is
restricted to 12 deduplicated, current-byte, actually opened targeted excerpts.
The metadata ZIP records all 14,744 unique generated images and makes the
14,732 withheld-pixel dispositions explicit.

The parent reader, obsolete scan, whole-page renders, raw session logs,
private paths, generation scripts, and working TeX bodies are not proposed in
this visual-evidence release. This package neither changes nor certifies any
SGA 7 reader.

Publication must use the existing SGA concept and preserve prior versions. No
duplicate concept or parallel draft is authorized.
