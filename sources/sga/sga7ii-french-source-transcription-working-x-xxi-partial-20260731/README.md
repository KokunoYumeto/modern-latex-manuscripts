# SGA 7 II French source transcription: Exposes X-XXI partial

This package preserves a cumulative working French transcription of SGA 7 II
from Expose X through source index 406 in Expose XXI. It contains the complete
transcribed text of Exposes X-XX and the first 37 of 39 source pages of Expose
XXI.

The exact remaining cursor is source index 407. Indices 407-408 finish Expose
XXI; indices 409-445 comprise Expose XXII. Those 39 pages are not represented
here. This is therefore a useful partial source reader, not a complete SGA 7 II
transcription, an English translation, a critical edition, or a mathematical
certification.

## Direct reading and source

- `reader/SGA7II_French_Source_Transcription_Working_X-XXI_Partial_20260731.pdf`
  is the 201-page A4 cumulative reader.
- `source/SGA7II_French_Source_Transcription_Working_X-XXI_Partial_20260731.tex`
  is the build wrapper.
- `source/expose_*_body.tex` contains twelve editable expose bodies.
- `evidence/source-pages/` contains five 600-dpi source leaves used to settle
  formula, diagram, and integration defects.
- `SHA256SUMS.csv` identifies every other package file.

The reader starts directly with the volume text. It contains no project
preface, workflow status page, or production commentary.
