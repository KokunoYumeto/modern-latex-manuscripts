# Public support-package withdrawal

Current SGA version: [10.5281/zenodo.21430393](https://doi.org/10.5281/zenodo.21430393)

The corrected 381-page English working-reader PDF remains current and
byte-identical, with SHA-256
`F8B1E15754BEB5C83CF2A47B261D6F9F907DE5B7E8A6ED4DF311C624E38C7B8E`.

The earlier grouped support ZIP and the corresponding path-bearing GitHub
control files have been withdrawn from the current public surfaces. A
wrap-aware audit found reconstructable host-local paths in build logs,
validation controls, provenance/source ledgers, and repair evidence. This is a
publication-hygiene defect in the support layer, not a new change to the reader
PDF or its mathematical text.

The GitHub correction removes fifteen path-bearing text/control files and three
now-stale package manifests. The retained 135-file public subset is indexed by
`GITHUB_PUBLIC_SHA256SUMS_AFTER_WITHDRAWAL.txt`.

A replacement support package must use path-neutral public build records and
ledgers, regenerate all manifests and checksums, and pass a wrap-aware privacy
audit before publication. Historical Zenodo versions remain immutable and are
not the current support-package surface.

The reader's authority caveat is unchanged: its inherited prefix,
French-synchronized middle layer, and scan-checked later layer do not have
uniform whole-volume source-certification status.
