\begin{prooftext}[Demostración]
\begin{enumerate}[label=(\alph*)]
\item Las condiciones del enunciado son suficientes: si $X$ verifica (MLAR), es AR-isomorfo a su sistema proyectivo de imágenes universales $X'$. Por otra parte, la hipótesis hecha sobre $X'$ significa que el sistema proyectivo
\[
\bigl(X'_{n+r}/J^{n+1}X'_{n+r}\bigr)_{n\ge0},
\]
con los morfismos de transición evidentes, es $J$-ádico. Ahora bien, es claro que este sistema proyectivo es AR-isomorfo (2.4.6) a $X'$.
\item Las condiciones del enunciado son necesarias: si $X$ es AR-$J$-ádico, es AR-isomorfo a un sistema proyectivo estricto y, por tanto, verifica (MLAR). El sistema proyectivo $X'$ de las imágenes universales de $X$ es AR-isomorfo a $X$ y, por tanto, AR-$J$-ádico. Para demostrar el segundo punto nos reducimos, pues, a comprobar que, si $X$ es un sistema proyectivo AR-$J$-ádico y estricto, existe un entero $r$ tal que el sistema proyectivo $\ell_r(X)$ definido por
\[
\ell_r(X)_n=X_{n+r}/J^{n+1}X_{n+r}
\]
sea $J$-ádico. Para ello, sea $u:Y\to X$ un AR-isomorfismo, siendo $Y$ $J$-ádico. Como el núcleo $T$ de $u$ es AR-nulo, sea $r$ un entero tal que el morfismo canónico $T[r]\to T$ sea nulo. Es inmediato que el morfismo canónico
\[
\ell_r(u):\ell_r(Y)\longrightarrow\ell_r(X)
\]
es un isomorfismo, de donde se sigue la afirmación.
\end{enumerate}
\end{prooftext}
