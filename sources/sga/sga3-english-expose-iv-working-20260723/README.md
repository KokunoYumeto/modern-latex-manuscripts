# SGA 3 Exposé IV English working reader

This is a complete standalone translation checkpoint for Exposé IV, published
alongside the separate cumulative SGA 3 working reader through Exposé III. It
does not make SGA 3 complete.

## Scope

- Complete Exposé IV, all 21 translated components.
- Authority local pages 1--73; authority page 74 is blank.
- Reader: 65 A4 pages.
- Exposé V is not included.
- Exposés VI--XXVI remain untranslated as of this checkpoint.
