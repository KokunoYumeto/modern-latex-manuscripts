This compact package preserves a complete English working reconstruction of
SGA 3, Expose XIV, including Serre's appendix.

## Quality Status

This is an additive **working reader**, not a claim that all of SGA 3 is
complete or that Expose XIV is a critical edition.

All four previously raster-delivered Dynkin-automorphism rows were rebuilt as
native editable TikZ. The Session-C lead compared the authority and delivered
rows at 5000 dpi and recorded a strict pass. The public source closure has no
active `includegraphics` call, and the PDF contains no raster image XObjects.

Three fresh archive rebuild passes completed without selected diagnostics.
The 37 producer and rebuild pages agree in extracted text, decoded content,
geometry, and 180-dpi raster output. The release does not claim exhaustive
reference-v2 coverage or tagged-PDF accessibility.
