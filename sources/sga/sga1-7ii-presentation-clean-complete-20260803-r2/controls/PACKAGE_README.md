# SGA 1–7.2 English presentation-clean checkpoint

This checkpoint contains nine standalone English SGA readers and one cumulative
4,177-page reader.  The cumulative PDF preserves the page content of each
standalone input exactly while namespacing its destinations so that duplicate
local labels cannot misroute across volumes.

Reader PDFs contain mathematical and bibliographic content only.  Production
status, source-comparison rationale, and archive workflow prose are kept in the
external controls and logbooks.  Genuine source-era or published-editor matter
is retained, including the SGA 2 and SGA 3 editor notes recorded in the surface
adjudication ledger.

The cumulative PDF is generated from the nine standalone PDFs by the enclosed
Python builder.  It is not falsely represented as a monolithic TeX compilation.
Buildable TeX/source closures and discoverable master TeX files are supplied for
all nine standalone readers.

The package does not include French scans or publisher PDFs.  Rights and
provenance caveats are in `RIGHTS_AND_PROVENANCE.md`.
