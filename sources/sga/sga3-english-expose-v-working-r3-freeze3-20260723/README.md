# SGA 3 Expose V English working reader, R3 freeze3

This package preserves the independently reviewed R3 freeze3 reconstruction
of complete SGA 3 Expose V. It is a standalone Loop-1/reference-v2 working
checkpoint. It does not make SGA 3 complete.

## Scope and status

- Complete Expose V, opening through bibliography.
- Reader: 54 A4 pages.
- Editable closure: one master plus 24 component TeX files.
- Reference surface: 273 targets, 333 linked edges, and an exhaustive
  4,328-candidate partition into 333 edges and 3,995 adjudicated residuals.
- Compiled PDF: 355 destinations and 411 valid internal GoTo actions.
- Visual QA: 54/54 pages and six contact sheets reviewed.

Exposes VI--XXVI remain untranslated. The 66 diagram PNGs are temporary
Loop-1 reconstructions derived from the controlling source PDF. Native or
faithful Loop-2 diagram replacement remains open.
