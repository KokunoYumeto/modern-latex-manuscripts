# SGA 3 Exposé XXIII English Working Reader

This bounded package preserves the complete current English Loop-1
reconstruction of SGA 3 Exposé XXIII, *Reductive Groups: Uniqueness of
Pinned Groups*.

## Scope

- Complete Exposé XXIII only.
- Polo--Gille authority local pages 1-37 / combined-reader pages 1209-1245.
- Hard stop before Exposé XXIV local page 1 / combined-reader page 1246.
- Fourteen editable TeX files: one master, one macros file, and twelve
  ordered content components.
- One 37-page A4 working reader.

This is not a complete SGA 3 reader, a critical edition, exhaustive
reference-v2 certification, rights clearance, or mathematical
certification.

## Diagram Status

The complete TeX closure contains one diagram, implemented as native
editable `tikz-cd`, and zero `\includegraphics` calls. Direct 5000-dpi
authority comparison found four label-side errors in the first native
version. The session lead corrected all four and signed the included
high-resolution review receipt.

The 600-dpi page renders remain valid locator and context evidence. They
and the 5000-dpi authority crops are not redistributed in this package.
No raster diagram is delivered.
