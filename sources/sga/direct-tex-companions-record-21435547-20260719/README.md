# Direct SGA TeX companions

This directory mirrors the five TeX files newly surfaced as direct downloads on SGA record `10.5281/zenodo.21435547`, together with the public status note and checksum ledger. The three already-direct SGA1/SGA2 TeX files remain in their work-specific GitHub mirrors and are covered by the same checksum ledger.

The SGA6 English file is a mechanically flattened, dependency-complete projection of the exact modular source retained in `sources/sga/sga6-english-layered-idx684-20260718/`. A fresh two-pass build reproduced the 377-page reader's extracted text exactly and left no unresolved `input` or `include` dependency.

These are editable working sources, not completion, critical-edition, certification, independent human-review, accessibility, or rights-clearance claims.
