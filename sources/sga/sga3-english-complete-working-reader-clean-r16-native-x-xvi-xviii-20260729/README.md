# SGA 3 English reader

This compact package fronts one continuous English reader containing the
Editorial Notice, Introduction, Exposes I-XXVI, Tome I subject index,
Tome III mathematical guide, and terminal index.

The PDF is the primary reading surface. The master TeX is directly available
for editing. The source-and-history ZIP contains the exact recursive build
closure, release controls, and the superseded R15 reader. Hundreds of source
fragments therefore remain available without crowding the public file list.

R16 integrates the sealed native-TeX diagram successors for Exposes X, XVI,
and XVIII. Nine native diagram inputs replace the corresponding earlier
implementations, and the cumulative PDF now contains eight fewer raster image
objects while preserving its page count, destinations, and internal links.

The reader contains only the mathematical and bibliographic material, with no
workflow, production-status, source-status, or release-audit preface. It
remains a scholarly working translation and TeX edition, not a critical
edition, blanket rights clearance, or final certification of every remaining
diagram.
