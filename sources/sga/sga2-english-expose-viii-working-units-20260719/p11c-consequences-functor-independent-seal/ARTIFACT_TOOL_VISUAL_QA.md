# Artifact Tool visual QA

Artifact Tool renders all four substantive CSV ledgers and the exact final
manifest to PNG previews in the temporary QA workspace. Every preview is
inspected for headers, rows, column alignment, blank output, and formula
substitution. Long evidence cells remain machine-readable in the source CSV
even when compressed in an overview preview.

PASS: five of five ledger previews are populated and structurally legible;
record counts agree with strict validation. This spreadsheet QA validates
evidence presentation and structure only; it does not replace the independent
French formula and PDF review.
