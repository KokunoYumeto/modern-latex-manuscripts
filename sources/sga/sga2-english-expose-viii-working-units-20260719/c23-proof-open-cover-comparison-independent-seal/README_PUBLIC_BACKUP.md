# SGA 2 Expose VIII bounded unit C23-POC

This directory is an off-PC GitHub backup of the independently sealed English
proof/open-cover working unit following Corollary 2.3. It covers corrected
French lines 2683-2713, original printed pp. 89-90, physical source-PDF
pp. 79-80, and recomposed running pp. 71-72. Line 2714 is blank and excluded;
the next cursor is French source line 2715.

overlap, glyph, note, formula, or boundary defect. This is a bounded portion

certification, publication, or rights clearance. It supersedes only internal
