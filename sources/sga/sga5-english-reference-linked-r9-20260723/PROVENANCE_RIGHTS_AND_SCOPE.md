# Provenance, rights, and scope

## Exact lineage

The reference retrofit was applied to the frozen R8 English synchronized
reader source (SHA-256
`7E0A05459F0D5D7D396E7AE2B8658F046E0DF0FC0850E19F0A22C458952EE83D`).
Removing only the 720 R9 hyperlink wrappers reconstructs that R8 TeX exactly.
The final R9 TeX SHA-256 is
`765067892F2F208015235BF548F2F8FA03E56DA63D4ED470CF5B67F08CA1CE2F`.

This release projection is derived from the frozen internal directory named
`sga5_full_reader_reference_retrofit_r9_exhaustive`. The internal absolute
path is deliberately omitted. Exact copied-file identities are recorded in
the public manifests.

## Editorial status

The reader describes itself as an English source-synchronized working edition
of ten curated SGA 5 exposes. The R9 work changes only reference machinery:
visible flow text and layout text remain byte-exact relative to R8, the page
count remains 309, and the source-preservation ledger records the reversible
markup.

## Rights boundary

No source scan is included. This package supplies no license grant for the
underlying SGA text and makes no claim that a new public-domain or open-license
status has been established. Archive maintenance must retain attribution and
rights caveats appropriate to the existing SGA 5 record. GitHub custody may be
updated if policy permits; do not create a duplicate Zenodo concept.

## Privacy boundary

Raw logs, build directories, helper scripts containing runtime details,
temporary render assets, and absolute private paths are excluded. The public
TeX, PDF, ledgers, prose controls, and path-neutral validation were rescanned
in raw, slash-normalized, and whitespace-dewrapped modes before handoff.
