# SGA 7 I English working reader through Expose VIII, Proposition 3.7

This current-progress reader contains complete English Exposes I, II, VI, and
VII, followed by Expose VIII through Proposition 3.7. It covers source folios
1-264 of the 528-folio SGA 7 I scan. The exact continuation is Expose VIII
section 4 and Lemma 4.1, authority `source/expose_VIII_body.tex` line 1559,
zero-based scan index 276 / source folio 265 / physical PDF page 277.

This is a bounded working reader, not a complete English SGA 7 I, critical
edition, peer review, mathematical certification, accessibility certification,
or rights-clearance decision.
