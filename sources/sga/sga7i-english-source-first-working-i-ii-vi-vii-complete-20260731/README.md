# SGA 7 I English working reader through complete Expose VII

This current-progress reader contains complete English Exposes I, II, VI, and
VII. It covers source folios 1-217 of the 528-folio SGA 7 I scan. The exact
continuation is the Expose VIII opening, authority `source/expose_VIII_body.tex`
line 5, zero-based scan index 229 / source folio 218.

This is a bounded working reader, not a complete English SGA 7 I, critical
edition, peer review, mathematical certification, accessibility certification,
or rights-clearance decision.

## Read or build

- `reader/SGA7I_English_SourceFirst_Working_I_II_VI_VII_Complete_20260731.pdf`
  is the 134-page A4 reader.
- `source/SGA7I_English_SourceFirst_Working_I_II_VI_VII_Complete_20260731.tex`
  is the build wrapper.
- `source/components/` contains the exact 92 editable components used by the
  wrapper.
- `SGA7I_English_SourceFirst_Working_I_II_VI_VII_Complete_Reader_and_TeX_20260731.zip`
  groups the reader and buildable TeX for one-click use.

The reader begins directly with the mathematics. A fresh isolated three-pass
pdfLaTeX build converged without warnings, errors, overfull or underfull boxes,
missing inputs, undefined references, or rerun requests. The producer reader
and isolated rebuild have identical geometry, decoded page-content streams,
and extracted text on all 134 pages; their file hashes differ because their PDF
metadata timestamps differ.

Pages 132-134, including diagram (3.8.2), the terminal formulas, and the Expose
VII bibliography, were rendered directly and inspected at 600 dpi. No blank
page, clipping, overlap, or malformed diagram was found. All font resources are
embedded; seven Type 3 resources lack Unicode mappings. The PDF is not claimed
to be tagged or accessibility-remediated, so the editable TeX remains the
durable text surface.
