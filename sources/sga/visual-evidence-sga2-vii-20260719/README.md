# SGA2 Expose VII visual evidence

This package contains fifteen project-generated images from the independently
audited bounded English Expose VII checkpoint: seven full target-reader page
renders and eight rendered previews of machine-readable evidence ledgers.

No French-source pixels are included. The target page images are linked to the
seven-page reader and the bounded structural root. Ledger previews are linked
to their source CSV artifacts. The JSONL index is canonical; the CSV is a
tabular projection.

The visual package supports QA and reproducibility. It does not expand the
claim beyond corrected French lines 2274-2498 and does not establish a
critical edition, complete SGA2 translation, human review, accessibility
conformance, or rights clearance.
