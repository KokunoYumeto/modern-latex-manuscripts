# SGA 7 I fresh source transcription: Exposes I, II, VI, and VII

This package preserves a fresh scan-based working transcription of four complete exposés from
*Groupes de Monodromie en Géométrie Algébrique I* (Lecture Notes in Mathematics 288). The
included reader is 115 A4 pages and reproduces the mathematical text without project status,
method, or process pages.

## Included scope

- Exposé I: complete, source folios 1-24
- Exposé II: complete, source folios 25-31
- Exposé VI: complete, source folios 32-132; the source text is in English
- Exposé VII: complete, source folios 133-217

Together these frozen bodies cover 217 of the 529 mathematical body pages in SGA 7 I. Another 32
Exposé VIII pages existed only as unfinished production material at packaging time and are not
included. This is therefore a substantial partial source transcription, not a complete SGA 7 I
reader and not an English translation of the French exposés.

## Files

- `reader/SGA7I_Fresh_Transcription_Exposes_I_II_VI_VII_Working.pdf`: direct 115-page reader
- `source/SGA7I_Fresh_Transcription_Exposes_I_II_VI_VII_Working.tex`: build wrapper
- `source/expose_*_body.tex`: the four exact frozen source bodies
- `SGA7I_Fresh_Transcription_Exposes_I_II_VI_VII_Source_20260730.zip`: compact buildable source
- `RIGHTS_AND_PROVENANCE.md`: source identity and claim limits
- `TRANSCRIPTION_SCOPE_AND_LIMITS.md`: quality and completeness boundaries
- `SHA256SUMS.csv`: exact package identities
- `PUBLIC_PROJECTION_VALIDATION.json`: release replay summary

The underlying scan is not redistributed. An older June 2026 SGA 7 package remains preserved as
historical working material, but it is not the controlling source transcription for this range.

## Status

The four included exposés compile cleanly and contain 116 native `tikzcd` diagrams with no raster
diagram inputs. The public build uses breakable underlining and seven explicit display-scaling
wrappers so no extracted text extends beyond the A4 media box; the four original frozen bodies
remain byte-exact under `source/frozen/`. The edition remains a working transcription: uncertain
readings and source defects still require scholarly checking against the scan. The PDF is untagged
and has no exhaustive internal reference-link layer.
