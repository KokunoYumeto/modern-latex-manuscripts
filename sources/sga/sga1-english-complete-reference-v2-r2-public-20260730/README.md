# SGA 1 Complete Reference-v2 Successor

This directory preserves the privacy-clean public projection of the 2026-07-30
SGA 1 English reference-v2 R2 package under `payload/`. The frozen producer R2
remains unchanged in local custody. The public projection contains the same
262-page cumulative reader, 139-file buildable TeX closure, stable-reference
graph, sanitized build evidence, and bounded visual QA.

Archive maintenance independently replayed both the frozen R2 and public
projection manifests, removed five machine-local paths, rebuilt the reader in
four clean passes, and compared all 262 decoded
page streams, extracted text pages, link rectangles and targets, named
destinations, and destination coordinates. The result is recorded in
`INDEPENDENT_ARCHIVE_REPLAY.json`.

Reader-facing publication remains compact:

- the cumulative PDF and top-level TeX are direct downloads;
- the exact source/evidence package is one ZIP;
- the leading SGA 1-6 bundle contains this cumulative PDF and its complete
  buildable TeX closure together with the corresponding SGA 2-6 readers.

The reader itself contains mathematical content only. Workflow, provenance,
rights, and QA material remains outside the PDF in the grouped package.

This is a scholarly working translation and reference-linked reading edition,
not a critical edition, mathematical certification, accessibility
certification, peer review, or rights-clearance determination.
