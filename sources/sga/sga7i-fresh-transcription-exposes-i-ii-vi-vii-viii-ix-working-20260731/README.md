# SGA 7 I complete fresh source transcription

This package preserves a fresh scan-based working transcription of the full
mathematical and editorial body of *Groupes de Monodromie en Geometrie
Algebrique I* (Lecture Notes in Mathematics 288). The reader contains the six
written exposes present in the volume: I, II, VI, VII, VIII, and IX. Exposes
III-V do not appear as separate written exposes in SGA 7 I.

## Included scope

- Expose I: complete, source folios 1-24
- Expose II: complete, source folios 25-31
- Expose VI: complete, source folios 32-132; printed in English
- Expose VII: complete, source folios 133-217
- Expose VIII: complete, source folios 218-312
- Expose IX: complete, source folios 313-528, including bibliography and
  terminal publisher matter

The six bodies cover every source page from zero-based scan index 12 through
539 exactly once. There is no continuation cursor within SGA 7 I. This is a
complete working source transcription, not an English translation of the
French exposes, a critical edition, or a mathematical certification.

## Direct reading and source

- `reader/SGA7I_Fresh_Source_Transcription_Complete_Working.pdf`: 267-page
  cumulative reader containing only volume text
- `source/SGA7I_Fresh_Source_Transcription_Complete_Working.tex`: build wrapper
- `source/expose_*_body.tex`: six editable source bodies
- `SGA7I_Fresh_Source_Transcription_Complete_Reader_and_TeX_20260731.zip`:
  compact reader and complete editable TeX closure

The authority scan, source-page crops, raw production records, and operational
notes are excluded. The PDF contains no project preface, status page, or
production commentary.
