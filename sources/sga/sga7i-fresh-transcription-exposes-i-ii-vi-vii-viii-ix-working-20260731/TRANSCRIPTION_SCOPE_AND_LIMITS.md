# Transcription scope and limits

This checkpoint contains complete Exposes I, II, VI, VII, VIII, and IX of SGA
7 I, preserving the language printed in the source. Expose VI is English in
the source; the other exposes are French. The six bodies span zero-based scan
indices 12-539, with 528 unique page markers and no gap or duplicate.

The package uses native LaTeX/TikZ source and contains no raster diagram
inputs. The PDF is a reader-facing mathematical object with no production
preface, status report, or process page. Source defects and uncertain
readings may remain and should be checked against the controlling scan for
consequential scholarly use. The PDF is untagged, and no exhaustive
machine-readable internal-reference layer is claimed.

This checkpoint supersedes the earlier five-expose working reader only as the
current SGA 7 I source-transcription surface. Earlier GitHub commits and
Zenodo versions remain immutable history.
