# Alexandre Grothendieck — Tôhoku bilingual working edition

This record is the dedicated project lineage for Grothendieck's *Sur quelques
points d'algèbre homologique*. `source.zip` preserves every current producer
byte: both authority parts, all three text layers, every draft and correction,
earlier generations, errors, reversals, build evidence, page images, semantic
controls, and continuation records.

The direct PDFs expose the current bilingual page checkpoints for printed
pages 119, 120, and 121; `p121.pdf` is the default preview. The next canonical
cursor is printed page 122 and the work ends at printed page 221.

This is an immediate working checkpoint, not a complete translation, critical
edition, peer review, or mathematical certification. Earlier and adverse
generations remain preserved rather than curated away.
