# EGA readers and source

The current GitHub reading surface is the byte-exact
[`global-r1`](global-r1/README.md) package. Start with its
[1,356-page linked English reader](global-r1/EGA_English_Global_0_IV_complete_linked_reader.pdf),
then browse the complete buildable `source/` tree directly.

Current represented scopes are:

- EGA 0 through Section 13;
- EGA I and EGA II through their authority endpoints;
- the complete published EGA III text through 7.9.14; and
- EGA IV Sections 1–21, bibliography, indexes, contents, and errata/addenda
  through EOF.

The standalone source shelves remain independently browsable:

- [EGA 0 and EGA III](checkpoints/ega0-ega3-complete-reference-v2-r1-20260730/README.md)
- [EGA I](checkpoints/ega1-complete-reference-v2-r2-reader-clean-20260730/README.md)
- [EGA II](checkpoints/ega2-complete-reference-v2-r1-20260730/README.md)
- [EGA IV](iv-r4/README.md)

The separate [printed-page 143 checkpoint](p143/p143-status.md) records the
newer bounded EGA I French-authority recheck through Definition 6.2.1. It does
not silently replace the frozen global-reader source snapshot.

Use [CURRENT_PUBLIC_RELEASE.md](CURRENT_PUBLIC_RELEASE.md) and the
[coverage map](../../docs/ega-map.md) before assigning new work. Earlier
release and checkpoint directories are immutable history. These are working
editions, not critical editions, peer review, or uniform whole-corpus source
certification.
