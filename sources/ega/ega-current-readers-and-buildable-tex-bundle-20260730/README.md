# EGA Current English Reader Bundle

- `00_Current_EGA_English_Readers_and_Buildable_TeX_20260730.zip`
- 5,802,085 bytes

The ZIP contains every cumulative English EGA reader currently present on
the public archive surface and each reader's complete TeX build closure. It
has 99 readable members: 98 self-excluded manifest rows plus
`SHA256SUMS.csv`.

The current scopes are EGA 0, EGA II, EGA III Sections 1-7, and EGA IV
Sections 1-10. The scope names are part of the bundle identity and do not
imply that all four EGA volumes are complete.

The bundle deliberately excludes provenance archives, QA imagery, machine
ledgers, build logs, historical releases, authority scans, and internal
project notes. Those remain separately preserved in the archive.

Each of the four source closures was rebuilt from a clean extracted copy
with zero missing source files and zero fatal TeX errors. The ZIP was then
replayed member by member with zero unsafe paths, byte mismatches, or
SHA-256 mismatches.

On Zenodo this ZIP is intended to sort first in the file list while a direct
reader PDF remains the record's default preview.
