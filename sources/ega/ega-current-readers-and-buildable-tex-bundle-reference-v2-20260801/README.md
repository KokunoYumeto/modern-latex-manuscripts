# Current EGA English Readers and Buildable TeX

`00 Current_EGA_English_Readers_and_Buildable_TeX_20260801.zip` is the
one-click bundle of the current cumulative English readers and their buildable
TeX for EGA 0, I, II, the complete published EGA III text, and complete EGA IV.

This revision retains every EGA 0/I/II/III member byte-identically and replaces
only the EGA-IV subtree with the complete 651-page reference-v2 reader and its
59-file TeX closure.

These are working translations, not critical editions, mathematical or
accessibility certification, or a new rights grant.
