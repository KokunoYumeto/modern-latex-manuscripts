# Complete linked English reader of EGA 0–IV

This package contains a no-overwrite cumulative English reader of Alexander
Grothendieck and Jean Dieudonné's *Éléments de géométrie algébrique*: EGA 0,
I, II, III, and IV. It combines the complete standalone English source trees
into one 1,356-page PDF with a global table of contents, explicit volume
boundaries, working intra-volume and cross-volume links, and a consolidated
bibliography.

The reader is `EGA_English_Global_0_IV_complete_linked_reader.pdf`:
8,588,550 bytes, SHA-256
`3B9D399515AA074C22D3DF6C6F0F7349954444D7BCF980B87CCE5CAED671928A`.
It contains 17,808 internal GoTo actions with no broken destinations, no raster
images, and no Type 3 fonts.

Rebuild from the `source` directory with XeLaTeX and BibTeX using
`EGA_English_Global_0_IV.tex` as the master. The supplied active-source
manifest records every editable input. References to material outside the
delivered EGA 0–IV corpus remain visible but deliberately unlinked.

The French authority PDFs and OCR witnesses are not redistributed. This is a
machine-assisted, source-aligned working English edition; it is not represented
as author-approved, publisher-proofread, or a critical edition. See
`RIGHTS_AND_PROVENANCE.md` and `PUBLICATION_READINESS.md`.
