# EGA IV Section 19 printed-page-185 visual-witness metadata

This package records the high-detail authority images generated while opening
the disjoint EGA IV Sections 19-21 source-alignment lane. It publishes no
source pixel, authority PDF, OCR body, or translated source change.

  SHA-256
  `B4277FB99C6EDF8FEEC5B01F54368E4B8521BCD52871316C0EDF6FF4AE69389E`.
- Intended page: zero-based source-PDF index 183 / physical page 184 / printed
  page 185, MediaBox `[0,0,600,845]` points, rotation 0.
- Linked working source: `source/source_aligned/ega4-19.tex`; it remains

Ten grayscale 5000-dpi PNG crops cover five overlapping vertical bands split
into left/right halves. Their exact parent-coordinate boxes survive in the
intermediate crop PDFs and are listed in
`RIGHTS_BLOCKED_VISUAL_WITNESS.csv`. One corrected 600-dpi whole-page
navigation render is also recorded.

The ledger retains one adverse locator event: the first file named
`IV4_printed185_navigation_600dpi.png` visibly contains printed page 186, not
185. Its 5084x7100 pixels correspond to the following physical page's
610x852-point MediaBox. The corrected `r2` navigation render is printed page
185 at 5000x7042 pixels and matches the intended 600x845-point parent page.

`rights_blocked_not_public`. Their hashes, page mappings, geometry, dimensions,
and QA dispositions are public so the visual work is not silently omitted.

These are locator and authority-review witnesses, not translation evidence,
source-alignment completion, a critical edition, a rights grant, or a reader
release. No GitHub source body, EGA reader, or Zenodo record is replaced by
this metadata package.
