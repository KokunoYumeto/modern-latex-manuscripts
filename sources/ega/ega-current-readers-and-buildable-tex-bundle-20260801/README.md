# Current EGA English Readers and Buildable TeX

`00 Current_EGA_English_Readers_and_Buildable_TeX_20260801.zip` is the one-click reading and source bundle.

It contains the current cumulative English working readers and buildable TeX for EGA 0, I, II, the published EGA III text, and the complete cumulative EGA IV reader. Each volume has a direct PDF and a self-contained source directory inside the ZIP.

These are working translations, not critical editions, mathematical certification, accessibility certification, or a new rights grant.
