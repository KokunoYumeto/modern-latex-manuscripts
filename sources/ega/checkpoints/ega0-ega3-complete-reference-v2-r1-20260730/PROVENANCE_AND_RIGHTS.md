rights are retained by their holders; this package asserts no new license or
redistribution grant for them.

## English and TeX lineage

The inherited English TeX tree derives from the public `ryankeleti/ega`
community translation project. The recovered project snapshot was preserved in
the Modern LaTeX Manuscripts repository at local Git identity
`fc261645438fbeb2e1b3ca1052c4ba9a489f3628`. Its contributor file names Mateo
Carmona, Tim Holzschuh, Tim Hosgood, Ryan Keleti, Thiago Solovera & Nery, and
Wayne Yang.

The recovered tree contains no root license file covering the complete
translation body. Accordingly, this package records lineage and exact hashes
but does not invent or assert a license grant for the community translation.

Local continuation work completed EGA 0_III sections 8–13 and EGA III sections
1–7 directly against the frozen French authorities. The present successor adds
only source-proven reference repairs, exact-text clickable wrappers, stable
machine ledgers, and packaging controls.

This is a machine-assisted working translation for checking and continued
scholarly use. It is not represented as author-approved, peer reviewed,
proofread by a publisher, or a critical edition.
