# EGA — canonical French TeX

This tree transcribes the bounded French text of EGA 0–IV from the eight
NUMDAM scans listed in `controls/AUTHORITY_SHA256.csv`.

The transcription is diplomatic: it preserves the source wording, notation,
numbering, and source peculiarities as printed. TeX encoding and structural
markup are supplied for modern readability and reuse, but the French text is
not silently corrected or rewritten. Suspected source errors are recorded
outside the canonical source.

Every place where the English edition previously corrected or regularized the
source is rechecked against the NUMDAM image. A correction remains in English
only when the source image supports it; otherwise it is reversed. These checks
do not alter the canonical French body.

This is a source corpus, not a separate French-reader or editorial-edition
project.
