# EGA IV English Complete Cumulative Working Reader

Start with `reader/EGA4_English_Complete_Cumulative_Working_Reader_20260801.pdf`.

This package contains the complete cumulative English EGA IV working reader: Sections 1-21, bibliography, notation and terminology indexes, contents, and the printed errata/addenda. The buildable source is under `source/`; its entry point is `source/EGA4_English_Complete_Cumulative.tex`.

The reader has 651 letter-size pages, 2,987 named destinations, and 6,911 valid internal links. All EGA IV references are resolved. References to other EGA volumes and external works remain honest cross-volume references and are not fabricated as local links.

This is a source-aligned working translation, not a critical edition, peer review, accessibility certification, or new rights grant.
