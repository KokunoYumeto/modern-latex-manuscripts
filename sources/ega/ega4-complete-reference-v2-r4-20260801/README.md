# EGA IV Complete Reference-v2 Reader

Start with `EGA4_English_Complete_Reference_v2_Reader_20260801.pdf`, a
651-page cumulative English working reader covering EGA IV Sections 1-21,
bibliography, indexes, contents, and errata/addenda through EOF.

`EGA4_English_Complete_Reference_v2_Master_20260801.tex` is the direct master
file. `EGA4_English_Complete_Reference_v2_TeX_PDF_QA_20260801.zip` contains
the complete 84-file buildable source, reference graph, reader, and compact QA
package.

The reader contains 5,911 named destinations and 7,374 resolved internal GoTo
actions. References to EGA 0/I/II/III and external works remain visible but do
not falsely link into EGA IV. Those intentional cross-volume nonlinks produce
documented XeLaTeX warnings; they do not create broken PDF actions.

This is a source-aligned working English reader, not a critical edition,
mathematical peer review, accessibility certification, or rights-clearance
decision. The four NUMDAM French authority PDFs are identified by hash in the
package and are not redistributed there.
