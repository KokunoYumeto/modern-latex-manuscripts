# Source-alignment and printed-source corrections

The complete English body was checked sequentially against the four NUMDAM
authorities. The workpass restores omitted results, proofs, equations,
hypotheses, qualifiers, and notation and corrects inherited mathematical or
translation defects. It does not silently rewrite definite printed-source
slips.

The final reference pass visibly discloses and redirects these definite local
printed-source slips to the result actually used:

- `(5.5.1.2)` → `(5.5.1.1)`;
- `(6.3.9)` → Corollary `(6.3.5)(i)`;
- `(11.6.4)` → `(11.6.2)`;
- `(14.5.12.1)` → `(14.5.11.1)`;
- `(16.5.12.5)` → `(16.5.13.5)`;
- `(17.5.9)` → `(17.5.1)`;
- `(17.12.5.1)` → Proposition `(17.12.5)`.

The visible printed locator is preserved in each explanatory note. The package
does not claim to be a critical edition or a complete errata census.
