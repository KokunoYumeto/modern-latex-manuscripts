\section*{Neunter Abschnitt. Diskriminante}
\section*{\S\,84. Definition der Diskriminanten}

In der Theorie der quadratischen Körper treten als Diskriminanten gewisse ganze rationale, positive oder negative Zahlen auf, die, wenn sie gerade sind, durch \(4\) teilbar sind, und wenn sie ungerade sind, bei der Teilung durch \(4\) den Rest \(1\) lassen.  Kronecker hat solche Zahlen Zahlen von Diskriminantenform genannt.  Wir wollen sie hier kurz Diskriminanten nennen.

1. Eine positive oder negative, von Null verschiedene ganze Zahl, die einer der Kongruenzen
\begin{equation}
        D\equiv0,\quad D\equiv1\pmod4
\tag{1}
\end{equation}
genügt, heißt eine Diskriminante.

Jede Quadratzahl ist nach dieser Definition eine Diskriminante.  Diese nennen wir, wenn die Unterscheidung nötig ist, uneigentliche Diskriminanten.

2. Das Produkt zweier und folglich beliebig vieler Diskriminanten ist wieder eine Diskriminante.

3. Eine Diskriminante, die außer \(1\) keinen quadratischen Teiler enthält, nach dessen Absonderung eine Diskriminante übrig bleibt, heißt Stammdiskriminante.  Ist \(D\) keine Stammdiskriminante, so gibt es eine und nur eine Quadratzahl \(Q^2\) und eine Stammdiskriminante \(\Delta\), so daß
\begin{equation}
        D=Q^2\Delta.
\tag{2}
\end{equation}
Ist \(\Delta\) durch \(4\) teilbar, so muß
\begin{equation}
        \Delta\equiv8,12\pmod {16}
\tag{3}
\end{equation}
sein.

4. Eine eigentliche Diskriminante, die nicht in Faktoren zerlegbar ist, die selbst wieder Diskriminanten sind, heißt Primdiskriminante.  Ist \(p\) eine natürliche ungerade Primzahl und wird das Zeichen so bestimmt, daß \(\pm p\equiv1\pmod4\) ist, so gibt es folgende Primdiskriminanten:
\begin{equation}
        \pm p,\quad -4,\quad +8,\quad -8.
\tag{4}
\end{equation}

5. Jede Stammdiskriminante läßt sich auf eine und nur auf eine Weise in Primdiskriminanten zerlegen.

\section*{\S\,85. Das erweiterte Legendre-Jacobische Symbol}

Das Legendresche Symbol \(\Jac{m}{p}\) hat, wenn \(m\) eine von Null verschiedene Zahl und \(p\) eine Primzahl ist, den Wert \(+1\) oder \(-1\), je nachdem \(m\) quadratischer Rest oder Nichtrest von \(p\) ist.  Für eine Diskriminante \(D\) und eine ganze Zahl \(n\) definieren wir ein Symbol \((D,n)\) durch
\begin{align}
        (D,0)&=0,\tag{1}\\
        (D,1)&=1,\tag{2}\\
        (D,-1)&=\begin{cases}1,&D>0,\\ -1,&D<0,\end{cases}\tag{3}\\
        (D,p)&=0\quad(p\mid D),\tag{4}\\
        (D,2)&=(-1)^{(D^2-1)/8},\quad D\hbox{ ungerade},\tag{5}\\
        (D,p)&=\Jac{D}{p}\quad(p\hbox{ ungerade},\ p\nmid D).\tag{6}
\end{align}
Zerlegt man \(\pm n\) in seine Primfaktoren,
\[
        \pm n=p_1p_2\cdots p_r,
\]
so ist
\begin{equation}
        (D,n)=(D,\pm1)(D,p_1)(D,p_2)\cdots(D,p_r).
\tag{7}
\end{equation}
Daraus folgt
\begin{equation}
        (D,nn')=(D,n)(D,n'),
\tag{8}
\end{equation}
und, wenn \(q^2\) zu \(n\) teilerfremd ist,
\begin{equation}
        (q^2D,n)=(D,n).
\tag{9}
\end{equation}

Für die Primdiskriminanten erhält man
\begin{equation}
        (\pm p,n)=\Jac{\pm p}{n},
\tag{10}
\end{equation}
und für ungerades \(n\)
\begin{equation}
        (-4,n)=(-1)^{(n-1)/2},\quad
        (8,n)=(-1)^{(n^2-1)/8},\quad
        (-8,n)=(-1)^{(n-1)/2+(n^2-1)/8}.
\tag{11}
\end{equation}
Sind \(D,D'\) zwei Diskriminanten, so ist
\begin{equation}
        (DD',n)=(D,n)(D',n).
\tag{12}
\end{equation}
Das Reziprozitätsgesetz mit seinen Ergänzungssätzen lautet in dieser Bezeichnung
\begin{equation}
        (D,D')=\pm(D',D),
\tag{13}
\end{equation}
wobei das obere Zeichen gilt, wenn wenigstens eine der Diskriminanten positiv ist, das untere, wenn beide negativ sind.  Ferner gilt
\begin{equation}
        (D,m^2)=1,
\tag{14}
\end{equation}
und
\begin{equation}
        (D,mn^2)=(D,m),
\tag{15}
\end{equation}
sowie
\begin{equation}
        (D,n)=(D,n')\quad(n\equiv n'\pmod D).
\tag{16}
\end{equation}
Hieraus folgen die weiteren Formen
\begin{equation}
        (D_1,D)=\pm(D_2,D),
\tag{17}
\end{equation}
und
\begin{equation}
        (D_1,m)=\pm(D_2,m),\qquad D_1\equiv D_2\pmod {4m}.
\tag{18--19}
\end{equation}
Ist \(D\) keine Quadratzahl, so läßt sich immer ein \(\beta\) so bestimmen, daß
\begin{equation}
        (D,\beta)=-1.
\tag{21}
\end{equation}
Läßt man \(s\) ein volles Restsystem modulo \(D\) durchlaufen, so ergibt sich
\begin{equation}
        \sum_s(D,s)=0.
\tag{22}
\end{equation}

\section*{\S\,86. Die Gaussschen Summen}

Wir haben im ersten Bande die Gaussschen Summen aus der Theorie der Kreisteilung kennen gelernt.  Diese Ausdrücke lassen sich verallgemeinern und nehmen durch Anwendung des Symbols \((D,n)\) eine einfache Gestalt an.  Ist \(n\) eine ungerade Primzahl, so ist
\begin{equation}
        \sum_k \Jac{k}{n}e^{2\pi isk/n}=\Jac{s}{n}\sqrt{\pm n}.
\tag{1}
\end{equation}
Setzt man \(\Delta=\pm n\equiv1\pmod4\), so kann diese Formel geschrieben werden als
\begin{equation}
        \sum_k(\Delta,k)e^{2\pi isk/\Delta}=(\Delta,s)\sqrt{\Delta}.
\tag{2}
\end{equation}
Sie gilt auch für \(\Delta=-4,+8,-8\), also für jede Primdiskriminante.

Ist die Formel für zwei teilerfremde Stammdiskriminanten \(\Delta',\Delta''\) richtig, so folgt sie mit
\begin{equation}
        \sqrt{\Delta'}\sqrt{\Delta''}=\pm\sqrt{\Delta'\Delta''}
\tag{3}
\end{equation}
auch für \(\Delta=\Delta'\Delta''\).  Setzt man
\[
        k=k'\Delta''-k''\Delta',
\]
so durchläuft \(k\) ein Restsystem nach \(\Delta\), wenn \(k',k''\) Restsysteme nach \(\Delta',\Delta''\) durchlaufen.  Aus dem Reziprozitätsgesetz folgt
\[
        (\Delta,k)=(\Delta',k')(
\Delta'',k''),
\]
und damit die allgemeine Gültigkeit von (2) für jede Stammdiskriminante.
