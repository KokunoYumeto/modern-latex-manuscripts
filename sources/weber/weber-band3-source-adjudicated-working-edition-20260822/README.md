# Heinrich Weber — Lehrbuch der Algebra, Band III

This directory is the bounded GitHub projection of the complete source-adjudicated German transcription and English working translation. It covers exactly 740 canonical scan leaves: i0022–i0414 and i0425–i0771. The repeated scan pass i0415–i0424 is excluded from the reader and retained in the full provenance.

The `reader/` directory contains the German and English PDFs. The `source/` directory contains their self-contained build masters. The `evidence/` directory binds the 3,457 terminal source-backed dispositions, strict build, all-page visual QA, and the independent three-package audit. Run `python verify_package.py` to verify the package bytes.

Full provenance—including all 19 predecessor-record files, the registered 772-page source scan, checkpoint evidence, terminal ledgers, and visual evidence—is preserved in the Zenodo concept lineage [10.5281/zenodo.20412153](https://zenodo.org/records/20412153). It is intentionally not duplicated as a monolithic Git blob.
