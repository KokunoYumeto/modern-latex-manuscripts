# Weber literal repair package - current continuation

Contents are TeX/PDF only. No scan images are embedded or packaged.

This package contains:

- repaired individual German transcriptions and English translations for the repaired Vol. II chain currently complete through sections 176-207, Nachtraege I-II, Register, and Corrections;
- cumulative German transcription and cumulative English translation for the same range;
- all artificial page-marker lines from prior repair batches removed from the TeX/PDF deliverables.

The register and correction tables retain Weber's own index and errata page references because those are part of the printed text.
