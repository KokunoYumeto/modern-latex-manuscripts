# Dedekind Round 05 packet

This packet completes Dedekind's **"Was sind und was sollen die Zahlen?"** in source-checked German and English translation.

New work this round covers printed pp. **368--391** of GMW III: §§8--14, items 119--172, and the printed explanatory note signed Noether. The cumulative-current files contain the complete work from title/dedication and prefaces through the explanatory note.
