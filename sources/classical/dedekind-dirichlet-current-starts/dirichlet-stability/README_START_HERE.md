# Dirichlet Round 01 - Stability Paper and Source Audit

This package starts the Dirichlet lane from the supplied Dedekind/Dirichlet starter packet.

Contents:

- `new_work_this_round/original_language/tex/` and `pdf/`: source-checked German TeX/PDF for Dirichlet's short paper **Über die Stabilität des Gleichgewichts**.
- `new_work_this_round/translation/english/tex/` and `pdf/`: faithful English translation TeX/PDF of the same paper.
- `new_work_this_round/source_scans_for_checking/`: rendered scan pages used for verification from `dirichlet_werke_vol2_1897.pdf`.
- `new_work_this_round/audit/`: status note, source-completeness audit, current-reader segment map, and evidence images for errors in the existing public selected reader.
- `cumulative_current/`: current cumulative TeX/PDF state after this round, currently Paper I only.

The existing public reader `Dirichlet - Selected Works.pdf` should not be treated as source-truth. It is useful as a rough OCR/typesetting scaffold, but the first paper already contains mathematical errors against the scan.
