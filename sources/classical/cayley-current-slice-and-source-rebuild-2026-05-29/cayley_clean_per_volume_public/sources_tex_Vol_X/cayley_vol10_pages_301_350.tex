\section[On a Functional Equation]{686. On a Functional Equation.\footnote{From the \textit{Quarterly Journal of Pure and Applied Mathematics}, vol.\ XV. (1878), pp.\ 131--137.}}

[301]

\noindent
[The paper continues from the previous page with the verification of certain formulae.]

For the value of $RS' - R'S$, we have
\begin{align*}
RS' - R'S &= (\lambda c + d)(-W - \lambda Z) - (-\lambda d - c)(W + \lambda Z)\\
&= -(\lambda^2 - 1)\{cZ + (\lambda + 1)((d-c)W - dR\},
\end{align*}
or substituting for $Z$ and $W$ their values, this is
\begin{multline*}
= -\frac{(\lambda - 1)}{\lambda}\bigl[(a^2 + d^2 + ad + bc)c\,(bC + dD)\\
+ (ad - bc)\{(c-d)(aC + cD) + d(bC + dD)\}\bigr].
\end{multline*}

In the term in $\{\dots\}$, the coefficient of $C$ is
\[
[(a^2 + d^2 + ad + bc)b + (ad - bc)a]c - d(a - b)(ad - bc)
= (a + d)(db - bd)c - (a + d)dx(ad - bc),
\]
and similarly the coefficient of $D$ is
\[
[(a^2 + d^2 + ad + bc)d + (ad - bc)c]c - d(c - d)(ad - bc)
= (a + d)(ad - bc)c - (a + d)d(ad - bc).
\]

Hence the whole term in $\{\dots\}$ is
\[
= (a + d)\{[(db - bd)c - d(ad - bc)x]C + [(ad - bc)c - d(ad - bc)]D\},
\]
which is readily reduced to
\[
(a + d)(ad - bc)(-dC + cD);
\]
also
\[
ad - bc = (a + d)\{cx^2 + (d - a)x - b\},
\]
so that we have
\[
RS' - R'S = \frac{(\lambda - 1)}{\lambda}(dC - cD)\{cx^2 + (d - a)x - b\},
\]
which is the required value of $RS' - R'S$; and there is no difficulty in obtaining the other two formulae,
\[
RX + S = (\lambda^2 - 1)(cx + d),\quad R'\lambda + S' = (\lambda - 1)(a + d)(Cx + D);
\]
the verification is thus completed.

\medskip
\noindent\textbf{(1)}\quad
To show how the formula was directly obtained, we have
\[
\frac{Ax + B}{Cx + D} = \frac{A}{C} - \frac{AD - BC}{C}\frac{1}{Cx + D}
= \frac{A}{C} + \rho x \quad \text{suppose};
\]
the equation then is
\[
\phi x - \phi x_1 = \frac{A}{C}(x - x_1) + (x - x_1)\rho x.
\]

Hence, if $x_1$, $x_2$, $x_3$, \dots\ denote the successive functions $\phi x$, $\phi^2 x$, $\phi^3 x$, \&c., we have
\begin{align*}
\phi x - \phi x_1 &= \frac{A}{C}(x - x_1) + (x - x_1)\rho x,\\
\phi x_1 - \phi x_2 &= \frac{A}{C}(x_1 - x_2) + (x_1 - x_2)\rho x_1,
\end{align*}
whence adding, and neglecting $\phi x_n$ and $x_n$, we have
\[
\phi x - \frac{A}{C}x = [(x - x_1)\rho x + (x_1 - x_2)\rho x_1 + (x_2 - x_3)\rho x_2 + \dots],
\]
where the term itself a given function of $x$ [therein regarding $x_1$, $x_2$, $x_3$, \dots\ as given functions of $x$], and it only remains to sum the series.

\medskip
\noindent\textbf{(2)}\quad
Starting from
\[
x_1 = \frac{ax + b}{cx + d},
\]
and writing
\[
\lambda = \frac{a^2 + d^2 + 2bc}{ad - bc},
\]
then the $n$th function is given by the formula
\[
x_n = \frac{(\lambda^{n+1} - 1)(ax + b) + (\lambda^n - \lambda)(-dx + b)}
{(\lambda^{n+1} - 1)c + (\lambda^n - \lambda)d}
= \frac{\lambda^n P + Q}{\lambda^n R + S},
\]
if $P = \lambda a + b$, $Q = -\lambda d + b$, and as before $R = \lambda c + d$, $S = -\lambda c - \lambda d$.

I stop to remark that $\lambda$ being real, if $\lambda > 1$ we have $\lambda^n$ very large, and $x_n = \rho$ which is independent of $n$; the value in question for $n$ very large is
\[
x_{n-1} = x_n = \frac{\lambda(ax + b) + (-dx + b)}{\lambda(cx + d) + (-cx - a)},
\]
which, observing that the equation in $\lambda$ may be written
\[
\frac{\lambda a - d}{c(\lambda + 1)} = \frac{b(\lambda + 1)}{\lambda d - a},
\]
is, in fact, independent of $x$, and calling each of these $= x$, we have $x_{n-1} = x_n$, or if the two equal values $= x$,
\[
x = \frac{ax + b}{cx + a},
\]
which is the same equation as is obtainable by the elimination of $\lambda$ from the equations
\[
x = \frac{\lambda a - d}{c(\lambda + 1)} = \frac{b(\lambda + 1)}{\lambda d - a}.
\]

The same result is obtained by taking $\lambda < 1$ and consequently $x_n = \frac{b}{d}$.

\medskip
\noindent\textbf{(3)}\quad
We find
\[
x_{n-1} - x_n = \frac{(\lambda^n P + Q)(\lambda^{n-1}R + S) - (\lambda^{n-1}P + Q)(\lambda^n R + S)}
{(\lambda^{n-1}R + S)(\lambda^n R + S)},
\]
where
\[
PS - QR = -(\lambda^2 - 1)(ad - bc) = -(\lambda^2 - 1)(a + d)\{cx^2 + (d - a)x - b\},
\]
and therefore
\[
x_{n-1} - x_n = \frac{(\lambda - 1)(\lambda^2 - 1)(a + d)\{cx^2 + (d - a)x - b\}\lambda^{n-1}}
{(\lambda^{n-1}R + S)(\lambda^n R + S)}.
\]

Also
\[
\rho x_{n-1} = \frac{AD - BC}{C}\frac{1}{Cx_{n-1} + D}
= \frac{AD - BC}{C}\frac{\lambda^{n-1}R + S}{\lambda^{n-1}W + Z},
\]
where
\[
\frac{W_1}{Z_1} = \frac{C(\lambda^{n-1}P + Q) + D(\lambda^{n-1}R + S)}{\dots},
\]
viz.
\[
W_1 = C(\lambda^{n-1}P + Q) + D(\lambda^{n-1}R + S),\quad Z_1 = C(-\lambda d - c)Q + D(\dots)
\]
[Further algebraic manipulations continue.]

We hence obtain
\[
\phi x - \frac{A}{C}x = \frac{(\lambda - 1)(\lambda^2 - 1)(a + d)\{cx^2 + (d - a)x - b\}}
{\lambda}\frac{(AD - BC)}{C(cD - dC)}
\sum_{n=1}^{\infty} \frac{(RS' - R'S)\lambda^n}{(\lambda^{n-1}R + S)(\lambda^n R + S)}.
\]

\medskip
\noindent\textbf{(4)}\quad
Now the before-mentioned integral formula gives
\[
\frac{1}{\lambda^n} = \frac{1}{\pi}\int_{-\infty}^{\infty} \frac{\sin(n\log\lambda + \log k)\,t}{\sinh\pi t}\,dt,
\]
and
\[
\frac{1}{\lambda'^n} = \frac{1}{\pi}\int_{-\infty}^{\infty} \frac{\sin(n\log\lambda + \log k')\,t}{\sinh\pi t}\,dt.
\]

Taking the difference, and then writing $k = -\frac{S'}{R'}$, $k' = -\frac{S}{R}$, we have under the integral sign
\[
\sin\bigl(n\log\lambda + \log(-\tfrac{S'}{R'})\bigr)t - \sin\bigl(n\log\lambda + \log(-\tfrac{S}{R})\bigr)t,
\]
which is
\[
= 2\sin\tfrac{1}{2}\bigl(\log\tfrac{RS'}{R'S}\bigr)t\,\cos\bigl(n\log\lambda + \tfrac{1}{2}\log\tfrac{RS'}{R'S}\bigr)t,
\]
which attending to the before-mentioned values of $\xi$, $\eta$, $\zeta$ is
\[
= 2\sin\xi t\,\cos(2n\xi - \zeta + \eta)t,
\]
and the formula thus is
\[
\frac{(RS' - R'S)\lambda^n}{(R\lambda^n + S)(R'\lambda^n + S')}
= \frac{2}{\pi}\int_{-\infty}^{\infty} \frac{\sin\xi t\,\cos(2n\xi - \zeta + \eta)t}{\sinh\pi t}\,dt.
\]

We have here
\[
\cos(2n\xi - \zeta + \eta)t = \cos 2n\xi t\,\cos(\eta - \zeta)t - \sin 2n\xi t\,\sin(\eta - \zeta)t,
\]
whence summing from $1$ to $\infty$, by means of the formulae
\[
\cos 2\xi t + \cos 4\xi t + \dots = -\tfrac{1}{2},\qquad
\sin 2\xi t + \sin 4\xi t + \dots = \tfrac{1}{2}\cot\xi t,
\]
(which series however are not convergent), the numerator under the integral sign becomes
\[
\sin\xi t\{-\cos(\eta - \zeta)t - \cot\xi t\,\sin(\eta - \zeta)t\},
\]
which is
\[
-\frac{\sin\eta t}{\sin\xi t},
\]
and the formula thus is
\[
\frac{(RS' - R'S)\lambda^n}{(R\lambda^n + S)(R'\lambda^n + S')}
= -\frac{2}{\pi}\int_{-\infty}^{\infty} \frac{\sin\eta t}{\sin\xi t\,\sinh\pi t}\,dt,
\]
and we therefore find
\[
\phi x = \frac{A}{C}x + \frac{\sqrt{(a-d)^2 + 4bc}\,(AD - BC)}{C(cD - dC)}
\int_{-\infty}^{\infty} \frac{\sin\xi t\,\sin\eta t\,dt}{\sin\xi t\,\sinh\pi t},
\]
which is the result in question.

The general solution is one particular solution $+$ the general solution of $\phi x = \frac{A}{C}x$; calling it $\phi x$, we have
\[
\phi x = \frac{A}{C}x + K\frac{Ax + B}{Cx + D},
\]
where $K$ is an arbitrary constant.

\section[Note on the function $\phi x = a^x(c-x)^{-\frac{1}{2}}\{c(c-x)-b^2\}^{-\frac{1}{2}}$]{687. Note on the function $\phi x = a^x(c-x)^{-\frac{1}{2}}\{c(c-x)-b^2\}^{-\frac{1}{2}}$.\footnote{From the \textit{Messenger of Mathematics}, vol.\ VII. (1878), pp.\ 113--114.}}

[307]

Starting from the general form
\[
\phi x = \frac{ax + b}{cx + d},
\]
we have
\[
x_n = \frac{(\lambda^{n+1} - 1)(ax + \beta) + (\lambda^n - \lambda)(-\delta x + \beta)}
{(\lambda^{n+1} - 1)(\gamma x + \delta) + (\lambda^n - \lambda)(\gamma x - \alpha)},
\]
where
\[
\lambda + \frac{1}{\lambda} = \frac{\alpha^2 + \delta^2 + 2\beta\gamma}{\alpha\delta - \beta\gamma}.
\]

For the function in question
\[
\phi x = a^2(c - x)\sqrt{c(c-x) - b^2}
\]
(form which presents itself in the problem of the distribution of electricity upon two spheres), the values of $\alpha$, $\beta$, $\gamma$, $\delta$ are
\[
\alpha = -a^2,\quad \beta = c^2 - b^2,\quad \gamma = -c,\quad \delta = c^2,
\]
the equation for $\lambda$ therefore is
\[
\lambda + \frac{1}{\lambda} = \frac{a^4 + (c^2 - b^2)^2 - 2a^2c^2}{-a^2c^2 + c^2(c^2 - b^2)},
\]
or, what is the same thing,
\[
\frac{(\lambda + 1)^2}{\lambda} = \frac{(a^2 + c^2 - b^2)^2}{c^2(c^2 - b^2)},
\]

[308]

Suppose that $a$, $b$, $c$ are the sides of a triangle the angles whereof are $A$, $B$, $C$; then
\[
c^2 = a^2 + b^2 - 2ab\cos C,\quad \text{or we have}\quad
\frac{c^2 - a^2 - b^2}{ab} = -2\cos C;
\]
or, writing this under the form
\[
\sqrt{\lambda} + \frac{1}{\sqrt{\lambda}} = 2\cos C,
\]
the value of $\lambda$ is at once seen to be $= e^{2iC}$; and it is interesting to obtain the expression of the $n$th function in terms of the sides and angles of the triangle.

The numerator and the denominator are
\[
\lambda^n P + Q,\quad \lambda^n R + S,
\]
where
\begin{align*}
P &= \lambda(\alpha x + \beta) + (-\delta x + \beta),\qquad
Q = -(\alpha x + \beta) - \lambda(-\delta x + \beta),\\
R &= \lambda(\gamma x + \delta) + (\gamma x - \alpha),\qquad
S = -(\gamma x + \delta) - \lambda(\gamma x - \alpha).
\end{align*}

Hence, writing the numerator and the denominator in the forms
\[
\lambda^n P + \lambda^{-n}Q,\quad \lambda^n R + \lambda^{-n}S,
\]
these are
\[
(P + Q)\cos nC + (P - Q)i\sin nC,\quad (R + S)\cos nC + (R - S)i\sin nC;
\]
viz.\ they are
\begin{align*}
&(\lambda - 1)(\alpha + \delta)x\cos nC + (\lambda + 1)\{(\alpha - \delta)x + 2\beta\}i\sin nC,\\
&(\lambda - 1)(\alpha + \delta)\cos nC + (\lambda + 1)\{2\gamma x - (\alpha - \delta)\}i\sin nC,
\end{align*}
or, observing that $\frac{\lambda - 1}{\lambda + 1} = i\tan C$ and removing the common factor $i(\lambda + 1)$, they may be written
\begin{align*}
&\tan C\,(\alpha + \delta)x\cos nC + \{ (\alpha - \delta)x + 2\beta \}\sin nC,\\
&\tan C\,(\alpha + \delta)\cos nC + \{ 2\gamma x - (\alpha - \delta) \}\sin nC.
\end{align*}

Substituting for $\alpha$, $\beta$, $\gamma$, $\delta$ their values, these are
\begin{align*}
&\tan C\{(c^2 - a^2 - b^2)x\cos nC\} + \{(b^2 - a^2 - c^2)x + 2a^2c\}\sin nC,\\
&\tan C\{(c^2 - a^2 - b^2)\cos nC\} + \{-2cx - (b^2 - a^2 - c^2)\}\sin nC,
\end{align*}
\begin{align*}
&= \tan C\{-ab\cos C\,x\cos nC\} + \{-ac\cos B\,x + a^2c\}\sin nC,\\
&= \tan C\{-ab\cos C\,x\cos nC\} + \{-cx + ac\cos B\}\sin nC,
\end{align*}
\begin{align*}
&= x\{-ab\sin C\cos nC - ac\cos B\sin nC\} + a^2c\sin nC,\\
&\quad -cx\sin nC + \{ac\cos B\sin nC - ab\sin C\cos nC\};
\end{align*}

[309]

or, writing herein $b\sin C = c\sin B$, these are
\begin{align*}
&-acx\{\sin B\cos nC + \cos B\sin nC\} + a^2c\sin nC,\\
&-cx\sin nC + ac\{\cos B\sin nC - \sin B\cos nC\},
\end{align*}
whence finally
\[
\phi^n x = \frac{a^2\sin nC - cx\sin(nC + B)}{a\sin(nC - B) - x\sin nC}.
\]

As a verification, writing $n = 1$, we have
\[
\phi x = \frac{a^2\sin C - cx\sin(C + B)}{a\sin(C - B) - x\sin C}
= \frac{a^2c - acx\frac{\sin A}{\sin C}}{a\sin(C - B) - x\sin C},
\]
or observing that
\[
\frac{ac}{\sin C}\{\sin A\sin(C - B)\} = c^2 - b^2
\]
(for this is $\sin A\sin(C - B) = \sin^2 C - \sin^2 B$), we have
\[
\phi x = \frac{c^2 - b^2 - cx}{\sqrt{c(c - x) - b^2}},
\]
as it should be.

If in the formula for $\phi^n x$ we write $x = 0$, we have
\[
\phi^n 0 = \frac{a^2\sin nC}{a\sin(nC - B)},
\]
a formula given in the Senate-House Problems, January 14, 1878: it was thus that I was led to investigate the general expression.

\section[Geometrical Considerations on a Solar Eclipse]{688. Geometrical Considerations on a Solar Eclipse.\footnote{From the \textit{Quarterly Journal of Pure and Applied Mathematics}, vol.\ XV. (1878), pp.\ 145--149.}}

[310]

I consider, from a geometrical point of view, the phenomena of a solar eclipse over the earth generally; attending at present only to the penumbral cone, the vertex of which I denote by $V$. It is convenient to regard the earth as fixed, and the sun and moon as moving each of them with its proper motion, and also with the diurnal motion. The penumbral cone meets the earth's surface in a curve which may be called the penumbral curve; viz.\ when the cone is not completely traversed by the earth's surface, (that is, when only some of the generating lines of the cone meet the earth's surface), this is a horse-shoe shaped oval; the penumbra is a region bounded by the two branches of the oval, or say these are separated, the one being the rising, the other the setting branch of the penumbral curve.

It is to be noticed that the whole of the oval may be visible, or the whole invisible, or only a portion may be visible; and moreover the character of the oval may change from visible to invisible, or \textit{vice vers\^a}, according as it does or does not intersect the horizon of any given place on the earth's surface.

\medskip
\noindent\textbf{1.}\quad
I attend in the first instance to the penumbral curve, and its relation to the horizon at any given place on the earth's surface. I say that the penumbral curve and the horizon have a common tangent $TT'$; viz.\ this is the line of intersection of the horizon-plane by a plane through the axis of the cone (that is, through $V$ and the centre of the moon) parallel to the horizon-plane; or, what is the same thing, it is the line of intersection of the horizon-plane by a plane through the centre of the earth parallel to the plane through the axis of the cone and the horizon-plane.

\medskip
\noindent\textbf{2.}\quad
Consider now any point $P$ on the horizon; through $P$ draw a line $PT$ in the direction $T$ of the common tangent; and let $\theta$ denote the angle which the generating line $VP$ of the cone makes with $PT$; then the condition in order that the generating line may meet the earth's surface is that $\cos\theta$ may be between the limits $\pm\cos\theta_0$, where $\theta_0$ is a given angle; and if $\cos\theta$ is within these limits, then the generating line does meet the earth's surface, or does not meet it, according as $P$ lies on the one side or the other of the tangent line $TT'$.

\medskip
\noindent\textbf{3.}\quad
Hence, taking $P$ a point on the horizon in the direction $T$ of the common tangent, and drawing lines $PQ$ in directions making with $PT$ angles between the limits $\pm\theta_0$, the generating lines $VPQ$ will meet the earth's surface; and we thus see that the points $Q$ form a region bounded by the conic which is the intersection of the earth's surface by the plane through $V$ touching the horizon-plane along the line $TT'$. But if the angle $PTQ$ is outside the limits, then the generating line does not meet the earth's surface, and the corresponding point $Q$ is on the sky.

\medskip
\noindent\textbf{4.}\quad
The foregoing completely determines the visibility or invisibility of any given point of the penumbral curve, and it is easy to see how the character of the penumbral curve as visible or invisible changes as the position of the place on the earth's surface varies. For as the place moves on the earth's surface, the tangent line $TT'$ moves in the plane of the penumbral curve, and the character of any given point changes as the tangent line passes over it; viz.\ the point changes from visible to invisible or \textit{vice vers\^a}, as the tangent line passes over it in such wise that the angle $PTQ$ passes from within to without the limits, or \textit{vice vers\^a}.

\medskip
\noindent\textbf{5.}\quad
The vertex $V$ (considered as a point in the heavens) is rising, for a point on the one side of the horizon-envelope, and setting, for a point on the other of them; and the two points $K_1$, $K_2$ are the northern and southern limits respectively. There is, as before, no passage through a point $W$ or $W'$, the curve in question thus retains throughout the same character; and by consideration of the two terminal points it at once appears that the two portions $K_1W$, $K_2W'$ (or $K_1W'$, $K_2W$ as the case may be) are the northern and southern limits respectively.

\section[On the Geometrical Representation of Imaginary Variables by a Real Correspondence of Two Planes]{689. On the Geometrical Representation of Imaginary Variables by a Real Correspondence of Two Planes.\footnote{From the \textit{Proceedings of the London Mathematical Society}, vol.\ IX. (1878), pp.\ 31--39. Read December 13, 1877.}}

[316]

In my recently published paper, ``Geometrical Illustration of a Theorem relating to an Irrational Function of an Imaginary Variable,'' \textit{Proceedings of the London Mathematical Society}, t.\ VIII. (1877), pp.\ 212--214, [627], I remark as follows:---``If we have $v$ a function of $u$ determined by an equation $f(u, v) = 0$, then to any given imaginary value $x + iy$ of $u$ there belong two or more values, in general imaginary, and for the complete understanding of the relation between the two imaginary variables we require to know the series of values $x' + iy'$ which correspond to a given series of values $x + iy$ of $u$; or, what is the same thing, we require to have a geometrical representation of the one series of points by means of the other series of points.'' I propose in the present paper to develop this idea.

\medskip
\noindent\textbf{1.}\quad
I consider first the general case of a $(m, n)$ correspondence between two planes; viz.\ to any given point $P$ in the first plane there correspond $n$ points $P'$ in the second plane; and to any given point $P'$ in the second plane there correspond $m$ points $P$ in the first plane. The correspondence is determined by an equation
\[
\Phi(x, y; x', y') = 0,
\]
where $\Phi$ is of the degree $m$ in $(x, y)$ and of the degree $n$ in $(x', y')$.

\medskip
\noindent\textbf{2.}\quad
To a given point $P$ in the first plane there correspond $n$ points $P'$ in the second plane; and these may be distinct or some of them may be united. In the general case they are distinct; but if the point $P$ is on a certain curve, the branch-curve, then two or more of the corresponding points $P'$ unite together. The branch-curve is a curve on the first plane; and in like manner there is a branch-curve on the second plane.

\medskip
\noindent\textbf{3.}\quad
If the point $P$ describes on the first plane a closed curve, the $n$ corresponding points $P'$ describe on the second plane $n$ closed curves; but these may be such that the series of values is not restored, viz.\ the point $P$ may return to its original position, but the $n$ points $P'$ may have been permuted among themselves. To avoid this, we introduce the notion of barriers; viz.\ we draw on the first plane a system of barriers, such that the point $P$ cannot pass from one side to the other of any barrier; and in like manner we draw on the second plane a system of barriers. The barriers are so drawn that when $P$ returns to its original position, each of the $n$ points $P'$ also returns to its original position.

\medskip
\noindent\textbf{4.}\quad
The branch-curve on the first plane consists of a system of points $V$ and of barriers; the point $P$ cannot pass through a point $V$, and it cannot cross a barrier. In like manner the branch-curve on the second plane consists of a system of points $V'$ and of barriers. And we have on the first plane a system of counter-barriers corresponding to the barriers on the second plane; and on the second plane a system of counter-barriers corresponding to the barriers on the first plane.

\medskip
\noindent\textbf{5.}\quad
If there were only a single barrier $OV_{12}$, then we might have through $P$ a closed curve cutting $OV_{12}$ once only, and including within it the two portions of a bifid curve.

\medskip
\noindent\textbf{6.}\quad
[Further development of the theory of branch points, barriers, and the correspondence between the two planes.]

\medskip
\noindent\textbf{7.}\quad
The question may be considered in itself, without any reference to such origin.

\medskip
\noindent\textbf{8.}\quad
[Discussion of the analytical representation.]

\medskip
\noindent\textbf{9.}\quad
Everything is of course symmetrical as regards the two planes; we have therefore, in the second plane, a system of points $V'$ and of barriers, and in the first plane a system of points $(W)$ and of counter-barriers. To a given point $P'$ in the second plane there correspond $m$ points $P$ in the first plane; and we can (the determination depending on the system of barriers in the second plane) assign to the $m$ points suffixes, thereby distinguishing them as the corresponding points $P_1$, $P_2$, \dots, $P_m$. And we may imagine the second plane as consisting of $m$ superimposed planes or sheets, say the sheets $1$, $2$, $3$, \dots, $m$; the general theorem then is that to a point $P$ or $P'$ in either plane, considered as a point $P_a$ or $P'_a$ in the sheet $a$ or $a'$, there corresponds in the other plane one and only one point $P'_{a'}$ or $P_{a'}$; and that the first-mentioned point in either plane moving continuously in any manner (subject to the proper change of sheet), the corresponding point in the other plane will also move continuously, and will return to its original position and sheet, upon the first-mentioned point returning to its original position and sheet.

This is, in fact, Riemann's theory, only instead of the points $P'$ we must speak of the values $x' + iy'$ of the irrational function of $x + iy$.

\medskip
\noindent\textbf{10.}\quad
In all that precedes it has been assumed that, to a branch-point $V$, there correspond two united points represented by $(W)$ and $n - 2$ distinct points $W'$; the cases of a point $(W)$ composed of three or more united points, or of the points $W'$ uniting themselves in sets in any other manner, would give rise to further specialities.

\section[On the Theory of Groups]{690. On the Theory of Groups.\footnote{From the \textit{Proceedings of the London Mathematical Society}, t.\ IX. (1878), pp.\ 126--133. Read May 9, 1878.}}

[325]

I recapitulate the general theory so far as is necessary in order to render intelligible the quasi-geometrical representation of it which will be given.

\medskip
\noindent\textbf{1.}\quad
Let $\alpha$, $\beta$, \dots\ be functional symbols each operating upon one and the same number of letters, and producing as its result the same number of functions of these letters. For instance,
\[
\alpha(x, y, z) = (X, Y, Z),
\]
where the capitals denote each of them a given function of $(x, y, z)$.

Such symbols are susceptible of repetition and combination; thus
\[
\alpha^2(x, y, z) = \alpha(X, Y, Z),\quad \text{or}\quad
\beta\alpha(x, y, z) = \beta(X, Y, Z),
\]
in each case equal to three given functions of $(x, y, z)$; and similarly for $\alpha^3$, $\alpha^2\beta$, \dots, $\alpha\beta\alpha$, \&c.

\medskip
\noindent\textbf{2.}\quad
The functional symbols may be of any form whatever, but I consider in particular those which arise from the substitutions of a group of letters; and using in the first instance a set of non-specialized functional symbols, I establish the notion of a group.

A set of symbols
\[
1,\ \alpha,\ \beta,\ \dots
\]
(such that the number of symbols is finite), forming a group, if they are such that the product of any two of them (in either order) is a symbol of the set, and the inverse of each symbol is also a symbol of the set.

\medskip
\noindent\textbf{3.}\quad
The number of symbols is called the \textit{order} of the group.

A group may be represented by means of the substitutions of a set of letters; and conversely, any group of substitutions gives rise to a group in the foregoing sense.

\medskip
\noindent\textbf{4.}\quad
To explain the hemihedron, certain configurations by the diagram, as presently appearing, may (instead of any other equivalent representation) be employed.

\noindent\textbf{5.}\quad
[The paper discusses colorings of polygons associated with the group.]

The polygons may have different colours; the polygons being assigned colors according to group-theoretic principles. The colors of the polygons correspond to the different operations of the group, and the adjacency relations of the colored polygons reflect the group structure.

\section[Note on Mr Monro's Paper ``On Flexure of Spaces'']{691. Note on Mr Monro's Paper ``On Flexure of Spaces''.\footnote{From the \textit{Proceedings of the London Mathematical Society}, vol.\ IX. (1878), pp.\ 171, 172. Read June 13, 1878.}}

[331]

Consider an element of surface, surrounding a point $P$; the flexure of the element may be interfered with by the continuity round $P$, and on this account it is proper to regard the element as cut or slit along a radius drawn from $P$ to the periphery of the element. This being understood, we have the well-known theorem that, considering in the neighbourhood of the origin elements of the surfaces
\[
z = \tfrac{1}{2}(ax^2 + 2hxy + by^2),\qquad
z' = \tfrac{1}{2}(a'x'^2 + 2h'x'y' + b'y'^2),
\]
these will be applicable to be the one on the other, provided only $ab - h^2 = a'b' - h'^2$.

But Mr Monro's paper considers the more general problem of the flexure of spaces, and establishes certain differential equations which must be satisfied. The equation will be satisfied identically as regards $dx$, $dy$ if the appropriate conditions on the coefficients are met.

\medskip
\noindent\textbf{[The note continues with remarks on the differential equations of flexure.]}

The conditions for the flexure may be expressed by saying that the element at any point $P$ must be applicable upon the element at the corresponding point $P'$, or that the two elements must have the same measure of curvature at corresponding points.
