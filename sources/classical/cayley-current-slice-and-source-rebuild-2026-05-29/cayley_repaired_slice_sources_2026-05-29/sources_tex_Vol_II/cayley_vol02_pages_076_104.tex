\end{center}

\noindent\emph{[Continuation of \S\,3, beginning at book p.~60.]}

\bigskip

\noindent\emph{[The opening of \S\,3, with the surface $2yz + 2zx + 2xy + w^{2} = 0$ and the three determinators
$-\alpha x + \tfrac{1}{2\alpha}y + \tfrac{1}{2\alpha}z + w = 0$, $\tfrac{1}{2\beta}x - \beta y + \tfrac{1}{2\beta}z + w = 0$,
$\tfrac{1}{2\gamma}x + \tfrac{1}{2\gamma}y - \gamma z + w = 0$, was given in the preceding slice.
We resume at p.~60, where the tactors are to be found.]}

\bigskip

The values of $a$, $b$, $c$ remaining to be determined. Now before fixing the values of these quantities, we may find three sections each of them touching a determinator at a point of intersection with the section which corresponds to it of the sections
\[
cy - bz = 0,\qquad az - cx = 0,\qquad bx - ay = 0,
\]
and touching the other two of the last-mentioned sections; and when $a$, $b$, $c$ have their proper values the sections so found are the \emph{tactors}. For, let $\lambda x + \mu y + \nu z + \rho w = 0$ be the equation of a section touching the determinator $-\alpha x + \tfrac{1}{2\alpha}y + \tfrac{1}{2\alpha}z + w = 0$, and the two sections $bx - ay = 0$, $az - cx = 0$; and suppose
\[
\Delta^{2} \;=\; \lambda^{2} + \mu^{2} + \nu^{2} - 2\mu\nu - 2\nu\lambda - 2\lambda\mu - 2\rho^{2}\,;
\]
the conditions of contact with the sections $bx - ay = 0$, $az - cx = 0$ are found to be
\begin{align*}
(b + a)\,\Delta &\;=\; (b + a)\lambda - (b + a)\mu - (b - a)\nu,\\
(c + a)\,\Delta &\;=\; (c + a)\lambda - (c - a)\mu - (c + a)\nu,
\end{align*}
values, however, which suppose a correspondence in the signs of the radicals. Thence $(b + a)\mu = (c + a)\nu$; or since the ratios only of the quantities $\lambda$, $\mu$, $\nu$, $\rho$ are material, $\mu = c + a$, $\nu = b + a$, and therefore
\[
\Delta^{2} \;=\; \lambda^{2} - 2\,(2a + b + c)\,\lambda + (b - c)^{2} - 2\rho^{2} \;=\; (\lambda - b - c)^{2},
\]
or
\[
\rho^{2} \;=\; -2\,(a\lambda + bc).
\]
Hence the equation to a section touching $bx - ay = 0$, $az - cx = 0$ is
\[
\lambda x + (c + a)\,y + (b + a)\,z + \sqrt{-2\,(a\lambda + bc)}\;w \;=\; 0,
\]
and to express that this touches the determinator in question, we have
\[
\pm\alpha\,(\lambda - b - c) \;=\; -\alpha\lambda - \tfrac{1}{\alpha}(2a + b + c) + 2\sqrt{-2\,(a\lambda + bc)},
\]
and selecting the upper sign,
\[
-\lambda - 2a\alpha \;=\; -2\sqrt{-2\,(a\lambda + bc)}\,;
\]
whence
\[
\lambda \;=\; -2a\,(a\alpha - \sqrt{-2bc}),\qquad \sqrt{-2\,(a\lambda + bc)} \;=\; (2a\alpha - \sqrt{-2bc}).
\]
Therefore the section touching the determinator and the sections $bx - ay = 0$, $az - cx = 0$ is
\[
-2a\,(a\alpha - \sqrt{-2bc})\,x + (c + a)\,y + (b + a)\,z + (2a\alpha - \sqrt{-2bc})\,w \;=\; 0\,;
\]
and at the point of contact with the determinator
\[
2yz + 2zx + 2xy + w^{2} \;=\; 0.
\]

\bigskip

\noindent\emph{[Book p.~61.]} Eliminating $w$ between the first and second equations, and between the second and third equations,
\[
\sqrt{-2bc}\,\Bigl(ax + \tfrac{1}{2\alpha}y + \tfrac{1}{2\alpha}z\Bigr) + cy + bz \;=\; 0,
\]
and from these equations $(cy - bz) = 0$, or the point of contact lies in the section $cy - bz = 0$. It follows that the equations of the \emph{tactors} are
\begin{align*}
-2a\,(a\alpha - \sqrt{-2bc})\,x + (c + a)\,y + (b + a)\,z + (2a\alpha - \sqrt{-2bc})\,w &\;=\; 0,\\
(c + b)\,x - 2\beta\,(b\beta - \sqrt{-2ca})\,y + (a + b)\,z + (2b\beta - \sqrt{-2ca})\,w &\;=\; 0,\\
(b + c)\,x + (a + c)\,y - 2\gamma\,(c\gamma - \sqrt{-2ab})\,z + (2c\gamma - \sqrt{-2ab})\,w &\;=\; 0,
\end{align*}
where $a$, $b$, $c$ still remain to be determined.

\medskip

Now the separators pass through the point of intersection of the determinators; the equations of these give for the point in question,
\begin{align*}
x : y : z : w &\;=\; (2\beta\gamma + 1)(-\alpha + \beta + \gamma + 2\alpha\beta\gamma)\\
              &\quad : (2\gamma\alpha + 1)( \alpha - \beta + \gamma + 2\alpha\beta\gamma)\\
              &\quad : (2\alpha\beta + 1)( \alpha + \beta - \gamma + 2\alpha\beta\gamma)\\
              &\quad : -1 + \alpha^{2} + \beta^{2} + \gamma^{2} + 4\alpha^{2}\beta^{2}\gamma^{2}\,;
\end{align*}
and the values of $a$, $b$, $c$ are therefore
\begin{align*}
a : b : c \;=\; (2\beta\gamma + 1)(-\alpha + \beta + \gamma + 2\alpha\beta\gamma)\\
            : (2\gamma\alpha + 1)( \alpha - \beta + \gamma + 2\alpha\beta\gamma)\\
            : (2\alpha\beta + 1)( \alpha + \beta - \gamma + 2\alpha\beta\gamma),
\end{align*}
which are to be substituted for $a$, $b$, $c$ in the equations of the separators and tactors respectively.

\medskip

Now proceeding to find the \emph{bisectors}, let $\lambda x + \mu y + \nu z + \rho w = 0$ be the equation of a section touching the determinators, and suppose as before $\Delta^{2} = \lambda^{2} + \mu^{2} + \nu^{2} - 2\mu\nu - 2\nu\lambda - 2\lambda\mu - 2\rho^{2}$; the conditions of contact are
\begin{align*}
\pm\beta\,\Delta &\;=\; \beta\lambda - (\beta + \tfrac{1}{2\beta})\mu + \beta\nu - 2\rho,\\
\mp\gamma\,\Delta &\;=\; \gamma\lambda + \gamma\mu - (\gamma + \tfrac{1}{2\gamma})\nu - 2\rho,
\end{align*}

\noindent\emph{[Book p.~62.]} where it is necessary, for the present purpose, to give opposite signs to the radicals. For if the radicals had the same sign, it would follow that
\[
\tfrac{1}{\beta}\Bigl[\beta\lambda - (\beta + \tfrac{1}{2\beta})\mu + \beta\nu - 2\rho\Bigr] - \tfrac{1}{\gamma}\Bigl[\gamma\lambda + \gamma\mu - (\gamma + \tfrac{1}{2\gamma})\nu - 2\rho\Bigr] \;=\; 0,
\]
hence the section $\lambda x + \mu y + \nu z + \rho w = 0$ would pass through the point
\[
x : y : z : w \;=\; 0 : \tfrac{1}{2\beta^{2}} : -\tfrac{1}{2\gamma^{2}} : -\tfrac{1}{\beta} + \tfrac{1}{\gamma}\,,
\]
or the section would be a tangent section of the two determinators of the same class with the resultor $x = 0$, which ought not to be the case. The proper formula is
\[
\tfrac{1}{\beta}\Bigl[\beta\lambda - (\beta + \tfrac{1}{2\beta})\mu + \beta\nu - 2\rho\Bigr] + \tfrac{1}{\gamma}\Bigl[\gamma\lambda + \gamma\mu - (\gamma + \tfrac{1}{2\gamma})\nu - 2\rho\Bigr] \;=\; 0,
\]
and this equation being satisfied, the section
\[
\lambda x + \mu y + \nu z + \rho w \;=\; 0
\]
passes through a point
\[
x : y : z : w \;=\; -\tfrac{1}{\beta^{2}} - \tfrac{1}{\gamma^{2}} : \tfrac{1}{\gamma^{2}} : \tfrac{1}{\beta^{2}} : -\tfrac{2}{\beta} - \tfrac{2}{\gamma}\,.
\]
The bisector passes through this point and the line of intersection of the determinators; its equation is
\[
\tfrac{1}{\beta}\Bigl(\tfrac{1}{2\beta}x - \beta y + \tfrac{1}{2\beta}z + w\Bigr) - \tfrac{1}{\gamma}\Bigl(\tfrac{1}{2\gamma}x + \tfrac{1}{2\gamma}y - \gamma z + w\Bigr) \;=\; 0,
\]
or, reducing and completing the system, the equations of the bisectors are
\begin{align*}
\Bigl(\tfrac{1}{2\beta^{2}} - \tfrac{1}{2\gamma^{2}}\Bigr)x \;+\; \Bigl(\gamma + \tfrac{1}{2\beta^{2}}\Bigr)y \;+\; \Bigl(\tfrac{1}{2\gamma^{2}} - \beta\Bigr)z \;+\; \Bigl(\tfrac{1}{\beta} - \tfrac{1}{\gamma}\Bigr)w &\;=\; 0,\\
\Bigl(\tfrac{1}{2\gamma^{2}} - \alpha\Bigr)x \;+\; \Bigl(\tfrac{1}{2\gamma^{2}} - \tfrac{1}{2\alpha^{2}}\Bigr)y \;+\; \Bigl(\tfrac{1}{2\alpha^{2}} - \gamma\Bigr)z \;+\; \Bigl(\tfrac{1}{\gamma} - \tfrac{1}{\alpha}\Bigr)w &\;=\; 0,\\
\Bigl(\alpha - \tfrac{1}{2\beta^{2}}\Bigr)x \;+\; \Bigl(\tfrac{1}{2\alpha^{2}} - \beta\Bigr)y \;+\; \Bigl(\tfrac{1}{2\alpha^{2}} - \tfrac{1}{2\beta^{2}}\Bigr)z \;+\; \Bigl(\tfrac{1}{\alpha} - \tfrac{1}{\beta}\Bigr)w &\;=\; 0.
\end{align*}

In order to verify the geometrical construction, it only remains to show that each bisector touches two tactors. Consider the bisector and tactor
\[
-\Bigl(1 + \tfrac{c}{2\beta^{2}}\Bigr)x + \Bigl(1 + \tfrac{a}{2\gamma^{2}}\Bigr)y + \Bigl(\tfrac{a}{2\beta^{2}} - \tfrac{b}{2\gamma^{2}}\Bigr)z - \tfrac{1}{a}\Bigl(\tfrac{1}{\gamma} - \tfrac{1}{\beta}\Bigr)w \;=\; 0,
\]
\[
-2a\,(a\alpha - \sqrt{-2bc})\,x + (c + a)\,y + (b + a)\,z + (2a\alpha - \sqrt{-2bc})\,w \;=\; 0;
\]
and represent these for a moment by
\[
\lambda x + \mu y + \nu z + \rho w \;=\; 0,\qquad \lambda' x + \mu' y + \nu' z + \rho' w \;=\; 0\,;
\]

\bigskip

\noindent\emph{[Book p.~63.]} if $\Delta$ be the same as before, and $\Delta'$ the like function of $\lambda'$, $\mu'$, $\nu'$, $\rho'$; also if
\[
\Phi \;=\; \lambda\lambda' + \mu\mu' + \nu\nu' - (\mu\nu' + \mu'\nu) - (\nu\lambda' + \nu'\lambda) - (\lambda\mu' + \lambda'\mu) - 2\rho\rho',
\]
then
\[
\Delta^{2} \;=\; \Bigl(2 + \tfrac{1}{a\beta}\Bigr)^{2},
\]
\[
\Delta'^{2} \;=\; (2a\alpha^{2} - 2\alpha\sqrt{-2bc} + b + c)^{2},
\]
\[
\Phi \;=\; a\alpha^{2}\Bigl(2 + \tfrac{1}{a\beta}\Bigr)^{2} - 2\alpha\sqrt{-2bc}\Bigl(2 + \tfrac{1}{a\beta}\Bigr) + c\Bigl(2 + \tfrac{1}{a\beta}\Bigr),
\]
and the condition of contact $\Delta\Delta' = \Phi$ (taking the proper sign for the radicals) becomes
\[
\Bigl(2 + \tfrac{1}{a\beta}\Bigr)\,(2a\alpha^{2} - 2\alpha\sqrt{-2bc} + b + c) \;=\; a\alpha^{2}\Bigl(2 + \tfrac{1}{a\beta}\Bigr) - 2\alpha\sqrt{-2bc}\Bigl(2 + \tfrac{1}{a\beta}\Bigr) + c\Bigl(2 + \tfrac{1}{a\beta}\Bigr),
\]
or reducing,
\[
a\alpha - b\beta + c\,\frac{\alpha - \beta}{2\alpha\beta + 1} \;=\; 0,
\]
an equation which is evidently not altered by the interchange of $a$, $\alpha$ and $b$, $\beta$. The conditions, in order that each bisector may touch two tactors, reduce themselves to the three equations,
\begin{align*}
a\alpha - b\beta + c\,\frac{\alpha - \beta}{2\alpha\beta + 1} &\;=\; 0,\\
b\beta - c\gamma + a\,\frac{\beta - \gamma}{2\beta\gamma + 1} &\;=\; 0,\\
c\gamma - a\alpha + b\,\frac{\gamma - \alpha}{2\gamma\alpha + 1} &\;=\; 0,
\end{align*}
which are satisfied by the values above found for the quantities $a$, $b$, $c$. The possibility and truth of the geometrical construction are thus demonstrated.

\bigskip

\subsection*{\S\,4.}

Let it be in the first instance proposed to find the equation of a section touching all or any of the sections $x = 0$, $y = 0$, $z = 0$ of the surface of the second order,
\[
a x^{2} + b y^{2} + c z^{2} + 2 f y z + 2 g z x + 2 h x y + p w^{2} \;=\; 0.
\]
Any section whatever of this surface may be written in the form
\[
\sqrt{(a\lambda^{2} + b\mu^{2} + c\nu^{2} + 2f\mu\nu + 2g\nu\lambda + 2h\lambda\mu - K)}\;\rho\,/\sqrt{-p}\cdot w
\]
\[
+ (a\lambda + h\mu + g\nu)\,x + (h\lambda + b\mu + f\nu)\,y + (g\lambda + f\mu + c\nu)\,z \;=\; 0,
\]
where
\[
\nabla^{2} \;=\; a\lambda^{2} + b\mu^{2} + c\nu^{2} + 2f\mu\nu + 2g\nu\lambda + 2h\lambda\mu - K,
\]

\bigskip

\noindent\emph{[Book p.~64.]} and $\lambda$, $\mu$, $\nu$ are indeterminate. And considering any other section represented by a like equation,
\[
\sqrt{(a\lambda'^{2} + b\mu'^{2} + c\nu'^{2} + 2f\mu'\nu' + 2g\nu'\lambda' + 2h\lambda'\mu' - K)}\;\rho'\,/\sqrt{-p}\cdot w
\]
\[
+ (a\lambda' + h\mu' + g\nu')\,x + (h\lambda' + b\mu' + f\nu')\,y + (g\lambda' + f\mu' + c\nu')\,z \;=\; 0,
\]
where
\[
\nabla'^{2} \;=\; a\lambda'^{2} + b\mu'^{2} + c\nu'^{2} + 2f\mu'\nu' + 2g\nu'\lambda' + 2h\lambda'\mu' - K,
\]
it may be shown, by means of the lemma previously given, that the condition of contact is
\begin{align*}
a\lambda\lambda' + b\mu\mu' + c\nu\nu' + f(\mu\nu' + \mu'\nu) + g(\nu\lambda' + \nu'\lambda) + h(\lambda\mu' + \lambda'\mu) + K\,\tfrac{\rho\rho'}{p}
\;=\; \nabla\nabla'.
\end{align*}

Suppose that $\lambda'$, $\mu'$, $\nu'$ satisfy the equations
\begin{align*}
a\lambda' + h\mu' + g\nu' &\;=\; 0,\\
h\lambda' + b\mu' + f\nu' &\;=\; 0,\\
g\lambda' + f\mu' + c\nu' &\;=\; 0,
\end{align*}
so that the last-mentioned section becomes $x = 0$; and observing that the first of the above equations may be transformed into
\[
a\lambda'^{2} + b\mu'^{2} + c\nu'^{2} \;=\; \frac{K}{a},
\]
it is easy to obtain $\lambda' = \sqrt{\fA}$, $\mu' = \tfrac{\fH}{\sqrt{\fA}}$, $\nu' = \tfrac{\fG}{\sqrt{\fA}}$. The condition of contact thus becomes
\[
\frac{K}{\sqrt{\fA}}\,\rho^{2} + K \;=\; 0\,;
\]
and taking the under sign, $\lambda = \sqrt{\fA}$, so that if in the above-written equation we establish all or any of the equations $\lambda = \sqrt{\fA}$, $\mu = \sqrt{\fB}$, $\nu = \sqrt{\fC}$, we have the equation of a section touching all or the corresponding sections of the sections
\[
x = 0,\qquad y = 0,\qquad z = 0.
\]

In particular we have for a solution of the problem of tactions, the following equation of the section touching $x = 0$, $y = 0$, $z = 0$:
\[
(a\sqrt{\fA} + h\sqrt{\fB} + g\sqrt{\fC})\,x + (h\sqrt{\fA} + b\sqrt{\fB} + f\sqrt{\fC})\,y + (g\sqrt{\fA} + f\sqrt{\fB} + c\sqrt{\fC})\,z
\]
\[
+\;\frac{\rho}{\sqrt{-p}}\sqrt{2\,(\sqrt{\fB\fC} - \fF)(\sqrt{\fC\fA} - \fG)(\sqrt{\fA\fB} - \fH)} \;\cdot w \;=\; 0.
\]

Anticipating the use of a notation the value of which will subsequently appear, or putting

\bigskip

\noindent\emph{[Book p.~65.]}
\[
K^{2} \;=\; -\mathrm{f}^{4} - \mathrm{g}^{4} - \mathrm{h}^{4} + 2\mathrm{g}^{2}\mathrm{h}^{2} + 2\mathrm{h}^{2}\mathrm{f}^{2} + 2\mathrm{f}^{2}\mathrm{g}^{2} - \frac{4\mathrm{f}^{2}\mathrm{g}^{2}\mathrm{h}^{2}}{J^{2}},
\]
the equation of the section in question is
\[
\frac{\mathrm{f}^{2}}{\sqrt{\fA}}\,(-\mathrm{f}^{2} + \mathrm{g}^{2} + \mathrm{h}^{2})\,x + \frac{\mathrm{g}^{2}}{\sqrt{\fB}}\,(\mathrm{f}^{2} - \mathrm{g}^{2} + \mathrm{h}^{2})\,y + \frac{\mathrm{h}^{2}}{\sqrt{\fC}}\,(\mathrm{f}^{2} + \mathrm{g}^{2} - \mathrm{h}^{2})\,z + \frac{4\mathrm{f}^{2}\mathrm{g}^{2}\mathrm{h}^{2}}{J^{2}}\,\frac{\rho\sqrt{-pK}}{\sqrt{\fA\fB\fC}}\,w \;=\; 0.
\]

I proceed to investigate a transformation of the equation for the section with an indeterminate parameter $\lambda$, which touches the two sections $y = 0$, $z = 0$. We have
\[
a\nabla^{2} \;=\; (a\lambda + h\mu + g\nu)^{2} + (b\mu^{2} + c\nu^{2} - 2f\mu\nu) - \fB - K,
\]
or, putting for $\mu^{2}$ and $\nu^{2}$ their values $\fB$, $\fC$ in the second term,
\[
a\nabla^{2} \;=\; (a\lambda + h\mu + g\nu)^{2} + (\sqrt{\fB\fC} - \fF)^{2}\,;
\]
and introducing instead of $\lambda$ an indeterminate quantity $X$, such that
\[
a\lambda + h\mu + g\nu \;=\; (\sqrt{\fB\fC} - \fF)\,X,
\]
we have, also introducing throughout $X$ instead of $\lambda$, and completing the substitution of $\sqrt{\fB}$, $\sqrt{\fC}$ for $\mu$, $\nu$, the equation of the section touching $y = 0$, $z = 0$, becomes
\[
(ax + hy + gz)\,X + y\sqrt{\fC} + z\sqrt{\fB} + w\sqrt{-ap}\sqrt{1 + X^{2}} \;=\; 0.
\]

It may be remarked here in passing, that this is a very convenient form for the demonstration of the theorem: ``If two sections of a surface of the second order touch each other, and are also tangent sections (of the same class) to two fixed sections, then considering the planes through the axis of the fixed sections and the poles of the tangent sections, and also the tangent planes through this axis, the anharmonic ratio of the four planes is independent of the position of the moveable tangent sections;'' where by the axis of the fixed sections is to be understood the line joining their poles.

The sections touching $z = 0$, $x = 0$ and $x = 0$, $y = 0$ are of course
\begin{align*}
z\sqrt{\fA} + x\sqrt{\fC} + (hx + by + fz)\,Y + w\sqrt{-bp}\sqrt{1 + Y^{2}} &\;=\; 0,\\
x\sqrt{\fB} + y\sqrt{\fA} + (gx + fy + cz)\,Z + w\sqrt{-cp}\sqrt{1 + Z^{2}} &\;=\; 0.
\end{align*}

The conditions of contact of the sections represented by the above-written equations would be perhaps most simply obtained directly from the lemma, but it is proper to deduce it from the formula for contact used in the present memoir. If for shortness
\[
\Phi(\pm) \;=\; a\lambda'\lambda'' + b\mu'\mu'' + c\nu'\nu'' + f(\mu'\nu'' + \mu''\nu') + g(\nu'\lambda'' + \nu''\lambda') + h(\lambda'\mu'' + \lambda''\mu') \pm K\,\tfrac{\rho'\rho''}{p}\,,
\]

\bigskip

\noindent\emph{[Book p.~66.]} where the symbol $\Phi(\pm)$ is used in order to mark the essentially different character of the results corresponding to the different values of the ambiguous sign, then
\begin{align*}
bc\,\Phi(-) &\;=\; f(h\lambda' + b\mu' + f\nu')(g\lambda'' + f\mu'' + c\nu'')\\
            &\quad + (\sqrt{\fA\fC} - \fG)(g\lambda'' + f\mu'' + c\nu'')\\
            &\quad + (\sqrt{\fA\fB} - \fH)(h\lambda'' + b\mu'' + f\nu'')\\
            &\quad + f(-a\sqrt{\fB\fC} + h\sqrt{\fC\fA} + g\sqrt{\fA\fB} - aF - (\fG\fH - aF))\\
            &\;=\; \cdots \\
            &\;=\; (\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)\{f\,YZ + \sqrt{\fA}(Y + Z) + f\}.
\end{align*}

That is, $bc\,\Phi(-) = (\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)\{f\,YZ + \sqrt{\fA}(Y + Z) + f\}$.

What, however, is really required\footnote{It may be shown without difficulty that the ($-$) sign would imply that the sections touching $z = 0$, $x = 0$, and $x = 0$, $y = 0$ were sections touching $x = 0$ at the same point. By taking the ($-$) sign in each equation we should have the solution of the problem ``to determine three sections of a surface of the second order, the two sections of each pair touching one of three given sections at the same point,'' which is not without interest; the solution may be completed without any difficulty.}, is the value of $\Phi(+)$; to find this, we have
\[
bc\,\Phi(+) \;=\; bc\,\Phi(-) + 2bcK
\]
\[
\;=\; (\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)\{f\,YZ + \sqrt{\fA}(Y + Z) + f\} + 2bcK - 2f(\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH),
\]
the second line of which is
\[
2\,(\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)\,\Bigl\{\frac{bcK - f(\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)}{(\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)}\Bigr\}
\;=\; 2\,(\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)\,\sqrt{\fA}\,\theta,
\]

\bigskip

\noindent\emph{[Book p.~67.]} where
\[
\theta \;=\; \frac{1}{K}\,\bigl(\sqrt{\fA\fB\fC} + \fF\sqrt{\fA} + \fG\sqrt{\fB} + \fH\sqrt{\fC}\bigr),
\]
and consequently
\[
bc\,\Phi(+) \;=\; (\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)\bigl[f\,YZ + \sqrt{\fA}\,(Y + Z) + f + 2\theta\sqrt{\fA}\bigr],
\]
a reduction, which on account of its peculiarity, I have thought right to work out in full.

The condition of contact is
\[
\Phi(+) \;=\; \nabla'\nabla'' \;=\; \tfrac{1}{\sqrt{bc}}\,(\sqrt{\fA\fC} - \fG)(\sqrt{\fA\fB} - \fH)\,\sqrt{1 + Y^{2}}\,\sqrt{1 + Z^{2}}.
\]
Hence finally, the condition in order that the sections
\begin{align*}
z\sqrt{\fA} + (hx + by + fz)\,Y + x\sqrt{\fC} + w\sqrt{-bp}\sqrt{1 + Y^{2}} &\;=\; 0,\\
x\sqrt{\fB} + y\sqrt{\fA} + (gx + fy + cz)\,Z + w\sqrt{-cp}\sqrt{1 + Z^{2}} &\;=\; 0,
\end{align*}
(the former of which is a section touching $z = 0$, $x = 0$, and the latter a section touching $x = 0$, $y = 0$) may touch, is
\[
f\,YZ + \sqrt{\fA}\,(Y + Z) + (f + 2\theta\sqrt{\fA}) - \sqrt{bc}\sqrt{1 + Y^{2}}\sqrt{1 + Z^{2}} \;=\; 0.
\]

The preceding researches show that the solution of Steiner's extension of Malfatti's problem depends on a system of equations, such as the system mentioned at the commencement of the following section.

\bigskip

\subsection*{\S\,5.}

Consider the system of equations
\begin{align*}
\alpha + \beta(Y + Z) + \gamma\,YZ + \delta\sqrt{1 + Y^{2}}\sqrt{1 + Z^{2}} &\;=\; 0,\\
\alpha' + \beta'(Z + X) + \gamma'\,ZX + \delta'\sqrt{1 + Z^{2}}\sqrt{1 + X^{2}} &\;=\; 0,\\
\alpha'' + \beta''(X + Y) + \gamma''\,XY + \delta''\sqrt{1 + X^{2}}\sqrt{1 + Y^{2}} &\;=\; 0\,;
\end{align*}
these equations may, it will be seen, be solved by quadratics only, when the coefficients satisfy the relations
\[
\frac{\gamma - \alpha}{\gamma^{2} - \alpha^{2}} \;=\; \frac{\gamma' - \alpha'}{\gamma'^{2} - \alpha'^{2}} \;=\; \frac{\gamma'' - \alpha''}{\gamma''^{2} - \alpha''^{2}}\,.
\]

\bigskip

\noindent\emph{[Book p.~68.]} It may be remarked that these equations are satisfied by
\[
\beta = 0,\quad \beta' = 0,\quad \beta'' = 0,\quad \gamma = \delta,\quad \gamma' = \delta',\quad \gamma'' = \delta'',
\]
or if we write
\[
\frac{\alpha}{\gamma} = -l,\quad \frac{\alpha'}{\gamma'} = -m,\quad \frac{\alpha''}{\gamma''} = -n,
\]
the equations become, by a simple reduction,
\begin{align*}
Y^{2} + Z^{2} + 2l\,YZ &\;=\; l^{2} - 1,\\
Z^{2} + X^{2} + 2m\,ZX &\;=\; m^{2} - 1,\\
X^{2} + Y^{2} + 2n\,XY &\;=\; n^{2} - 1,
\end{align*}
which are equivalent to the equations discussed in my paper ``On a system of Equations connected with Malfatti's Problem and on another Algebraical System,'' \emph{Cambridge and Dublin Mathematical Journal}, t.\ iv.\ [1849] pp.~270--275, [79]; the solution might have been effected by the direct method, which I shall here adopt, of eliminating any one of the variables between the two equations into which it enters, and combining the result with the third equation.

Writing the second and third equations under the form
\begin{align*}
A' + B'X + C'\sqrt{1 + X^{2}} &\;=\; 0,\\
A'' + B''X + C''\sqrt{1 + X^{2}} &\;=\; 0,
\end{align*}
the result of the elimination may be presented in the form
\[
A'A'' + B'B'' - C'C'' \;=\; \sqrt{A'^{2} + B'^{2} - C'^{2}}\cdot\sqrt{A''^{2} + B''^{2} - C''^{2}},
\]
which is most easily obtained by writing $X = \tan\phi$ and operating with the symbol $\cos^{-1}$; but if the rationalized equations be represented by
\[
\lambda' + 2\mu' X + \nu' X^{2} \;=\; 0,\qquad \lambda'' + 2\mu'' X + \nu'' X^{2} \;=\; 0,
\]
the form
\[
(\lambda'\nu'' - \lambda''\nu')^{2} \;=\; 4(\lambda'\nu' - \mu'^{2})(\lambda''\nu'' - \mu''^{2})\;-\;(\lambda'\nu'' - 2\mu'\mu'')^{2}\cdot\cdots
\]
leads easily to the result in question. The values which enter are
\begin{align*}
A' = \alpha' + \beta'Z,&\qquad A'' = \alpha'' + \beta''Y,\\
B' = \beta' + \gamma'Z,&\qquad B'' = \beta'' + \gamma''Y,\\
C' = \delta'\sqrt{1 + Z^{2}},&\qquad C'' = \delta''\sqrt{1 + Y^{2}}\,;
\end{align*}
whence, in the first place, by the equation connecting $Y$, $Z$,
\[
C'C'' \;=\; -\,\frac{\delta'\delta''}{\delta}\,\{\alpha + \beta(Y + Z) + \gamma\,YZ\}.
\]

\bigskip

\noindent\emph{[Book p.~69.]} It is obviously convenient that $A'A'' + B'B''$ should be symmetrical with respect to $Y$ and $Z$, and this will be the case if
\[
\alpha'\beta'' + \beta'\gamma'' \;=\; \alpha''\beta' + \beta''\gamma',
\]
that is, if
\[
\beta'\,(\gamma'' - \alpha'') \;=\; \beta''\,(\gamma' - \alpha'),
\]
or, assuming that the equations are symmetrically related to the system, we have the first set of relations between the coefficients, relations which are satisfied by
\[
\alpha = \gamma + 2\phi\beta,\qquad \alpha' = \gamma' + 2\phi\beta',\qquad \alpha'' = \gamma'' + 2\phi\beta'',
\]
and the values of $\alpha$, $\alpha'$, $\alpha''$ will be considered henceforth as given by these conditions.

We have
\[
A'A'' + B'B'' - C'C'' \;=\; \alpha'\alpha'' + \beta'\beta'' + (\gamma'\beta'' + \gamma''\beta' + 2\phi\beta'\beta'')(Y + Z) + (\beta'\beta'' + \gamma'\gamma'')\,YZ + \frac{\delta'\delta''}{\delta}\,\{\alpha + \beta(Y + Z) + \gamma YZ\}.
\]

The quantities $A'^{2} + B'^{2} - C'^{2}$, $A''^{2} + B''^{2} - C''^{2}$ are quadratic functions of $Z$ and $Y$ respectively, and with proper relations between the coefficients, we may assume
\[
(A'^{2} + B'^{2} - C'^{2})(A''^{2} + B''^{2} - C''^{2}) \;=\; U^{2} + k\bigl[(\alpha + \beta(Y + Z) + \gamma YZ)^{2} - \delta^{2}(1 + Y^{2})(1 + Z^{2})\bigr],
\]
in which $U$ is a linear function of $Y + Z$ and $YZ$, and $k$ and $\delta^{2}$ are constants. The first side must, in the first place, be symmetrical with respect to $Y$ and $Z$, or
\[
\alpha'^{2} + \beta'^{2} - \delta'^{2},\quad (\alpha' + \gamma')\,\beta',\quad \beta'^{2} + \gamma'^{2} - \delta'^{2}
\]
must be proportional to
\[
\alpha''^{2} + \beta''^{2} - \delta''^{2},\quad (\alpha'' + \gamma'')\,\beta'',\quad \beta''^{2} + \gamma''^{2} - \delta''^{2}.
\]
But since $(\alpha' + \gamma')\beta'$, $(\alpha'' + \gamma'')\beta''$ are proportional to $\gamma'^{2} - \alpha'^{2}$, $\gamma''^{2} - \alpha''^{2}$, it is only necessary that $\beta'^{2} + \gamma'^{2} - \delta'^{2}$ should be proportional to $\beta''^{2} + \gamma''^{2} - \delta''^{2}$, that is, that
\[
\frac{\gamma'^{2} - \alpha'^{2}}{\beta'^{2} + \gamma'^{2} - \delta'^{2}} \;=\; \frac{\gamma''^{2} - \alpha''^{2}}{\beta''^{2} + \gamma''^{2} - \delta''^{2}},
\]
or since the equations are supposed symmetrically related to the system, we must have the second set of relations between the coefficients. Suppose
\[
\frac{\gamma - \alpha}{\beta^{2} + \gamma^{2} - \delta^{2}} \;=\; \frac{\gamma' - \alpha'}{\beta'^{2} + \gamma'^{2} - \delta'^{2}} \;=\; \frac{\gamma'' - \alpha''}{\beta''^{2} + \gamma''^{2} - \delta''^{2}} \;=\; -\frac{s}{\phi'}\,,
\]
then since
\[
\gamma^{2} - \alpha^{2} \;=\; -4\,(\gamma + \phi\beta)\,\phi\beta,\quad \&\mathrm{c}.,
\]

\bigskip

\noindent\emph{[Book p.~70.]} we have
\begin{align*}
\delta^{2}     &\;=\; \beta^{2} + \gamma^{2} - 4s\,(\gamma + \phi\beta)\,\beta,\\
\delta'^{2}    &\;=\; \beta'^{2} + \gamma'^{2} - 4s\,(\gamma' + \phi\beta')\,\beta',\\
\delta''^{2}   &\;=\; \beta''^{2} + \gamma''^{2} - 4s\,(\gamma'' + \phi\beta'')\,\beta'',
\end{align*}
and $\delta$, $\delta'$, $\delta''$ will be supposed henceforth to satisfy these equations.

We have next
\begin{align*}
A'^{2} + B'^{2} - C'^{2} &\;=\; 4\,(\gamma' + \phi\beta')\,\beta'\,s\,(Z + \tfrac{\beta'}{\phi} + sZ^{2}),\\
A''^{2} + B''^{2} - C''^{2} &\;=\; 4\,(\gamma'' + \phi\beta'')\,\beta''\,s\,(Y + \tfrac{\beta''}{\phi} + sY^{2}),
\end{align*}
which may be simplified by writing
\[
s \;=\; \frac{\mu - \phi}{1 + \mu^{2}},\qquad \tfrac{1 + \mu^{2}}{\mu - \phi} \;=\; \frac{1 + \nu^{2}}{\mu - \phi},
\]
where $\mu$, $\nu$ are to be considered as given functions of $s$ and $\phi$. These values give
\begin{align*}
A'^{2} + B'^{2} - C'^{2} &\;=\; 4\,(\gamma' + \phi\beta')\,\beta'\,s\,(Z + \mu)\,(Z + \nu),\\
A''^{2} + B''^{2} - C''^{2} &\;=\; 4\,(\gamma'' + \phi\beta'')\,\beta''\,s\,(Y + \mu)\,(Y + \nu).
\end{align*}

Hence, putting for simplicity
\[
b^{2} \;=\; 4\,(\gamma' + \phi\beta')\,(\gamma'' + \phi\beta'')\,\beta'\beta'',
\]
we have
\[
b^{2}s^{2}\,(Z + \mu)(Z + \nu)(Y + \mu)(Y + \nu) \;=\; U^{2} + k\bigl[(\alpha + \beta(Y + Z) + \gamma YZ)^{2} - \delta^{2}(1 + Y^{2})(1 + Z^{2})\bigr];
\]
and the two sides have next to be expressed in terms of $Y + Z$ and $YZ$.

If for symmetry we write
\[
\xi = 1,\qquad \eta = Y + Z,\qquad \zeta = YZ,
\]
then
\[
b^{2}s^{2}\,(\mu^{2}\xi + \mu\eta + \zeta)(\nu^{2}\xi + \nu\eta + \zeta) \;=\; U^{2} + k\bigl[(\alpha\xi + \beta\eta + \gamma\zeta)^{2} - \delta^{2}\{(\zeta - \xi)^{2} + \eta^{2}\}\bigr],
\]
and $U$ is now to be considered as a linear function of $\xi$, $\eta$, $\zeta$.

The condition that the first side of the equation may divide into factors, gives an equation for determining $k$; and since the condition is satisfied for $k = \infty$, the equation will be linear, and it is easily seen that the value is $k = \tfrac{b^{2}s^{2}}{\delta^{2}}\,(\mu - \nu)^{2}$. hence

\noindent\emph{[Book p.~71.]} and we may assume

subject to its being shown that the value of $\Lambda$ given by the comparison of coefficients is constant. The comparison of coefficients gives

\]
\[
4\,\xi \;=\; \frac{\mu - \nu}{\delta}\,\Bigl\{\Bigl(\Lambda + \tfrac{1}{\Lambda}\Bigr)\gamma - \Bigl(\Lambda - \tfrac{1}{\Lambda}\Bigr)\delta\Bigr\},
\]
\[
4\,(1 - \mu^{2}) \;=\; \frac{\mu - \nu}{\delta}\,\Bigl(\Lambda + \tfrac{1}{\Lambda}\Bigr)(\gamma - \alpha),
\]
the first and third of which give
\[
4\,(1 - \mu^{2}) \;=\; \frac{\mu - \nu}{\delta}\,\Bigl(\Lambda + \tfrac{1}{\Lambda}\Bigr)(\gamma - \alpha),
\]
which will be identical with the second, if
\[
\frac{2(1 - \mu\nu)}{\mu + \nu} \;=\; \frac{\beta}{\gamma - \alpha} \;=\; -\,2\phi,
\]
which follows at once from the equation $\nu = \tfrac{1 + \mu\phi}{\mu - \phi}$.

Forming next the two equations

\cdots
\]
these will be equivalent to a single equation, if
\[
\tfrac{1}{4}\,(\mu + \nu)^{2}\,\delta^{2} \;=\; (\mu + \nu)^{2}(\beta^{2} + \gamma^{2}) - 4\,(\mu + \nu)\beta\gamma - 4\,(\mu^{2} - 1)\beta^{2},
\]

\bigskip

\noindent\emph{[Book p.~72.]} or, finally, if
\[
\delta^{2} + \delta^{2} \;=\; \beta^{2} + \gamma^{2} - 4s\beta\bigl[\gamma + \tfrac{\mu\nu - 1}{\mu + \nu}\beta\bigr] \;=\; \beta^{2} + \gamma^{2} - 4s\,(\gamma + \phi\beta)\,\beta,
\]
which is in fact the case.

Writing the equations for
\[
\Lambda \;+\; \tfrac{1}{\Lambda} \;=\; \tfrac{2\delta}{(\mu - \nu)\beta s}\,(\gamma - 2s\beta),

\[
\Lambda \;-\; \tfrac{1}{\Lambda} \;=\; \tfrac{2}{(\mu - \nu)\beta s\delta}\,(\gamma - 2s\beta - 2\phi\beta),

in the form

\cdots

and substituting in

we have
\[
U \;=\; \frac{2}{\beta s}\,\bigl\{(-\beta + 2s\gamma + 2\phi\gamma)\,\xi + (\gamma - 2s\beta)\,\eta + (-\beta + 2s\gamma + 4\phi\gamma)\,\zeta\bigr\}\frac{1}{\delta},
\]
and consequently, multiplying by
\[
b \;=\; 2\sqrt{(\gamma' + \phi\beta')(\gamma'' + \phi\beta'')\beta'\beta''},
\]
we have
\[
\tfrac{1}{\delta}\,\sqrt{(\gamma' + \phi\beta')(\gamma'' + \phi\beta'')\beta'\beta''}\,\bigl\{(-\beta + 2s\gamma + 2\phi\gamma)\,\xi + (\gamma - 2s\beta)\,\eta + (-\beta + 2s\gamma + 4\phi\gamma)\,\zeta\bigr\},

or collecting the different terms which enter into the equation

the result is

which, combined with the first equation written under the form

\subsection*{\S\,6.}

The system of equations
\begin{align*}
(f + 2\theta\sqrt{\fA}) + \sqrt{\fA}\,(Y + Z) + f\,YZ - \sqrt{bc}\,\sqrt{1 + Y^{2}}\sqrt{1 + Z^{2}} &\;=\; 0,\\
(g + 2\theta\sqrt{\fB}) + \sqrt{\fB}\,(Z + X) + g\,ZX - \sqrt{ca}\,\sqrt{1 + Z^{2}}\sqrt{1 + X^{2}} &\;=\; 0,\\
(h + 2\theta\sqrt{\fC}) + \sqrt{\fC}\,(X + Y) + h\,XY - \sqrt{ab}\,\sqrt{1 + X^{2}}\sqrt{1 + Y^{2}} &\;=\; 0,
\end{align*}
where
\[
\theta \;=\; \tfrac{1}{K}\,\bigl(\sqrt{\fA\fB\fC} + \fF\sqrt{\fA} + \fG\sqrt{\fB} + \fH\sqrt{\fC}\bigr),
\]
on which depends the solution of Steiner's extension of Malfatti's problem, is at once seen to belong to the class of equations treated of in the preceding section, and we have $\phi = 0$, $s = 0$. The equations at the conclusion of the preceding section become
\begin{align*}

\end{align*}

K^{2}                                  &\;=\; -\mathrm{f}^{4} - \mathrm{g}^{4} - \mathrm{h}^{4} + 2\mathrm{g}^{2}\mathrm{h}^{2} + 2\mathrm{h}^{2}\mathrm{f}^{2} + 2\mathrm{f}^{2}\mathrm{g}^{2} - \tfrac{4\mathrm{f}^{2}\mathrm{g}^{2}\mathrm{h}^{2}}{J^{2}}\,.

\begin{align*}

the former of which, combined with the similar equations for $Z + X$ and $X + Y$, gives for $X$, $Y$, $Z$ the values to be presently stated, and these values will of course verify the second equation and the corresponding equations for $ZX$ and $XY$.

\begin{center}\textbf{115.}\par\medskip
{\large NOTE ON THE PORISM OF THE IN-AND-CIRCUMSCRIBED\\
POLYGON.}
\end{center}

\noindent\emph{[From the Philosophical Magazine, vol.\ vi.\ (1853), pp.\ 99--102.]}

\bigskip

The equation of a conic passing through the points of intersection of the conics
\[
U = 0,\qquad V = 0
\]
is of the form
\[
w U + V \;=\; 0,
\]
where $w$ is an arbitrary parameter. Suppose that the conic touches a given line, we have for the determination of $w$ a quadratic equation, the roots of which may be considered as parameters for determining the line in question. Let one of the values of $w$ be considered as equal to a given constant $k$; the line is always a tangent to the conic
\[
k U + V \;=\; 0\,;
\]
and taking $w = p$ for the other value of $w$, $p$ is a parameter determining the particular tangent, or, what is the same thing, the point of contact of this tangent.

Suppose the tangent meets the conic $U = 0$ (which is of course the conic corresponding to $w = \infty$) in the points $P$, $P'$, and let $\theta$, $\infty$ be the parameters of the point $P$, and $\theta'$, $\infty$ the parameters of the point $P'$. It follows from my ``Note on the Geometrical representation of the Integral $\int dx \div \sqrt{(x + a)(x + b)(x + c)}$,'' [113]\,\footnote{I take the opportunity of correcting an obvious error in the note in question, viz.\ $a^{2} + b^{2} + c^{2} - 2bc - 2ca - 2ab$ is throughout written instead of (what the expression should be) $a^{2} + b^{2} + c^{2} - 2 a^{2} b c - 2 b^{2} c a - 2 c^{2} a b$. [This correction is made, \emph{ante} p.~55.]} and from the theory of invariants, that if $\square \xi$ represent the ``Discriminant'' of $\xi U + V$

\bigskip

\noindent\emph{[Book p.~88.]} (I now use the term discriminant in the same sense in which determinant is sometimes used, viz.\ the discriminant of a quadratic function $ax^{2} + by^{2} + cz^{2} + 2fyz + 2gzx + 2hxy$ or $(a, b, c, f, g, h)(x, y, z)^{2}$, is the determinant $k = abc - af^{2} - bg^{2} - ch^{2} + 2fgh$), and if
\[
\Pi\,\xi \;=\; \int_{\infty}^{\xi}\,\frac{d\xi}{\sqrt{\square\xi}}\,,
\]
then the following theorem is true, viz.

``If $(\theta, \infty)$, $(\theta', \infty)$ are the parameters of the points $P$, $P'$ in which the conic $U = 0$ is intersected by the tangent, the parameter of which is $p$, of the conic $kU + V = 0$, then the equations
\begin{align*}
\Pi\,\theta &\;=\; \Pi\,p - \Pi\,k,\\
\Pi\,\theta' &\;=\; \Pi\,p + \Pi\,k,
\end{align*}
determine the parameters $\theta$, $\theta'$ of the points in question.''  And again,

``If the variable parameters $\theta$, $\theta'$ are connected by the equation
\[
\Pi\,\theta' - \Pi\,\theta \;=\; 2\,\Pi\,k,
\]
then the line $PP'$ will be a tangent to the conic $kU + V = 0$.''  Whence, also,

``If the sides of a triangle inscribed in the conic $U = 0$ touch the conics
\[
k\,U + V = 0,\qquad k'\,U + V = 0,\qquad k''\,U + V = 0,
\]
then the equation
\[
\Pi\,k + \Pi\,k' + \Pi\,k'' \;=\; 0
\]
must hold good between the parameters $k$, $k'$, $k''$.''

And, conversely, when this equation holds good, there are an infinite number of triangles inscribed in the conic $U = 0$, and the sides of which touch the three conics; and similarly for a polygon of any number of sides.
