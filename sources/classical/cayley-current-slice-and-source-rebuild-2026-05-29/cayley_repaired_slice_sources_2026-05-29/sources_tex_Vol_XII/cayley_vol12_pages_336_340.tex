\medskip

If a circle be given without its centre being known, then taking any three points $A$, $B$, $C$ on the circle, and a pair of counter-points $D$, $E$ of the line $AB$, and also a pair of counter-points $F$, $G$ of the line $AC$, we have obviously the centre of the given circle as the intersection of the lines $DE$ and $FG$; and the centre can thus be found with the compass only.

\medskip

It is proper to remark that the problems considered in the present paper are those connecting the theory with ordinary geometry, not the problems which are most readily and elegantly solved with the compass only: a large collection of these are contained in the work, and in particular the twelfth book contains some interesting \textit{approximate} solutions of the problems of the quadrature of the circle, the duplication of the cube, and other problems not solvable by ordinary geometry.

\section*{841. On a Differential Operator.}

\smallskip
\noindent\textit{[From the Messenger of Mathematics, vol.\ \textsc{xiv}.\ (1885), pp.\ 190, 191.]}

\medskip

\noindent\textbf{[Printed p.~318]}\hfill

Write $X = 1 + bx + cx^{2} + \ldots$, $= (1-\alpha x)(1-\beta x)(1-\gamma x)\ldots$; then by Capt.\ MacMahon's theorem, any non-unitary function of the roots $\alpha$, $\beta$, $\gamma$, \ldots\ is reduced to zero by the operation
\[
\Delta_{x} = \partial_{b} + b\partial_{c} + c\partial_{d} + \ldots;
\]
for instance, if
\[
(2)_{x} = \Sigma \alpha^{2} = b^{2} - 2c,
\]
we have
\[
\Delta(b^{2} - 2c) = 2b + b(-2), = 0.
\]
We have
\[
\Delta X = x + bx^{2} + cx^{3} + \ldots = (xX).
\]
And writing, moreover, $X' = b + 2cx + 3dx^{2} + \&\mathrm{c}$., for the derived function of $X$, then
\[
\Delta X' = 1 + 2bx + 3cx^{2} + \ldots = (xX)'.
\]

We can hence shew that $\Delta\!\left(\dfrac{X'}{X}-b\right) = 0$; the value is, in fact,
\[
\frac{\Delta X'}{X} - \frac{X' \Delta X}{X^{2}} - \Delta b, \quad \text{that is,} \quad \frac{(xX)'}{X} - \frac{X' xX}{X^{2}} - 1,
\]
which is
\[
= -\frac{X + xX'}{X} - \frac{xX'}{X} - 1.
\]

This is right, for $\dfrac{X'}{X}$ is a sum of non-unitary symmetric functions of the roots; in fact,
\[
\frac{X'}{X} = \Sigma\frac{-\alpha}{1 - \alpha x} = -(1) - (2)x - (3)x^{2} - \&\mathrm{c}.,
\]
or since $b = -(1)$, this is
\[
\frac{X'}{X} - b = -(2)x - (3)x^{2} - \&\mathrm{c}.,
\]
a sum of non-unitary functions of the roots.

\section*{842. On the Value of $\tan(\sin\theta) - \sin(\tan\theta)$.}

\smallskip
\noindent\textit{[From the Messenger of Mathematics, vol.\ \textsc{xiv}.\ (1885), pp.\ 191, 192.]}

\medskip

\noindent\textbf{[Printed p.~319]}\hfill

The following equation is given p.~59 of the \textit{Lady's and Gentleman's Diary} for 1853:
\[
\tan(\sin\theta) - \sin\tan\theta = \tfrac{1}{30}\theta^{7} + \tfrac{29}{756}\theta^{9} + \&\mathrm{c}.
\]

Write in general
\begin{align*}
X &= \theta + A\theta^{3} + B\theta^{5} + C\theta^{7} + D\theta^{9} + \ldots, \\
Y &= \theta + A'\theta^{3} + B'\theta^{5} + C'\theta^{7} + D'\theta^{9} + \ldots.
\end{align*}

Then, as far as $\theta^{9}$, we have
\begin{align*}
& X + A'X^{3} + B'X^{5} + C'X^{7} + D'X^{9} \\
={}& \theta + A\,\theta^{3} + B\theta^{5} + C\theta^{7} + D\theta^{9} \\
&+ A'\bigl[\theta^{3} + 3A\theta^{5} + 3(A^{2}+B)\theta^{7} + (A^{3} + 6AB + 3C)\theta^{9}\bigr] \\
&+ B'\bigl[\theta^{5} + 5A\theta^{7} + (10A^{2} + 5B)\theta^{9}\bigr] \\
&+ C'\bigl[\theta^{7} + 7A\theta^{9}\bigr] \\
&+ D'\bigl[\theta^{9}\bigr] \\
={}& \theta \\
&+ \theta^{3}(A + A') \\
&+ \theta^{5}(B + 3AA' + B') \\
&+ \theta^{7}(C + 3A^{2}A' + 3A'B + 5AB' + C') \\
&+ \theta^{9}(D + 3A^{3}A' + 6A A'B + 3A'B + 6AB'A + 5BB' + 7AC' + D').
\end{align*}

\medskip

\noindent\textbf{[Printed p.~320]}\hfill

and hence
\begin{align*}
& X + A'X^{3} + B'X^{5} + C'X^{7} + D'X^{9} \\
&\quad - Y - AY^{3} - BY^{5} - CY^{7} - DY^{9} \\
={}& \theta^{7}\bigl[3AA'(A-A') + 2(AB' - A'B)\bigr] \\
&+ \theta^{9}\bigl[AA'(A^{3} - A'^{3}) + 6AA'(B-B') + 4(AC' - A'C) + 10(A^{2}B'A - A'^{2}B)\bigr].
\end{align*}

Now let
\begin{align*}
X &= \sin\theta = \theta - \tfrac{1}{6}\theta^{3} + \tfrac{1}{120}\theta^{5} - \tfrac{1}{5040}\theta^{7} + \ldots; \quad A = -\tfrac{1}{6},\; B = \tfrac{1}{120},\; C = -\tfrac{1}{5040}; \\
Y &= \tan\theta = \theta + \tfrac{1}{3}\theta^{3} + \tfrac{2}{15}\theta^{5} + \tfrac{17}{315}\theta^{7} + \ldots; \quad A' = \tfrac{1}{3},\; B' = \tfrac{2}{15},\; C' = \tfrac{17}{315}.
\end{align*}

we have therefore
\[
AA' = -\tfrac{1}{18}, \quad A - A' = -\tfrac{1}{2}, \quad A + A' = \tfrac{1}{6}, \quad B - B' = -\tfrac{1}{8},
\]
\[
AB - A'B = -\tfrac{1}{45}, \quad AC - A'C' = -\tfrac{1}{315}, \quad A^{2}B' - A^{2}B = \tfrac{1}{216}.
\]

Hence
\[
\text{coeff. } \theta^{7} = \tfrac{1}{12} - \tfrac{2}{45} = \tfrac{1}{30},
\]
\[
\text{coeff. } \theta^{9} = \tfrac{1}{216} + \tfrac{1}{45} - \tfrac{1}{45} + \tfrac{1}{315} = \tfrac{29}{756};
\]

and the required equation is thus verified.
