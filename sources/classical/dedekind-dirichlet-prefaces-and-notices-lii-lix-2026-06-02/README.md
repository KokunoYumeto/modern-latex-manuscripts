# Dedekind Round 07 - Dirichlet paratext LVI-LIX, pp. 408-427

This packet is deliberately nested as a single top-level folder with subfolders, so extraction should not scatter files into the receiving directory.

## New work in this round

- LVI. Notice of P. Bachmann, *Die Lehre von der Kreisteilung und ihre Beziehungen zur Zahlentheorie*, pp. 408-420, including the printed explanatory note signed Ore.
- LVII. Notice of the first edition of Riemann's collected works, pp. 421-423.
- LVIII. Preface to the third edition of Dirichlet's *Vorlesungen über Zahlentheorie*, pp. 424-425.
- LIX. Preface to the fourth edition of Dirichlet's *Vorlesungen über Zahlentheorie*, pp. 426-427.

## Packaging policy applied here

- `01_new_work_this_round/` contains the new source scan slice, new German TeX/PDF, new English TeX/PDF, and the round audit.
- `02_cumulative_current/` contains only clean cumulative German/English TeX/PDF and status/manifest material. It does not contain source scans, rendercheck images, transcription notes, or round audit notes.
- `03_rendercheck/selected/` contains a small number of visual-check PNGs only, not a full image dump.
