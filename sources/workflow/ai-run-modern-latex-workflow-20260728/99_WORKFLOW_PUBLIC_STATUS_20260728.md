# Workflow publication status

Date: 2026-07-28

This package updates the existing AI-run Modern LaTeX Manuscript Workflow
concept. It documents production methods and corrective controls; it does not
certify any manuscript or create a new quality bureaucracy.

## Current method

The July 28 workflow update makes these controls explicit:

- top-level sessions own disjoint whole-expose ranges;
- sessions are not subagents;
- mathematical translation, transcription adjudication, diagram
  reconstruction, reference semantics, and visual PASS decisions remain with
  the top-level session;
- subagents are limited to bounded mechanical support or preliminary drafting;
- the controlling source image decides scan-sensitive readings;
- the complete user-supplied OCR is read-only locator/drafting evidence and
  must not be generated, rerun, re-extracted, or delegated;
- SGA1 and SGA2 are not subjected to another blanket image retranscription
  when their completed mathematical TeX transcription is already controlling;
- page work uses printed page, running header, and folio coordinates;
- source-controlled pages use five overlapping 2400-dpi bands and targeted
  6500-9000-dpi crops for actual ambiguities;
- contact sheets are navigation aids, not PASS evidence;
- diagrams are checked node-by-node and edge-by-edge;
- source typos are preserved and catalogued while project deviations are fixed;
- a zero-fix inspection does not trigger another build;
- Loop 1 advances canonical text and equations while Loop 2 handles native
  diagrams and exhaustive reference/release work; and
- duplicate audits, manifests, rebuilds, and handoffs are avoided when they do
  not advance the mathematical corpus.
