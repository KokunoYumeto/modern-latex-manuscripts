# Contributing

This repository is the forkable working mirror for the manuscript typesetting and translation archive. The Zenodo records are the archival source of record; GitHub is for readable diffs, issues, and pull requests.

## Good Contributions

- Correct OCR or transcription errors in TeX.
- Fix LaTeX rendering, theorem numbering, labels, references, indexes, or bibliography entries.
- Improve translations while preserving mathematical content and numbering.
- Report missing source witnesses, better public scans, or existing public-domain editions.
- Add compact review notes that compare a specific PDF page or theorem against a specific source page.

## Pull Request Shape

Keep pull requests focused. A correction to one work, one expose, or one author folder is much easier to review than a broad mixed change.

When possible, include:

- The affected work and page/theorem/section.
- The source witness used for comparison.
- A short note saying whether the PDF was rebuilt and checked.

## Archive Policy

GitHub should remain lightweight and forkable. Large scans, raw workflow archives, and preservation bundles belong on Zenodo. Reader PDFs included here are small convenience copies for review.

The default dedication for project-created material is CC0/public-domain dedication to the extent possible. Upstream projects retain their own credit history and license context where applicable.
