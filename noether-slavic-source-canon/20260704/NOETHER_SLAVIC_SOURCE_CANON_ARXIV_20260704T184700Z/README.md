# Noether Slavic Source Canon Corpus

This artifact is the dedicated source-canon surface requested for the Slavic target-language cluster. It is separate from generated Noether translation output.

Priority: find and publish existing mathematical source witnesses before any translation claim.

Scope: Polish, Czech, Slovak, Slovene, Serbian, Croatian, Bosnian, Montenegrin, Bulgarian, Macedonian, Belarusian, Upper Sorbian, and Lower Sorbian. Russian and Ukrainian are excluded from this artifact because the user requested the other Slavic target languages.

Policy: arXiv e-print/source packages are downloaded and zipped only when the arXiv license URL is a redistribution-friendly Creative Commons/public-domain URL. Missing or unclear licenses are manifested as blocked/not-uploaded rows rather than silently redistributed.

Manifests:

- `manifests/SLAVIC_SOURCE_CANON_BY_LANGUAGE.csv`
- `manifests/SLAVIC_ARXIV_TARGET_LANGUAGE_CANDIDATES.csv`
- `manifests/SLAVIC_ARXIV_SOURCE_ARCHIVES.csv`
- `manifests/SLAVIC_ARXIV_EXTRACTED_LATEX.csv`
- `manifests/SLAVIC_ARXIV_BLOCKED_OR_NOT_UPLOADED.csv`
- `manifests/LOCAL_SLAVIC_REFERENCE_SHELF_INDEX.csv`
- `manifests/SLAVIC_SOURCE_CANON_GAP_REPORT.csv`
- `manifests/SLAVIC_SOURCE_CANON_PAYLOAD_ZIPS.csv`

Boundary: this is source-corpus/provenance support only. It does not certify native review, canonical approval, or translation completion.
