\section{Architektura Visual Transformers}
\subsection{Podstawy architektury Transformer}
Architektura Transformer, pierwotnie zaprojektowana do zadań NLP \cite{vaswani2017attention}, opiera się na kilku kluczowych elementach:
\begin{itemize}
    \item Mechanizm self-attention
    \item Multi-head attention
    \item Feed-forward networks
    \item Layer normalization
    \item Residual connections
\end{itemize}

\subsection{Adaptacja do przetwarzania obrazów}
Visual Transformers (ViT) \cite{dosovitskiy2020image} wprowadzają modyfikacje umożliwiające pracę z obrazami:
\begin{itemize}
    \item Podział obrazu na patches (typowo 16x16 pikseli)
    \item Liniowa projekcja patches na embeddingi
    \item Dodanie tokena klasyfikacyjnego [CLS]
    \item Dodanie pozycyjnych embeddingów
\end{itemize}

\subsection{Mechanizm self-attention}
\subsubsection{Matematyczne podstawy}
Mechanizm self-attention można opisać następującymi równaniami \cite{vaswani2017attention}:
\begin{equation}
    Attention(Q,K,V) = softmax(\frac{QK^T}{\sqrt{d_k}})V
\end{equation}
gdzie:
\begin{itemize}
    \item Q - macierz zapytań (queries)
    \item K - macierz kluczy (keys)
    \item V - macierz wartości (values)
    \item $d_k$ - wymiar kluczy
\end{itemize}

\subsection{Hybrydowe architektury}
Współczesne rozwiązania często łączą zalety obu podejść \cite{chen2021transunet}:
\begin{itemize}
    \item Wykorzystanie CNN do wstępnego przetwarzania

    \item Adaptacyjne mechanizmy uwagi

\section{Zastosowania w segmentacji medycznej}
\subsection{Architektura TransUNet}
TransUNet \cite{chen2021transunet} łączy architekturę U-Net z Transformerami:
\begin{itemize}
    \item Encoder oparty na CNN i Transformerach
    \item Decoder wykorzystujący skip connections
    \item Mechanizm uwagi do precyzyjnej segmentacji
\end{itemize}

\subsection{Modyfikacje dla obrazów medycznych}
Specjalne adaptacje dla obrazowania medycznego \cite{hatamizadeh2022swin}:
\begin{itemize}
    \item Hierarchiczne przetwarzanie patches
    \item Wielopoziomowe mapy cech
    \item Adaptacyjne mechanizmy uwagi
    \item Specjalizowane strategie treningu
\end{itemize}
