# Noether Slavic GitHub TeX Source Canon

This artifact harvests source-level TeX/LaTeX files from public GitHub code search using native Slavic mathematical terminology. It exists because the arXiv-only pass did not provide uploadable target-language source packages at the required scale.

Only repositories with recognized open-source license metadata are copied into payload zips. No-license or unclear-license hits are manifest-only blocked rows.

Boundary: source-canon support only; no native review, canonical approval, or translation completion.
