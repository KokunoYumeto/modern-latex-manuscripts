# Slavic Web/PDF Source-Provenance Supplement

Run: `20260704T194207Z`

This artifact answers the immediate "where is it?" problem for target Slavic
languages where the TeX/source-package gate is thin or empty. It points local
agents at official or bibliographic source witnesses and records remote hashes
where the source was fetchable.

It does **not** commit raw PDF/HTML bodies, and it does not turn public access
into redistribution permission. Use these rows as source-canon/provenance
support and source-acquisition targets before translation work resumes.

Key files:

- `manifests/WEB_PDF_SOURCE_WITNESSES.csv`
- `manifests/WEB_PDF_SOURCE_WITNESSES.json`
- `manifests/LANGUAGE_COVERAGE_SUMMARY.csv`
- `manifests/LOCAL_SOURCE_CANON_ARTIFACT_POINTERS.csv`
- `ARTIFACT_SHA256SUMS.txt`

Boundary: source-canon/provenance support only; no native review, canonical
approval, accepted terminology, gate promotion, blanket license clearance, or
translation completion.
