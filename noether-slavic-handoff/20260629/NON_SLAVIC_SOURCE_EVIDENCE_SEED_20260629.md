# Non-Slavic source evidence shelf seed - 2026-06-29

This is the first PC-branch seed shelf for non-Slavic Noether language lanes. It is intentionally a catalog of witnesses, not a translation start. Each entry should be checked against the source before it is used for terminology or prose decisions.

Companion machine-readable file: `NON_SLAVIC_SOURCE_EVIDENCE_SEED_20260629.json`

## Method

- Prefer university, institutional, author-hosted, or clearly open educational sources.
- Keep native-register sources separate from English bridge sources.
- Mark what the source can prove: topic vocabulary, course-register style, advanced register, physics-adjacent register, or potential reviewer/source contact.
- Do not treat a source as authority for a whole language. It is only one witness.
- For constructed/interlanguage work, use these shelves as comparison material, not as permission to invent canonical forms.

   URL: https://webusers.imj-prg.fr/~jean-francois.dat/enseignement/AlgebreM1/Alg_Com.pdf
