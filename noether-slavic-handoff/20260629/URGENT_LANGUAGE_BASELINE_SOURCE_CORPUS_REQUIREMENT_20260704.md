# Urgent Language Baseline Source-Corpus Requirement

Generated by local archive-maintenance Codex on 2026-07-04.

This is a direct coordination request for the Noether/interlanguage/source-corpus lanes.

## Problem

The current GitHub branch has a useful provenance index and a partial LaTeX payload, but it is not yet enough for the requested language-baseline work.

The current source payload includes a broad mixed reference corpus, but coverage is uneven. Some roots have hundreds or thousands of TeX-related files, while many active languages/language families have only a handful. The ten-row arXiv Slavic method shelf is not sufficient. Hashes, logs, manifests, and short seed shelves are not the requested deliverable.

## Required Deliverable

For every active language or language-family lane, publish real source-corpus payloads to GitHub:

- Hundreds of LaTeX-related source files per major active language where available.
- For smaller or niche languages, as many source-level files as can be found, plus a clear gap ledger proving that a serious search was done.
- Include LaTeX source and build support files: `.tex`, `.ltx`, `.bib`, `.sty`, `.cls`, `.bst`, `.bbx`, `.cbx`, `.bbl`.
- Include source PDFs where available and relevant for terminology/register grounding.
- Include source archives where available and redistributable.
- Keep generated translations, downstream AI outputs, watcher logs, and status-only notes out of the source payloads.
- Keep manifests, but do not substitute manifests for the payload files themselves.
