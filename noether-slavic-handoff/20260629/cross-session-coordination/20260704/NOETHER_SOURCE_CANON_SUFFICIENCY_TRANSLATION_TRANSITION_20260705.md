# Noether Source-Canon Sufficiency Translation Transition

Timestamp: 2026-07-05.

This record is a GitHub-visible instruction packet for all Noether lanes,
models, and open-machine sessions.

## Controlling Update

Source canon remains first. However, source-canon-first is not an endless
holding pattern. When a lane has sufficient baseline witnesses for the offered
language/topic scope, it must begin the appropriate draft translation work for
the covered rows.

## Sufficient Baseline

A lane has sufficient baseline for a scoped translation task when it has:

- target-language source witnesses relevant to the mathematical topic and
  register, preferably TeX/LaTeX/source archives;
- or strong official, academic, or community PDF/DOCX/HTML/text provenance when
  source files are not exposed, with explicit source-package gap rows;
- language/topic coverage, source URLs, hashes, and license/access signals;
- marked gaps and weak witnesses;
- no credential, raw-source-body, OCR-cache, or package-safety blocker.

## Required Work After Sufficiency

For covered rows, begin draft review artifacts:

- target-language renderings;
- source-context notes;
- term alternatives and register notes;
- formula-neighboring usage notes;
- interlinear or semi-constructed interlanguage/linguistic scaffolds where
  useful for comparing registers across languages.

For uncovered rows, keep source-acquisition/gap status and keep looking for
baseline witnesses.

## Boundaries

These outputs are draft, non-canonical, not native reviewed, not accepted
terminology, not gate promotion, not blanket license clearance, and not
translation completion.

Language lanes do not push directly. B3/package steward publishes coherent,
safety-checked GitHub artifacts from the clean checkout.
