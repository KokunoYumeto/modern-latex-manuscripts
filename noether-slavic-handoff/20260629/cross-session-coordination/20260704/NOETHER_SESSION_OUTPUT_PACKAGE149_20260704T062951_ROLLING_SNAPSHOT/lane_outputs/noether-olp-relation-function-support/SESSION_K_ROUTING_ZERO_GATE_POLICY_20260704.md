# Session K Routing And Zero-Gate Policy

Generated date: 2026-07-04

Status: `routing_policy_no_mapping_no_translation_no_approval`

## Purpose

Keep OLP/OpenTranslation/relation-function support useful to translation lanes without letting support infrastructure become unauthorized content. This policy should travel with any Session K template or sidecar when another lane adopts it.

## Routing Table

| Trigger | Route to | Session K action | Blocked action |
| --- | --- | --- | --- |
| language-specific terminology or register question | relevant language owner lane | attach blank support template and source pointer only | accepting or revising language forms |
| interlanguage content owned by an existing language-family lane | relevant language owner lane | provide relation/function slot ledger shell only | promoting bridge surfaces or local terms |
| truly novel ownerless construction-method issue | Session D | record routing note and keep Session K fields blank | deciding constructed-language method authority |
| reviewer return without date or authority class | originating lane | request completed non-personal metadata before intake | counting return as ingested evidence |
| source text or excerpt appears inside a return | evidence owner plus source-policy lane | quarantine from Session K promotion | copied source text or excerpt promotion |
| mapping normalization requested without completed returns | requesting lane | provide precondition checklist template only | activating mapping or normalization decision |
| translation request from source-pointer artifact | language owner lane | provide source-pointer sidecar only | creating translated passage |
| approval request from blank template | review owner lane | record zero-gate status only | recording approval |

## Zero-Gate Rule

For Session K, all of the following remain zero unless direct reviewer/source evidence changes them:

- mapping decisions
- translation passages
- approval decisions
- reviewer returns ingested
- source-text or excerpt files
- accepted local terms
- accepted bridge surfaces
- constructed surfaces
- readiness claims

Boundary: this is a routing policy and gate guard. It is not review evidence, approval, mapping, translation, or publication material.
