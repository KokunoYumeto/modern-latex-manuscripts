## Guardrail Decision

Zenodo/source-baseline, draft-release, and completed-reader labels may support only these claims:

- source baseline observed;
- file/package present;
- hash/checksum recorded;
- no source replacement required at a recorded check time;
- render or build evidence exists, if separately validated;
- handoff package exists.

They may not support these claims:

- native/external review completed;
- community consent;
- accepted terminology;
- bridge approval;
- pilot readiness;
- canonical translation publication;
- public-final edition status.

## Completed-Reader Label Rule

Any label resembling `completed`, `current`, `cumulative`, `reader`, `release`, `handoff`, `draft release`, `Zenodo latest`, or `source baseline` must carry a nearby authority boundary:

```text
This label is a file/source/render/package state label only.
It does not claim external/native review, community consent, accepted terms,
bridge approval, pilot readiness, or canonical public-final publication.
```
